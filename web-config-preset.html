npm preset package

@heejun/* Web Config Preset

여러 저장소가 공유하는 프론트엔드 표준 설정을 모노레포로 관리하고 npm에 발행한 Presets입니다. 설정 불일치(Drifts)를 원천 차단하고 단일 표준으로 일관성을 정렬합니다.

GitHub 저장소 포트폴리오 홈

@heejun/eslint-config

v1.2.0

ESLint Flat Config 표준 규칙 프리셋. TypeScript, React 19, React Compiler 플러그인 탑재 및 계층 구조 경계 라이브러리 연동으로 아키텍처 규칙 강제.

$ pnpm add -D @heejun/eslint-config

@heejun/prettier-config

v1.0.5

일관성 있는 코드 스타일 정렬을 위한 프리티어 글로벌 룰 프리셋. import 순서 정렬 및 탭 너비 설정.

$ pnpm add -D @heejun/prettier-config

@heejun/typescript-config

v2.0.1

프로젝트 유형별 tsconfig 베이스 빌더. Base, React(SPA/Next), Node 사양의 엄격 모드(strict) 컴파일러 옵션 제공.

$ pnpm add -D @heejun/typescript-config

@heejun/tailwind-config

v4.0.0

Tailwind CSS v4 최신 스펙 기반의 스타일 테마 및 디자인 시스템 토큰 통합 프리셋. CSS-first @theme 명세 탑재.

$ pnpm add -D @heejun/tailwind-config

@heejun/vite-config

v1.1.2

Vite 8 기반의 최적화 컴파일러 구성 세트. React Compiler 연동 최적화 및 빌드 타임 청크 분할 튜닝.

$ pnpm add -D @heejun/vite-config

핵심 운영 원칙 & 효과

설정 드리프트 방지

다수의 리포지토리 설정 일치 여부를 수동으로 비교할 필요 없이, npm 패키지 버전 관리 하나로 동기화합니다.

Self-Dogfooding

모노레포의 최상위 빌드 환경에서 프리셋 자체를 즉시 활용하여 린터 및 포매터의 정합성을 스스로 검증합니다.

일관성 정렬 회고

개발된 표준 프리셋을 전 사이드 프로젝트에 단계적 PR(Stack PR)로 적용해 전체 아키텍처 규칙을 통일했습니다.
