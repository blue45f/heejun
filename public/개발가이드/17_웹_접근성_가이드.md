## 1. AI 프롬프트 7선 -- 접근성 자동화

접근성 개선의 핵심 작업을 AI 프롬프트로 자동화한다. 컴포넌트 감사부터 문서 생성까지 7가지 프롬프트를 표준으로 사용한다.

### 프롬프트 1: 컴포넌트 접근성 감사

> ```
> 다음 React 컴포넌트의 접근성 문제를 WCAG 2.2 AA 기준으로 전수 검사해줘.
> 각 문제에 대해:
> (1) 위반 기준 번호 (예: 1.1.1 Non-text Content)
> (2) 심각도 (Critical / Major / Minor)
> (3) 수정 전/후 코드 diff
> (4) 해당 위반이 실제 사용자에게 미치는 영향
>
> 특히 키보드 네비게이션, 스크린 리더 호환성, ARIA 속성, 색상 대비를 중점 점검해줘.
>
> --- 컴포넌트 코드 ---
> {코드 붙여넣기}
> ```

### 프롬프트 2: ARIA 속성 자동 생성

> ```
> 다음 커스텀 UI 컴포넌트에 적절한 ARIA 속성을 추가해줘.
> WAI-ARIA 1.2 명세 기준으로 role, aria-label, aria-describedby,
> aria-expanded, aria-controls, aria-live, aria-atomic 등을 적용하고,
> 각 속성을 추가한 이유를 인라인 주석으로 설명해줘.
> 불필요한 ARIA (예: role="button"을 <button>에 추가)는 제거해줘.
>
> --- 컴포넌트 코드 ---
> {코드 붙여넣기}
> ```

### 프롬프트 3: 접근성 테스트 코드 생성

> ```
> 다음 컴포넌트에 대해 Playwright + axe-core 접근성 테스트를 작성해줘.
> 포함할 항목:
> - axe-core 자동 스캔 (위반 0건 확인)
> - Tab 키 순서 검증 (논리적 흐름 확인)
> - Enter/Space 키 동작 검증
> - Escape 키 닫기 동작 (모달/드롭다운)
> - 스크린 리더 접근 가능한 이름(accessible name) 검증
> - 포커스 트랩 검증 (모달/다이얼로그)
> - aria-live 영역 동적 업데이트 검증
>
> --- 컴포넌트 코드 ---
> {코드 붙여넣기}
> ```

### 프롬프트 4: 색상 대비 수정

> ```
> 다음 디자인 토큰(색상 팔레트)에서 WCAG 2.2 기준을 충족하지 못하는 조합을 찾아줘.
> 기준:
> - AA 일반 텍스트: 4.5:1
> - AA 대형 텍스트(18px bold / 24px): 3:1
> - AA UI 컴포넌트/그래픽: 3:1
> - AAA 일반 텍스트: 7:1
>
> 각 문제 조합에 대해 현재 대비율, AA/AAA 충족 여부,
> 색상 톤을 최소한으로 변경한 대체 색상(HEX + HSL)을 제안해줘.
>

> ```

> 점검 항목:
> - Tab 순서가 시각적 레이아웃과 일치하는지

> - 포커스 트랩이 필요한 곳에 구현되었는지
> - Arrow 키 네비게이션이 적절한 곳에 구현되었는지 (Roving Focus)
>
> 문제 발견 시 수정 코드와 키보드 인터랙션 표를 제공해줘.
>
> --- 코드 ---

> 점검 항목:

>
> 스크린 리더별 발화 예시와 개선 방안을 제시해줘.
>
> --- 컴포넌트 코드 ---

## 2. axe-core + AI 수정 제안 파이프라인

axe-core가 탐지한 위반 사항을 AI가 분석하여 수정 코드를 자동 생성하고 PR 코멘트로 제안한다.

### 2.1 자동 수정 스크립트

```typescript
// scripts/ai-a11y-fix.ts
import { execSync } from "node:child_process";
import { readFileSync, writeFileSync } from "node:fs";

interface AxeViolation {
  id: string;
  impact: "critical" | "serious" | "moderate" | "minor";
  description: string;
  helpUrl: string;
  nodes: Array<{
    html: string;
    target: string[];
    failureSummary: string;
  }>;
}

interface AxeReport {
  violations: AxeViolation[];
  url: string;
  timestamp: string;
}

interface AISuggestion {
  violationId: string;
  original: string;
  fixed: string;
  explanation: string;
  wcagCriteria: string;
}

async function analyzeAndFix(reportPath: string): Promise<AISuggestion[]> {
  const report: AxeReport = JSON.parse(readFileSync(reportPath, "utf-8"));

  const critical = report.violations.filter(
    (v) => v.impact === "critical" || v.impact === "serious"
  );

  if (critical.length === 0) {
    console.log("Critical/Serious 위반 없음");
    return [];
  }

  const prompt = `
다음 axe-core 접근성 위반 사항을 분석하고 각각에 대해 수정 코드를 제안해줘.
JSON 배열로 응답해줘: [{ violationId, original, fixed, explanation, wcagCriteria }]

위반 사항:
${JSON.stringify(critical, null, 2)}
  `.trim();

  const response = await fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-api-key": process.env.ANTHROPIC_API_KEY!,
      "anthropic-version": "2024-06-01",
    },
    body: JSON.stringify({
      model: "claude-sonnet-4-20250514",
      max_tokens: 4096,
      messages: [{ role: "user", content: prompt }],
    }),
  });

  const result = await response.json();
  const content = result.content[0].text;
  const jsonMatch = content.match(/\[[\s\S]*\]/);

  if (!jsonMatch) throw new Error("AI 응답에서 JSON 파싱 실패");

  const suggestions: AISuggestion[] = JSON.parse(jsonMatch[0]);

  writeFileSync(
    reportPath.replace(".json", "-suggestions.json"),
    JSON.stringify(suggestions, null, 2)
  );

  return suggestions;
}

// 실행
const reportPath = process.argv[2];
if (!reportPath) {
  console.error("Usage: npx tsx scripts/ai-a11y-fix.ts <report.json>");
  process.exit(1);
}
analyzeAndFix(reportPath).then((s) =>
  console.log(`${s.length}개 수정 제안 생성 완료`)
);
```

### 2.2 GitHub Actions -- axe-core + AI 파이프라인

```yaml
# .github/workflows/a11y-ai-pipeline.yml
name: Accessibility AI Pipeline
on:
  pull_request:
    branches: [main, "beta-*"]

jobs:
  a11y-scan:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        environment: [preview-alpha, preview-beta, preview-rc]
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 22

      - run: npm ci

      - name: Build for ${{ matrix.environment }}
        run: npm run build
        env:
          DEPLOY_ENV: ${{ matrix.environment }}

      - name: Start preview server
        run: npx serve dist -l 3000 &
        env:
          PORT: 3000

      - name: Run axe-core scan
        run: |
          npx playwright test tests/a11y/ --reporter=json \
            --output=a11y-report-${{ matrix.environment }}.json
        env:
          BASE_URL: http://localhost:3000
          A11Y_ENV: ${{ matrix.environment }}

      - name: AI fix suggestions
        if: failure()
        run: npx tsx scripts/ai-a11y-fix.ts a11y-report-${{ matrix.environment }}.json
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

      - name: Comment PR with results
        if: always()
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const env = '${{ matrix.environment }}';
            const reportPath = `a11y-report-${env}.json`;
            const suggestionsPath = reportPath.replace('.json', '-suggestions.json');

            let body = `## 접근성 리포트: ${env}\n\n`;

            if (fs.existsSync(reportPath)) {
              const report = JSON.parse(fs.readFileSync(reportPath, 'utf-8'));
              const violations = report.violations || [];
              body += `| 위반 | 심각도 | 설명 |\n|------|--------|------|\n`;
              violations.forEach(v => {
                body += `| ${v.id} | ${v.impact} | ${v.description} |\n`;
              });
            }

            if (fs.existsSync(suggestionsPath)) {
              const suggestions = JSON.parse(fs.readFileSync(suggestionsPath, 'utf-8'));
              body += `\n### AI 수정 제안\n\n`;
              suggestions.forEach(s => {
                body += `**${s.violationId}** (${s.wcagCriteria})\n`;
                body += `${s.explanation}\n\n`;
              });
            }

            github.rest.issues.createComment({
              owner: context.repo.owner,
              repo: context.repo.repo,
              issue_number: context.issue.number,
              body
            });

      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: a11y-report-${{ matrix.environment }}
          path: a11y-report-*.json
```

### 3.1 환경별 접근성 테스트 설정

```typescript
// tests/a11y/config.ts
interface A11yEnvConfig {
  baseUrl: string;
  wcagLevel: "A" | "AA" | "AAA";
  skipRules: string[];
  pages: string[];
}

const envConfigs: Record<string, A11yEnvConfig> = {
  "preview-alpha": {
    baseUrl: process.env.ALPHA_URL || "http://localhost:3001",
    wcagLevel: "AA",
    skipRules: [],
    pages: ["/", "/login", "/dashboard"],
  },
  "preview-beta": {
    baseUrl: process.env.BETA_URL || "http://localhost:3002",
    wcagLevel: "AA",
    skipRules: [],
    pages: ["/", "/login", "/dashboard", "/settings", "/profile"],
  },
  "preview-rc": {
    baseUrl: process.env.RC_URL || "http://localhost:3003",
    wcagLevel: "AAA",
    skipRules: [],
    pages: ["/", "/login", "/dashboard", "/settings", "/profile", "/help"],
  },
};

export function getA11yConfig(): A11yEnvConfig {
  const env = process.env.A11Y_ENV || "preview-beta";
  const config = envConfigs[env];
  if (!config) throw new Error(`Unknown a11y environment: ${env}`);
  return config;
}
```

### 3.2 환경별 Playwright 접근성 테스트

```typescript
// tests/a11y/multi-env.spec.ts
import { test, expect } from "@playwright/test";
import AxeBuilder from "@axe-core/playwright";
import { getA11yConfig } from "./config";

const config = getA11yConfig();
const wcagTags =
  config.wcagLevel === "AAA"
    ? ["wcag2a", "wcag2aa", "wcag2aaa", "wcag22aa"]
    : ["wcag2a", "wcag2aa", "wcag22aa"];

for (const pagePath of config.pages) {
  test.describe(`[${process.env.A11Y_ENV}] ${pagePath}`, () => {
    test("axe-core 위반 0건", async ({ page }) => {
      await page.goto(`${config.baseUrl}${pagePath}`);
      await page.waitForLoadState("networkidle");

      const results = await new AxeBuilder({ page })
        .withTags(wcagTags)
        .disableRules(config.skipRules)
        .analyze();

      const violations = results.violations.map((v) => ({
        id: v.id,
        impact: v.impact,
        description: v.description,
        nodes: v.nodes.length,
      }));

      expect(violations, `접근성 위반 발견:\n${JSON.stringify(violations, null, 2)}`).toHaveLength(0);
    });

    test("포커스 순서 검증", async ({ page }) => {
      await page.goto(`${config.baseUrl}${pagePath}`);
      const focusableElements: string[] = [];

      // Tab 키로 모든 포커스 가능 요소 순회
      for (let i = 0; i < 50; i++) {
        await page.keyboard.press("Tab");
        const tagName = await page.evaluate(() => {
          const el = document.activeElement;
          if (!el || el === document.body) return null;
          return `${el.tagName.toLowerCase()}${el.getAttribute("aria-label") ? `[${el.getAttribute("aria-label")}]` : ""}`;
        });
        if (!tagName) break;
        focusableElements.push(tagName);
      }

      // 포커스 가능 요소가 1개 이상 존재
      expect(focusableElements.length).toBeGreaterThan(0);
    });

    test("skip navigation 존재 확인", async ({ page }) => {
      await page.goto(`${config.baseUrl}${pagePath}`);
      await page.keyboard.press("Tab");

      const skipLink = await page.evaluate(() => {
        const el = document.activeElement;
        return el?.textContent?.toLowerCase().includes("skip") ||
          el?.textContent?.toLowerCase().includes("본문")
          ? el.textContent
          : null;
      });

      // 메인 페이지에는 skip nav 필수
      if (pagePath === "/") {
        expect(skipLink).toBeTruthy();
      }
    });
  });
}
```

### 3.3 환경별 접근성 리포트 자동 생성

```typescript
// scripts/generate-a11y-report.ts
import { readFileSync, writeFileSync, readdirSync } from "node:fs";

interface EnvReport {
  environment: string;
  timestamp: string;
  summary: {
    totalPages: number;
    totalViolations: number;
    criticalCount: number;
    seriousCount: number;
    moderateCount: number;
    minorCount: number;
  };
  violations: Array<{
    id: string;
    impact: string;
    pages: string[];
    count: number;
  }>;
}

function generateConsolidatedReport(reportDir: string): void {
  const files = readdirSync(reportDir).filter((f) => f.startsWith("a11y-report-"));
  const reports: EnvReport[] = [];

  for (const file of files) {
    const raw = JSON.parse(readFileSync(`${reportDir}/${file}`, "utf-8"));
    const env = file.replace("a11y-report-", "").replace(".json", "");

    const violationMap = new Map<string, { impact: string; pages: Set<string>; count: number }>();

    for (const v of raw.violations || []) {
      const existing = violationMap.get(v.id);
      if (existing) {
        existing.pages.add(raw.url);
        existing.count += v.nodes.length;
      } else {
        violationMap.set(v.id, {
          impact: v.impact,
          pages: new Set([raw.url]),
          count: v.nodes.length,
        });
      }
    }

    reports.push({
      environment: env,
      timestamp: new Date().toISOString(),
      summary: {
        totalPages: 1,
        totalViolations: raw.violations?.length || 0,
        criticalCount: raw.violations?.filter((v: any) => v.impact === "critical").length || 0,
        seriousCount: raw.violations?.filter((v: any) => v.impact === "serious").length || 0,
        moderateCount: raw.violations?.filter((v: any) => v.impact === "moderate").length || 0,
        minorCount: raw.violations?.filter((v: any) => v.impact === "minor").length || 0,
      },
      violations: Array.from(violationMap.entries()).map(([id, data]) => ({
        id,
        impact: data.impact,
        pages: Array.from(data.pages),
        count: data.count,
      })),
    });
  }

  // 환경별 비교 Markdown 생성
  let markdown = "# 접근성 리포트 -- 멀티 베타 환경 비교\n\n";
  markdown += `생성일: ${new Date().toISOString()}\n\n`;
  markdown += "| 환경 | 총 위반 | Critical | Serious | Moderate | Minor |\n";
  markdown += "|------|---------|----------|---------|----------|-------|\n";

  for (const r of reports) {
    markdown += `| ${r.environment} | ${r.summary.totalViolations} | ${r.summary.criticalCount} | ${r.summary.seriousCount} | ${r.summary.moderateCount} | ${r.summary.minorCount} |\n`;
  }

  writeFileSync(`${reportDir}/consolidated-report.md`, markdown);
  writeFileSync(`${reportDir}/consolidated-report.json`, JSON.stringify(reports, null, 2));

  console.log(`리포트 생성 완료: ${reports.length}개 환경`);
}

generateConsolidatedReport(process.argv[2] || "./reports");
```

## 4. WCAG 2.2 AA/AAA 기준 상세

### 4.1 핵심 기준 요약

## 5. React 접근성 패턴 -- 포커스 트랩과 Roving Focus

### 5.1 포커스 트랩 (Focus Trap)

모달, 다이얼로그 등에서 포커스가 외부로 빠져나가지 않도록 한다.

```typescript
// hooks/use-focus-trap.ts
import { useEffect, useRef, useCallback } from "react";

const FOCUSABLE_SELECTOR = [
  "a[href]",
  "button:not([disabled])",
  "input:not([disabled])",
  "select:not([disabled])",
  "textarea:not([disabled])",
  '[tabindex]:not([tabindex="-1"])',
  "[contenteditable]",
].join(", ");

interface UseFocusTrapOptions {
  enabled?: boolean;
  returnFocusOnDeactivate?: boolean;
  initialFocusRef?: React.RefObject<HTMLElement>;
}

export function useFocusTrap<T extends HTMLElement>(options: UseFocusTrapOptions = {}) {
  const { enabled = true, returnFocusOnDeactivate = true, initialFocusRef } = options;
  const containerRef = useRef<T>(null);
  const previousFocusRef = useRef<HTMLElement | null>(null);

  const getFocusableElements = useCallback(() => {
    if (!containerRef.current) return [];
    return Array.from(containerRef.current.querySelectorAll<HTMLElement>(FOCUSABLE_SELECTOR)).filter(
      (el) => !el.closest("[hidden]") && !el.closest('[aria-hidden="true"]')
    );
  }, []);

  useEffect(() => {
    if (!enabled || !containerRef.current) return;

    previousFocusRef.current = document.activeElement as HTMLElement;

    // 초기 포커스 설정
    const initialTarget = initialFocusRef?.current || getFocusableElements()[0];
    initialTarget?.focus();

    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key !== "Tab") return;

      const focusable = getFocusableElements();
      if (focusable.length === 0) return;

      const first = focusable[0];
      const last = focusable[focusable.length - 1];

      if (e.shiftKey && document.activeElement === first) {
        e.preventDefault();
        last.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    };

    document.addEventListener("keydown", handleKeyDown);

    return () => {
      document.removeEventListener("keydown", handleKeyDown);
      if (returnFocusOnDeactivate && previousFocusRef.current) {
        previousFocusRef.current.focus();
      }
    };
  }, [enabled, returnFocusOnDeactivate, initialFocusRef, getFocusableElements]);

  return containerRef;
}
```

### 5.2 Roving Focus (화살표 키 네비게이션)

탭 그룹, 메뉴, 라디오 그룹 등에서 Arrow 키로 포커스를 이동한다.

```typescript
// hooks/use-roving-focus.ts
import { useState, useCallback, type KeyboardEvent } from "react";

interface UseRovingFocusOptions {
  /** 아이템 총 개수 */
  itemCount: number;
  /** 방향 */
  orientation?: "horizontal" | "vertical" | "both";
  /** 순환 여부 */
  loop?: boolean;
  /** 초기 활성 인덱스 */
  defaultIndex?: number;
}

export function useRovingFocus(options: UseRovingFocusOptions) {
  const { itemCount, orientation = "horizontal", loop = true, defaultIndex = 0 } = options;
  const [activeIndex, setActiveIndex] = useState(defaultIndex);

  const handleKeyDown = useCallback(
    (e: KeyboardEvent, itemRefs: React.RefObject<HTMLElement>[]) => {
      const prevKeys = orientation === "vertical" ? ["ArrowUp"] : ["ArrowLeft"];
      const nextKeys = orientation === "vertical" ? ["ArrowDown"] : ["ArrowRight"];

      if (orientation === "both") {
        prevKeys.push("ArrowUp", "ArrowLeft");
        nextKeys.push("ArrowDown", "ArrowRight");
      }

      let newIndex = activeIndex;

      if (nextKeys.includes(e.key)) {
        e.preventDefault();
        newIndex = activeIndex + 1;
        if (newIndex >= itemCount) newIndex = loop ? 0 : itemCount - 1;
      } else if (prevKeys.includes(e.key)) {
        e.preventDefault();
        newIndex = activeIndex - 1;
        if (newIndex < 0) newIndex = loop ? itemCount - 1 : 0;
      } else if (e.key === "Home") {
        e.preventDefault();
        newIndex = 0;
      } else if (e.key === "End") {
        e.preventDefault();
        newIndex = itemCount - 1;
      }

      if (newIndex !== activeIndex) {
        setActiveIndex(newIndex);
        itemRefs[newIndex]?.current?.focus();
      }
    },
    [activeIndex, itemCount, orientation, loop]
  );

  const getItemProps = useCallback(
    (index: number) => ({
      tabIndex: index === activeIndex ? 0 : -1,
      "aria-selected": index === activeIndex,
      "data-active": index === activeIndex ? "" : undefined,
    }),
    [activeIndex]
  );

  return { activeIndex, setActiveIndex, handleKeyDown, getItemProps };
}
```

### 5.3 사용 예시 -- 탭 컴포넌트

```typescript
// components/ui/tabs.tsx
import { useRef, createRef, type ReactNode } from "react";
import { useRovingFocus } from "@/hooks/use-roving-focus";

interface TabItem {
  id: string;
  label: string;
  content: ReactNode;
}

interface TabsProps {
  items: TabItem[];
  defaultTab?: string;
  "aria-label": string;
}

export function Tabs({ items, defaultTab, "aria-label": ariaLabel }: TabsProps) {
  const defaultIndex = defaultTab ? items.findIndex((i) => i.id === defaultTab) : 0;
  const tabRefs = useRef(items.map(() => createRef<HTMLButtonElement>()));

  const { activeIndex, setActiveIndex, handleKeyDown, getItemProps } = useRovingFocus({
    itemCount: items.length,
    orientation: "horizontal",
    defaultIndex: Math.max(0, defaultIndex),
  });

  return (
    <div>
      <div
        role="tablist"
        aria-label={ariaLabel}
        onKeyDown={(e) => handleKeyDown(e, tabRefs.current)}
      >
        {items.map((item, index) => (
          <button
            key={item.id}
            ref={tabRefs.current[index]}
            role="tab"
            id={`tab-${item.id}`}
            aria-controls={`panel-${item.id}`}
            onClick={() => setActiveIndex(index)}
            {...getItemProps(index)}
          >
            {item.label}
          </button>
        ))}
      </div>
      {items.map((item, index) => (
        <div
          key={item.id}
          role="tabpanel"
          id={`panel-${item.id}`}
          aria-labelledby={`tab-${item.id}`}
          hidden={index !== activeIndex}
          tabIndex={0}
        >
          {item.content}
        </div>
      ))}
    </div>
  );
}
```

### 6.3 접근성 테스트 유틸리티

```typescript
// tests/a11y/helpers.ts
import { type Page, expect } from "@playwright/test";
import AxeBuilder from "@axe-core/playwright";

export interface A11yTestOptions {
  wcagLevel?: "AA" | "AAA";
  disableRules?: string[];
  includeSelectors?: string[];
  excludeSelectors?: string[];
}

export async function runAxeScan(page: Page, options: A11yTestOptions = {}) {
  const { wcagLevel = "AA", disableRules = [], includeSelectors, excludeSelectors } = options;

  const tags =
    wcagLevel === "AAA"
      ? ["wcag2a", "wcag2aa", "wcag2aaa", "wcag22aa"]
      : ["wcag2a", "wcag2aa", "wcag22aa"];

  let builder = new AxeBuilder({ page }).withTags(tags).disableRules(disableRules);

  if (includeSelectors) builder = builder.include(includeSelectors);
  if (excludeSelectors) {
    for (const sel of excludeSelectors) {
      builder = builder.exclude(sel);
    }
  }

  const results = await builder.analyze();

  return {
    violations: results.violations,
    passes: results.passes.length,
    incomplete: results.incomplete.length,
  };
}

export async function verifyFocusTrap(page: Page, containerSelector: string) {
  const container = page.locator(containerSelector);
  await expect(container).toBeVisible();

  // 포커스가 컨테이너 내부에 있는지 확인
  const isInsideContainer = async () => {
    return page.evaluate(
      (sel) => {
        const container = document.querySelector(sel);
        return container?.contains(document.activeElement) ?? false;
      },
      containerSelector
    );
  };

  // Tab 20번 눌러도 컨테이너 밖으로 나가지 않는지 확인
  for (let i = 0; i < 20; i++) {
    await page.keyboard.press("Tab");
    expect(await isInsideContainer()).toBe(true);
  }

  // Shift+Tab도 동일
  for (let i = 0; i < 20; i++) {
    await page.keyboard.press("Shift+Tab");
    expect(await isInsideContainer()).toBe(true);
  }
}

export async function verifyAriaLiveUpdate(
  page: Page,
  triggerAction: () => Promise<void>,
  liveRegionSelector: string
) {
  const liveRegion = page.locator(liveRegionSelector);
  const initialText = await liveRegion.textContent();

  await triggerAction();

  // aria-live 영역 텍스트가 변경되었는지 확인
  await expect(liveRegion).not.toHaveText(initialText || "");
}
```
