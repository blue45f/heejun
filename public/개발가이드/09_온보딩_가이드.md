## 1. 온보딩 철학: AI + 멀티 베타 시대

온보딩의 본질은 신규 멤버가 **최단 시간 안에 독립적으로 가치를 창출**할 수 있도록 돕는 것이다. 멀티 베타 환경에서는 신규 멤버가 첫날부터 자신만의 격리된 환경에서 코드를 배포하고 검증할 수 있다.

### 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **AI First** | 코드 분석, 환경 셋업, 반복 질문 등 자동화 가능한 모든 영역에 AI를 적용한다 |
| **원클릭 환경** | devcontainer로 개발 환경을, Preview로 배포 환경을 원클릭 구성한다 |
| **격리된 실험** | 신규 멤버 전용 베타/Preview 환경에서 안전하게 실험한다 |
| **비동기 기본** | 원격/하이브리드 환경을 전제로 모든 프로세스를 설계한다 |
| **측정 가능** | 온보딩 품질을 정량 지표로 추적하고 매 분기 개선한다 |

### 2.3 Codespaces / GitHub CLI 원클릭 실행

```typescript
// scripts/create-dev-environment.ts
import { execSync } from "node:child_process";

interface DevEnvironmentConfig {
  repo: string;
  branch: string;
  machine: "basicLinux32gb" | "standardLinux32gb" | "premiumLinux";
  idleTimeout: string;
  devcontainerPath: string;
}

function createCodespace(config: DevEnvironmentConfig): string {
  const cmd = [
    "gh codespace create",
    `--repo ${config.repo}`,
    `--branch ${config.branch}`,
    `--machine ${config.machine}`,
    `--idle-timeout ${config.idleTimeout}`,
    `--devcontainer-path ${config.devcontainerPath}`,
    "--default-permissions",
  ].join(" ");

  const result = execSync(cmd, { encoding: "utf-8" }).trim();
  console.log(`Codespace 생성 완료: ${result}`);
  return result;
}

function listActiveCodespaces(repo: string): string[] {
  const result = execSync(
    `gh codespace list --repo ${repo} --json name,state -q '.[] | select(.state == "Available") | .name'`,
    { encoding: "utf-8" },
  );
  return result.trim().split("\n").filter(Boolean);
}

// 신규 멤버용 원클릭 실행
const DEFAULT_CONFIG: DevEnvironmentConfig = {
  repo: "org/project",
  branch: "main",
  machine: "standardLinux32gb",
  idleTimeout: "30m",
  devcontainerPath: ".devcontainer/devcontainer.json",
};

export { createCodespace, listActiveCodespaces, DEFAULT_CONFIG };
export type { DevEnvironmentConfig };
```

### 3.1 GitHub Actions: 온보딩 워크플로우

```yaml
# .github/workflows/onboarding-preview.yml
name: Onboarding Preview Environment

on:
  workflow_dispatch:
    inputs:
      member_github_id:
        description: "신규 멤버 GitHub ID"
        required: true
        type: string
      environment_name:
        description: "환경 이름 (예: onboard-john)"
        required: true
        type: string
      base_branch:
        description: "기반 브랜치"
        required: false
        default: "main"
        type: string

permissions:
  id-token: write
  contents: read
  pull-requests: write

jobs:
  create-onboarding-env:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ inputs.base_branch }}

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm

      - run: pnpm install --frozen-lockfile

      - name: Build with onboarding environment config
        run: pnpm build
        env:
          VITE_BASE_PATH: /${{ inputs.environment_name }}/
          VITE_ENV_LABEL: "Onboarding: ${{ inputs.member_github_id }}"
          VITE_ENABLE_DEV_TOOLS: "true"

      - name: Configure AWS credentials
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: ${{ secrets.AWS_DEPLOY_ROLE_ARN }}
          aws-region: ap-northeast-2

      - name: Deploy to S3
        run: |
          aws s3 sync dist/ \
            s3://${{ vars.PREVIEW_BUCKET }}/${{ inputs.environment_name }}/ \
            --delete \
            --cache-control "public, max-age=300"

      - name: Invalidate CloudFront
        run: |
          aws cloudfront create-invalidation \
            --distribution-id ${{ vars.CF_DISTRIBUTION_ID }} \
            --paths "/${{ inputs.environment_name }}/*"

      - name: Generate onboarding summary
        uses: actions/github-script@v7
        with:
          script: |
            const envName = '${{ inputs.environment_name }}';
            const memberId = '${{ inputs.member_github_id }}';
            const previewUrl = `https://${{ vars.CDN_DOMAIN }}/${envName}/`;

            // 멤버에게 이슈 생성
            await github.rest.issues.create({
              owner: context.repo.owner,
              repo: context.repo.repo,
              title: `[온보딩] ${memberId} 개발 환경 준비 완료`,
              body: [
                `## 환영합니다, @${memberId}!`,
                '',
                '### 개발 환경',
                `| 항목 | 값 |`,
                `|------|------|`,
                `| Preview URL | ${previewUrl} |`,
                `| 환경 이름 | \`${envName}\` |`,
                `| 기반 브랜치 | \`${{ inputs.base_branch }}\` |`,
                '',
                '### 시작하기',
                '1. Codespace 생성: `gh codespace create --repo ${{ github.repository }}`',
                '2. 또는 로컬: `git clone` 후 VS Code에서 "Reopen in Container" 선택',
                '3. Preview 환경에 자신의 변경사항을 배포해보세요',
                '',
                '### 온보딩 체크리스트',
                '- [ ] 개발 환경 셋업 완료 (devcontainer 또는 로컬)',
                '- [ ] Preview 환경 접속 확인',
                '- [ ] 첫 번째 PR 생성',
                '- [ ] AI 프롬프트로 코드베이스 분석',
                '- [ ] 팀 Slack 채널 참여',
              ].join('\n'),
              labels: ['onboarding'],
              assignees: [memberId],
            });
```

### 3.3 정리 스크립트

```typescript
// scripts/cleanup-onboarding-envs.ts
import {
  S3Client,
  ListObjectsV2Command,
  DeleteObjectsCommand,
} from "@aws-sdk/client-s3";
import {
  CloudFrontClient,
  CreateInvalidationCommand,
} from "@aws-sdk/client-cloudfront";

interface OnboardingEnv {
  name: string;
  prefix: string;
  lastModified: Date;
  objectCount: number;
}

async function findOnboardingEnvironments(
  s3: S3Client,
  bucket: string,
): Promise<OnboardingEnv[]> {
  const environments: OnboardingEnv[] = [];
  let continuationToken: string | undefined;

  do {
    const response = await s3.send(new ListObjectsV2Command({
      Bucket: bucket,
      Prefix: "onboard-",
      Delimiter: "/",
      ContinuationToken: continuationToken,
    }));

    for (const prefix of response.CommonPrefixes ?? []) {
      const name = prefix.Prefix?.replace(/\/$/, "") ?? "";
      const objects = await s3.send(new ListObjectsV2Command({
        Bucket: bucket,
        Prefix: prefix.Prefix,
        MaxKeys: 1,
      }));

      environments.push({
        name,
        prefix: prefix.Prefix!,
        lastModified: objects.Contents?.[0]?.LastModified ?? new Date(0),
        objectCount: objects.KeyCount ?? 0,
      });
    }

    continuationToken = response.NextContinuationToken;
  } while (continuationToken);

  return environments;
}

async function cleanupStaleEnvironments(): Promise<void> {
  const bucket = process.env.PREVIEW_BUCKET!;
  const distributionId = process.env.CF_DISTRIBUTION_ID!;
  const maxAgeDays = parseInt(process.env.MAX_AGE_DAYS ?? "30", 10);
  const region = "ap-northeast-2";

  const s3 = new S3Client({ region });
  const cf = new CloudFrontClient({ region });
  const cutoff = new Date(Date.now() - maxAgeDays * 86400_000);

  const environments = await findOnboardingEnvironments(s3, bucket);
  const stale = environments.filter((env) => env.lastModified < cutoff);

  console.log(`온보딩 환경: ${environments.length}개, 만료: ${stale.length}개`);

  for (const env of stale) {
    let continuationToken: string | undefined;
    do {
      const list = await s3.send(new ListObjectsV2Command({
        Bucket: bucket,
        Prefix: env.prefix,
        ContinuationToken: continuationToken,
      }));

      if (list.Contents?.length) {
        await s3.send(new DeleteObjectsCommand({
          Bucket: bucket,
          Delete: {
            Objects: list.Contents.map((obj) => ({ Key: obj.Key })),
          },
        }));
      }
      continuationToken = list.NextContinuationToken;
    } while (continuationToken);

    await cf.send(new CreateInvalidationCommand({
      DistributionId: distributionId,
      InvalidationBatch: {
        CallerReference: `cleanup-${env.name}-${Date.now()}`,
        Paths: { Quantity: 1, Items: [`/${env.name}/*`] },
      },
    }));

    console.log(`정리 완료: ${env.name}`);
  }
}

cleanupStaleEnvironments();
```

## 6. AI 멘토링 봇 (Slack + Claude API)

### 6.1 봇 구현

```typescript
// ai-mentor-bot/src/bot.ts
import Anthropic from "@anthropic-ai/sdk";
import { App as SlackApp } from "@slack/bolt";
import { readFileSync } from "node:fs";
import { join } from "node:path";

interface ProjectContext {
  claudeMd: string;
  faq: FAQEntry[];
}

interface FAQEntry {
  question: string;
  answer: string;
  category: "env" | "architecture" | "process" | "culture" | "multi-beta";
}

interface MentorBotConfig {
  slackBotToken: string;
  slackAppToken: string;
  anthropicApiKey: string;
  projectRoot: string;
}

function loadProjectContext(projectRoot: string): ProjectContext {
  const claudeMd = readFileSync(join(projectRoot, "CLAUDE.md"), "utf-8");
  const faqPath = join(projectRoot, "docs/onboarding-faq.json");
  const faq: FAQEntry[] = JSON.parse(readFileSync(faqPath, "utf-8"));
  return { claudeMd, faq };
}

function buildSystemPrompt(context: ProjectContext): string {
  const faqText = context.faq
    .map((f) => `Q: ${f.question}\nA: ${f.answer}`)
    .join("\n\n");

  return `당신은 개발팀의 AI 온보딩 멘토입니다.

프로젝트 정보:
${context.claudeMd}

자주 묻는 질문:
${faqText}

응답 규칙:
1. 정확한 파일 경로와 코드 예시를 포함하여 답변하세요.
2. 멀티 베타/Preview 환경 관련 질문은 환경 URL 패턴을 포함하세요.
3. 확실하지 않은 내용은 "@멘토에게 확인해주세요"라고 안내하세요.
4. 보안에 민감한 정보(시크릿, 토큰)는 절대 포함하지 마세요.
5. 한국어로 답변하세요.`;
}

function createMentorBot(config: MentorBotConfig) {
  const anthropic = new Anthropic({ apiKey: config.anthropicApiKey });
  const context = loadProjectContext(config.projectRoot);
  const systemPrompt = buildSystemPrompt(context);

  const slack = new SlackApp({
    token: config.slackBotToken,
    appToken: config.slackAppToken,
    socketMode: true,
  });

  slack.event("app_mention", async ({ event, say }) => {
    const question = event.text.replace(/<@[A-Z0-9]+>/g, "").trim();

    const response = await anthropic.messages.create({
      model: "claude-sonnet-4-20250514",
      max_tokens: 2048,
      system: systemPrompt,
      messages: [{ role: "user", content: question }],
    });

    const answer = response.content
      .filter((block): block is Anthropic.TextBlock => block.type === "text")
      .map((block) => block.text)
      .join("\n");

    await say({ text: answer, thread_ts: event.ts });
  });

  return slack;
}

export { createMentorBot, loadProjectContext };
export type { MentorBotConfig, ProjectContext };
```

## 9. 효과 측정과 지속적 개선

### 9.1 핵심 지표

```typescript
// scripts/onboarding-metrics.ts
interface OnboardingMetrics {
  memberId: string;
  startDate: Date;

  // 환경 셋업
  timeToFirstBuild: number;       // 분: clone -> 첫 빌드 성공
  timeToFirstPreview: number;     // 분: 첫 Preview 환경 접속

  // 첫 기여
  timeToFirstPR: number;          // 시간: 합류 -> 첫 PR 생성
  timeToFirstMerge: number;       // 시간: 합류 -> 첫 PR 머지

  // 독립성
  timeToIndependentTask: number;  // 일: 합류 -> 멘토 도움 없이 task 완료
  aiPromptsUsed: number;          // AI 프롬프트 활용 횟수

  // 만족도
  satisfactionScore: number;      // 1-5
  feedbackComments: string;
}

function calculateOnboardingScore(metrics: OnboardingMetrics): number {
  const weights = {
    timeToFirstBuild: 0.1,
    timeToFirstPR: 0.2,
    timeToFirstMerge: 0.2,
    timeToIndependentTask: 0.3,
    satisfactionScore: 0.2,
  };

  // 각 지표를 0-100 점수로 정규화
  const scores = {
    timeToFirstBuild: Math.max(0, 100 - metrics.timeToFirstBuild * 2),
    timeToFirstPR: Math.max(0, 100 - metrics.timeToFirstPR * 2),
    timeToFirstMerge: Math.max(0, 100 - metrics.timeToFirstMerge),
    timeToIndependentTask: Math.max(0, 100 - metrics.timeToIndependentTask * 5),
    satisfactionScore: metrics.satisfactionScore * 20,
  };

  return Object.entries(weights).reduce(
    (total, [key, weight]) => total + scores[key as keyof typeof scores] * weight,
    0,
  );
}

export { calculateOnboardingScore };
export type { OnboardingMetrics };
```
