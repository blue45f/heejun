## 온보딩의 목표

### 신규 입사자 관점
- **1주차**: 팀과 회사 이해, 환경 설정 완료
- **2주차**: 프로젝트 구조 파악, 작은 기여 시작
- **3주차**: 독립적인 업무 수행 가능
- **4주차**: 팀의 일원으로 완전히 정착

### 팀 관점
- 신규 입사자가 빠르게 생산적으로 기여
- 팀 문화와 업무 방식 전수
- 장기적인 성장 기반 마련

---

## 역할 정의

### 조직장 (Manager)
- 온보딩 전체 책임
- 주 1회 1 on 1 미팅
- 커리어 및 성장 목표 논의

### 돌보미 (Buddy/Mentor)
- 일상적인 질문 대응
- 코드 리뷰 및 기술 멘토링
- 팀 문화 전수
- 주 1~2회 티타임

### 신규 입사자
- 적극적으로 질문하기
- 문서화하며 학습하기
- 피드백 요청하기

**개발 환경 셋업 가이드:**

```bash
# 1. Node.js (nvm 사용 권장)
nvm install 18
nvm use 18

# 2. Git 설정
git config --global user.name "Your Name"
git config --global user.email "your.email@company.com"

# 3. 프로젝트 클론 및 설정
git clone git@github.com:company/frontend-app.git
cd frontend-app
npm install
cp .env.example .env.local
# .env.local 파일을 열어 필요한 값 입력
npm run dev
# 브라우저에서 http://localhost:3000 접속 확인

# 4. 주요 명령어
npm run dev        # 개발 서버
npm run build      # 프로덕션 빌드
npm test           # 테스트 실행
npm run lint       # 린트 체크
npm run type-check # 타입 체크
```

### 개발 환경 문제 해결 FAQ

```markdown
# 자주 묻는 질문 (FAQ)

## Q: npm install이 실패해요
rm -rf node_modules
rm package-lock.json
npm install

## Q: 로컬 서버가 실행이 안 돼요
1. .env.local 파일이 있는지 확인
2. 필요한 환경 변수가 모두 설정되어 있는지 확인
3. 포트가 이미 사용 중인지 확인: lsof -ti:3000 | xargs kill -9

## Q: Git push가 안 돼요
SSH 키 설정 확인: ssh -T git@github.com

## Q: 테스트가 실패해요
1. 캐시 클리어: npm test -- --clearCache
2. node_modules 재설치
```

## 조직장 & 돌보미 가이드

### 효과적인 돌보미 되기

**DO ✅:**
- 매일 체크인 ("오늘 어떤 거 하고 있어요?")
- 질문하기 쉬운 분위기 조성
- 빠른 응답 (1시간 이내)
- 페어 프로그래밍 적극 활용
- 실수해도 괜찮다는 분위기

**DON'T ❌:**
- "이거 문서에 있는데요" (→ 문서 위치를 알려주기)
- "이건 너무 간단한데요" (→ 모든 질문을 소중히)
- "바빠서 나중에요" (→ 우선순위 조정 필요)
- 답만 알려주기 (→ 스스로 찾는 법 알려주기)

### 1 on 1 주제 예시

- **1주차**: 첫 인상과 적응 상태, 팀 분위기에 대한 느낌, 필요한 지원 확인
- **2주차**: 코드베이스 이해도, 첫 기능 개발 경험, 어려운 점과 해결 방법
- **3주차**: 독립 작업 진행 상황, 팀 프로세스 이해도, 커리어 목표 논의 시작
- **4주차**: 전체 온보딩 회고, 강점과 개발 영역, 3개월/6개월 목표 설정

### 원격 근무 온보딩 팁

**추가 고려사항:**
- 화상 회의 도구 익히기 (Zoom, Google Meet)
- 비동기 커뮤니케이션 강화 (문서화)
- 더 자주, 더 명확한 체크인
- 가상 티타임 / 커피챗

**원격 환경에서의 돌보미 역할:**
- 매일 아침 화상 체크인 (15분)
- Slack 즉시 응답
- 화면 공유 페어 프로그래밍
- 주 2회 비공식 화상 미팅

좋은 온보딩은:
- **체계적**: 4주 계획과 명확한 마일스톤
- **인간적**: 돌보미와 1 on 1로 심리적 안전감
- **실전적**: 문서만이 아닌 실제 코드 기여
- **반복적**: 피드백으로 계속 개선
