## 1. 빌드 도구: Vite 6 & Rolldown

Vite 6는 Rust 기반의 초고속 번들러인 **Rolldown**을 탑재하여 빌드 성능과 결과물 품질을 획기적으로 높였습니다.

### 1.1 트리쉐이킹(Tree-shaking) 고도화
Rolldown은 기존 Rollup보다 더 정밀하게 미사용 코드를 제거합니다.
*   **전략**: 라이브러리 선택 시 `sideEffects: false`가 명시된 ESM 지원 패키지를 우선순위로 둡니다.
*   **Vite 설정**: `build.target`을 `esnext`로 설정하여 현대적 브라우저 기능을 최대한 활용하세요.

### 1.2 Lightning CSS 도입
Vite 6는 PostCSS 대신 Lightning CSS를 기본으로 사용하여 CSS 컴파일 및 미니피케이션 속도를 10배 이상 높였습니다.

## 2. 렌더링 최적화: React Compiler 시대

React 19과 함께 출시된 **React Compiler**는 개발자가 수동으로 하던 최적화를 자동화합니다.

*   **수동 최적화 제거**: 이제 `memo`, `useMemo`, `useCallback`을 고민할 필요가 거의 없습니다. 컴파일러가 의존성을 자동으로 분석하여 최소한의 리렌더링만 발생시킵니다.
*   **준수 사항**: 컴파일러가 코드를 올바르게 이해하도록 'React의 규칙(Rules of React)'을 엄격히 지켜야 합니다. (예: 렌더링 도중 외부 변수 수정 금지)

## 3. 핵심 사용자 지표: INP (Interaction to Next Paint)

FID를 대체하여 2024년부터 표준이 된 **INP**는 사용자의 클릭/입력에 대한 실제 반응 속도를 측정합니다.

### 3.1 메인 스레드 점유 차단 방지
긴 작업(Long Task)을 쪼개어 브라우저가 사용자 입력에 즉시 반응할 수 있게 합니다.

```typescript
// 긴 연산을 수행할 때
async function processLargeData(data) {
  for (const item of data) {
    performHeavyTask(item);
    // 50ms마다 메인 스레드에 양보 (yield)
    if (shouldYield()) {
      await new Promise(resolve => setTimeout(resolve, 0));
    }
  }
}
```

### 3.2 `startTransition` 활용
사용자 입력과 직접 관련 없는 UI 업데이트는 낮은 우선순위로 처리하여 입력을 방해하지 않게 합니다.

## 4. 브라우저 레벨의 선제적 최적화

### 4.1 Speculation Rules API
사용자가 다음 페이지를 클릭하기 전에 브라우저가 미리 페이지를 가져오거나(Prefetch) 렌더링(Prerender)하도록 명령합니다.

```html
<script type="speculationrules">
{
  "prerender": [
    {
      "source": "document",
      "where": { "and": [{ "href_matches": "/products/*" }] },
      "eagerness": "moderate"
    }
  ]
}
</script>
```

### 4.2 Fetch Priority API
중요한 자산(LCP 이미지 등)의 로드 우선순위를 명시적으로 높입니다.

```tsx
<img src="/hero.webp" fetchpriority="high" alt="메인 이미지" />
```
