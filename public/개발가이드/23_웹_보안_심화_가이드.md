## 1. AI 기반 보안 (최우선)

> 보안 영역에서 AI를 활용하면 **코드베이스 전체를 스캔하여 취약점을 자동 탐지**하고, **CSP 정책을 프로젝트에 맞게 자동 생성**하며, **CI 파이프라인에서 보안 검사를 완전 자동화**할 수 있다. 수동 보안 리뷰 대비 탐지율 3배 향상, 오탐률 80% 감소가 목표다.

#### 프롬프트 1: 코드베이스 전체 보안 스캔

```text
아래 코드베이스를 보안 관점에서 정밀 분석하라.

## 분석 대상 코드
{source_code}

## 검사 항목 (OWASP 기반)
1. XSS 취약점: dangerouslySetInnerHTML, innerHTML, eval, new Function 사용
2. 인젝션: URL 파라미터 직접 사용, SQL/NoSQL 인젝션 가능성
3. 인증/인가 우회: 클라이언트 사이드 권한 체크만 의존하는 경우
4. 민감 정보 노출: API 키, 토큰, 비밀번호가 코드에 하드코딩
5. CSRF: 상태 변경 요청에 CSRF 토큰 없음
6. 안전하지 않은 통신: HTTP 사용, 인증서 검증 비활성화
7. 프로토타입 오염: Object.assign, spread로 사용자 입력 병합
8. 정규식 DoS (ReDoS): 백트래킹 가능한 정규식

## 출력 형식
각 취약점별로:
- 심각도: Critical / High / Medium / Low
- 위치: 파일경로:라인번호
- 설명: 무엇이 문제인지
- 수정 코드: 안전한 코드로 교체한 예시
- 참고: OWASP/CWE 번호
```

### 1.2 AI 기반 CSP 정책 자동 생성

```typescript
// ai-csp-generator.ts
import Anthropic from "@anthropic-ai/sdk";

interface CSPDirective {
  directive: string;
  values: string[];
  reason: string;
}

interface CSPGenerationResult {
  policy: string;
  directives: CSPDirective[];
  reportOnly: string;
  warnings: string[];
}

interface ProjectAnalysis {
  externalScripts: string[];     // CDN 스크립트 URL
  externalStyles: string[];      // 외부 CSS URL
  apiEndpoints: string[];        // API 호출 대상
  imageHosts: string[];          // 이미지 호스트
  fontHosts: string[];           // 폰트 호스트
  iframeEmbeds: string[];        // iframe 임베드 URL
  usesInlineScript: boolean;     // 인라인 스크립트 사용 여부
  usesInlineStyle: boolean;      // 인라인 스타일 사용 여부
  usesEval: boolean;             // eval 사용 여부
  framework: "next" | "vite" | "remix";
}

async function generateCSPWithAI(
  analysis: ProjectAnalysis,
): Promise<CSPGenerationResult> {
  const client = new Anthropic();

  const prompt = `
프로젝트 분석 결과를 기반으로 최적의 CSP(Content Security Policy) 정책을 생성하라.

## 프로젝트 분석
- 프레임워크: ${analysis.framework}
- 외부 스크립트: ${analysis.externalScripts.join(", ") || "없음"}
- 외부 스타일: ${analysis.externalStyles.join(", ") || "없음"}
- API 엔드포인트: ${analysis.apiEndpoints.join(", ")}
- 이미지 호스트: ${analysis.imageHosts.join(", ") || "없음"}
- 폰트 호스트: ${analysis.fontHosts.join(", ") || "없음"}
- iframe 임베드: ${analysis.iframeEmbeds.join(", ") || "없음"}
- 인라인 스크립트: ${analysis.usesInlineScript}
- 인라인 스타일: ${analysis.usesInlineStyle}
- eval 사용: ${analysis.usesEval}

## CSP 생성 규칙
1. default-src는 반드시 'self'로 시작
2. unsafe-inline은 가능한 사용하지 않음 (nonce 또는 hash 사용)
3. unsafe-eval은 절대 사용하지 않음
4. 각 directive별 최소 권한 원칙 적용
5. report-uri 또는 report-to 설정 포함
6. Next.js의 경우 _next/static 허용 필요
7. 개발 환경용 느슨한 정책도 별도 생성

JSON 형식으로 응답:
{
  "policy": "전체 CSP 헤더 문자열",
  "directives": [{ "directive": "...", "values": ["..."], "reason": "..." }],
  "reportOnly": "Report-Only 모드 CSP 헤더 문자열",
  "warnings": ["주의사항"]
}`;

  const response = await client.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 4096,
    messages: [{ role: "user", content: prompt }],
  });

  const text =
    response.content[0].type === "text" ? response.content[0].text : "";
  return JSON.parse(text);
}

// CSP 정책 검증 유틸리티
function validateCSP(policy: string): string[] {
  const issues: string[] = [];
  const directives = policy.split(";").map((d) => d.trim());

  for (const directive of directives) {
    if (directive.includes("'unsafe-inline'") && !directive.includes("'nonce-")) {
      issues.push(
        `${directive.split(" ")[0]}: unsafe-inline 사용 — nonce로 교체 권장`,
      );
    }
    if (directive.includes("'unsafe-eval'")) {
      issues.push(
        `${directive.split(" ")[0]}: unsafe-eval 사용 금지`,
      );
    }
    if (directive.includes("*") && !directive.includes("*.example.com")) {
      issues.push(
        `${directive.split(" ")[0]}: 와일드카드(*) 사용 — 도메인 명시 필요`,
      );
    }
    if (directive.includes("data:") && directive.startsWith("script-src")) {
      issues.push(
        `script-src: data: URI는 XSS 벡터 — 제거 필요`,
      );
    }
  }

  if (!directives.some((d) => d.startsWith("default-src"))) {
    issues.push("default-src 누락 — 반드시 설정 필요");
  }

  return issues;
}

export { generateCSPWithAI, validateCSP };
export type { CSPGenerationResult, ProjectAnalysis };
```

### 1.3 AI로 코드베이스 보안 스캔 자동화 (GitHub Actions)

```yaml
# .github/workflows/security-scan.yml
name: AI Security Scan

on:
  pull_request:
    types: [opened, synchronize]
  schedule:
    - cron: "0 9 * * 1" # 매주 월요일 09:00 UTC

permissions:
  contents: read
  pull-requests: write
  security-events: write

jobs:
  ai-security-scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: pnpm/action-setup@v4
        with:
          version: 9

      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: "pnpm"

      - run: pnpm install --frozen-lockfile

      # 1. 변경된 파일 추출
      - name: Get changed files
        id: changed
        run: |
          if [ "${{ github.event_name }}" = "pull_request" ]; then
            FILES=$(git diff --name-only origin/${{ github.base_ref }}...HEAD -- '*.ts' '*.tsx' '*.js' '*.jsx' | head -50)
          else
            FILES=$(git diff --name-only HEAD~1 -- '*.ts' '*.tsx' '*.js' '*.jsx' | head -50)
          fi
          echo "files<<EOF" >> "$GITHUB_OUTPUT"
          echo "$FILES" >> "$GITHUB_OUTPUT"
          echo "EOF" >> "$GITHUB_OUTPUT"

      # 2. AI 보안 스캔 실행
      - name: Run AI Security Scan
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: node scripts/ai-security-scan.js "${{ steps.changed.outputs.files }}"

      # 3. npm audit
      - name: Dependency audit
        run: pnpm audit --audit-level=moderate || true

      # 4. 결과를 PR 코멘트로 게시
      - name: Post scan results
        if: github.event_name == 'pull_request'
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const report = fs.existsSync('security-report.md')
              ? fs.readFileSync('security-report.md', 'utf-8')
              : 'No security issues found.';

            await github.rest.issues.createComment({
              owner: context.repo.owner,
              repo: context.repo.repo,
              issue_number: context.issue.number,
              body: `## AI Security Scan Results\n\n${report}`,
            });
```

```typescript
// scripts/ai-security-scan.ts
import Anthropic from "@anthropic-ai/sdk";
import { readFileSync, writeFileSync, existsSync } from "node:fs";

interface SecurityFinding {
  severity: "critical" | "high" | "medium" | "low";
  file: string;
  line: number;
  title: string;
  description: string;
  cwe: string;
  fix: string;
}

async function runSecurityScan(files: string[]): Promise<SecurityFinding[]> {
  const client = new Anthropic();
  const allFindings: SecurityFinding[] = [];

  // 파일을 배치로 나누어 분석 (토큰 제한 고려)
  const batches = chunk(files.filter((f) => existsSync(f)), 5);

  for (const batch of batches) {
    const sources = batch.map((file) => ({
      path: file,
      content: readFileSync(file, "utf-8"),
    }));

    const prompt = `
아래 소스 코드를 보안 관점에서 분석하고 취약점을 찾아라.

## 소스 코드
${sources.map((s) => `### ${s.path}\n\`\`\`typescript\n${s.content}\n\`\`\``).join("\n\n")}

## 검사 항목
1. XSS (dangerouslySetInnerHTML, innerHTML, document.write)
2. 인젝션 (URL 파라미터 직접 사용, 동적 import)
3. 민감 정보 노출 (API 키, 토큰 하드코딩)
4. 안전하지 않은 정규식 (ReDoS)
5. 프로토타입 오염
6. 오픈 리다이렉트
7. CSRF 토큰 미적용
8. postMessage origin 미검증
9. 안전하지 않은 난수 생성 (Math.random을 보안 목적 사용)
10. Server Component에서 클라이언트로 민감 데이터 전달

취약점이 없으면 빈 배열 반환.
JSON 배열로 응답:
[{
  "severity": "high",
  "file": "파일경로",
  "line": 42,
  "title": "취약점 제목",
  "description": "상세 설명",
  "cwe": "CWE-79",
  "fix": "수정 코드 또는 방법"
}]`;

    const response = await client.messages.create({
      model: "claude-sonnet-4-20250514",
      max_tokens: 4096,
      messages: [{ role: "user", content: prompt }],
    });

    const text =
      response.content[0].type === "text" ? response.content[0].text : "";

    try {
      const findings: SecurityFinding[] = JSON.parse(text);
      allFindings.push(...findings);
    } catch {
      console.warn("AI 응답 파싱 실패, 다음 배치 계속");
    }
  }

  // 보고서 생성
  generateReport(allFindings);

  return allFindings;
}

function generateReport(findings: SecurityFinding[]): void {
  if (findings.length === 0) {
    writeFileSync("security-report.md", "보안 취약점이 발견되지 않았습니다.");
    return;
  }

  const critical = findings.filter((f) => f.severity === "critical");
  const high = findings.filter((f) => f.severity === "high");
  const medium = findings.filter((f) => f.severity === "medium");
  const low = findings.filter((f) => f.severity === "low");

  let report = `| 심각도 | 건수 |\n|--------|------|\n`;
  report += `| Critical | ${critical.length} |\n`;
  report += `| High | ${high.length} |\n`;
  report += `| Medium | ${medium.length} |\n`;
  report += `| Low | ${low.length} |\n\n`;

  for (const finding of findings) {
    const icon =
      finding.severity === "critical"
        ? "CRITICAL"
        : finding.severity === "high"
          ? "HIGH"
          : finding.severity === "medium"
            ? "MEDIUM"
            : "LOW";
    report += `### [${icon}] ${finding.title}\n`;
    report += `- **파일**: ${finding.file}:${finding.line}\n`;
    report += `- **CWE**: ${finding.cwe}\n`;
    report += `- **설명**: ${finding.description}\n`;
    report += `- **수정 방법**: ${finding.fix}\n\n`;
  }

  writeFileSync("security-report.md", report);
}

function chunk<T>(array: T[], size: number): T[][] {
  const result: T[][] = [];
  for (let i = 0; i < array.length; i += size) {
    result.push(array.slice(i, i + size));
  }
  return result;
}

// CLI 실행
const files = process.argv[2]?.split("\n").filter(Boolean) ?? [];
if (files.length > 0) {
  runSecurityScan(files).then((findings) => {
    console.log(`보안 스캔 완료: ${findings.length}건 발견`);
    const critical = findings.filter((f) => f.severity === "critical");
    if (critical.length > 0) {
      console.error(`Critical 취약점 ${critical.length}건 — 즉시 수정 필요`);
      process.exit(1);
    }
  });
}

export { runSecurityScan };
export type { SecurityFinding };
```

## 2. OWASP Top 10 프론트엔드 관점

### 2.1 프론트엔드 관련 주요 취약점

| 순위 | OWASP 항목 | 프론트엔드 영향 | 방어 방법 |
|------|-----------|---------------|----------|
| A01 | Broken Access Control | 클라이언트 라우트 가드 우회 | 서버 사이드 권한 검증 필수, 라우트 가드는 UX 용도만 |
| A02 | Cryptographic Failures | 민감 데이터 평문 저장 | HTTPS 강제, 토큰은 HttpOnly Cookie |
| A03 | Injection | XSS, HTML Injection | CSP, DOMPurify, React 자동 이스케이프 활용 |
| A05 | Security Misconfiguration | 디버그 모드, 소스맵 노출 | 프로덕션 빌드 설정 검증 |

function buildCSP(config: CSPConfig = {}): string {
  const { nonce, reportUri } = config;
  const nonceValue = nonce ? `'nonce-${nonce}'` : "";

  const directives: Record<string, string[]> = {
    "default-src": ["'self'"],
    "script-src": [
      "'self'",
      ...(nonceValue ? [nonceValue] : []),
      "'strict-dynamic'",   // nonce 기반 동적 스크립트 허용
    ],
    "style-src": [
      "'self'",
      ...(nonceValue ? [nonceValue] : []),
    ],
    "img-src": [
      "'self'",
      "data:",
      "https://cdn.example.com",
      "https://*.cloudfront.net",
    ],
    "font-src": [
      "'self'",
      "https://cdn.example.com",
    ],
    "connect-src": [
      "'self'",
      "https://api.example.com",
      "https://*.sentry.io",
    ],
    "frame-src": ["'none'"],
    "frame-ancestors": ["'none'"],
    "object-src": ["'none'"],
    "base-uri": ["'self'"],
    "form-action": ["'self'"],
    "upgrade-insecure-requests": [],
    ...(reportUri ? { "report-uri": [reportUri] } : {}),
  };

  return Object.entries(directives)
    .map(([key, values]) =>
      values.length > 0 ? `${key} ${values.join(" ")}` : key,
    )
    .join("; ");
}

function applyCORS(
  request: Request,
  response: Response,
  config: CORSConfig,
): Response {
  const origin = request.headers.get("Origin");

  if (origin && config.allowedOrigins.includes(origin)) {
    response.headers.set("Access-Control-Allow-Origin", origin);
    response.headers.set("Vary", "Origin");
  }

  if (config.credentials) {
    response.headers.set("Access-Control-Allow-Credentials", "true");
  }

  // Preflight 응답
  if (request.method === "OPTIONS") {
    response.headers.set(
      "Access-Control-Allow-Methods",
      config.allowedMethods.join(", "),
    );
    response.headers.set(
      "Access-Control-Allow-Headers",
      config.allowedHeaders.join(", "),
    );
    response.headers.set("Access-Control-Max-Age", String(config.maxAge));
  }

  if (config.exposeHeaders.length > 0) {
    response.headers.set(
      "Access-Control-Expose-Headers",
      config.exposeHeaders.join(", "),
    );
  }

  return response;
}

async function generateSRIHash(
  url: string,
  algorithm: "sha256" | "sha384" | "sha512" = "sha384",
): Promise<string> {
  const response = await fetch(url);
  const buffer = await response.arrayBuffer();

  const hashBuffer = await crypto.subtle.digest(
    algorithm.toUpperCase().replace("SHA", "SHA-"),
    buffer,
  );

  const base64 = Buffer.from(hashBuffer).toString("base64");
  return `${algorithm}-${base64}`;
}

async function generateSRIForAssets(

): Promise<Map<string, string>> {
  const hashes = new Map<string, string>();

  for (const url of assetUrls) {
    const hash = await generateSRIHash(url);
    hashes.set(url, hash);
  }

async function fetchWithCSRF(
  url: string,
  options: RequestInit = {},
): Promise<Response> {
  const token = getCSRFToken();
  if (!token) {
    throw new Error("CSRF token not found");
  }

  return fetch(url, {
    ...options,
    headers: {
      ...options.headers,
      "X-CSRF-Token": token,
    },
    credentials: "same-origin",
  });
}

// 패턴 3: Origin/Referer 검증 (서버 사이드)
function validateOrigin(
  request: Request,
  allowedOrigins: string[],
): boolean {
  const origin = request.headers.get("Origin");
  const referer = request.headers.get("Referer");

  if (origin) {
    return allowedOrigins.includes(origin);
  }

  if (referer) {
    try {
      const refererOrigin = new URL(referer).origin;
      return allowedOrigins.includes(refererOrigin);
    } catch {
      return false;
    }
  }

  // Origin과 Referer 모두 없으면 차단
  return false;
}

// oauth-pkce.ts

interface OAuthConfig {
  clientId: string;
  authorizationEndpoint: string;
  tokenEndpoint: string;
  redirectUri: string;
  scope: string;
  logoutEndpoint?: string;
}

interface TokenResponse {
  access_token: string;
  refresh_token?: string;
  id_token?: string;
  expires_in: number;
  token_type: string;
}

// PKCE 코드 생성
async function generatePKCE(): Promise<{
  codeVerifier: string;
  codeChallenge: string;
}> {
  // 코드 검증기 생성 (43-128자)
  const array = new Uint8Array(32);
  crypto.getRandomValues(array);
  const codeVerifier = base64UrlEncode(array);

  // 코드 챌린지 생성 (S256)
  const encoder = new TextEncoder();
  const data = encoder.encode(codeVerifier);
  const hash = await crypto.subtle.digest("SHA-256", data);
  const codeChallenge = base64UrlEncode(new Uint8Array(hash));

  return { codeVerifier, codeChallenge };
}

function base64UrlEncode(buffer: Uint8Array): string {
  return btoa(String.fromCharCode(...buffer))
    .replace(/\+/g, "-")
    .replace(/\//g, "_")
    .replace(/=+$/, "");
}

// 인증 요청 시작
async function startAuth(config: OAuthConfig): Promise<void> {
  const { codeVerifier, codeChallenge } = await generatePKCE();
  const state = generateState();

  // PKCE 코드 검증기와 state를 sessionStorage에 저장
  sessionStorage.setItem("oauth_code_verifier", codeVerifier);
  sessionStorage.setItem("oauth_state", state);

  const params = new URLSearchParams({
    response_type: "code",
    client_id: config.clientId,
    redirect_uri: config.redirectUri,
    scope: config.scope,
    state,
    code_challenge: codeChallenge,
    code_challenge_method: "S256",
  });

  window.location.href = `${config.authorizationEndpoint}?${params}`;
}

// 콜백 처리
async function handleCallback(
  config: OAuthConfig,
): Promise<TokenResponse | null> {
  const params = new URLSearchParams(window.location.search);
  const code = params.get("code");
  const state = params.get("state");
  const error = params.get("error");

  if (error) {
    console.error(`OAuth 에러: ${error} - ${params.get("error_description")}`);
    return null;
  }

  if (!code || !state) {
    console.error("인증 코드 또는 state 누락");
    return null;
  }

  // state 검증 (CSRF 방어)
  const savedState = sessionStorage.getItem("oauth_state");
  if (state !== savedState) {
    console.error("state 불일치 — CSRF 공격 의심");
    return null;
  }

  const codeVerifier = sessionStorage.getItem("oauth_code_verifier");
  if (!codeVerifier) {
    console.error("코드 검증기 누락");
    return null;
  }

  // 토큰 교환
  const response = await fetch(config.tokenEndpoint, {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: new URLSearchParams({
      grant_type: "authorization_code",
      code,
      redirect_uri: config.redirectUri,
      client_id: config.clientId,
      code_verifier: codeVerifier,
    }),
  });

  // 사용 완료된 PKCE 데이터 삭제
  sessionStorage.removeItem("oauth_code_verifier");
  sessionStorage.removeItem("oauth_state");

  if (!response.ok) {
    console.error("토큰 교환 실패:", response.status);
    return null;
  }

  return response.json();
}

function generateState(): string {
  const array = new Uint8Array(16);
  crypto.getRandomValues(array);
  return Array.from(array, (b) => b.toString(16).padStart(2, "0")).join("");
}

// 토큰 갱신
async function refreshAccessToken(
  config: OAuthConfig,
  refreshToken: string,
): Promise<TokenResponse | null> {
  const response = await fetch(config.tokenEndpoint, {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: new URLSearchParams({
      grant_type: "refresh_token",
      refresh_token: refreshToken,
      client_id: config.clientId,
    }),
  });

  if (!response.ok) {
    return null;
  }

  return response.json();
}

// 로그아웃
function logout(config: OAuthConfig, idToken?: string): void {
  sessionStorage.clear();

  if (config.logoutEndpoint) {
    const params = new URLSearchParams({
      post_logout_redirect_uri: window.location.origin,
      ...(idToken ? { id_token_hint: idToken } : {}),
    });
    window.location.href = `${config.logoutEndpoint}?${params}`;
  }
}

### 5.2 ID Token 검증 (OIDC)

```typescript
// oidc-validation.ts
interface JWTHeader {
  alg: string;
  kid: string;
  typ: string;
}

interface IDTokenPayload {
  iss: string;      // 발급자
  sub: string;      // 사용자 ID
  aud: string;      // 클라이언트 ID
  exp: number;      // 만료 시간
  iat: number;      // 발급 시간
  nonce?: string;   // 리플레이 공격 방지
  email?: string;
  name?: string;
}

function decodeJWT(token: string): {
  header: JWTHeader;
  payload: IDTokenPayload;
} {
  const [headerB64, payloadB64] = token.split(".");

  const header: JWTHeader = JSON.parse(atob(headerB64));
  const payload: IDTokenPayload = JSON.parse(atob(payloadB64));

  return { header, payload };
}

function validateIDToken(
  token: string,
  expectedIssuer: string,
  expectedAudience: string,
  expectedNonce?: string,
): { valid: boolean; error?: string; payload?: IDTokenPayload } {
  try {
    const { payload } = decodeJWT(token);

    // 1. 발급자 검증
    if (payload.iss !== expectedIssuer) {
      return { valid: false, error: `잘못된 발급자: ${payload.iss}` };
    }

    // 2. 대상 검증
    if (payload.aud !== expectedAudience) {
      return { valid: false, error: `잘못된 대상: ${payload.aud}` };
    }

    // 3. 만료 검증
    const now = Math.floor(Date.now() / 1000);
    if (payload.exp < now) {
      return { valid: false, error: "토큰 만료" };
    }

    // 4. nonce 검증 (리플레이 공격 방지)
    if (expectedNonce && payload.nonce !== expectedNonce) {
      return { valid: false, error: "nonce 불일치" };
    }

    return { valid: true, payload };
  } catch (error) {
    return { valid: false, error: `토큰 파싱 실패: ${error}` };
  }
}

export { decodeJWT, validateIDToken };
export type { IDTokenPayload };

## 6. 토큰 관리 (HttpOnly Cookie vs LocalStorage)

### 6.1 비교표

| 항목 | HttpOnly Cookie | LocalStorage |

  private tokenExpiresAt: number = 0;
  private refreshPromise: Promise<string> | null = null;

  setAccessToken(token: string, expiresIn: number): void {
    this.accessToken = token;
    // 만료 10초 전에 갱신하도록 설정
    this.tokenExpiresAt = Date.now() + (expiresIn - 10) * 1000;
  }

  async getAccessToken(): Promise<string> {
    // 토큰이 유효하면 반환
    if (this.accessToken && Date.now() < this.tokenExpiresAt) {
      return this.accessToken;
    }

    // 이미 갱신 중이면 대기
    if (this.refreshPromise) {
      return this.refreshPromise;
    }

    // 토큰 갱신
    this.refreshPromise = this.refreshToken();
    try {
      const token = await this.refreshPromise;
      return token;
    } finally {
      this.refreshPromise = null;
    }
  }

  private async refreshToken(): Promise<string> {
    // BFF의 토큰 갱신 엔드포인트 호출
    // Refresh token은 HttpOnly Cookie로 자동 전송됨
    const response = await fetch("/api/auth/refresh", {
      method: "POST",
      credentials: "same-origin",
    });

    if (!response.ok) {
      this.clear();
      // 로그인 페이지로 리다이렉트
      window.location.href = "/login";
      throw new Error("Token refresh failed");
    }

    const data: { accessToken: string; expiresIn: number } =
      await response.json();

    this.setAccessToken(data.accessToken, data.expiresIn);
    return data.accessToken;
  }

  clear(): void {
    this.accessToken = null;
    this.tokenExpiresAt = 0;
  }

  isAuthenticated(): boolean {
    return this.accessToken !== null && Date.now() < this.tokenExpiresAt;
  }
}

// 싱글톤 인스턴스
const tokenManager = new TokenManager();

// fetch 래퍼: 자동으로 토큰 주입 + 만료 시 갱신
async function authenticatedFetch(
  url: string,
  options: RequestInit = {},
): Promise<Response> {
  const token = await tokenManager.getAccessToken();

  const response = await fetch(url, {
    ...options,
    headers: {
      ...options.headers,
      Authorization: `Bearer ${token}`,
    },
  });

  // 401이면 토큰 갱신 후 재시도
  if (response.status === 401) {
    tokenManager.clear();
    const newToken = await tokenManager.getAccessToken();

    return fetch(url, {
      ...options,
      headers: {
        ...options.headers,
        Authorization: `Bearer ${newToken}`,
      },
    });
  }

  return response;
}

export { tokenManager, authenticatedFetch, TokenManager };
```

import { cookies } from "next/headers";

export async function POST(): Promise<Response> {
  const cookieStore = await cookies();
  const refreshToken = cookieStore.get("refresh_token")?.value;

  if (!refreshToken) {
    return Response.json({ error: "No refresh token" }, { status: 401 });
  }

  // Identity Provider에 토큰 갱신 요청
  const tokenResponse = await fetch(
    process.env.OAUTH_TOKEN_ENDPOINT!,
    {
      method: "POST",
      headers: { "Content-Type": "application/x-www-form-urlencoded" },
      body: new URLSearchParams({
        grant_type: "refresh_token",
        refresh_token: refreshToken,
        client_id: process.env.OAUTH_CLIENT_ID!,
        client_secret: process.env.OAUTH_CLIENT_SECRET!,
      }),
    },
  );

  if (!tokenResponse.ok) {
    // Refresh token도 만료된 경우
    cookieStore.delete("refresh_token");
    return Response.json({ error: "Refresh failed" }, { status: 401 });
  }

  const tokens: {
    access_token: string;
    refresh_token: string;
    expires_in: number;
  } = await tokenResponse.json();

  // 새 refresh token을 HttpOnly Cookie에 저장
  cookieStore.set("refresh_token", tokens.refresh_token, {
    httpOnly: true,
    secure: true,
    sameSite: "strict",
    path: "/",
    maxAge: 30 * 24 * 60 * 60, // 30일
  });

  // Access token만 응답 바디로 반환 (메모리에 저장)
  return Response.json({
    accessToken: tokens.access_token,
    expiresIn: tokens.expires_in,
  });
}

function runAudit(): AuditResult {
  try {
    const output = execSync("pnpm audit --json", {
      encoding: "utf-8",
    });
    return JSON.parse(output);
  } catch (error) {
    // pnpm audit는 취약점 발견 시 exit code 1 반환
    const output = (error as { stdout: string }).stdout;
    return JSON.parse(output);
  }
}

function enforceAuditPolicy(result: AuditResult): void {
  const { critical, high } = result.vulnerabilities;

  if (critical > 0) {
    console.error(`Critical 취약점 ${critical}건 — 즉시 수정 필요`);
    process.exit(1);
  }

  if (high > 0) {
    console.warn(`High 취약점 ${high}건 — 1주 내 수정 필요`);
    // CI에서는 실패 처리
    if (process.env.CI) {
      process.exit(1);
    }
  }

  console.log("의존성 보안 검사 통과");
}

const result = runAudit();
enforceAuditPolicy(result);

export type { AuditResult };

    .map(([feature, origins]) =>

  var response = event.response;

      response.headers['content-type'].value.includes('text/html')) {
    headers['cache-control'] = {
      value: 'no-cache, no-store, must-revalidate'
    };
  }

  return response;
}`;
}

interface HeaderCheck {
  header: string;
  required: boolean;
  expectedValue?: string | RegExp;
  description: string;
}

const requiredHeaders: HeaderCheck[] = [
  {
    header: "content-security-policy",
    required: true,
    expectedValue: /default-src/,
    description: "CSP 정책이 설정되어 있어야 한다",
  },
  {
    header: "strict-transport-security",
    required: true,
    expectedValue: /max-age=\d{7,}/,
    description: "HSTS max-age가 최소 1년(31536000초) 이상이어야 한다",
  },
  {
    header: "x-content-type-options",
    required: true,
    expectedValue: "nosniff",
    description: "MIME 타입 스니핑 방지가 설정되어 있어야 한다",
  },
  {
    header: "x-frame-options",
    required: true,
    expectedValue: /DENY|SAMEORIGIN/,
    description: "클릭재킹 방지가 설정되어 있어야 한다",
  },
  {
    header: "referrer-policy",
    required: true,
    description: "Referrer 정책이 설정되어 있어야 한다",
  },
  {
    header: "permissions-policy",
    required: true,
    description: "Permissions 정책이 설정되어 있어야 한다",
  },
];

async function verifySecurityHeaders(
  url: string,
): Promise<{ passed: number; failed: number; results: string[] }> {
  const response = await fetch(url, { method: "HEAD" });
  const results: string[] = [];
  let passed = 0;
  let failed = 0;

  for (const check of requiredHeaders) {
    const value = response.headers.get(check.header);

    if (!value) {
      if (check.required) {
        results.push(`FAIL: ${check.header} — 누락 (${check.description})`);
        failed++;
      }
      continue;
    }

    if (check.expectedValue) {
      const matches =
        check.expectedValue instanceof RegExp
          ? check.expectedValue.test(value)
          : value === check.expectedValue;

      if (!matches) {
        results.push(
          `FAIL: ${check.header} — 값 불일치 (현재: ${value})`,
        );
        failed++;
        continue;
      }
    }

    results.push(`PASS: ${check.header}`);
    passed++;
  }

  return { passed, failed, results };
}
