> **AI를 디버깅/설계/리뷰의 핵심 파트너로, 멀티 베타를 PR 단위 무한 확장 인프라로 -- 25개 문서 종합 가이드**

---

## 1. AI-First 개발 가이드 소개

### 이 가이드의 핵심 원칙

1. **AI-First**: 코드 작성, 리뷰, 테스트, 디버깅, 문서화 전 과정에 AI 투입
2. **멀티 베타 네이티브**: PR별 독립 Preview 환경이 기본 인프라
3. **Server Components 시대**: 클라이언트 상태 최소화, 서버 우선 데이터 페칭
4. **TypeScript Strict**: 모든 코드 예제가 TypeScript strict 기준

### AI 도구 생태계

| 도구 | 역할 | 주요 활용 |
|------|------|---------|
| **GitHub Copilot** | 인라인 코드 생성 | 자동완성, 테스트 생성, 반복 패턴 자동화 |
| **Claude Code** | 심층 분석/아키텍처 | 디버깅 분석, 리팩토링, 코드베이스 탐색, RFC 초안 |
| **Cursor** | AI 통합 IDE | 멀티파일 편집, 컨텍스트 기반 코딩, .cursorrules |
| **CodeRabbit** | 자동 코드 리뷰 | PR 리뷰, 보안 취약점 탐지, 품질 분석 |

### 5분 퀵스타트

```
Step 1: AI 도구 세팅
  $ gh extension install github/gh-copilot     # Copilot CLI
  $ npm i -g @anthropic-ai/claude-code          # Claude Code
  → Cursor 설치 + .cursorrules 프로젝트 루트에 배치
  → CodeRabbit GitHub App 설치 (organization 단위)

Step 2: 첫 AI 분석 실행
  $ claude "이 프로젝트 아키텍처 분석해줘. 디렉토리 구조,
    주요 의존성, 상태 관리 패턴, API 통신 방식을 정리해줘."

Step 3: PR 생성 → 자동 Preview + AI 리뷰
  $ git push origin feature/my-feature
  → GitHub Actions: 동적 S3+CloudFront 생성 → Preview URL 코멘트
  → CodeRabbit: 자동 코드 리뷰 코멘트
```

## 3. 멀티 베타 아키텍처 다이어그램

```
 개발자 로컬                    GitHub                        AWS 동적 인프라
 ──────────                    ──────                        ──────────────

 git push ──────► PR 생성 ──────► GitHub Actions Trigger
                    │                     │
                    │              ┌──────┴──────────────────────────────┐
                    │              │                                     │
                    │         Build & Test                    CDK Deploy (동적)
                    │              │                                     │
                    │         ┌────┴────┐                    ┌──────────┴──────────┐
                    │         │         │                    │                     │
                    │     Vitest    Playwright          S3 Bucket            CloudFront
                    │     (Unit)    (E2E)              (pr-{number})      Distribution
                    │         │         │                    │            (pr-{number})
                    │         └────┬────┘                    └──────────┬──────────┘
                    │              │                                     │
                    │         CodeRabbit                          Preview URL
                    │         (AI Review)                  https://pr-123.preview.example.com
                    │              │                                     │
                    ▼              ▼                                     ▼
              PR 코멘트 ◄──── 리뷰 결과 + Preview URL + 테스트 결과 + 성능 리포트

 PR 머지/닫힘 ──────► GitHub Actions ──────► CDK Destroy ──────► 인프라 자동 정리
                                                                  (비용 0원)
```

### 핵심 흐름

| 단계 | 트리거 | 동작 | 결과 |
|------|--------|------|------|
| **1. PR 생성** | `pull_request: opened` | CDK 스택 배포 (S3 + CloudFront) | `pr-{N}.preview.example.com` URL 발급 |
| **2. 코드 푸시** | `pull_request: synchronize` | 빌드 → S3 업로드 → CloudFront 무효화 | Preview 자동 갱신 |
| **3. AI 리뷰** | CodeRabbit webhook | 코드 분석, 보안 스캔, 성능 영향 분석 | PR 코멘트에 리뷰 결과 |
| **4. 테스트** | GitHub Actions | Unit + E2E + 성능 버짓 검증 | 체크 통과/실패 리포트 |
| **5. PR 머지** | `pull_request: closed` | CDK 스택 삭제 | 모든 리소스 정리 |
