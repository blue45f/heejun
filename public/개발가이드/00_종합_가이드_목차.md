## 문서 개요

이 종합 가이드는 실무 현장의 기술 문서를 기반으로 작성된 범용 프론트엔드 개발 가이드입니다.

### 특징
- 2026년 최신 기술 반영 (React 19.x, TypeScript 5.8+, Next.js 15 등)
- AI 활용 전략 전 문서 포함 (Copilot, Claude, CodeRabbit 등)
- 멀티 배포 전략 (Multi-CDN, 모노레포, Feature Flag)
- 실무에 즉시 적용 가능한 코드 예시
- 검증된 베스트 프랙티스
- 완전한 한글 문서

### 사용 방법

각 섹션은 독립적으로 읽을 수 있도록 구성되어 있습니다.

**추천 학습 순서:**
1. **신규 프로젝트**: 테스팅 → 아키텍처 → CI/CD → 멀티 배포
2. **기존 프로젝트 개선**: 성능 최적화 → 모니터링 → AI 활용 도입
3. **팀 온보딩**: 온보딩 가이드 → 코드 리뷰 → RFC 프로세스

## 실무 적용 가이드

### 스타트업 (10-30명)
**우선 적용**: 코드 리뷰 가이드 → 배포 체크리스트 → 기본 테스팅 → AI 도구 도입

### 중소기업 (30-100명)
**시스템 구축**: CI/CD 파이프라인 → Sentry 모니터링 → 성능 최적화 → 멀티 배포 전략

### 대기업 (100명+)
**완전한 거버넌스**: 아키텍처 표준화 (RFC/ADR) → 통합 모니터링 → 장애 대응 → Multi-CDN
