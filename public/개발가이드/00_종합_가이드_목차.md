## 🛠️ 기술 스택 (Standard Stack 2025)

| 카테고리 | 기술 | 비고 |
| :--- | :--- | :--- |
| **Framework** | React 19, Next.js 15 | Server Actions 기본 활용 |
| **Styling** | Tailwind CSS v4 | CSS-first configuration |
| **Build Tool** | Vite 6 (Rolldown) | 고성능 Rust 기반 번들링 |
| **Language** | TypeScript 5.7+ | isolatedDeclarations 활성화 |
| **State** | TanStack Query, Zustand | 서버/클라이언트 상태 분리 |
| **Testing** | Vitest, Playwright | AI 테스트 코드 생성 연동 |
| **Infra** | AWS CDK v2 (TypeScript) | PR별 동적 Preview 환경 |
| **Lint/Format** | Biome 2.0 | ESLint/Prettier 통합 및 고속화 |
