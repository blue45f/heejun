> **AI를 핵심 개발 파트너로, 멀티 베타 환경을 무한 확장 가능하게 — 28개 문서 종합 가이드**

---

## 1. AI-First 개발 가이드 소개

### 이 가이드의 차별점

- 모든 28개 문서에 **AI 프롬프트 예시 5개+** 기본 포함
- **멀티 베타 환경** (PR별 Preview, Feature Flag, 동적 인프라) 전 문서 관통
- 실무에서 즉시 복사-붙여넣기 가능한 **TypeScript 코드 예제**
- 2026 최신 기술 스택 반영

### AI 도구 생태계

| 도구 | 역할 | 주요 활용 |
|------|------|---------|
| **GitHub Copilot** | 인라인 코드 생성 | 코드 자동완성, 테스트 생성, 반복 패턴 |
| **Claude Code** | 심층 분석/생성 | 아키텍처 설계, 리팩토링, 문서 생성, 코드베이스 분석 |
| **Cursor** | AI 통합 IDE | 멀티파일 편집, 컨텍스트 기반 코딩, .cursorrules |
| **CodeRabbit** | 자동 코드 리뷰 | PR 리뷰, 보안 탐지, 품질 분석 |

### 5분 퀵스타트

1. **CodeRabbit 연동** → 모든 PR에 AI 리뷰 자동화
2. **Copilot `// test:` 주석** → 테스트 케이스 자동 생성
3. **Claude Code 실행** → "이 프로젝트 아키텍처 분석해줘"

## 3. 멀티 베타 환경 아키텍처

### 핵심 개념

```
PR 생성 → GitHub Actions → 동적 S3 + CloudFront 생성 → Preview URL 발급
PR 머지/닫힘 → GitHub Actions → 인프라 자동 정리 → 비용 0원
```

### 관련 문서 크로스레퍼런스

| 전략 | 설명 | 관련 문서 |
|------|------|----------|
| **동적 인프라** | PR별 S3+CloudFront 자동 생성/삭제 | [인프라](./13_인프라_배포시스템.md), [CloudFront](./02_CloudFront_캐시_사용_표준.md) |
| **Preview Deployments** | PR별 독립 환경 + URL 자동 코멘트 | [CI/CD](./12_CICD_파이프라인_가이드.md), [배포](./07_배포_체크리스트_프로세스.md) |
| **Feature Flag** | 동일 빌드에서 기능 점진적 롤아웃 | [배포](./07_배포_체크리스트_프로세스.md), [React 19](./04_React19_최신기능_가이드.md) |
| **모노레포 선별 배포** | affected 앱만 빌드/배포 | [모노레포](./22_모노레포_운영_가이드.md), [CI/CD](./12_CICD_파이프라인_가이드.md) |
| **환경별 모니터링** | N개 환경 독립 로그/메트릭/알림 | [Sentry](./04_Sentry_관리_표준.md), [장애 대응](./01_장애대응표준.md) |
| **마이크로 FE** | 앱별 독립 Preview + 리모트 오버라이드 | [마이크로 FE](./19_마이크로_프론트엔드_가이드.md) |
