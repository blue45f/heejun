## 1. AI 기반 보안 워크플로우

> 보안 영역에서 AI를 활용하면 **코드베이스 전체를 스캔하여 취약점을 자동 탐지**하고, **CSP 정책을 프로젝트에 맞게 자동 생성**하며, **CI 파이프라인에서 보안 검사를 완전 자동화**할 수 있다. 수동 보안 리뷰 대비 탐지율 3배 향상, 오탐률 80% 감소가 목표다.

### 프롬프트 1: 보안 취약점 분석

```bash
1) XSS 취약점 - dangerouslySetInnerHTML, innerHTML, eval 사용

4) 민감 데이터 노출 - API 키, 비밀번호, PII 클라이언트 노출

- 심각도 (Critical / High / Medium / Low)
```

## 2. 멀티 베타 환경 보안 격리

> 멀티 베타 환경에서는 Preview 환경과 Production 환경의 보안 수준을 명확히 분리해야 한다. Preview 환경은 개발 편의를 위해 일부 보안 정책을 완화하되, Production 환경은 최대한 엄격하게 유지한다.

### 2.1 환경 감지 유틸리티

```typescript
// lib/security/environment.ts

type DeploymentEnv = 'production' | 'preview' | 'development';

interface EnvironmentInfo {
  env: DeploymentEnv;
  previewId: string | null;
  baseUrl: string;
  isPreview: boolean;
  isProduction: boolean;
}

export function getDeploymentEnv(): EnvironmentInfo {
  const vercelEnv = process.env.VERCEL_ENV as DeploymentEnv | undefined;
  const previewId = process.env.VERCEL_DEPLOYMENT_ID ?? null;

  const env: DeploymentEnv = vercelEnv ?? 'development';
  const isPreview = env === 'preview';
  const isProduction = env === 'production';

  const baseUrl = isProduction
    ? process.env.NEXT_PUBLIC_PRODUCTION_URL!
    : isPreview
      ? `https://${process.env.VERCEL_URL}`
      : 'http://localhost:3000';

  return { env, previewId, baseUrl, isPreview, isProduction };
}

/** Preview 환경 전용 접근 제어 */
export function requirePreviewAuth(request: Request): boolean {
  const { isPreview } = getDeploymentEnv();
  if (!isPreview) return true;

  const authHeader = request.headers.get('x-preview-token');
  const expectedToken = process.env.PREVIEW_AUTH_TOKEN;

  if (!expectedToken) return false;
  return authHeader === expectedToken;
}
```

## 3. OWASP Top 10 프론트엔드 관점

### 3.1 주요 위험 항목 매핑

| OWASP 항목 | 프론트엔드 관련성 | 방어 전략 |
|---|---|---|
| A01: Broken Access Control | 클라이언트 측 라우트 가드 우회 | 서버 측 검증 필수 + 라우트 미들웨어 |
| A02: Cryptographic Failures | 민감 데이터 로컬 저장 | HttpOnly Cookie + 암호화 |
| A03: Injection | XSS, HTML Injection | 자동 이스케이프 + CSP |
| A05: Security Misconfiguration | CORS 과도 허용, 디버그 노출 | 환경별 설정 분리 |
| A06: Vulnerable Components | npm 패키지 취약점 | 자동 감사 + Lockfile |
| A07: Auth Failures | 토큰 노출, 세션 고정 | PKCE + Token Rotation |
| A08: Data Integrity Failures | CDN 변조, 공급망 공격 | SRI + Socket.dev |
| A09: Logging Failures | 민감 정보 콘솔 출력 | 프로덕션 로그 필터링 |

### 3.2 프론트엔드 보안 검증 미들웨어

```typescript
// middleware.ts

import { NextRequest, NextResponse } from 'next/server';
import { getDeploymentEnv } from '@/lib/security/environment';
import { buildCspHeader } from '@/lib/security/csp';
import { getAllowedOrigins } from '@/lib/security/cors';

export function middleware(request: NextRequest) {
  const { env, isProduction } = getDeploymentEnv();
  const response = NextResponse.next();

  // 보안 헤더 설정
  const nonce = Buffer.from(crypto.randomUUID()).toString('base64');
  const csp = buildCspHeader(env, nonce);

  response.headers.set('Content-Security-Policy', csp);
  response.headers.set('X-Content-Type-Options', 'nosniff');
  response.headers.set('X-Frame-Options', 'DENY');
  response.headers.set('Referrer-Policy', 'strict-origin-when-cross-origin');
  response.headers.set(
    'Permissions-Policy',
    'camera=(), microphone=(), geolocation=()',
  );

  if (isProduction) {
    response.headers.set(
      'Strict-Transport-Security',
      'max-age=63072000; includeSubDomains; preload',
    );
    response.headers.set('Cross-Origin-Opener-Policy', 'same-origin');
    response.headers.set('Cross-Origin-Embedder-Policy', 'require-corp');
  }

  // CORS 동적 처리
  const origin = request.headers.get('origin');
  const allowedOrigins = getAllowedOrigins(env);

  if (origin && allowedOrigins.includes(origin)) {
    response.headers.set('Access-Control-Allow-Origin', origin);
    response.headers.set('Access-Control-Allow-Credentials', 'true');
  }

  // nonce를 요청 헤더에 전달 (서버 컴포넌트에서 사용)
  response.headers.set('x-nonce', nonce);

  return response;
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico).*)'],
};
```

## 4. CSP 정책 (환경별 분리)

### 4.1 환경별 CSP 빌더

```typescript
// lib/security/csp.ts

type DeploymentEnv = 'production' | 'preview' | 'development';

interface CspDirectives {
  'default-src': string[];
  'script-src': string[];
  'style-src': string[];
  'img-src': string[];
  'font-src': string[];
  'connect-src': string[];
  'frame-src': string[];
  'frame-ancestors': string[];
  'report-uri'?: string[];
}

function getBaseCsp(): CspDirectives {
  return {
    'default-src': ["'self'"],
    'script-src': ["'self'"],
    'style-src': ["'self'"],
    'img-src': ["'self'", 'data:', 'https:'],
    'font-src': ["'self'", 'https://fonts.gstatic.com'],
    'connect-src': ["'self'"],
    'frame-src': ["'none'"],
    'frame-ancestors': ["'none'"],
  };
}

const envOverrides: Record<DeploymentEnv, (csp: CspDirectives, nonce: string) => CspDirectives> = {
  production: (csp, nonce) => ({
    ...csp,
    'script-src': ["'self'", `'nonce-${nonce}'`, "'strict-dynamic'"],
    'style-src': ["'self'", `'nonce-${nonce}'`, 'https://fonts.googleapis.com'],
    'connect-src': ["'self'", 'https://api.example.com', 'https://sentry.io'],
    'report-uri': ['https://sentry.io/api/csp-report/'],
  }),

  preview: (csp, nonce) => ({
    ...csp,
    'script-src': ["'self'", `'nonce-${nonce}'`, "'strict-dynamic'", 'https://vercel.live'],
    'style-src': ["'self'", `'nonce-${nonce}'`, "'unsafe-inline'", 'https://fonts.googleapis.com'],
    'connect-src': [
      "'self'",
      'https://api-preview.example.com',
      'https://vercel.live',
      'wss://ws.vercel.live',
      'https://sentry.io',
    ],
    'frame-src': ['https://vercel.live'],
    'frame-ancestors': ["'self'"],
  }),

  development: (csp, nonce) => ({
    ...csp,
    'script-src': ["'self'", "'unsafe-eval'", "'unsafe-inline'"],
    'style-src': ["'self'", "'unsafe-inline'"],
    'connect-src': ["'self'", 'http://localhost:*', 'ws://localhost:*'],
    'frame-src': ["'self'"],
    'frame-ancestors': ["'self'"],
  }),
};

export function buildCspHeader(env: DeploymentEnv, nonce: string): string {
  const base = getBaseCsp();
  const directives = envOverrides[env](base, nonce);

  return Object.entries(directives)
    .map(([key, values]) => `${key} ${values.join(' ')}`)
    .join('; ');
}
```

### 4.2 CSP 위반 리포팅

```typescript
// app/api/csp-report/route.ts

import { NextRequest, NextResponse } from 'next/server';
import { getDeploymentEnv } from '@/lib/security/environment';

interface CspViolationReport {
  'csp-report': {
    'document-uri': string;
    'violated-directive': string;
    'blocked-uri': string;
    'original-policy': string;
  };
}

export async function POST(request: NextRequest) {
  const { env } = getDeploymentEnv();

  try {
    const report: CspViolationReport = await request.json();
    const violation = report['csp-report'];

    // 환경별 로깅 분기
    if (env === 'production') {
      // Sentry 등 외부 모니터링 전송
      await fetch(process.env.SENTRY_CSP_ENDPOINT!, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          environment: env,
          violation,
          timestamp: new Date().toISOString(),
        }),
      });
    } else {
      console.warn('[CSP Violation]', violation);
    }

    return NextResponse.json({ received: true });
  } catch {
    return NextResponse.json({ error: 'Invalid report' }, { status: 400 });
  }
}
```

## 5. XSS / CSRF 방어 패턴

### 5.1 입력 살균(Sanitization) 유틸리티

```typescript
// lib/security/sanitize.ts

import DOMPurify from 'isomorphic-dompurify';

/** HTML 살균 - 리치 텍스트용 */
export function sanitizeHtml(dirty: string): string {
  return DOMPurify.sanitize(dirty, {
    ALLOWED_TAGS: ['b', 'i', 'em', 'strong', 'a', 'p', 'br', 'ul', 'ol', 'li', 'code', 'pre'],
    ALLOWED_ATTR: ['href', 'target', 'rel'],
    ALLOW_DATA_ATTR: false,
  });
}

/** 평문 전용 - 모든 HTML 태그 제거 */
export function sanitizePlainText(input: string): string {
  return DOMPurify.sanitize(input, { ALLOWED_TAGS: [] });
}

/** URL 검증 - javascript: 프로토콜 차단 */
export function sanitizeUrl(url: string): string {
  try {
    const parsed = new URL(url);
    if (!['http:', 'https:', 'mailto:'].includes(parsed.protocol)) {
      return '#';
    }
    return parsed.href;
  } catch {
    return '#';
  }
}
```

### 5.2 React 안전 패턴

```typescript
// components/SafeContent.tsx

'use client';

import { sanitizeHtml, sanitizeUrl } from '@/lib/security/sanitize';

interface SafeHtmlProps {
  content: string;
  className?: string;
}

/** dangerouslySetInnerHTML 안전 래퍼 */
export function SafeHtml({ content, className }: SafeHtmlProps) {
  const clean = sanitizeHtml(content);

  return (
    <div
      className={className}
      dangerouslySetInnerHTML={{ __html: clean }}
    />
  );
}

interface SafeLinkProps {
  href: string;
  children: React.ReactNode;
  external?: boolean;
}

/** 외부 링크 안전 래퍼 */
export function SafeLink({ href, children, external }: SafeLinkProps) {
  const safeHref = sanitizeUrl(href);

  return (
    <a
      href={safeHref}
      {...(external && {
        target: '_blank',
        rel: 'noopener noreferrer',
      })}
    >
      {children}
    </a>
  );
}
```

### 5.3 CSRF 방어 (Double Submit Cookie)

```typescript
// lib/security/csrf.ts

import { cookies } from 'next/headers';

const CSRF_COOKIE = '__csrf-token';
const CSRF_HEADER = 'x-csrf-token';

export async function generateCsrfToken(): Promise<string> {
  const token = crypto.randomUUID();
  const cookieStore = await cookies();

  cookieStore.set(CSRF_COOKIE, token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'strict',
    path: '/',
    maxAge: 60 * 60, // 1시간
  });

  return token;
}

export async function validateCsrfToken(request: Request): Promise<boolean> {
  const headerToken = request.headers.get(CSRF_HEADER);
  const cookieStore = await cookies();
  const cookieToken = cookieStore.get(CSRF_COOKIE)?.value;

  if (!headerToken || !cookieToken) return false;
  return headerToken === cookieToken;
}
```

```typescript
const STATIC_ORIGINS: Record<DeploymentEnv, string[]> = {
  production: [
    'https://example.com',
    'https://www.example.com',
  ],
  preview: [
    'https://example.com',
  ],
  development: [
    'http://localhost:3000',
    'http://localhost:3001',
    'http://127.0.0.1:3000',
  ],
};

/** Preview URL 패턴 매칭 (*.vercel.app) */
function isValidPreviewOrigin(origin: string): boolean {
  try {
    const url = new URL(origin);
    return url.hostname.endsWith('.vercel.app') && url.protocol === 'https:';
  } catch {
    return false;
  }
}

export function getAllowedOrigins(env: DeploymentEnv): string[] {
  return STATIC_ORIGINS[env] ?? [];
}

export function isOriginAllowed(origin: string, env: DeploymentEnv): boolean {
  const staticOrigins = getAllowedOrigins(env);

  if (staticOrigins.includes(origin)) return true;
  if (env === 'preview' && isValidPreviewOrigin(origin)) return true;

  return false;
}

/** API Route용 CORS 핸들러 */
export function handleCors(request: Request, env: DeploymentEnv): HeadersInit {
  const origin = request.headers.get('origin') ?? '';
  const headers: Record<string, string> = {};

  if (isOriginAllowed(origin, env)) {
    headers['Access-Control-Allow-Origin'] = origin;
    headers['Access-Control-Allow-Methods'] = 'GET, POST, PUT, DELETE, OPTIONS';
    headers['Access-Control-Allow-Headers'] = 'Content-Type, Authorization, x-csrf-token';
    headers['Access-Control-Allow-Credentials'] = 'true';
    headers['Access-Control-Max-Age'] = '86400'; // 24시간 프리플라이트 캐시
  }

  return headers;
}
```

```typescript
// lib/security/pkce.ts

/** PKCE code_verifier 생성 (43-128자 랜덤 문자열) */
export function generateCodeVerifier(): string {
  const array = new Uint8Array(64);
  crypto.getRandomValues(array);
  return base64UrlEncode(array);
}

/** PKCE code_challenge 생성 (S256) */
export async function generateCodeChallenge(verifier: string): Promise<string> {
  const encoder = new TextEncoder();
  const data = encoder.encode(verifier);
  const digest = await crypto.subtle.digest('SHA-256', data);
  return base64UrlEncode(new Uint8Array(digest));
}

function base64UrlEncode(buffer: Uint8Array): string {
  const base64 = btoa(String.fromCharCode(...buffer));
  return base64.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}
```

### 7.2 인증 흐름 구현

```typescript
// lib/security/auth-flow.ts

import { getDeploymentEnv } from './environment';
import { getTokenConfig } from './token-config';
import { generateCodeVerifier, generateCodeChallenge } from './pkce';

interface AuthConfig {
  authorizationEndpoint: string;
  tokenEndpoint: string;
  clientId: string;
  redirectUri: string;
  scope: string;
}

function getAuthConfig(): AuthConfig {
  const { env, baseUrl } = getDeploymentEnv();

  const authDomain = env === 'production'
    ? 'https://auth.example.com'
    : 'https://auth-preview.example.com';

  return {
    authorizationEndpoint: `${authDomain}/authorize`,
    tokenEndpoint: `${authDomain}/oauth/token`,
    clientId: process.env.NEXT_PUBLIC_AUTH_CLIENT_ID!,
    redirectUri: `${baseUrl}/auth/callback`,
    scope: 'openid profile email',
  };
}

/** 로그인 시작 - Authorization Code Flow with PKCE */
export async function initiateLogin(): Promise<string> {
  const config = getAuthConfig();
  const verifier = generateCodeVerifier();
  const challenge = await generateCodeChallenge(verifier);
  const state = crypto.randomUUID();

  // verifier와 state를 sessionStorage에 임시 저장
  sessionStorage.setItem('pkce_verifier', verifier);
  sessionStorage.setItem('oauth_state', state);

  const params = new URLSearchParams({
    response_type: 'code',
    client_id: config.clientId,
    redirect_uri: config.redirectUri,
    scope: config.scope,
    state,
    code_challenge: challenge,
    code_challenge_method: 'S256',
  });

  return `${config.authorizationEndpoint}?${params}`;
}

/** 콜백 처리 - 코드를 토큰으로 교환 */
export async function handleCallback(code: string, state: string): Promise<void> {
  const config = getAuthConfig();
  const savedState = sessionStorage.getItem('oauth_state');
  const verifier = sessionStorage.getItem('pkce_verifier');

  if (state !== savedState) {
    throw new Error('State mismatch - possible CSRF attack');
  }

  if (!verifier) {
    throw new Error('Missing PKCE verifier');
  }

  // 토큰 교환은 서버 API Route를 통해 수행 (시크릿 보호)
  const response = await fetch('/api/auth/token', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      code,
      code_verifier: verifier,
      redirect_uri: config.redirectUri,
    }),
    credentials: 'include', // HttpOnly Cookie 수신
  });

  if (!response.ok) {
    throw new Error('Token exchange failed');
  }

  // 임시 데이터 정리
  sessionStorage.removeItem('pkce_verifier');
  sessionStorage.removeItem('oauth_state');
}
```

```typescript
  timestamp: number;
}

let channel: BroadcastChannel | null = null;

export function initSessionSync(onEvent: (event: SessionEvent) => void): () => void {
  if (typeof BroadcastChannel === 'undefined') return () => {};

  channel = new BroadcastChannel('session-sync');

  const handler = (event: MessageEvent<SessionMessage>) => {
    onEvent(event.data.type);
  };

  channel.addEventListener('message', handler);

  return () => {
    channel?.removeEventListener('message', handler);
    channel?.close();
    channel = null;
  };
}

  channel?.postMessage({ type, timestamp: Date.now() } satisfies SessionMessage);
```

## 8. 토큰 관리 (HttpOnly Cookie 패턴)

### 8.1 서버 측 토큰 처리

```typescript
// app/api/auth/token/route.ts

import { NextRequest, NextResponse } from 'next/server';
import { getTokenConfig } from '@/lib/security/token-config';
import { getDeploymentEnv } from '@/lib/security/environment';

interface TokenResponse {
  access_token: string;
  refresh_token: string;
  expires_in: number;
  id_token: string;
}

export async function POST(request: NextRequest) {
  const { env } = getDeploymentEnv();
  const tokenConfig = getTokenConfig();

  const { code, code_verifier, redirect_uri } = await request.json();

  // 인증 서버에 토큰 교환 요청
  const tokenResponse = await fetch(
    `${tokenConfig.issuer}/oauth/token`,
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        grant_type: 'authorization_code',
        code,
        code_verifier,
        redirect_uri,
        client_id: process.env.NEXT_PUBLIC_AUTH_CLIENT_ID!,
        client_secret: process.env.AUTH_CLIENT_SECRET!, // 서버에서만 접근
      }),
    },
  );

  if (!tokenResponse.ok) {
    return NextResponse.json(
      { error: 'Token exchange failed' },
      { status: 401 },
    );
  }

  const tokens: TokenResponse = await tokenResponse.json();

  const response = NextResponse.json({ success: true });

  // Access Token을 HttpOnly Cookie로 설정
  response.cookies.set(tokenConfig.cookieName, tokens.access_token, {
    httpOnly: true,
    secure: tokenConfig.secure,
    sameSite: tokenConfig.sameSite,
    path: '/',
    maxAge: tokens.expires_in,
  });

  // Refresh Token도 HttpOnly Cookie (별도)
  response.cookies.set(`${tokenConfig.cookieName}-refresh`, tokens.refresh_token, {
    httpOnly: true,
    secure: tokenConfig.secure,
    sameSite: tokenConfig.sameSite,
    path: '/api/auth',
    maxAge: 60 * 60 * 24 * 30, // 30일
  });

  return response;
}
```

```typescript
// lib/security/token-refresh.ts

let refreshPromise: Promise<boolean> | null = null;

/** 토큰 자동 갱신 - 중복 요청 방지 */
export async function refreshToken(): Promise<boolean> {
  if (refreshPromise) return refreshPromise;

  refreshPromise = fetch('/api/auth/refresh', {
    method: 'POST',
    credentials: 'include',
  })
    .then((res) => res.ok)
    .finally(() => {
      refreshPromise = null;
    });

  return refreshPromise;
}

/** fetch 래퍼 - 401 시 자동 갱신 후 재시도 */
export async function secureFetch(
  url: string,
  options: RequestInit = {},
): Promise<Response> {
  const response = await fetch(url, {
    ...options,
    credentials: 'include',
  });

  if (response.status === 401) {
    const refreshed = await refreshToken();
    if (refreshed) {
      return fetch(url, { ...options, credentials: 'include' });
    }

    // 갱신 실패 시 로그아웃
    window.location.href = '/auth/logout';
  }

  return response;
}
```

```typescript
        totalVulnerabilities: audit.metadata?.vulnerabilities?.total ?? 0,
        criticalCount: (audit.metadata?.vulnerabilities?.critical ?? 0)
          + (audit.metadata?.vulnerabilities?.high ?? 0),
```

### 11.2 플래그 조작 방지 (서명 검증)

```typescript
// lib/security/flag-integrity.ts

const SIGNING_KEY = process.env.FLAG_SIGNING_KEY!;

/** 플래그 값에 HMAC 서명 추가 */
export async function signFlags(
  flags: Record<string, boolean>,
): Promise<{ flags: Record<string, boolean>; signature: string }> {
  const payload = JSON.stringify(flags);
  const encoder = new TextEncoder();

  const key = await crypto.subtle.importKey(
    'raw',
    encoder.encode(SIGNING_KEY),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign'],
  );

  const signatureBuffer = await crypto.subtle.sign(
    'HMAC',
    key,
    encoder.encode(payload),
  );

  const signature = Array.from(new Uint8Array(signatureBuffer))
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('');

  return { flags, signature };
}

/** 클라이언트에서 받은 플래그의 무결성 검증 */
export async function verifyFlags(
  flags: Record<string, boolean>,
  signature: string,
): Promise<boolean> {
  const { signature: expected } = await signFlags(flags);
  return signature === expected;
}
```

### 환경 공통

- [ ] CSP 헤더가 환경별로 올바르게 적용되는가
- [ ] 모든 사용자 입력이 살균(sanitize)되는가

- [ ] npm audit에서 critical/high 취약점이 없는가
- [ ] 외부 스크립트에 SRI(Subresource Integrity)가 적용되는가

- [ ] HSTS 헤더가 설정되어 있는가 (max-age >= 2년)
- [ ] CSP가 strict-dynamic + nonce 기반인가
- [ ] Cross-Origin-Opener-Policy: same-origin인가
- [ ] 토큰이 HttpOnly + Secure + SameSite=Strict 쿠키인가
- [ ] Refresh Token Rotation이 활성화되어 있는가

- [ ] Preview 전용 인증 토큰이 분리되어 있는가

- [ ] CORS에서 *.vercel.app 패턴만 동적 허용하는가
- [ ] Feature Flag 조작이 서버 측에서 차단되는가
- [ ] Preview 환경의 시크릿이 Production과 분리되어 있는가
