## 1. AI 번역 QA 시나리오 프롬프트

번역 품질은 텍스트 정확성만이 아니다. **UI에 실제로 렌더링했을 때** 글자 잘림, 레이아웃 깨짐, 컨텍스트 부적합이 없어야 한다. 아래 프롬프트들은 번역 QA의 실전 시나리오를 다룬다.

### 프롬프트 1: 번역이 UI에 맞는지 시각적 검증

```
이 컴포넌트의 번역 결과가 UI에 적합한지 검증해줘.

검증 항목:
1) 버튼 텍스트가 컨테이너 너비를 초과하는지 (max-width 기준)
2) 독일어/러시아어 등 긴 언어에서 줄바꿈이 발생하는 지점
3) 아랍어/히브리어 RTL 전환 시 레이아웃 미러링 누락
4) 플레이스홀더 텍스트가 input 영역을 넘어가는지

- 스크린샷 기반 예상 깨짐 위치
- CSS 수정안 (text-overflow, flex-shrink, min-width 등)
- 번역문 축약 대안
```

## 2. next-intl 4.0 vs Paraglide.js 비교

2026년 기준 i18n 라이브러리 선택의 핵심 축은 **런타임 vs 컴파일 타임** 접근이다.

### 비교 매트릭스

| 기준 | next-intl 4.0 | Paraglide.js |
|---|---|---|
| **접근 방식** | 런타임 (JSON 로딩) | 컴파일 타임 (함수 생성) |
| **번들 사이즈** | 전체 locale JSON 포함 | 사용된 키만 tree-shake |
| **타입 안전성** | 플러그인 기반 | 네이티브 (함수 시그니처) |
| **Next.js App Router** | 네이티브 지원 | 어댑터 필요 |
| **ICU 메시지 포맷** | 완전 지원 | 부분 지원 |
| **서버 컴포넌트** | 네이티브 | 어댑터 필요 |
| **동적 로케일 전환** | `useLocale` 훅 | 라우팅 기반 |
| **번역 키 자동완성** | VS Code 플러그인 | 네이티브 (import) |

### 선택 가이드

```typescript
// lib/i18n-strategy.ts -- 프로젝트 특성별 권장 라이브러리
type ProjectProfile = {
  teamSize: 'small' | 'medium' | 'large';
  localeCount: number;
  translationKeyCount: number;
  needsRuntimeSwitch: boolean;
  framework: 'nextjs' | 'remix' | 'astro' | 'sveltekit';
};

function recommendI18nLibrary(profile: ProjectProfile): string {
  // Paraglide.js 권장: 번들 사이즈 민감, 타입 안전성 최우선
  if (
    profile.translationKeyCount > 1000 &&
    !profile.needsRuntimeSwitch &&
    profile.framework !== 'nextjs'
  ) {
    return 'paraglide';
  }

  // next-intl 4.0 권장: Next.js App Router, 서버 컴포넌트, ICU 포맷
  if (profile.framework === 'nextjs') {
    return 'next-intl';
  }

  // 소규모 프로젝트: Paraglide로 시작
  if (profile.localeCount <= 3 && profile.teamSize === 'small') {
    return 'paraglide';
  }

  return 'next-intl';
}
```

## 3. AI 번역 파이프라인 -- Claude API 자동 번역 + PR 생성

소스 언어 번역 파일이 변경되면 Claude API로 자동 번역하고, 리뷰어 승인 후 PR을 자동 생성하는 파이프라인이다.

### 파이프라인 아키텍처

```
ko.json 변경 감지 → 변경된 키 추출 → Claude API 번역
    → 번역 결과 검증 → 리뷰어 Slack 알림 → 승인
    → 번역 파일 업데이트 → PR 자동 생성 → CI 검증 → 머지
```

### Claude API 번역 엔진

```typescript
// scripts/ai-translate.ts
import Anthropic from '@anthropic-ai/sdk';
import { readFileSync, writeFileSync } from 'fs';
import { diff } from 'deep-object-diff';

interface TranslationConfig {
  sourceLocale: string;
  targetLocales: string[];
  glossaryPath: string;
  contextPath: string;
  maxBatchSize: number;
}

interface TranslationEntry {
  key: string;
  source: string;
  context?: string;
  maxLength?: number;
  uiElement?: 'button' | 'label' | 'title' | 'description' | 'placeholder' | 'error' | 'toast';
}

interface TranslationResult {
  key: string;
  locale: string;
  translation: string;
  confidence: number;
  alternatives: string[];
  notes: string;
}

const client = new Anthropic();

async function translateBatch(
  entries: TranslationEntry[],
  targetLocale: string,
  glossary: Record<string, Record<string, string>>,
): Promise<TranslationResult[]> {
  const localeNames: Record<string, string> = {
    en: 'English',
    ja: 'Japanese',
    zh: 'Simplified Chinese',
    ar: 'Arabic',
    de: 'German',
    fr: 'French',
    es: 'Spanish',
  };

  const systemPrompt = `You are a professional UI translator for a web application.
Target language: ${localeNames[targetLocale] ?? targetLocale}

Rules:
1. Preserve all ICU message format syntax ({name}, {count, plural, ...}, {gender, select, ...})
2. Never translate brand names, technical terms in the glossary
3. Match the tone: buttons should be concise, descriptions natural
4. Consider maxLength constraints -- abbreviate naturally if needed
5. For Arabic: ensure proper RTL markers for mixed content
6. Return valid JSON array

Glossary: ${JSON.stringify(glossary[targetLocale] ?? {})}`;

  const message = await client.messages.create({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 4096,
    system: systemPrompt,
    messages: [
      {
        role: 'user',
        content: `Translate these UI strings. Return JSON array with keys: key, translation, confidence (0-1), alternatives (array), notes.

${JSON.stringify(entries, null, 2)}`,
      },
    ],
  });

  const content = message.content[0];
  if (content.type !== 'text') throw new Error('Unexpected response type');

  const jsonMatch = content.text.match(/\[[\s\S]*\]/);
  if (!jsonMatch) throw new Error('No JSON array in response');

  return JSON.parse(jsonMatch[0]).map((r: TranslationResult) => ({
    ...r,
    locale: targetLocale,
  }));
}

// 변경된 키만 추출
function extractChangedKeys(
  prevSource: Record<string, string>,
  currentSource: Record<string, string>,
): string[] {
  const changes = diff(prevSource, currentSource) as Record<string, unknown>;
  return Object.keys(flattenObject(changes));
}

function flattenObject(obj: Record<string, unknown>, prefix = ''): Record<string, string> {
  const result: Record<string, string> = {};
  for (const [key, value] of Object.entries(obj)) {
    const fullKey = prefix ? `${prefix}.${key}` : key;
    if (typeof value === 'object' && value !== null) {
      Object.assign(result, flattenObject(value as Record<string, unknown>, fullKey));
    } else {
      result[fullKey] = String(value);
    }
  }
  return result;
}

// 메인 파이프라인
async function runTranslationPipeline(config: TranslationConfig): Promise<void> {
  const prevSource = JSON.parse(
    readFileSync(`messages/${config.sourceLocale}.prev.json`, 'utf-8'),
  );
  const currentSource = JSON.parse(
    readFileSync(`messages/${config.sourceLocale}.json`, 'utf-8'),
  );
  const glossary = JSON.parse(readFileSync(config.glossaryPath, 'utf-8'));

  const changedKeys = extractChangedKeys(prevSource, currentSource);
  if (changedKeys.length === 0) {
    console.log('No translation changes detected');
    return;
  }

  console.log(`Found ${changedKeys.length} changed keys`);
  const flat = flattenObject(currentSource);
  const entries: TranslationEntry[] = changedKeys.map((key) => ({
    key,
    source: flat[key] ?? '',
  }));

  // 배치 단위로 번역
  for (const locale of config.targetLocales) {
    const results: TranslationResult[] = [];
    for (let i = 0; i < entries.length; i += config.maxBatchSize) {
      const batch = entries.slice(i, i + config.maxBatchSize);
      const batchResults = await translateBatch(batch, locale, glossary);
      results.push(...batchResults);
    }

    // confidence가 낮은 항목 플래그
    const lowConfidence = results.filter((r) => r.confidence < 0.8);
    if (lowConfidence.length > 0) {
      console.warn(`[${locale}] ${lowConfidence.length} low-confidence translations:`);
      lowConfidence.forEach((r) => {
        console.warn(`  - ${r.key}: "${r.translation}" (${r.confidence}) -- ${r.notes}`);
      });
    }

    // 번역 파일 업데이트
    const targetPath = `messages/${locale}.json`;
    const existing = JSON.parse(readFileSync(targetPath, 'utf-8'));
    for (const result of results) {
      setNestedValue(existing, result.key, result.translation);
    }
    writeFileSync(targetPath, JSON.stringify(existing, null, 2) + '\n');
    console.log(`Updated ${targetPath} with ${results.length} translations`);
  }

  // prev 파일 갱신
  writeFileSync(
    `messages/${config.sourceLocale}.prev.json`,
    JSON.stringify(currentSource, null, 2) + '\n',
  );
}

function setNestedValue(obj: Record<string, unknown>, path: string, value: string): void {
  const keys = path.split('.');
  let current = obj;
  for (let i = 0; i < keys.length - 1; i++) {
    if (!(keys[i] in current)) current[keys[i]] = {};
    current = current[keys[i]] as Record<string, unknown>;
  }
  current[keys[keys.length - 1]] = value;
}
```

## 4. Pseudo-Localization으로 UI 깨짐 자동 탐지

Pseudo-localization은 번역 없이도 UI 국제화 문제를 조기에 발견하는 기법이다. 문자열을 의도적으로 늘이거나 특수 문자로 치환하여 하드코딩, 글자 잘림, 레이아웃 깨짐을 시각적으로 드러낸다.

### Pseudo-Locale 생성기

```typescript
// lib/pseudo-locale.ts
type PseudoStrategy = 'accented' | 'elongated' | 'mirrored' | 'enclosed';

interface PseudoConfig {
  strategy: PseudoStrategy;
  elongationFactor: number; // 1.0 = 원본, 1.5 = 50% 길어짐
  prefix: string;
  suffix: string;
  preservePlaceholders: boolean;
}

const ACCENTED_MAP: Record<string, string> = {
  a: 'ààà', b: 'ƀ', c: 'ç', d: 'ð', e: 'ééé', f: 'ƒ', g: 'ĝ', h: 'ĥ',
  i: 'ííí', j: 'ĵ', k: 'ķ', l: 'ĺ', m: 'ḿ', n: 'ñ', o: 'óóó', p: 'þ',
  q: 'q', r: 'ŕ', s: 'š', t: 'ţ', u: 'ùùù', v: 'ṽ', w: 'ŵ', x: 'x',
  y: 'ý', z: 'ž',
};

const MIRROR_MAP: Record<string, string> = {
  a: '\u0252', b: 'd', c: '\u0254', d: 'b', e: '\u01DD', f: '\u025F',
  g: '\u0183', h: '\u0265', i: '\u0131', j: '\u027E', k: '\u029E', l: 'l',
  m: '\u026F', n: 'u', o: 'o', p: 'q', q: 'p', r: '\u0279', s: 's',
  t: '\u0287', u: 'n', v: '\u028C', w: '\u028D', x: 'x', y: '\u028E', z: 'z',
};

function pseudoLocalize(text: string, config: PseudoConfig): string {
  const placeholderRegex = /\{[^}]+\}/g;
  const placeholders: { index: number; match: string }[] = [];

  if (config.preservePlaceholders) {
    let match: RegExpExecArray | null;
    while ((match = placeholderRegex.exec(text)) !== null) {
      placeholders.push({ index: match.index, match: match[0] });
    }
  }

  let result = '';
  let skipUntil = -1;

  for (let i = 0; i < text.length; i++) {
    if (i < skipUntil) continue;

    const placeholder = placeholders.find((p) => p.index === i);
    if (placeholder) {
      result += placeholder.match;
      skipUntil = i + placeholder.match.length;
      continue;
    }

    const char = text[i].toLowerCase();
    const map = config.strategy === 'accented' ? ACCENTED_MAP
      : config.strategy === 'mirrored' ? MIRROR_MAP
      : undefined;

    if (map && map[char]) {
      result += text[i] === text[i].toUpperCase() ? map[char].toUpperCase() : map[char];
    } else {
      result += text[i];
    }
  }

  // 문자열 늘이기 (elongation)
  if (config.elongationFactor > 1.0) {
    const padding = '~'.repeat(Math.floor(result.length * (config.elongationFactor - 1)));
    result = result + padding;
  }

  return `${config.prefix}${result}${config.suffix}`;
}

// 전체 번역 파일을 pseudo-locale로 변환
function generatePseudoLocale(
  messages: Record<string, unknown>,
  config: PseudoConfig,
): Record<string, unknown> {
  const result: Record<string, unknown> = {};

  for (const [key, value] of Object.entries(messages)) {
    if (typeof value === 'string') {
      result[key] = pseudoLocalize(value, config);
    } else if (typeof value === 'object' && value !== null) {
      result[key] = generatePseudoLocale(value as Record<string, unknown>, config);
    } else {
      result[key] = value;
    }
  }

  return result;
}

// 프리셋
const PSEUDO_PRESETS: Record<string, PseudoConfig> = {
  // 문자열 길이 테스트 (독일어/핀란드어 시뮬레이션)
  longText: {
    strategy: 'accented',
    elongationFactor: 1.5,
    prefix: '[!!',
    suffix: '!!]',
```

```typescript
  key: string,

  environment: string,
): string | null {

      (v) => v.key === key && v.locale === locale,
    );

    if (matchingVariants.length > 0) {
      const variant = matchingVariants[envIndex % matchingVariants.length];
      return variant?.value ?? null;
    }
  }

  return null;
```

```typescript
  zh: { locale: 'zh', currency: 'CNY', timezone: 'Asia/Shanghai' },
  ar: { locale: 'ar', currency: 'SAR', timezone: 'Asia/Riyadh', numberingSystem: 'arab' },
  de: { locale: 'de', currency: 'EUR', timezone: 'Europe/Berlin' },
  fr: { locale: 'fr', currency: 'EUR', timezone: 'Europe/Paris' },
};

function createLocalizedFormatter(locale: SupportedLocale) {
  const config = LOCALE_FORMATTER_CONFIG[locale];
  const localeTag = config.numberingSystem
    ? `${config.locale}-u-nu-${config.numberingSystem}`
    : config.locale;

  return {
    currency(amount: number): string {
      return new Intl.NumberFormat(localeTag, {
        style: 'currency',
        currency: config.currency,
        maximumFractionDigits: config.currency === 'KRW' || config.currency === 'JPY' ? 0 : 2,
      }).format(amount);
    },

    number(value: number): string {
      return new Intl.NumberFormat(localeTag).format(value);
    },

    date(date: Date, style: 'short' | 'medium' | 'long' = 'medium'): string {
      const options: Intl.DateTimeFormatOptions = {
        timeZone: config.timezone,
        ...(style === 'short' && { day: 'numeric', month: 'numeric', year: '2-digit' }),
        ...(style === 'medium' && { day: 'numeric', month: 'short', year: 'numeric' }),
        ...(style === 'long' && { day: 'numeric', month: 'long', year: 'numeric', weekday: 'long' }),
      };
      return new Intl.DateTimeFormat(localeTag, options).format(date);
    },

    relativeTime(date: Date): string {
      const rtf = new Intl.RelativeTimeFormat(localeTag, { numeric: 'auto' });
      const diffMs = date.getTime() - Date.now();
      const diffSec = Math.round(diffMs / 1000);
      const diffMin = Math.round(diffSec / 60);
      const diffHour = Math.round(diffMin / 60);
      const diffDay = Math.round(diffHour / 24);

      if (Math.abs(diffSec) < 60) return rtf.format(diffSec, 'second');
      if (Math.abs(diffMin) < 60) return rtf.format(diffMin, 'minute');
      if (Math.abs(diffHour) < 24) return rtf.format(diffHour, 'hour');
      return rtf.format(diffDay, 'day');
    },

    list(items: string[], type: 'conjunction' | 'disjunction' = 'conjunction'): string {
      return new Intl.ListFormat(localeTag, { type }).format(items);
    },
  };
}

export { createLocalizedFormatter, LOCALE_FORMATTER_CONFIG };
export type { SupportedLocale, FormatterConfig };
```
