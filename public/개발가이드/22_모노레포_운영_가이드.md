## 1. AI 기반 모노레포 (최우선)

> 모노레포 운영에서 AI를 활용하면 **패키지 구조를 자동 설계**하고, **변경 영향 범위를 지능적으로 분석하여 빌드를 최적화**하며, **패키지 의존성 문제를 자동 탐지하고 정리**할 수 있다. CI 시간 50% 단축, 의존성 문제 자동 해결 90%가 목표다.

### 1.1 Claude로 패키지 구조 설계 프롬프트

#### 프롬프트 1: 모노레포 초기 패키지 구조 설계

```text
아래 프로젝트 요구사항을 분석하여 최적의 모노레포 패키지 구조를 설계하라.

## 프로젝트 정보
- 앱 수: {app_count}개 (예: 웹 대시보드, 모바일 웹, 어드민)
- 공유 컴포넌트 비율: {shared_ratio}%
- 백엔드 포함 여부: {has_backend}
- 팀 규모: {team_size}명
- 배포 환경: {deploy_targets}

## 설계 원칙
1. 순환 의존성 절대 금지
2. internal packages (빌드 없이 소스 직접 참조)와 published packages 구분
3. 패키지 경계는 팀 구조에 맞게 설정 (Conway's Law)
4. shared 패키지는 최대 2단계 깊이로 제한
5. 각 패키지에 명확한 public API (barrel exports) 정의

## 출력 형식
- 폴더 구조 트리
- 각 패키지별 역할 설명
- 패키지 간 의존성 다이어그램 (텍스트)
- tsconfig, package.json 샘플
- 추천 빌드 도구 및 설정
```

#### 프롬프트 2: 기존 모노리스를 모노레포로 분리

```text
아래 모노리스 프로젝트의 소스 구조를 분석하여 모노레포로 분리 계획을 수립하라.

## 현재 폴더 구조
{folder_tree}

## 파일 간 의존성 그래프 (import 분석 결과)
{dependency_graph}

## 분석 항목
1. 자연스러운 패키지 경계 식별 (결합도 낮은 지점)
2. 순환 의존성 탐지 및 해결 방안
3. 단계별 마이그레이션 계획 (한 번에 하지 않음)
4. 각 단계별 리스크 평가
5. 공유 코드 추출 후보 (3곳 이상에서 import되는 모듈)

## 제약 조건
- 마이그레이션 중에도 기존 빌드/배포 파이프라인 유지
- 단계별로 롤백 가능해야 함
- 팀원 {team_size}명이 병렬 작업 가능한 단위로 분할
```

#### 프롬프트 3: 패키지 의존성 최적화 분석

```text
아래 모노레포의 패키지 의존성 정보를 분석하여 최적화 방안을 제시하라.

## 패키지 목록 및 의존성
{package_dependencies_json}

## 분석 요청
1. 불필요한 의존성 (사용되지 않는 dependency) 탐지
2. 중복 의존성 (여러 패키지에서 다른 버전 사용) 통합 방안
3. devDependencies로 옮겨야 할 항목
4. peerDependencies로 설정해야 할 항목
5. 패키지 크기 최적화 (tree-shaking 가능 여부)
6. 의존성 업데이트 우선순위 (보안, 호환성 기준)

각 항목별로 자동 수정 가능한 package.json 패치를 JSON 형식으로 제공하라.
```

### 1.2 AI로 affected 분석 및 선별 빌드 최적화

```typescript
// ai-affected-analyzer.ts
import Anthropic from "@anthropic-ai/sdk";

interface AffectedResult {
  buildTargets: string[];
  testTargets: string[];
  deployTargets: string[];
  skipReasons: Record<string, string>;
  confidence: number;
}

interface ChangedFile {
  path: string;
  changeType: "added" | "modified" | "deleted" | "renamed";
  diff: string;
}

interface PackageInfo {
  name: string;
  path: string;
  dependencies: string[];
  devDependencies: string[];
  scripts: Record<string, string>;
}

async function analyzeAffectedWithAI(
  changedFiles: ChangedFile[],
  packages: PackageInfo[],
  dependencyGraph: Map<string, string[]>,
): Promise<AffectedResult> {
  const client = new Anthropic();

  // 1단계: 정적 분석으로 affected 후보 추출
  const staticAffected = getStaticAffected(changedFiles, packages, dependencyGraph);

  // 2단계: AI로 실제 영향 범위 정밀 분석
  const prompt = `
모노레포의 변경사항을 분석하여 실제로 빌드/테스트/배포가 필요한 패키지만 선별하라.

## 변경된 파일
${changedFiles.map((f) => `- ${f.path} (${f.changeType})\n\`\`\`diff\n${f.diff}\n\`\`\``).join("\n")}

## 정적 분석 affected 후보
${staticAffected.map((p) => `- ${p}`).join("\n")}

## 전체 패키지 의존성 그래프
${JSON.stringify(Object.fromEntries(dependencyGraph), null, 2)}

## 판단 기준
1. 타입 정의만 변경된 경우 → 런타임 빌드 불필요, 타입 체크만
2. 테스트 파일만 변경된 경우 → 해당 패키지 테스트만 실행
3. 문서/README만 변경된 경우 → 빌드/테스트 모두 불필요
4. devDependency만 변경된 경우 → 해당 패키지만, downstream 불필요
5. 공유 유틸 변경 시 → 실제 사용하는 함수 기준으로 영향 범위 축소
6. 설정 파일 (tsconfig, eslint 등) 변경 → 영향받는 패키지 전체

JSON 형식으로 응답:
{
  "buildTargets": ["패키지명"],
  "testTargets": ["패키지명"],
  "deployTargets": ["패키지명"],
  "skipReasons": { "패키지명": "스킵 사유" },
  "confidence": 0.95
}`;

  const response = await client.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 4096,
    messages: [{ role: "user", content: prompt }],
  });

  const text =
    response.content[0].type === "text" ? response.content[0].text : "";
  const result: AffectedResult = JSON.parse(text);

  // 안전장치: confidence가 낮으면 정적 분석 결과로 폴백
  if (result.confidence < 0.8) {
    console.warn("AI 분석 confidence 낮음, 정적 분석으로 폴백");
    return {
      buildTargets: staticAffected,
      testTargets: staticAffected,
      deployTargets: staticAffected,
      skipReasons: {},
      confidence: 1.0,
    };
  }

  return result;
}

function getStaticAffected(
  changedFiles: ChangedFile[],
  packages: PackageInfo[],
  dependencyGraph: Map<string, string[]>,
): string[] {
  const directlyAffected = new Set<string>();

  for (const file of changedFiles) {
    const pkg = packages.find((p) => file.path.startsWith(p.path));
    if (pkg) directlyAffected.add(pkg.name);
  }

  // 의존성 그래프 순회하여 downstream 추가
  const allAffected = new Set(directlyAffected);
  const queue = [...directlyAffected];

  while (queue.length > 0) {
    const current = queue.shift()!;
    const dependents = dependencyGraph.get(current) ?? [];
    for (const dep of dependents) {
      if (!allAffected.has(dep)) {
        allAffected.add(dep);
        queue.push(dep);
      }
    }
  }

  return [...allAffected];
}

export { analyzeAffectedWithAI };
export type { AffectedResult, ChangedFile, PackageInfo };
```

### 1.3 AI 기반 패키지 의존성 정리

```typescript
// ai-dependency-cleanup.ts
interface DependencyIssue {
  type:
    | "unused"
    | "duplicate-version"
    | "wrong-category"
    | "circular"
    | "missing-peer";
  package: string;
  dependency: string;
  currentVersion?: string;
  suggestedAction: string;
  autoFixable: boolean;
  fix?: {
    file: string;
    field: string;
    action: "remove" | "move" | "update";
    value?: string;
  };
}

interface PackageDependencies {
  name: string;
  packageJsonPath: string;
  dependencies: Record<string, string>;
  devDependencies: Record<string, string>;
  peerDependencies: Record<string, string>;
  importedModules: string[]; // 실제 소스에서 import하는 모듈
}

async function analyzeDependenciesWithAI(
  packages: PackageDependencies[],
): Promise<DependencyIssue[]> {
  const prompt = `
모노레포의 패키지 의존성을 분석하여 문제점을 찾고 수정 방안을 제시하라.

## 패키지 정보
${packages
  .map(
    (p) => `
### ${p.name} (${p.packageJsonPath})
- dependencies: ${JSON.stringify(p.dependencies)}
- devDependencies: ${JSON.stringify(p.devDependencies)}
- peerDependencies: ${JSON.stringify(p.peerDependencies)}
- 실제 import 목록: ${p.importedModules.join(", ")}
`,
  )
  .join("\n")}

## 분석 항목
1. **unused**: package.json에 있지만 소스에서 import하지 않는 의존성
2. **duplicate-version**: 같은 패키지를 다른 버전으로 사용하는 경우
3. **wrong-category**: dependencies에 있어야 할 것이 devDependencies에 있거나 그 반대
4. **circular**: 순환 의존성
5. **missing-peer**: peerDependencies로 설정해야 하는데 dependencies로 되어 있는 경우

각 이슈별로 자동 수정 패치를 포함하여 JSON 배열로 응답하라.`;

  const response = await callAI(prompt);
  return response as DependencyIssue[];
}

// 자동 수정 실행
async function autoFixDependencies(
  issues: DependencyIssue[],
): Promise<{ fixed: number; skipped: number }> {
  const fixableIssues = issues.filter((i) => i.autoFixable && i.fix);
  let fixed = 0;

  for (const issue of fixableIssues) {
    const fix = issue.fix!;
    try {
      const packageJson = JSON.parse(
        await Bun.file(fix.file).text(),
      ) as Record<string, Record<string, string>>;

      switch (fix.action) {
        case "remove":
          delete packageJson[fix.field]?.[issue.dependency];
          break;
        case "move": {
          const version = packageJson[fix.field]?.[issue.dependency];
          if (version && fix.value) {
            delete packageJson[fix.field][issue.dependency];
            packageJson[fix.value] = packageJson[fix.value] ?? {};
            packageJson[fix.value][issue.dependency] = version;
          }
          break;
        }
        case "update":
          if (fix.value && packageJson[fix.field]) {
            packageJson[fix.field][issue.dependency] = fix.value;
          }
          break;
      }

      await Bun.write(fix.file, JSON.stringify(packageJson, null, 2) + "\n");
      fixed++;
      console.log(`[FIX] ${issue.package}: ${issue.suggestedAction}`);
    } catch (error) {
      console.error(`[SKIP] ${issue.package}: ${error}`);
    }
  }

  return { fixed, skipped: fixableIssues.length - fixed };
}

async function callAI(prompt: string): Promise<unknown> {
  const client = new (await import("@anthropic-ai/sdk")).default();
  const response = await client.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 8192,
    messages: [{ role: "user", content: prompt }],
  });
  const text =
    response.content[0].type === "text" ? response.content[0].text : "";
  return JSON.parse(text);
}

export { analyzeDependenciesWithAI, autoFixDependencies };
export type { DependencyIssue, PackageDependencies };
```

## 2. Turborepo vs Nx vs pnpm workspace 비교

| 항목 | Turborepo | Nx | pnpm workspace (단독) |
|------|-----------|-----|----------------------|
| **설정 복잡도** | 낮음 (turbo.json) | 중간 (nx.json + project.json) | 최소 (pnpm-workspace.yaml) |
| **빌드 캐시** | 로컬 + Remote (Vercel) | 로컬 + Nx Cloud | 없음 (별도 구현) |
| **태스크 오케스트레이션** | 의존성 기반 자동 | 의존성 기반 + 커스텀 | 없음 |
| **affected 분석** | 기본 지원 | 고급 (코드 변경 분석) | 없음 (별도 구현) |
| **코드 생성기** | 없음 | 내장 (generators) | 없음 |
| **플러그인 시스템** | 없음 | 풍부 (100+) | 없음 |
| **모듈 경계 검사** | 없음 | ESLint rule 내장 | 없음 |
| **학습 곡선** | 낮음 | 중간~높음 | 최소 |
| **번들 사이즈** | ~2MB | ~50MB | 0 (패키지 관리자) |
| **권장 시나리오** | 중소규모, Vercel 배포 | 대규모, 엔터프라이즈 | 소규모, 단순 구조 |

### 권장 조합

```typescript
// monorepo-tool-selector.ts
interface MonorepoContext {
  packageCount: number;
  teamSize: number;
  ciProvider: "github-actions" | "gitlab-ci" | "jenkins";
  deployTarget: "vercel" | "aws" | "gcp" | "self-hosted";
  needsCodeGen: boolean;
  needsModuleBoundary: boolean;
}

function selectMonorepoTool(
  ctx: MonorepoContext,
): "turborepo" | "nx" | "pnpm-only" {
  // 대규모 + 코드 생성 + 모듈 경계 필요 → Nx
  if (
    ctx.packageCount > 20 ||
    ctx.needsCodeGen ||
    ctx.needsModuleBoundary
  ) {
    return "nx";
  }

  // 중소규모 + Vercel 배포 → Turborepo
  if (ctx.packageCount > 3 && ctx.deployTarget === "vercel") {
    return "turborepo";
  }

  // 소규모 + 단순 구조 → pnpm만으로 충분
  if (ctx.packageCount <= 5 && ctx.teamSize <= 5) {
    return "pnpm-only";
  }

  return "turborepo"; // 기본값
}
```

```typescript
// scripts/auto-changeset.ts
import { execSync } from "node:child_process";

interface ChangesetEntry {
  packages: string[];
  type: "patch" | "minor" | "major";
  summary: string;
}

function detectChangesAndCreateChangeset(): ChangesetEntry | null {
  // git diff로 변경된 패키지 감지
  const changedFiles = execSync("git diff --name-only HEAD~1", {
    encoding: "utf-8",
  })
    .trim()
    .split("\n");

  const affectedPackages = new Set<string>();

  for (const file of changedFiles) {
    if (file.startsWith("packages/")) {
      const packageName = file.split("/")[1];
      affectedPackages.add(`@repo/${packageName}`);
    }
    if (file.startsWith("apps/")) {
      const appName = file.split("/")[1];
      affectedPackages.add(`@repo/${appName}`);
    }
  }

  if (affectedPackages.size === 0) return null;

  // 변경 유형 결정
  const commitMessage = execSync("git log -1 --pretty=%B", {
    encoding: "utf-8",
  }).trim();

  const type = determineChangeType(commitMessage);

  return {
    packages: [...affectedPackages],
    type,
    summary: commitMessage,
  };
}

function determineChangeType(
  commitMessage: string,
): "patch" | "minor" | "major" {
  if (commitMessage.includes("BREAKING CHANGE") || commitMessage.startsWith("feat!")) {
    return "major";
  }
  if (commitMessage.startsWith("feat")) {
    return "minor";
  }
  return "patch";
}

export { detectChangesAndCreateChangeset };
```

### 5.2 커스텀 affected 분석 스크립트

```typescript
// scripts/affected.ts
import { execSync } from "node:child_process";
import { readFileSync, existsSync } from "node:fs";
import { join } from "node:path";

interface AffectedPackage {
  name: string;
  path: string;
  reason: "direct" | "dependency" | "config";
}

function getAffectedPackages(baseBranch = "origin/main"): AffectedPackage[] {
  const changedFiles = execSync(`git diff --name-only ${baseBranch}...HEAD`, {
    encoding: "utf-8",
  })
    .trim()
    .split("\n")
    .filter(Boolean);

  const affected = new Map<string, AffectedPackage>();

  // 루트 설정 파일 변경 → 전체 빌드
  const rootConfigFiles = [
    "tsconfig.json",
    "pnpm-workspace.yaml",
    "turbo.json",
    ".npmrc",
  ];
  const hasRootConfigChange = changedFiles.some((f) =>
    rootConfigFiles.includes(f),
  );

  if (hasRootConfigChange) {
    return getAllPackages().map((p) => ({
      ...p,
      reason: "config" as const,
    }));
  }

  // 패키지별 직접 변경 감지
  for (const file of changedFiles) {
    const pkg = findPackageForFile(file);
    if (pkg && !affected.has(pkg.name)) {
      affected.set(pkg.name, { ...pkg, reason: "direct" });
    }
  }

  // 의존성 그래프 기반 downstream 추가
  const graph = buildDependencyGraph();
  const queue = [...affected.keys()];

  while (queue.length > 0) {
    const current = queue.shift()!;
    const dependents = graph.get(current) ?? [];
    for (const dep of dependents) {
      if (!affected.has(dep)) {
        const pkg = getAllPackages().find((p) => p.name === dep);
        if (pkg) {
          affected.set(dep, { ...pkg, reason: "dependency" });
          queue.push(dep);
        }
      }
    }
  }

  return [...affected.values()];
}

function findPackageForFile(
  filePath: string,
): { name: string; path: string } | null {
  const prefixes = ["apps/", "packages/"];
  for (const prefix of prefixes) {
    if (filePath.startsWith(prefix)) {
      const packageDir = filePath.split("/").slice(0, 2).join("/");
      const packageJsonPath = join(packageDir, "package.json");
      if (existsSync(packageJsonPath)) {
        const pkg = JSON.parse(readFileSync(packageJsonPath, "utf-8"));
        return { name: pkg.name, path: packageDir };
      }
    }
  }
  return null;
}

function buildDependencyGraph(): Map<string, string[]> {
  const graph = new Map<string, string[]>();
  const packages = getAllPackages();

  for (const pkg of packages) {
    const packageJsonPath = join(pkg.path, "package.json");
    const packageJson = JSON.parse(readFileSync(packageJsonPath, "utf-8"));
    const allDeps = {
      ...packageJson.dependencies,
      ...packageJson.devDependencies,
    };

    for (const dep of Object.keys(allDeps)) {
      if (packages.some((p) => p.name === dep)) {
        const existing = graph.get(dep) ?? [];
        existing.push(pkg.name);
        graph.set(dep, existing);
      }
    }
  }

  return graph;
}

function getAllPackages(): Array<{ name: string; path: string }> {
  const result: Array<{ name: string; path: string }> = [];
  const dirs = ["apps", "packages"];

  for (const dir of dirs) {
    if (!existsSync(dir)) continue;
    const entries = execSync(`ls ${dir}`, { encoding: "utf-8" })
      .trim()
      .split("\n")
      .filter(Boolean);

    for (const entry of entries) {
      const packageJsonPath = join(dir, entry, "package.json");
      if (existsSync(packageJsonPath)) {
        const pkg = JSON.parse(readFileSync(packageJsonPath, "utf-8"));
        result.push({ name: pkg.name, path: join(dir, entry) });
      }
    }
  }

  return result;
}

export { getAffectedPackages };
export type { AffectedPackage };
```

```typescript
// scripts/env-manager.ts
interface AppEnvConfig {
  app: string;
  environment: "preview" | "staging" | "production";
  prNumber?: number;
  variables: Record<string, string>;
}

function generateEnvForApp(config: AppEnvConfig): Record<string, string> {
  const { app, environment, prNumber } = config;

  const baseEnv: Record<string, string> = {
    NODE_ENV: environment === "production" ? "production" : "development",
    NEXT_PUBLIC_APP_NAME: app,
    NEXT_PUBLIC_ENVIRONMENT: environment,
  };

  if (environment === "preview" && prNumber) {
    return {
      ...baseEnv,
      NEXT_PUBLIC_API_URL: `https://api-pr-${prNumber}.preview.example.com`,
      NEXT_PUBLIC_PREVIEW_URL: `https://${app}-pr-${prNumber}.preview.example.com`,
      NEXT_PUBLIC_SENTRY_ENVIRONMENT: `preview-${prNumber}`,
    };
  }

  if (environment === "staging") {
    return {
      ...baseEnv,
      NEXT_PUBLIC_API_URL: `https://api.staging.example.com`,
      NEXT_PUBLIC_SENTRY_ENVIRONMENT: "staging",
    };
  }

  return {
    ...baseEnv,
    NEXT_PUBLIC_API_URL: "https://api.example.com",
    NEXT_PUBLIC_SENTRY_ENVIRONMENT: "production",
  };
}
```

### 7.3 Self-hosted Remote Cache (대안)

```typescript
// scripts/custom-remote-cache.ts
// Turborepo 커스텀 Remote Cache 서버 (S3 기반)
import { S3Client, GetObjectCommand, PutObjectCommand } from "@aws-sdk/client-s3";
import { createServer } from "node:http";

const s3 = new S3Client({ region: "ap-northeast-2" });
const BUCKET = "turbo-cache";

const server = createServer(async (req, res) => {
  const hash = req.url?.split("/").pop();
  if (!hash) {
    res.writeHead(400);
    res.end();
    return;
  }

  if (req.method === "GET") {
    try {
      const result = await s3.send(
        new GetObjectCommand({ Bucket: BUCKET, Key: `cache/${hash}` }),
      );
      res.writeHead(200);
      const stream = result.Body as NodeJS.ReadableStream;
      stream.pipe(res);
    } catch {
      res.writeHead(404);
      res.end();
    }
  }

  if (req.method === "PUT") {
    const chunks: Buffer[] = [];
    req.on("data", (chunk: Buffer) => chunks.push(chunk));
    req.on("end", async () => {
      await s3.send(
        new PutObjectCommand({
          Bucket: BUCKET,
          Key: `cache/${hash}`,
          Body: Buffer.concat(chunks),
        }),
      );
      res.writeHead(200);
      res.end();
    });
  }
});

server.listen(9080, () => {
  console.log("Remote cache server running on :9080");
});
```
