## AI 기반 성능 최적화

2026년 현재, AI를 활용한 성능 최적화는 선택이 아닌 필수가 되었습니다. 수동으로 병목을 찾던 시대에서, AI가 코드 분석부터 개선 제안까지 자동화하는 시대로 전환되고 있습니다.

### 1. AI 코드 분석을 통한 성능 병목 자동 탐지

CI/CD 파이프라인에 AI 기반 성능 분석을 통합하여, 매 커밋마다 잠재적 성능 병목을 자동으로 탐지합니다.

```typescript
// scripts/ai-perf-analysis.ts
// CI에서 실행되는 AI 기반 성능 병목 탐지 스크립트

import Anthropic from '@anthropic-ai/sdk';
import { readFileSync, readdirSync } from 'fs';
import { join } from 'path';

interface PerfIssue {
  file: string;
  line: number;
  severity: 'critical' | 'warning' | 'info';
  description: string;
  suggestion: string;
}

async function analyzePerformanceBottlenecks(
  changedFiles: string[]
): Promise<PerfIssue[]> {
  const client = new Anthropic();

  const fileContents = changedFiles.map(file => ({
    path: file,
    content: readFileSync(file, 'utf-8'),
  }));

  const response = await client.messages.create({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 4096,
    messages: [{
      role: 'user',
      content: `다음 React/TypeScript 코드에서 성능 병목을 분석해주세요.
각 이슈를 JSON 배열로 반환해주세요.

분석 기준:
- 불필요한 리렌더링 유발 패턴
- 메모리 누수 가능성 (이벤트 리스너, 타이머 미정리)
- 번들 사이즈 증가 패턴 (barrel export, 무거운 라이브러리 전체 import)
- 메인 스레드 블로킹 작업
- 비효율적인 DOM 조작
- React Server Component 경계 위반

파일 목록:
${fileContents.map(f => `--- ${f.path} ---\n${f.content}`).join('\n\n')}`,
    }],
  });

  return JSON.parse(
    response.content[0].type === 'text' ? response.content[0].text : '[]'
  );
}

// GitHub Actions에서 PR 코멘트로 결과 게시
async function postPerfReview(issues: PerfIssue[]) {
  const critical = issues.filter(i => i.severity === 'critical');
  if (critical.length > 0) {
    console.error(`${critical.length}개의 심각한 성능 이슈가 발견되었습니다.`);
    process.exitCode = 1;
  }

  // GitHub PR 코멘트로 결과 게시
  const body = issues.map(issue =>
    `### ${issue.severity === 'critical' ? '[CRITICAL]' : issue.severity === 'warning' ? '[WARNING]' : '[INFO]'} ${issue.file}:${issue.line}\n${issue.description}\n> ${issue.suggestion}`
  ).join('\n\n');

  console.log(body);
}
```

### 3. AI 기반 이미지 최적화 파이프라인

빌드 시점에 이미지를 자동 분석하여 최적의 포맷, 압축률, 크기를 결정합니다.

```typescript
// scripts/ai-image-optimizer.ts
import sharp from 'sharp';
import { globSync } from 'glob';
import { readFileSync, writeFileSync, statSync } from 'fs';
import { join, parse } from 'path';

interface ImageOptimizationResult {
  original: { path: string; size: number; format: string };
  optimized: { path: string; size: number; format: string };
  savings: number;
  savingsPercent: string;
}

async function optimizeImagePipeline(
  inputDir: string,
  outputDir: string
): Promise<ImageOptimizationResult[]> {
  const images = globSync(`${inputDir}/**/*.{png,jpg,jpeg,gif,svg}`);
  const results: ImageOptimizationResult[] = [];

  for (const imagePath of images) {
    const { name, dir } = parse(imagePath);
    const metadata = await sharp(imagePath).metadata();
    const originalSize = statSync(imagePath).size;

    // 이미지 특성에 따라 최적 설정 결정
    const isPhoto = metadata.channels === 3 || metadata.channels === 4;
    const hasAlpha = metadata.hasAlpha;
    const isLarge = (metadata.width ?? 0) > 1920;

    // AVIF 변환 (최고 압축률)
    const avifPath = join(outputDir, dir, `${name}.avif`);
    await sharp(imagePath)
      .resize(isLarge ? { width: 1920, withoutEnlargement: true } : undefined)
      .avif({
        quality: isPhoto ? 50 : 60,
        effort: 6, // 압축 노력 수준 (0-9)
      })
      .toFile(avifPath);

    // WebP 변환 (폭넓은 호환성)
    const webpPath = join(outputDir, dir, `${name}.webp`);
    await sharp(imagePath)
      .resize(isLarge ? { width: 1920, withoutEnlargement: true } : undefined)
      .webp({
        quality: isPhoto ? 80 : 85,
        effort: 6,
      })
      .toFile(webpPath);

    // 반응형 이미지 세트 생성
    const widths = [400, 800, 1200, 1600];
    for (const w of widths) {
      if ((metadata.width ?? 0) >= w) {
        await sharp(imagePath)
          .resize({ width: w })
          .avif({ quality: isPhoto ? 50 : 60 })
          .toFile(join(outputDir, dir, `${name}-${w}w.avif`));

        await sharp(imagePath)
          .resize({ width: w })
          .webp({ quality: isPhoto ? 80 : 85 })
          .toFile(join(outputDir, dir, `${name}-${w}w.webp`));
      }
    }

    const optimizedSize = statSync(avifPath).size;
    results.push({
      original: { path: imagePath, size: originalSize, format: metadata.format ?? 'unknown' },
      optimized: { path: avifPath, size: optimizedSize, format: 'avif' },
      savings: originalSize - optimizedSize,
      savingsPercent: `${((1 - optimizedSize / originalSize) * 100).toFixed(1)}%`,
    });
  }

  // 최적화 리포트 생성
  const totalSavings = results.reduce((sum, r) => sum + r.savings, 0);
  console.log(`총 ${results.length}개 이미지 최적화 완료`);
  console.log(`총 절약: ${(totalSavings / 1024 / 1024).toFixed(2)}MB`);

  return results;
}
```

### 1. INP 최적화 심화 - scheduler.yield() 표준화

2026년에는 `scheduler.yield()`가 모든 주요 브라우저에서 표준으로 지원됩니다. Prioritized Task Scheduling API와 결합하여 더 정밀한 메인 스레드 제어가 가능합니다.

```typescript
// scheduler.yield() 표준화 + Prioritized Task Scheduling API

// 1. scheduler.yield()를 활용한 긴 태스크 분할
async function processLargeDataset(items: DataItem[]): Promise<ProcessedItem[]> {
  const results: ProcessedItem[] = [];
  const CHUNK_SIZE = 50;

  for (let i = 0; i < items.length; i += CHUNK_SIZE) {
    const chunk = items.slice(i, i + CHUNK_SIZE);

    for (const item of chunk) {
      results.push(processItem(item));
    }

    // 매 청크 처리 후 메인 스레드 양보
    // 브라우저가 사용자 입력, 렌더링 등을 처리할 수 있도록 함
    await scheduler.yield();
  }

  return results;
}

// 2. Prioritized Task Scheduling API로 작업 우선순위 제어
async function handleUserInteraction(event: PointerEvent) {
  // 시각적 피드백: 최고 우선순위 (user-blocking)

      updateUIFeedback(event.target);
    },

  // 데이터 처리: 중간 우선순위 (user-visible)

    async () => {
      const result = await computeResult(event);

    },
    { priority: 'user-visible' }
  );

  // 분석 이벤트: 낮은 우선순위 (background)

    () => {
      sendAnalyticsEvent('interaction', {

        target: (event.target as HTMLElement).tagName,

    },

}

// 3. AbortController와 결합한 취소 가능한 우선순위 작업
function useCancellableTask() {
  const controllerRef = useRef<TaskController | null>(null);

  const runTask = useCallback(async (taskFn: () => Promise<void>) => {
    // 이전 작업 취소
    controllerRef.current?.abort();

    const controller = new TaskController({ priority: 'user-visible' });
    controllerRef.current = controller;

    try {
      await scheduler.postTask(taskFn, { signal: controller.signal });
    } catch (e) {
      if (e instanceof DOMException && e.name === 'AbortError') {
        // 취소된 작업은 무시
        return;
      }
      throw e;
    }
  }, []);

  // 컴포넌트 언마운트 시 정리
  useEffect(() => {
    return () => controllerRef.current?.abort();
  }, []);

  return runTask;
}
```

### 2. Long Animation Frames (LoAF) API 활용

기존 Long Tasks API의 한계를 극복하는 LoAF API로, 성능 병목의 근본 원인을 정확히 진단합니다.

```typescript
// Long Animation Frames (LoAF) API - 상세한 성능 병목 진단

// 1. LoAF 모니터링 설정
function observeLongAnimationFrames() {
  if (!('PerformanceLongAnimationFrameTiming' in globalThis)) {
    console.warn('LoAF API가 지원되지 않습니다.');
    return;
  }

  const observer = new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
      const loaf = entry as PerformanceLongAnimationFrameTiming;

      // 50ms 이상의 프레임만 분석
      if (loaf.duration > 50) {
        analyzeLoAFEntry(loaf);
      }
    }
  });

  observer.observe({ type: 'long-animation-frame', buffered: true });
  return observer;
}

// 2. LoAF 엔트리 상세 분석
function analyzeLoAFEntry(entry: PerformanceLongAnimationFrameTiming) {
  const report = {
    // 프레임 전체 소요 시간
    totalDuration: entry.duration,
    // 블로킹 시간 (50ms 초과분)
    blockingDuration: entry.blockingDuration,
    // 렌더링 시작 시점
    renderStart: entry.renderStart,
    // 스타일/레이아웃 소요 시간
    styleAndLayoutDuration: entry.styleAndLayoutDuration,
    // 개별 스크립트 실행 정보
    scripts: entry.scripts.map(script => ({
      // 스크립트 소스 URL
      sourceURL: script.sourceURL,
      // 실행 시간
      duration: script.duration,
      // 호출 유형: 'classic-script', 'module-script', 'event-listener', 등
      invokerType: script.invokerType,
      // 호출자 정보 (이벤트 핸들러명 등)
      invoker: script.invoker,
      // 문자 위치 (소스맵과 매핑 가능)
      sourceCharPosition: script.sourceCharPosition,
      // 강제 스타일/레이아웃 재계산 여부
      forcedStyleAndLayoutDuration: script.forcedStyleAndLayoutDuration,
    })),
  };

  // 강제 레이아웃 재계산이 발생한 스크립트 경고
  const forcedLayoutScripts = entry.scripts.filter(
    s => s.forcedStyleAndLayoutDuration > 10
  );
  if (forcedLayoutScripts.length > 0) {
    console.warn(
      '[LoAF] 강제 레이아웃 재계산 감지:',
      forcedLayoutScripts.map(s => `${s.invoker} (${s.forcedStyleAndLayoutDuration}ms)`)
    );
  }

  // RUM 시스템으로 전송
  sendToRUM('loaf', report);
}

// 3. INP와 LoAF 연계 분석
function correlateINPWithLoAF() {
  const loafEntries: PerformanceLongAnimationFrameTiming[] = [];

  // LoAF 수집
  new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
      loafEntries.push(entry as PerformanceLongAnimationFrameTiming);
    }
  }).observe({ type: 'long-animation-frame', buffered: true });

  // Event Timing으로 INP 후보 수집
  new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
      const eventEntry = entry as PerformanceEventTiming;
      if (eventEntry.duration > 100) {
        // 해당 이벤트 시점의 LoAF 찾기
        const relatedLoAF = loafEntries.find(
          loaf =>
            loaf.startTime <= eventEntry.startTime &&
            loaf.startTime + loaf.duration >= eventEntry.startTime + eventEntry.duration
        );

        if (relatedLoAF) {
          console.log(`[INP 후보] ${eventEntry.name}: ${eventEntry.duration}ms`);
          console.log(`  관련 LoAF 스크립트:`, relatedLoAF.scripts.map(s => ({
            invoker: s.invoker,
            duration: s.duration,
          })));
        }
      }
    }
  }).observe({ type: 'event', buffered: true, durationThreshold: 100 });
}
```

### 3. Speculation Rules API (Prerendering 2.0)

사용자가 링크를 클릭하기 전에 페이지를 미리 렌더링하여 즉각적인 페이지 전환을 구현합니다.

```typescript
// 1. 정적 Speculation Rules (HTML에 직접 삽입)
function SpeculationRulesScript() {
  const rules = {
    prerender: [
      {
        // URL 패턴 기반 프리렌더링
        where: {
          and: [
            { href_matches: '/products/*' },
            { not: { href_matches: '/products/*/edit' } },
          ],
        },
        eagerness: 'moderate', // 'immediate' | 'eager' | 'moderate' | 'conservative'

      },
      {
        // 명시적 URL 목록
        urls: ['/about', '/pricing', '/contact'],
        eagerness: 'eager', // 페이지 로드 시 곧바로 프리렌더링

        eagerness: 'moderate',

    ],

// 2. 동적 Speculation Rules (사용자 행동 기반)
function useDynamicSpeculation() {
  const addSpeculationRule = useCallback((url: string) => {
    if (!HTMLScriptElement.supports?.('speculationrules')) {
      return;
    }

    const existing = document.querySelector('script[type="speculationrules"][data-dynamic]');
    existing?.remove();

    const script = document.createElement('script');
    script.type = 'speculationrules';
    script.dataset.dynamic = 'true';
    script.textContent = JSON.stringify({
      prerender: [{
        urls: [url],
        eagerness: 'immediate',
      }],
    });

    document.head.appendChild(script);
  }, []);

  return { addSpeculationRule };
}
```

### 2. CDN 캐시 워밍 전략

배포 직후 CDN 캐시 미스로 인한 성능 저하를 방지합니다.

```typescript
// scripts/cdn-cache-warming.ts
// 배포 후 주요 페이지의 CDN 캐시를 미리 워밍

interface WarmingConfig {
  baseUrl: string;
  regions: string[];
  paths: string[];
  concurrency: number;
}

async function warmCDNCache(config: WarmingConfig) {
  const { baseUrl, regions, paths, concurrency } = config;

  // 각 리전에서 모든 경로에 대해 요청 실행
  const tasks: Promise<void>[] = [];

  for (const region of regions) {
    for (const path of paths) {
      tasks.push(
        warmSinglePath(baseUrl, path, region)
      );
    }
  }

  // 동시성 제한하며 실행
  const chunks: Promise<void>[][] = [];
  for (let i = 0; i < tasks.length; i += concurrency) {
    chunks.push(tasks.slice(i, i + concurrency));
  }

  for (const chunk of chunks) {
    await Promise.all(chunk);
  }

}

async function warmSinglePath(baseUrl: string, path: string, region: string) {

  } catch (error) {
    console.error(`[${region}] ${path}: 실패 - ${error}`);
  }
}
```

```typescript
// 2. 인텔리전트 프리페치 훅
function usePrefetch() {
  const prefetchedRef = useRef<Set<string>>(new Set());

  const prefetch = useCallback((pageKey: keyof typeof pages) => {
    if (prefetchedRef.current.has(pageKey)) return;
    prefetchedRef.current.add(pageKey);

    // webpackPrefetch 대신 직접 dynamic import로 캐싱
    pages[pageKey]();
  }, []);

  return prefetch;
}

// 3. 호버 기반 프리페치 링크 컴포넌트
function PrefetchLink({
  to,
  pageKey,
  children,
  ...props
}: {
  to: string;
  pageKey: keyof typeof pages;
  children: React.ReactNode;
} & React.AnchorHTMLAttributes<HTMLAnchorElement>) {
  const navigate = useNavigate();
  const prefetch = usePrefetch();
  const timeoutRef = useRef<NodeJS.Timeout>();

  return (
    <a
      href={to}
      onMouseEnter={() => {
        // 100ms 후 프리페치 시작 (잠깐 스치는 호버 무시)
        timeoutRef.current = setTimeout(() => prefetch(pageKey), 100);
      }}
      onMouseLeave={() => {
        clearTimeout(timeoutRef.current);
      }}
      onFocus={() => prefetch(pageKey)} // 키보드 포커스도 지원
      onClick={(e) => {
        e.preventDefault();
        navigate(to);
      }}
      {...props}
    >
      {children}
    </a>
  );
}

// 4. Viewport 기반 자동 프리페치
function useViewportPrefetch(pageKey: keyof typeof pages) {
  const ref = useRef<HTMLElement>(null);
  const prefetch = usePrefetch();

  useEffect(() => {
    if (!ref.current) return;

    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          prefetch(pageKey);
          observer.disconnect();
        }
      },
      { rootMargin: '200px' }
    );

    observer.observe(ref.current);
    return () => observer.disconnect();
  }, [pageKey, prefetch]);

  return ref;
}
```

### 1. 자체 RUM 구축 가이드

외부 서비스에 의존하지 않고, 자체 Real User Monitoring 시스템을 구축합니다.

```typescript
// lib/rum/collector.ts
// 경량 RUM 수집기 (< 3KB gzip)

interface RUMMetric {
  name: string;
  value: number;
  rating: 'good' | 'needs-improvement' | 'poor';
  delta: number;
  id: string;
  navigationType: string;
  url: string;
  timestamp: number;
  connection?: {
    effectiveType: string;
    downlink: number;
    rtt: number;
  };
  device?: {
    memory?: number;
    cores?: number;
    viewport: { width: number; height: number };
  };
}

class RUMCollector {
  private buffer: RUMMetric[] = [];
  private flushInterval: number = 5000; // 5초마다 전송
  private endpoint: string;
  private sessionId: string;

  constructor(endpoint: string) {
    this.endpoint = endpoint;
    this.sessionId = crypto.randomUUID();
    this.init();
  }

  private init() {
    // Core Web Vitals 수집
    this.collectWebVitals();

    // Navigation Timing 수집
    this.collectNavigationTiming();

    // Resource Timing 수집
    this.collectResourceTiming();

    // Long Animation Frames 수집
    this.collectLoAF();

    // 주기적 전송
    setInterval(() => this.flush(), this.flushInterval);

    // 페이지 이탈 시 즉시 전송
    document.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'hidden') {
        this.flush(true);
      }
    });
  }

  private collectWebVitals() {
    import('web-vitals').then(({ onCLS, onINP, onLCP, onFCP, onTTFB }) => {
      const collect = (metric: any) => {
        this.addMetric({
          name: metric.name,
          value: metric.value,
          rating: metric.rating,
          delta: metric.delta,
          id: metric.id,
          navigationType: metric.navigationType,
          url: location.href,
          timestamp: Date.now(),
          connection: this.getConnectionInfo(),
          device: this.getDeviceInfo(),
        });
      };

      onCLS(collect);
      onINP(collect);
      onLCP(collect);
      onFCP(collect);
      onTTFB(collect);
    });
  }

  private collectNavigationTiming() {
    window.addEventListener('load', () => {
      setTimeout(() => {
        const nav = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming;
        if (!nav) return;

        this.addMetric({
          name: 'navigation',
          value: nav.loadEventEnd - nav.fetchStart,
          rating: nav.loadEventEnd - nav.fetchStart < 3000 ? 'good' : 'poor',
          delta: 0,
          id: crypto.randomUUID(),
          navigationType: nav.type,
          url: location.href,
          timestamp: Date.now(),
        });
      }, 0);
    });
  }

  private collectResourceTiming() {
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        const resource = entry as PerformanceResourceTiming;
        // 1초 이상 걸린 리소스만 수집
        if (resource.duration > 1000) {
          this.addMetric({
            name: 'slow-resource',
            value: resource.duration,
            rating: 'poor',
            delta: 0,
            id: crypto.randomUUID(),
            navigationType: 'resource',
            url: resource.name,
            timestamp: Date.now(),
          });
        }
      }
    });
    observer.observe({ type: 'resource', buffered: true });
  }

  private collectLoAF() {
    if (!('PerformanceLongAnimationFrameTiming' in globalThis)) return;

    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        const loaf = entry as PerformanceLongAnimationFrameTiming;
        if (loaf.duration > 100) {
          this.addMetric({
            name: 'long-animation-frame',
            value: loaf.duration,
            rating: loaf.duration > 200 ? 'poor' : 'needs-improvement',
            delta: loaf.blockingDuration,
            id: crypto.randomUUID(),
            navigationType: 'loaf',
            url: loaf.scripts[0]?.sourceURL ?? location.href,
            timestamp: Date.now(),
          });
        }
      }
    });
    observer.observe({ type: 'long-animation-frame', buffered: true });
  }

  private getConnectionInfo() {
    const conn = (navigator as any).connection;
    if (!conn) return undefined;
    return {
      effectiveType: conn.effectiveType,
      downlink: conn.downlink,
      rtt: conn.rtt,
    };
  }

  private getDeviceInfo() {
    return {
      memory: (navigator as any).deviceMemory,
      cores: navigator.hardwareConcurrency,
      viewport: {
        width: window.innerWidth,
        height: window.innerHeight,
      },
    };
  }

  private addMetric(metric: RUMMetric) {
    this.buffer.push(metric);
  }

  private flush(useBeacon = false) {
    if (this.buffer.length === 0) return;

    const payload = JSON.stringify({
      sessionId: this.sessionId,
      metrics: this.buffer,
    });

    this.buffer = [];

    if (useBeacon && navigator.sendBeacon) {
      navigator.sendBeacon(this.endpoint, payload);
    } else {
      fetch(this.endpoint, {
        method: 'POST',
        body: payload,
        headers: { 'Content-Type': 'application/json' },
        keepalive: true,
      }).catch(console.error);
    }
  }
}

// 초기화 (앱 진입점에서 한 번만)
export const rum = new RUMCollector('/api/rum/collect');
```

### 2. 성능 버짓 설정 및 자동 알림

성능 지표가 설정된 임계값을 초과하면 자동으로 알림을 발송합니다.

```typescript
// lib/rum/performance-budget.ts

interface PerformanceBudget {
  metric: string;
  warning: number;
  critical: number;
  unit: string;
}

const PERFORMANCE_BUDGETS: PerformanceBudget[] = [
  { metric: 'LCP', warning: 2000, critical: 2500, unit: 'ms' },
  { metric: 'INP', warning: 150, critical: 200, unit: 'ms' },
  { metric: 'CLS', warning: 0.08, critical: 0.1, unit: '' },
  { metric: 'FCP', warning: 1500, critical: 1800, unit: 'ms' },
  { metric: 'TTFB', warning: 600, critical: 800, unit: 'ms' },
  { metric: 'bundle-size', warning: 300, critical: 500, unit: 'KB' },
  { metric: 'total-js', warning: 800, critical: 1000, unit: 'KB' },
];

// CI에서 실행: 빌드 결과물의 성능 버짓 검증
async function checkPerformanceBudget(buildDir: string): Promise<boolean> {
  const results: { metric: string; value: number; status: string }[] = [];
  let hasViolation = false;

  // 번들 사이즈 체크
  const { statSync, readdirSync } = await import('fs');
  const { join } = await import('path');

  const jsFiles = readdirSync(join(buildDir, 'assets'))
    .filter(f => f.endsWith('.js'));

  let totalJS = 0;
  let largestChunk = 0;

  for (const file of jsFiles) {
    const size = statSync(join(buildDir, 'assets', file)).size / 1024; // KB
    totalJS += size;
    if (size > largestChunk) largestChunk = size;
  }

  const bundleBudget = PERFORMANCE_BUDGETS.find(b => b.metric === 'bundle-size')!;
  const totalBudget = PERFORMANCE_BUDGETS.find(b => b.metric === 'total-js')!;

  if (largestChunk > bundleBudget.critical) {
    console.error(`[CRITICAL] 최대 청크 크기: ${largestChunk.toFixed(1)}KB (임계값: ${bundleBudget.critical}KB)`);
    hasViolation = true;
  } else if (largestChunk > bundleBudget.warning) {
    console.warn(`[WARNING] 최대 청크 크기: ${largestChunk.toFixed(1)}KB (경고: ${bundleBudget.warning}KB)`);
  }

  if (totalJS > totalBudget.critical) {
    console.error(`[CRITICAL] 총 JS 크기: ${totalJS.toFixed(1)}KB (임계값: ${totalBudget.critical}KB)`);
    hasViolation = true;
  } else if (totalJS > totalBudget.warning) {
    console.warn(`[WARNING] 총 JS 크기: ${totalJS.toFixed(1)}KB (경고: ${totalBudget.warning}KB)`);
  }

  return !hasViolation;
}
```

### 3. Performance Observer 고급 활용

PerformanceObserver를 활용한 실시간 성능 모니터링 대시보드를 구축합니다.

```typescript
// lib/rum/perf-observer.ts
// Performance Observer 통합 모니터링

class PerformanceMonitor {
  private observers: PerformanceObserver[] = [];
  private metrics: Map<string, number[]> = new Map();

  constructor() {
    this.setupObservers();
  }

  private setupObservers() {
    // 1. Element Timing - 주요 UI 요소의 렌더링 시점 측정
    this.observe('element', (entries) => {
      for (const entry of entries) {
        const el = entry as PerformanceElementTiming;
        console.log(`[Element] ${el.identifier}: ${el.renderTime}ms`);
        this.record(`element:${el.identifier}`, el.renderTime);
      }
    });

    // 2. Paint Timing - FP, FCP 수집
    this.observe('paint', (entries) => {
      for (const entry of entries) {
        console.log(`[Paint] ${entry.name}: ${entry.startTime}ms`);
        this.record(entry.name, entry.startTime);
      }
    });

    // 3. Layout Shift - CLS 상세 분석
    this.observe('layout-shift', (entries) => {
      for (const entry of entries) {
        const ls = entry as LayoutShift;
        if (!ls.hadRecentInput) {
          console.log(`[CLS] Score: ${ls.value}, Sources:`, ls.sources?.map(s => ({
            node: s.node?.nodeName,
            previousRect: s.previousRect,
            currentRect: s.currentRect,
          })));
          this.record('cls-entry', ls.value);
        }
      }
    });

    // 4. Largest Contentful Paint - LCP 상세 분석
    this.observe('largest-contentful-paint', (entries) => {
      const lastEntry = entries[entries.length - 1] as LargestContentfulPaint;
      console.log(`[LCP] ${lastEntry.startTime}ms`, {
        element: lastEntry.element?.tagName,
        url: lastEntry.url,
        size: lastEntry.size,
        loadTime: lastEntry.loadTime,
        renderTime: lastEntry.renderTime,
      });
      this.record('lcp', lastEntry.startTime);
    });

    // 5. Event Timing - INP 후보 분석
    this.observe('event', (entries) => {
      for (const entry of entries) {
        const event = entry as PerformanceEventTiming;
        if (event.duration > 100) {
          console.log(`[Slow Event] ${event.name}: ${event.duration}ms`, {
            processingStart: event.processingStart - event.startTime,
            processingTime: event.processingEnd - event.processingStart,
            presentationDelay: event.startTime + event.duration - event.processingEnd,
          });
          this.record(`slow-event:${event.name}`, event.duration);
        }
      }
    }, { durationThreshold: 100 });
  }

  private observe(
    type: string,
    callback: (entries: PerformanceEntryList) => void,
    options?: Record<string, any>
  ) {
    try {
      const observer = new PerformanceObserver((list) => callback(list.getEntries()));
      observer.observe({ type, buffered: true, ...options });
      this.observers.push(observer);
    } catch (e) {
      // 지원하지 않는 entry type은 무시
    }
  }

  private record(name: string, value: number) {
    if (!this.metrics.has(name)) {
      this.metrics.set(name, []);
    }
    this.metrics.get(name)!.push(value);
  }

  // 수집된 메트릭 요약
  getSummary(): Record<string, { avg: number; p75: number; p95: number; count: number }> {
    const summary: Record<string, any> = {};

    for (const [name, values] of this.metrics) {
      const sorted = [...values].sort((a, b) => a - b);
      summary[name] = {
        avg: sorted.reduce((a, b) => a + b, 0) / sorted.length,
        p75: sorted[Math.floor(sorted.length * 0.75)] ?? 0,
        p95: sorted[Math.floor(sorted.length * 0.95)] ?? 0,
        count: sorted.length,
      };
    }

    return summary;
  }

  // 정리
  disconnect() {
    this.observers.forEach(o => o.disconnect());
    this.observers = [];
  }
}

// React Hook으로 래핑
function usePerformanceMonitor() {
  const monitorRef = useRef<PerformanceMonitor>();

  useEffect(() => {
    monitorRef.current = new PerformanceMonitor();
    return () => monitorRef.current?.disconnect();
  }, []);

  return {
    getSummary: () => monitorRef.current?.getSummary() ?? {},
  };
}
```

```tsx
// components/PerformanceDashboard.tsx
// 개발 환경에서 사용하는 실시간 성능 대시보드

'use client';

import { useState, useEffect } from 'react';
import { onCLS, onINP, onLCP, onFCP, onTTFB } from 'web-vitals';

interface VitalMetric {
  name: string;
  value: number;
  rating: 'good' | 'needs-improvement' | 'poor';
}

export function PerformanceDashboard() {
  const [vitals, setVitals] = useState<VitalMetric[]>([]);
  const [isOpen, setIsOpen] = useState(false);

  useEffect(() => {
    if (process.env.NODE_ENV !== 'development') return;

    const collect = (metric: any) => {
      setVitals(prev => {
        const existing = prev.findIndex(v => v.name === metric.name);
        const updated = {
          name: metric.name,
          value: metric.value,
          rating: metric.rating,
        };
        if (existing >= 0) {
          const next = [...prev];
          next[existing] = updated;
          return next;
        }
        return [...prev, updated];
      });
    };

    onCLS(collect);
    onINP(collect);
    onLCP(collect);
    onFCP(collect);
    onTTFB(collect);
  }, []);

  if (process.env.NODE_ENV !== 'development') return null;

  const ratingColors = {
    good: '#22c55e',
    'needs-improvement': '#f59e0b',
    poor: '#ef4444',
  };

  return (
    <div style={{ position: 'fixed', bottom: 16, right: 16, zIndex: 9999 }}>
      <button
        onClick={() => setIsOpen(!isOpen)}
        style={{
          padding: '8px 16px',
          borderRadius: '8px',
          background: '#1a1a2e',
          color: '#fff',
          border: 'none',
          cursor: 'pointer',
          fontSize: '12px',
        }}
      >
        Perf {vitals.some(v => v.rating === 'poor') ? '[!]' : '[OK]'}
      </button>

      {isOpen && (
        <div style={{
          position: 'absolute',
          bottom: '100%',
          right: 0,
          marginBottom: '8px',
          padding: '16px',
          borderRadius: '12px',
          background: '#1a1a2e',
          color: '#fff',
          minWidth: '280px',
          fontSize: '13px',
        }}>
          <h3 style={{ margin: '0 0 12px', fontSize: '14px' }}>Core Web Vitals</h3>
          {vitals.map(v => (
            <div key={v.name} style={{
              display: 'flex',
              justifyContent: 'space-between',
              padding: '4px 0',
            }}>
              <span>{v.name}</span>
              <span style={{ color: ratingColors[v.rating], fontWeight: 'bold' }}>
                {v.name === 'CLS' ? v.value.toFixed(3) : `${Math.round(v.value)}ms`}
              </span>
            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```
