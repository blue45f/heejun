## 1. AI 기반 디자인 시스템

디자인 시스템 구축과 운영의 30% 이상을 AI 자동화로 처리한다. 컴포넌트 생성, 토큰 추출, API 설계 리뷰, 문서 자동 생성까지 AI를 적극 활용한다.

### 1.1 AI 프롬프트 -- 컴포넌트 자동 생성

> **프롬프트 1: Compound Component 패턴 생성**
>
> ```
> 다음 요구사항에 맞는 React Compound Component를 생성해줘.
> - 컴포넌트: {컴포넌트명} (예: Accordion, Tabs, Select)
> - Radix UI 프리미티브 기반
> - Tailwind CSS v4 스타일링
> - TypeScript 제네릭 지원
> - 포함 사항: Context Provider, Trigger, Content, Item 서브 컴포넌트
> - ARIA 접근성 완전 준수
> - Storybook 스토리 포함
> - 테스트 코드(Vitest + Testing Library) 포함
>
> --- 디자인 토큰 ---
> {프로젝트의 디자인 토큰 붙여넣기}
> ```

> **프롬프트 2: Polymorphic 컴포넌트 생성**
>
> ```
> 다음 기본 컴포넌트를 Polymorphic 패턴으로 변환해줘.
> as prop으로 렌더링 요소를 변경할 수 있어야 하고,
> 각 요소 타입에 맞는 HTML 속성이 자동 완성되어야 한다.
> TypeScript의 제네릭과 ComponentPropsWithoutRef를 활용해줘.
>
> --- 기본 컴포넌트 코드 ---
> {코드 붙여넣기}
> ```

> **프롬프트 3: 디자인 토큰 기반 Variant 생성**
>
> ```
> 다음 디자인 토큰과 컴포넌트 스펙을 기반으로
> class-variance-authority(CVA)를 사용한 variant 시스템을 구현해줘.
> 포함할 variant: size(sm/md/lg), variant(primary/secondary/ghost/destructive),
> 그리고 compound variant(disabled + 각 variant 조합).
> Tailwind CSS v4 클래스를 사용해줘.
>
> --- 디자인 스펙 ---
> {Figma 스펙 또는 디자인 토큰 붙여넣기}
> ```

> **프롬프트 4: 기존 컴포넌트 리팩터링**
>
> ```
> 다음 컴포넌트를 디자인 시스템 표준에 맞게 리팩터링해줘.
> 적용할 패턴:
> - forwardRef + displayName
> - Slot 패턴 (asChild prop)
> - data-* 속성 기반 상태 스타일링
> - CSS 변수 기반 커스터마이징
> - 적절한 기본값과 타입 안전성
>
> --- 현재 컴포넌트 ---
> {코드 붙여넣기}
> ```

> **프롬프트 5: 컴포넌트 테스트 + 스토리 일괄 생성**
>
> ```
> 다음 컴포넌트에 대해 아래 항목을 모두 생성해줘.
> 1. Vitest + Testing Library 단위 테스트 (렌더링, 인터랙션, 접근성)
> 2. Storybook 스토리 (Default, AllVariants, Interactive, Playground)

>
> --- 컴포넌트 코드 ---

> ```

### 1.2 AI로 디자인 토큰 자동 추출 (Figma --> 코드)

Figma REST API에서 추출한 스타일 데이터를 AI가 분석하여 디자인 토큰 코드를 자동 생성한다.

```typescript
// scripts/figma-to-tokens.ts
import { writeFileSync } from "node:fs";

interface FigmaColor {
  r: number;
  g: number;
  b: number;
  a: number;
}

interface FigmaStyle {
  key: string;
  name: string;
  styleType: "FILL" | "TEXT" | "EFFECT" | "GRID";
  description: string;
}

interface FigmaTextStyle {
  fontFamily: string;
  fontWeight: number;
  fontSize: number;
  lineHeightPx: number;
  letterSpacing: number;
}

interface ExtractedTokens {
  colors: Record<string, string>;
  typography: Record<string, FigmaTextStyle>;
  spacing: Record<string, string>;
  shadows: Record<string, string>;
  radii: Record<string, string>;
}

/**
 * Figma API에서 스타일 데이터를 가져온다.
 */
async function fetchFigmaStyles(fileKey: string, token: string): Promise<FigmaStyle[]> {
  const response = await fetch(
    `https://api.figma.com/v1/files/${fileKey}/styles`,
    { headers: { "X-FIGMA-TOKEN": token } },
  );
  const data = await response.json();
  return data.meta.styles;
}

/**
 * Figma 색상값을 HEX로 변환한다.
 */
function figmaColorToHex(color: FigmaColor): string {
  const toHex = (v: number) =>
    Math.round(v * 255)
      .toString(16)
      .padStart(2, "0");
  return `#${toHex(color.r)}${toHex(color.g)}${toHex(color.b)}`;
}

/**
 * 추출된 토큰을 CSS 변수 파일로 변환한다.
 */
function generateCssVariables(tokens: ExtractedTokens): string {
  let css = ":root {\n";

  // 색상 토큰
  css += "  /* Colors */\n";
  for (const [name, value] of Object.entries(tokens.colors)) {
    css += `  --color-${name}: ${value};\n`;
  }

  // 타이포그래피 토큰
  css += "\n  /* Typography */\n";
  for (const [name, style] of Object.entries(tokens.typography)) {
    css += `  --font-size-${name}: ${style.fontSize}px;\n`;
    css += `  --line-height-${name}: ${style.lineHeightPx}px;\n`;
    css += `  --letter-spacing-${name}: ${style.letterSpacing}px;\n`;
  }

  // 간격 토큰
  css += "\n  /* Spacing */\n";
  for (const [name, value] of Object.entries(tokens.spacing)) {
    css += `  --spacing-${name}: ${value};\n`;
  }

  // 그림자 토큰
  css += "\n  /* Shadows */\n";
  for (const [name, value] of Object.entries(tokens.shadows)) {
    css += `  --shadow-${name}: ${value};\n`;
  }

  // 라운딩 토큰
  css += "\n  /* Radii */\n";
  for (const [name, value] of Object.entries(tokens.radii)) {
    css += `  --radius-${name}: ${value};\n`;
  }

  css += "}\n";
  return css;
}

/**
 * AI에 전달할 프롬프트를 생성한다.
 * Figma 원본 데이터를 AI가 분석하여 의미 있는 토큰 이름과 구조를 제안한다.
 */
function buildTokenExtractionPrompt(rawStyles: FigmaStyle[]): string {
  return `
다음 Figma 스타일 데이터를 분석하여 디자인 토큰으로 변환해줘.
규칙:
1. 색상은 semantic naming 사용 (예: primary, secondary, destructive, muted)
2. 타이포그래피는 scale 기반 (예: xs, sm, base, lg, xl, 2xl)
3. 간격은 4px 기반 스케일 (예: 1=4px, 2=8px, 3=12px, 4=16px)
4. 다크 모드 토큰도 함께 생성
5. Tailwind CSS v4 테마 설정과 호환되는 형식으로 출력

--- Figma 스타일 데이터 ---
${JSON.stringify(rawStyles, null, 2)}
`;
}
```

### 1.3 AI 기반 컴포넌트 API 설계 리뷰

```typescript
// scripts/ai-api-review.ts

interface ComponentAPI {
  name: string;
  props: Array<{
    name: string;
    type: string;
    required: boolean;
    defaultValue?: string;
    description?: string;
  }>;
  subComponents?: string[];
}

/**
 * 컴포넌트 API 설계를 AI에 검토 요청하기 위한 프롬프트를 생성한다.
 */
function buildApiReviewPrompt(api: ComponentAPI): string {
  return `
다음 React 컴포넌트 API를 디자인 시스템 관점에서 리뷰해줘.

컴포넌트: ${api.name}
Props:
${api.props.map((p) => `  - ${p.name}${p.required ? " (필수)" : ""}: ${p.type}${p.defaultValue ? ` = ${p.defaultValue}` : ""}`).join("\n")}
${api.subComponents ? `서브 컴포넌트: ${api.subComponents.join(", ")}` : ""}

검토 항목:
1. 네이밍 일관성 (Radix UI, shadcn/ui 컨벤션 준수 여부)
2. Props 최소화 원칙 (불필요한 prop은 없는지)
3. 합성 가능성 (Composition over Configuration)
4. 타입 안전성 (제네릭, 유니온 타입 활용도)
5. 접근성 prop 누락 여부
6. 기존 HTML 속성과의 충돌 여부
7. 확장성 (향후 기능 추가 시 breaking change 위험)

개선 제안을 코드와 함께 제시해줘.
`;
}
```

### 1.4 Storybook + AI 문서 자동 생성

```typescript
// scripts/generate-story-docs.ts
import { readFileSync, writeFileSync, readdirSync } from "node:fs";
import { join, basename } from "node:path";

/**
 * 컴포넌트 소스 코드에서 JSDoc과 타입 정보를 추출하여
 * AI가 Storybook MDX 문서를 자동 생성할 수 있는 프롬프트를 만든다.
 */
function generateStoryDocsPrompt(componentPath: string): string {
  const source = readFileSync(componentPath, "utf-8");
  const componentName = basename(componentPath, ".tsx");

  return `
다음 React 컴포넌트의 Storybook MDX 문서를 생성해줘.

컴포넌트: ${componentName}

포함할 섹션:
1. 개요 -- 컴포넌트의 용도와 사용 시점
2. 설치 및 임포트
3. 기본 사용법 (코드 예시 + Canvas)
4. Props 테이블 (ArgTypes 자동 생성)
5. Variants 갤러리 (모든 variant 조합 시각화)
6. 합성 패턴 (다른 컴포넌트와 조합 예시)
7. 접근성 -- 키보드 인터랙션 표, ARIA 속성
8. Do/Don't 가이드
9. 디자인 토큰 매핑

--- 컴포넌트 소스 ---
${source}
`;
}

/**
 * 컴포넌트 디렉토리의 모든 컴포넌트에 대해 문서 생성 프롬프트를 일괄 생성한다.
 */
function batchGenerateDocPrompts(componentsDir: string): Map<string, string> {
  const prompts = new Map<string, string>();
  const files = readdirSync(componentsDir).filter(
    (f) => f.endsWith(".tsx") && !f.includes(".stories") && !f.includes(".test"),
  );

  for (const file of files) {
    const fullPath = join(componentsDir, file);
    prompts.set(file, generateStoryDocsPrompt(fullPath));
  }

  return prompts;
}
```

```tsx
// components/ui/button.tsx
import { Slot } from "@radix-ui/react-slot";
import { cva, type VariantProps } from "class-variance-authority";
import { forwardRef, type ButtonHTMLAttributes } from "react";
import { cn } from "@/lib/utils";

const buttonVariants = cva(
  // 기본 스타일
  "inline-flex items-center justify-center gap-2 whitespace-nowrap rounded-md text-sm font-medium transition-colors focus-visible:outline-2 focus-visible:outline-offset-2 disabled:pointer-events-none disabled:opacity-50 [&_svg]:pointer-events-none [&_svg]:size-4 [&_svg]:shrink-0",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground shadow hover:bg-primary/90",
        destructive: "bg-destructive text-destructive-foreground shadow-sm hover:bg-destructive/90",
        outline: "border border-input bg-background shadow-sm hover:bg-accent hover:text-accent-foreground",
        secondary: "bg-secondary text-secondary-foreground shadow-sm hover:bg-secondary/80",
        ghost: "hover:bg-accent hover:text-accent-foreground",
        link: "text-primary underline-offset-4 hover:underline",
      },
      size: {
        sm: "h-8 rounded-md px-3 text-xs",
        md: "h-9 px-4 py-2",
        lg: "h-10 rounded-md px-8",
        icon: "size-9",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "md",
    },
  },
);

interface ButtonProps
  extends ButtonHTMLAttributes<HTMLButtonElement>,
    VariantProps<typeof buttonVariants> {
  /** Slot 패턴: 자식 요소를 렌더링 요소로 사용 */
  asChild?: boolean;
  /** 로딩 상태 */
  loading?: boolean;
}

const Button = forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, asChild = false, loading, disabled, children, ...props }, ref) => {
    const Component = asChild ? Slot : "button";

    return (
      <Component
        ref={ref}
        className={cn(buttonVariants({ variant, size, className }))}
        disabled={disabled || loading}
        aria-busy={loading || undefined}
        {...props}
      >
        {loading ? (
          <>
            <svg
              className="animate-spin"
              xmlns="http://www.w3.org/2000/svg"
              fill="none"
              viewBox="0 0 24 24"
              aria-hidden="true"
            >
              <circle
                className="opacity-25"
                cx="12"
                cy="12"
                r="10"
                stroke="currentColor"
                strokeWidth="4"
              />
              <path
                className="opacity-75"
                fill="currentColor"
                d="M4 12a8 8 0 018-8V0C5.373 0 0 5.373 0 12h4z"
              />
            </svg>
            <span className="sr-only">로딩 중</span>
            {children}
          </>
        ) : (
          children
        )}
      </Component>
    );
  },
);

Button.displayName = "Button";

export { Button, buttonVariants, type ButtonProps };
```

## 3. 디자인 토큰 시스템

### 3.1 토큰 계층 구조

```
Primitive Tokens (원시 토큰)
  └── blue-500: #3b82f6
  └── gray-100: #f3f4f6
  └── font-size-16: 1rem

Semantic Tokens (시맨틱 토큰)
  └── color-primary: {blue-500}
  └── color-background-muted: {gray-100}
  └── font-size-body: {font-size-16}

Component Tokens (컴포넌트 토큰)
  └── button-bg-primary: {color-primary}
  └── card-bg: {color-background-muted}
  └── input-font-size: {font-size-body}
```

## 4. 컴포넌트 설계 패턴

### 4.1 Compound Component 패턴

```tsx
// components/Accordion.tsx
import {
  createContext,
  useContext,
  useState,
  useCallback,
  useId,
  forwardRef,
  type ReactNode,
  type HTMLAttributes,
} from "react";
import { cn } from "@/lib/utils";

/* ---- Context ---- */
interface AccordionContextValue {
  expandedItems: Set<string>;
  toggleItem: (id: string) => void;
  type: "single" | "multiple";
}

const AccordionContext = createContext<AccordionContextValue | null>(null);

function useAccordionContext() {
  const context = useContext(AccordionContext);
  if (!context) throw new Error("Accordion 서브 컴포넌트는 Accordion 내부에서 사용해야 합니다");
  return context;
}

/* ---- Item Context ---- */
interface AccordionItemContextValue {
  itemId: string;
  isExpanded: boolean;
  triggerId: string;
  contentId: string;
}

const AccordionItemContext = createContext<AccordionItemContextValue | null>(null);

function useAccordionItemContext() {
  const context = useContext(AccordionItemContext);
  if (!context) throw new Error("AccordionTrigger/Content는 AccordionItem 내부에서 사용해야 합니다");
  return context;
}

/* ---- Root ---- */
interface AccordionProps extends HTMLAttributes<HTMLDivElement> {
  type?: "single" | "multiple";
  defaultExpanded?: string[];
  children: ReactNode;
}

function Accordion({
  type = "single",
  defaultExpanded = [],
  children,
  className,
  ...props
}: AccordionProps) {
  const [expandedItems, setExpandedItems] = useState(new Set(defaultExpanded));

  const toggleItem = useCallback(
    (id: string) => {
      setExpandedItems((prev) => {
        const next = new Set(prev);
        if (next.has(id)) {
          next.delete(id);
        } else {
          if (type === "single") next.clear();
          next.add(id);
        }
        return next;
      });
    },
    [type],
  );

  return (
    <AccordionContext.Provider value={{ expandedItems, toggleItem, type }}>
      <div className={cn("divide-y divide-border", className)} {...props}>
        {children}
      </div>
    </AccordionContext.Provider>
  );
}

/* ---- Item ---- */
interface AccordionItemProps extends HTMLAttributes<HTMLDivElement> {
  value: string;
  children: ReactNode;
}

function AccordionItem({ value, children, className, ...props }: AccordionItemProps) {
  const { expandedItems } = useAccordionContext();
  const generatedId = useId();
  const itemId = value || generatedId;
  const isExpanded = expandedItems.has(itemId);

  return (
    <AccordionItemContext.Provider
      value={{
        itemId,
        isExpanded,
        triggerId: `accordion-trigger-${itemId}`,
        contentId: `accordion-content-${itemId}`,
      }}
    >
      <div
        className={className}
        data-state={isExpanded ? "open" : "closed"}
        {...props}
      >
        {children}
      </div>
    </AccordionItemContext.Provider>
  );
}

/* ---- Trigger ---- */
const AccordionTrigger = forwardRef<HTMLButtonElement, HTMLAttributes<HTMLButtonElement>>(
  ({ children, className, ...props }, ref) => {
    const { toggleItem } = useAccordionContext();
    const { itemId, isExpanded, triggerId, contentId } = useAccordionItemContext();

    return (
      <h3>
        <button
          ref={ref}
          id={triggerId}
          type="button"
          role="button"
          aria-expanded={isExpanded}
          aria-controls={contentId}
          onClick={() => toggleItem(itemId)}
          className={cn(
            "flex w-full items-center justify-between py-4 text-left font-medium transition-all",
            className,
          )}
          {...props}
        >
          {children}
          <span
            aria-hidden="true"
            className={cn(
              "transition-transform duration-200",
              isExpanded && "rotate-180",
            )}
          >
            &#x25BC;
          </span>
        </button>
      </h3>
    );
  },
);
AccordionTrigger.displayName = "AccordionTrigger";

/* ---- Content ---- */
const AccordionContent = forwardRef<HTMLDivElement, HTMLAttributes<HTMLDivElement>>(
  ({ children, className, ...props }, ref) => {
    const { isExpanded, contentId, triggerId } = useAccordionItemContext();

    return (
      <div
        ref={ref}
        id={contentId}
        role="region"
        aria-labelledby={triggerId}
        hidden={!isExpanded}
        className={cn("overflow-hidden transition-all", className)}
        {...props}
      >
        <div className="pb-4 pt-0">{children}</div>
      </div>
    );
  },
);
AccordionContent.displayName = "AccordionContent";

export { Accordion, AccordionItem, AccordionTrigger, AccordionContent };
```

### 4.2 Polymorphic 컴포넌트

```tsx
// components/Polymorphic.tsx
import {
  forwardRef,
  type ComponentPropsWithoutRef,
  type ElementType,
  type ForwardRefRenderFunction,
  type ReactElement,
} from "react";

/**
 * Polymorphic 컴포넌트 타입 유틸리티
 * as prop으로 렌더링 요소를 변경하면 해당 요소의 HTML 속성이 자동 완성된다.
 */
type PolymorphicProps<
  E extends ElementType,
  P = object,
> = P &
  Omit<ComponentPropsWithoutRef<E>, keyof P | "as"> & {
    as?: E;
  };

type PolymorphicRef<E extends ElementType> =
  ComponentPropsWithoutRef<E> extends { ref?: infer R } ? R : never;

// 예시: Polymorphic Text 컴포넌트
type TextProps<E extends ElementType = "span"> = PolymorphicProps<
  E,
  {
    size?: "xs" | "sm" | "base" | "lg" | "xl";
    weight?: "normal" | "medium" | "semibold" | "bold";
    color?: "default" | "muted" | "subtle" | "primary" | "destructive";
    truncate?: boolean;
  }
>;

const TextInner: ForwardRefRenderFunction<HTMLElement, TextProps> = (
  {
    as,
    size = "base",
    weight = "normal",
    color = "default",
    truncate = false,
    className,
    style,
    children,
    ...props
  },
  ref,
) => {
  const Component = as || "span";

  const sizeMap = {
    xs: "var(--text-xs)",
    sm: "var(--text-sm)",
    base: "var(--text-base)",
    lg: "var(--text-lg)",
    xl: "var(--text-xl)",
  };

  const weightMap = {
    normal: 400,
    medium: 500,
    semibold: 600,
    bold: 700,
  };

  const colorMap = {
    default: "var(--color-foreground)",
    muted: "var(--color-foreground-muted)",
    subtle: "var(--color-foreground-subtle)",
    primary: "var(--color-primary)",
    destructive: "var(--color-destructive)",
  };

  return (
    <Component
      ref={ref as never}
      style={{
        fontSize: sizeMap[size],
        fontWeight: weightMap[weight],
        color: colorMap[color],
        ...(truncate && {
          overflow: "hidden",
          textOverflow: "ellipsis",
          whiteSpace: "nowrap" as const,
        }),
        ...style,
      }}
      {...props}
    >
      {children}
    </Component>
  );
};

const Text = forwardRef(TextInner) as <E extends ElementType = "span">(
  props: TextProps<E> & { ref?: PolymorphicRef<E> },
) => ReactElement | null;

export { Text, type PolymorphicProps, type TextProps };
```

### 8.2 cn 유틸리티 (clsx + tailwind-merge)

```typescript
// lib/utils.ts
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

/**
 * clsx로 조건부 클래스를 결합하고 tailwind-merge로 충돌을 해소한다.
 */
function cn(...inputs: ClassValue[]): string {
  return twMerge(clsx(inputs));
}

export { cn };
```

### 8.3 data-* 속성 기반 상태 스타일링

```css
/* Tailwind CSS v4에서 data-* 속성 활용 */

/* 컴포넌트 상태에 따른 스타일링 */
@utility data-state-open {
  &[data-state="open"] {
    @apply animate-in fade-in-0 zoom-in-95;
  }
}

@utility data-state-closed {
  &[data-state="closed"] {
    @apply animate-out fade-out-0 zoom-out-95;
  }
}
```

```tsx
// data-* 속성 활용 예시
function DropdownContent({ isOpen, children }: { isOpen: boolean; children: React.ReactNode }) {
  return (
    <div
      data-state={isOpen ? "open" : "closed"}
      data-side="bottom"
      data-align="start"
      className={cn(
        "z-50 min-w-32 rounded-md border bg-background-card p-1 shadow-md",
        // data-state에 따른 애니메이션
        "data-[state=open]:animate-in data-[state=open]:fade-in-0 data-[state=open]:zoom-in-95",
        "data-[state=closed]:animate-out data-[state=closed]:fade-out-0 data-[state=closed]:zoom-out-95",
        // data-side에 따른 진입 방향
        "data-[side=bottom]:slide-in-from-top-2",
        "data-[side=top]:slide-in-from-bottom-2",
        "data-[side=left]:slide-in-from-right-2",
        "data-[side=right]:slide-in-from-left-2",
      )}
    >
      {children}
    </div>
  );
}
```
