## 1. AI 기반 마이크로 FE 설계

> 마이크로 프론트엔드 아키텍처에서 **가장 어려운 것은 올바른 경계 설정**이다. AI를 활용하면 모놀리스 코드베이스의 의존성 그래프를 분석하여 최적의 분할 지점을 찾고, 팀 간 경계를 데이터 기반으로 설계할 수 있다. **전체 설계 시간의 30% 이상을 AI 기반 분석에 투자**한다.

### 1.3 AI 기반 의존성 분석 및 경계 설계

```typescript
// ai-dependency-analyzer.ts
import * as ts from 'typescript';

interface DependencyReport {
  graph: Map<string, string[]>;
  clusters: ModuleCluster[];
  crossBoundaryImports: CrossBoundaryImport[];
  recommendations: string[];
}

interface ModuleCluster {
  name: string;
  modules: string[];
  cohesion: number; // 0-1, 높을수록 응집도 높음
  coupling: number; // 0-1, 낮을수록 결합도 낮음
}

interface CrossBoundaryImport {
  from: string;
  to: string;
  importedSymbols: string[];
  suggestion: 'extract-to-shared' | 'duplicate' | 'event-based' | 'api-contract';
}

async function analyzeDependenciesWithAI(
  projectRoot: string,
): Promise<DependencyReport> {
  // 1단계: 정적 분석으로 import 그래프 생성
  const graph = buildImportGraph(projectRoot);

  // 2단계: AI로 클러스터링 및 경계 제안
  const prompt = `
다음 import 그래프를 분석하여 마이크로 프론트엔드 경계를 제안하라.

## Import 그래프
${serializeGraph(graph)}

## 분석 요구사항
1. 높은 응집도/낮은 결합도 기준으로 모듈 클러스터링
2. 경계를 넘는 import에 대한 해결 전략 제안
3. 공유 라이브러리로 추출해야 할 모듈 식별
4. 순환 의존성 탐지 및 해소 방안

각 클러스터의 cohesion과 coupling 점수를 0-1 범위로 제시하라.`;

  const analysis = await callAI(prompt);
  return analysis as DependencyReport;
}

function buildImportGraph(projectRoot: string): Map<string, string[]> {
  const graph = new Map<string, string[]>();
  // TypeScript Compiler API로 import 관계 추출
  const configPath = ts.findConfigFile(projectRoot, ts.sys.fileExists);
  if (!configPath) return graph;

  const config = ts.readConfigFile(configPath, ts.sys.readFile);
  const parsed = ts.parseJsonConfigFileContent(config.config, ts.sys, projectRoot);

  const program = ts.createProgram(parsed.fileNames, parsed.options);
  for (const sourceFile of program.getSourceFiles()) {
    if (sourceFile.isDeclarationFile) continue;
    const imports: string[] = [];
    ts.forEachChild(sourceFile, (node) => {
      if (ts.isImportDeclaration(node)) {
        const specifier = (node.moduleSpecifier as ts.StringLiteral).text;
        if (specifier.startsWith('.') || specifier.startsWith('@/')) {
          imports.push(specifier);
        }
      }
    });
    graph.set(sourceFile.fileName, imports);
  }

  return graph;
}

function serializeGraph(graph: Map<string, string[]>): string {
  return [...graph.entries()]
    .map(([file, imports]) => `${file}:\n${imports.map((i) => `  → ${i}`).join('\n')}`)
    .join('\n');
}
```

### 2.4 동적 리모트 로딩

```typescript
// dynamic-remote-loader.ts
import { init, loadRemote } from '@module-federation/enhanced/runtime';

interface RemoteConfig {
  name: string;
  entry: string;
  version?: string;
}

// 런타임에 리모트 앱 URL 결정 (환경별, A/B 테스트 등)
async function loadDynamicRemote<T>(
  remoteConfig: RemoteConfig,
  exposedModule: string,
): Promise<T> {
  // 리모트 앱 등록
  await init({
    name: 'hostApp',
    remotes: [
      {
        name: remoteConfig.name,
        entry: remoteConfig.entry,
      },
    ],
  });

  // 모듈 로딩
  const module = await loadRemote<T>(
    `${remoteConfig.name}/${exposedModule}`,
  );

  if (!module) {
    throw new Error(
      `Failed to load ${exposedModule} from ${remoteConfig.name}`,
    );
  }

  return module;
}

// 환경별 리모트 URL 결정
function getRemoteUrl(appName: string, env: string): string {
  const urls: Record<string, Record<string, string>> = {
    dashboardApp: {
      development: 'http://localhost:3001/remoteEntry.js',
      staging: 'https://staging-dashboard.example.com/remoteEntry.js',
      production: 'https://dashboard.example.com/remoteEntry.js',
    },
    settingsApp: {
      development: 'http://localhost:3002/remoteEntry.js',
      staging: 'https://staging-settings.example.com/remoteEntry.js',
      production: 'https://settings.example.com/remoteEntry.js',
    },
  };

  return urls[appName]?.[env] ?? '';
}

export { loadDynamicRemote, getRemoteUrl };
```

### 2.5 타입 안전한 리모트 컴포넌트 래퍼

```tsx
// RemoteComponent.tsx
import React, { Suspense, ComponentType, useEffect, useState } from 'react';

interface RemoteComponentProps {
  remoteName: string;
  exposedModule: string;
  fallback?: React.ReactNode;
  errorFallback?: React.ReactNode;
  props?: Record<string, unknown>;
}

function RemoteComponent({
  remoteName,
  exposedModule,
  fallback = <div>Loading...</div>,
  errorFallback = <div>Failed to load module</div>,
  props = {},
}: RemoteComponentProps) {
  const [Component, setComponent] = useState<ComponentType | null>(null);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    let cancelled = false;

    async function load() {
      try {
        const module = await loadDynamicRemote<{ default: ComponentType }>(
          {
            name: remoteName,
            entry: getRemoteUrl(remoteName, import.meta.env.MODE),
          },
          exposedModule,
        );
        if (!cancelled) {
          setComponent(() => module.default);
        }
      } catch (err) {
        if (!cancelled) {
          setError(err instanceof Error ? err : new Error(String(err)));
        }
      }
    }

    load();
    return () => {
      cancelled = true;
    };
  }, [remoteName, exposedModule]);

  if (error) return <>{errorFallback}</>;
  if (!Component) return <>{fallback}</>;

  return (
    <Suspense fallback={fallback}>
      <ErrorBoundary fallback={errorFallback}>
        <Component {...props} />
      </ErrorBoundary>
    </Suspense>
  );
}

// 에러 바운더리
class ErrorBoundary extends React.Component<
  { fallback: React.ReactNode; children: React.ReactNode },
  { hasError: boolean }
> {
  state = { hasError: false };

  static getDerivedStateFromError(): { hasError: boolean } {
    return { hasError: true };
  }

  render() {
    if (this.state.hasError) return this.props.fallback;
    return this.props.children;
  }
}

export { RemoteComponent };
```

## 3. 독립 배포 전략

> 각 마이크로 FE 앱은 **독립적으로 빌드, 테스트, 배포**되어야 한다. 한 앱의 배포가 다른 앱에 영향을 주지 않는 것이 핵심이다.

### 3.1 앱별 CI/CD 파이프라인

```yaml
# .github/workflows/deploy-dashboard-app.yml
name: Deploy Dashboard App

on:
  push:
    paths:
      - 'apps/dashboard/**'
      - 'packages/shared/**'
    branches: [main]
  pull_request:
    paths:
      - 'apps/dashboard/**'
      - 'packages/shared/**'

env:
  APP_NAME: dashboard-app
  AWS_REGION: ap-northeast-2

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: 'pnpm'

      - run: pnpm install --frozen-lockfile

      # 해당 앱 + 의존 패키지만 빌드
      - run: pnpm --filter dashboard-app... build

      # 해당 앱 테스트만 실행
      - run: pnpm --filter dashboard-app test --coverage

      # 계약 테스트: 다른 앱과의 인터페이스 검증
      - run: pnpm --filter dashboard-app test:contracts

  deploy:
    needs: build-and-test
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - run: pnpm install --frozen-lockfile
```

### 4.1 이벤트 버스 기반 앱 간 통신

```typescript
// packages/shared/event-bus.ts
type EventHandler<T = unknown> = (payload: T) => void;

interface EventBusEvents {
  'auth:login': { userId: string; token: string };
  'auth:logout': undefined;
  'navigation:change': { path: string; params?: Record<string, string> };
  'notification:show': { type: 'success' | 'error' | 'info'; message: string };
  'theme:change': { theme: 'light' | 'dark' };
  'locale:change': { locale: string };
}

class MicroFEEventBus {
  private handlers = new Map<string, Set<EventHandler>>();
  private history = new Map<string, unknown>();

  emit<K extends keyof EventBusEvents>(
    event: K,
    payload: EventBusEvents[K],
  ): void {
    this.history.set(event, payload);
    const eventHandlers = this.handlers.get(event);
    if (eventHandlers) {
      eventHandlers.forEach((handler) => {
        try {
          handler(payload);
        } catch (err) {
          console.error(`Event handler error for ${event}:`, err);
        }
      });
    }
  }

  on<K extends keyof EventBusEvents>(
    event: K,
    handler: EventHandler<EventBusEvents[K]>,
  ): () => void {
    if (!this.handlers.has(event)) {
      this.handlers.set(event, new Set());
    }
    this.handlers.get(event)!.add(handler as EventHandler);

    // 최신 이벤트가 있으면 즉시 전달 (late subscriber 지원)
    if (this.history.has(event)) {
      handler(this.history.get(event) as EventBusEvents[K]);
    }

    return () => {
      this.handlers.get(event)?.delete(handler as EventHandler);
    };
  }

  clear(): void {
    this.handlers.clear();
    this.history.clear();
  }
}

// 전역 싱글턴
const EVENT_BUS_KEY = '__MICRO_FE_EVENT_BUS__';

export function getEventBus(): MicroFEEventBus {
  if (!(window as Record<string, unknown>)[EVENT_BUS_KEY]) {
    (window as Record<string, unknown>)[EVENT_BUS_KEY] = new MicroFEEventBus();
  }
  return (window as Record<string, unknown>)[EVENT_BUS_KEY] as MicroFEEventBus;
}
```

### 4.2 공유 인증 상태

```typescript
// packages/shared/auth-provider.ts
import { getEventBus } from './event-bus';

interface AuthState {
  isAuthenticated: boolean;
  user: { id: string; name: string; roles: string[] } | null;
  token: string | null;
}

const AUTH_STORAGE_KEY = '__MICRO_FE_AUTH__';

// Shell 앱에서 인증 관리, 리모트 앱은 읽기만
export function createAuthProvider() {
  const eventBus = getEventBus();

  function getAuthState(): AuthState {
    const stored = sessionStorage.getItem(AUTH_STORAGE_KEY);
    if (!stored) return { isAuthenticated: false, user: null, token: null };
    return JSON.parse(stored);
  }

  function setAuthState(state: AuthState): void {
    sessionStorage.setItem(AUTH_STORAGE_KEY, JSON.stringify(state));
    if (state.isAuthenticated && state.token) {
      eventBus.emit('auth:login', {
        userId: state.user!.id,
        token: state.token,
      });
    } else {
      eventBus.emit('auth:logout', undefined);
    }
  }

  function getToken(): string | null {
    return getAuthState().token;
  }

  function onAuthChange(callback: (state: AuthState) => void): () => void {
    const unsubLogin = eventBus.on('auth:login', () => callback(getAuthState()));
    const unsubLogout = eventBus.on('auth:logout', () => callback(getAuthState()));
    return () => {
      unsubLogin();
      unsubLogout();
    };
  }

  return { getAuthState, setAuthState, getToken, onAuthChange };
}
```

```typescript
// preload-strategy.ts
interface PreloadRule {
  triggerRoute: string;
  preloadApps: string[];
  priority: 'high' | 'low';
}

const preloadRules: PreloadRule[] = [
  {
    triggerRoute: '/',
    preloadApps: ['dashboardApp'],
    priority: 'high',
  },
  {
    triggerRoute: '/dashboard',
    preloadApps: ['settingsApp'],
    priority: 'low',
  },
];

function setupRouteBasedPreloading(rules: PreloadRule[]): void {
  // 현재 라우트에 맞는 프리로드 규칙 실행
  const currentPath = window.location.pathname;

  for (const rule of rules) {
    if (currentPath.startsWith(rule.triggerRoute)) {
      for (const appName of rule.preloadApps) {
        const url = getRemoteUrl(appName, import.meta.env.MODE);
        if (rule.priority === 'high') {
          // <link rel="preload">로 즉시 로드
          const link = document.createElement('link');
          link.rel = 'preload';
          link.href = url;
          link.as = 'script';
          document.head.appendChild(link);
        } else {
          // requestIdleCallback으로 여유 시간에 로드
          requestIdleCallback(() => {
            const link = document.createElement('link');
            link.rel = 'prefetch';
            link.href = url;
            document.head.appendChild(link);
          });
        }
      }
    }
  }
}

export { setupRouteBasedPreloading, preloadRules };
```

```typescript
async function checkBundleSizeLimit(
  report: BundleReport,
  limits: { totalMaxKB: number; chunkMaxKB: number },
): Promise<{ passed: boolean; violations: string[] }> {
  const violations: string[] = [];
  const totalKB = report.totalSize / 1024;

  if (totalKB > limits.totalMaxKB) {
    violations.push(
      `Total size ${totalKB.toFixed(0)}KB exceeds limit ${limits.totalMaxKB}KB`,
    );
  }

  for (const chunk of report.chunks) {
    const chunkKB = chunk.size / 1024;
    if (chunkKB > limits.chunkMaxKB) {
      violations.push(
        `Chunk "${chunk.name}" ${chunkKB.toFixed(0)}KB exceeds limit ${limits.chunkMaxKB}KB`,
      );
    }
  }

  if (report.duplicates.length > 0) {
    const wastedKB = report.duplicates.reduce((sum, d) => sum + d.wastedBytes, 0) / 1024;
    violations.push(
      `${report.duplicates.length} duplicated modules wasting ${wastedKB.toFixed(0)}KB`,
    );
  }

  return { passed: violations.length === 0, violations };
}
```

## 7. 모노레포 vs 폴리레포 비교

| 항목 | 모노레포 | 폴리레포 |
|------|----------|----------|
| **구조** | 단일 저장소에 모든 앱 | 앱별 별도 저장소 |
| **의존성 관리** | pnpm workspace로 통합 관리 | 각 저장소에서 독립 관리 |
| **공유 코드** | 내부 패키지로 즉시 공유 | npm 패키지 배포 필요 |
| **CI/CD** | 변경 감지 기반 선택적 빌드 | 저장소별 독립 파이프라인 |
| **코드 리뷰** | 전체 변경 맥락 파악 용이 | 앱별 집중 리뷰 가능 |
| **팀 자율성** | 공통 규칙 적용 용이, 자율성 제한 | 팀별 기술 스택 자유 |
| **초기 설정** | Turborepo/Nx 설정 필요 | 별도 설정 불필요 |
| **권장 상황** | 팀 10명 이하, 기술 스택 통일 | 팀 10명 이상, 기술 스택 다양 |
