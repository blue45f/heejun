## 1. 배포 철학: Progressive Delivery 2.0

배포는 릴리즈가 아니라 **관측 가능한 실험**이다. 모든 배포는 Canary에서 시작하고, 메트릭이 안전을 증명할 때만 자동으로 승격된다. AI는 사람이 놓치는 리스크를 사전에 탐지하고, 멀티 베타 환경은 검증 범위를 극대화한다.

### 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **Canary First** | 모든 프로덕션 배포는 Canary(0.1%)에서 시작, 메트릭이 안전을 증명할 때만 승격 |
| **AI 사고 방지** | PR 단계에서 AI가 프로덕션 리스크, 롤백 시 데이터 정합성 이슈를 사전 분석 |
| **환경 수명 관리** | 모든 베타/Preview 환경은 TTL 72시간, 자동 만료로 비용 최적화 |
| **배포 동결 자동화** | 캘린더 연동으로 Code Freeze 기간 자동 감지, Branch Protection 자동 토글 |
| **관측 가능성** | N개 환경 상태를 단일 대시보드에서 실시간 모니터링 |

## 2. AI 배포 사고 방지 시나리오

### 시나리오 1: 프로덕션 리스크 분석

```text
당신은 시니어 SRE + 프로덕션 사고 전문가입니다.
이 PR이 프로덕션에 영향을 줄 리스크를 분석해줘.

## 분석 관점
1. 장애 시나리오: 이 변경이 프로덕션에서 장애를 일으킬 수 있는 구체적 시나리오 3개
2. Blast Radius: 영향받는 사용자 비율, 매출 영향, SLA 위반 가능성
3. 탈출 경로: 각 장애 시나리오별 즉시 복구 방법 (롤백 / Feature Flag OFF / 핫픽스)
4. 의존성 체인: 이 변경이 트리거하는 다운스트림 서비스 영향
5. 시간대 리스크: 배포 시간대별 위험도 (피크 시간 vs 새벽)

## 출력 형식
- 종합 위험도: [LOW|MEDIUM|HIGH|CRITICAL]
- 배포 가능 여부: [즉시 배포|리뷰 후 배포|동결 기간 이후|배포 차단]
- 필수 사전 조건: (배포 전 반드시 확인할 항목)

## PR Diff:
{diff_content}
```

### 시나리오 2: 롤백 시 데이터 정합성 예측

```text
당신은 데이터 정합성 전문가입니다.

## 분석 항목
1. 스키마 변경: 롤백 시 새 컬럼/테이블이 남아있을 때 구버전 코드 호환성

5. 외부 연동: 웹훅/콜백 URL 변경 시 롤백 후 외부 시스템 동기화
```

### 시나리오 3: 배포 전 통합 안전 점검

```text
당신은 릴리즈 매니저입니다.
현재 릴리즈 후보에 포함된 모든 PR 목록을 보고, 통합 배포 시 발생 가능한 충돌 및 리스크를 분석해줘.

## 분석 항목
1. PR 간 파일 충돌: 동일 파일을 수정한 PR이 합쳐질 때 의도치 않은 동작

4. 배포 순서 의존성: 특정 PR이 먼저 배포되어야 하는 순서 제약
5. 통합 테스트 필요 범위: 개별 PR에서는 안전하지만 합쳐지면 위험한 조합

## PR 목록:
{pr_list_with_diffs}
```

### GitHub Actions: AI 사고 방지 워크플로우

```yaml
# .github/workflows/ai-incident-prevention.yml

on:
  pull_request:
    types: [opened, synchronize, ready_for_review]
    branches: [main, release/*]

  pull-requests: write

jobs:

    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm

      - run: pnpm install --frozen-lockfile
      - run: npx tsx scripts/ai-incident-prevention.ts
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          PR_NUMBER: ${{ github.event.pull_request.number }}
```

```typescript
// scripts/ai-incident-prevention.ts
import Anthropic from "@anthropic-ai/sdk";
import { execSync } from "node:child_process";

interface RiskAnalysisResult {
  overallRisk: "LOW" | "MEDIUM" | "HIGH" | "CRITICAL";
  deployability: string;
  scenarios: IncidentScenario[];
  rollbackSafety: RollbackAssessment;
  prerequisites: string[];
}

interface IncidentScenario {
  title: string;
  probability: "LOW" | "MEDIUM" | "HIGH";
  blastRadius: string;
  escapePath: string;
}

interface RollbackAssessment {
  safety: "SAFE" | "CAUTION" | "DANGEROUS";
  dataIssues: DataIssue[];
  strategy: "instant" | "gradual" | "manual-with-script";
}

interface DataIssue {
  type: "schema" | "cache" | "event" | "external";
  description: string;
  mitigation: string;
}

async function analyzePRRisk(): Promise<RiskAnalysisResult> {
  const prNumber = process.env.PR_NUMBER!;
  const diff = execSync(
    `gh pr diff ${prNumber} --repo $GITHUB_REPOSITORY`,
    { encoding: "utf-8", maxBuffer: 10 * 1024 * 1024 },
  );

  const prInfo = JSON.parse(
    execSync(
      `gh pr view ${prNumber} --repo $GITHUB_REPOSITORY --json title,body,files,labels`,
      { encoding: "utf-8" },
    ),
  );

  const anthropic = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY });

  const response = await anthropic.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 4096,
    system: `당신은 시니어 SRE 전문가입니다. PR 분석 결과를 JSON으로 반환하세요.
응답은 반드시 RiskAnalysisResult JSON만 포함하세요.`,
    messages: [
      {
        role: "user",
        content: `PR #${prNumber}: ${prInfo.title}
변경 파일 수: ${prInfo.files.length}
Labels: ${prInfo.labels.map((l: { name: string }) => l.name).join(", ")}

Diff (처음 8000자):
${diff.slice(0, 8000)}

분석 항목:
1. 장애 시나리오 3개 (probability, blastRadius, escapePath 포함)
2. 롤백 안전성 (데이터 정합성 이슈 포함)
3. 배포 가능 여부 및 필수 사전 조건`,
      },
    ],
  });

  const text = response.content
    .filter((b): b is Anthropic.TextBlock => b.type === "text")
    .map((b) => b.text)
    .join("");

  const jsonMatch = text.match(/\{[\s\S]*\}/);
  return JSON.parse(jsonMatch![0]) as RiskAnalysisResult;
}

function formatRiskComment(result: RiskAnalysisResult): string {
  const riskEmoji: Record<string, string> = {
    LOW: "🟢", MEDIUM: "🟡", HIGH: "🟠", CRITICAL: "🔴",
  };

  const scenarios = result.scenarios
    .map(
      (s) =>
        `| ${s.title} | ${s.probability} | ${s.blastRadius} | ${s.escapePath} |`,
    )
    .join("\n");

  const dataIssues = result.rollbackSafety.dataIssues
    .map((d) => `- **[${d.type}]** ${d.description} → ${d.mitigation}`)
    .join("\n");

  return `## ${riskEmoji[result.overallRisk]} AI 배포 사고 방지 분석

**종합 위험도:** ${result.overallRisk}
**배포 가능 여부:** ${result.deployability}

### 장애 시나리오
| 시나리오 | 확률 | 영향 범위 | 탈출 경로 |
|---------|------|----------|----------|
${scenarios}

### 롤백 안전성: ${result.rollbackSafety.safety}
**권장 전략:** ${result.rollbackSafety.strategy}
${dataIssues || "데이터 정합성 이슈 없음"}

### 배포 전 필수 확인
${result.prerequisites.map((p) => `- [ ] ${p}`).join("\n")}`;
}

async function main(): Promise<void> {
  const result = await analyzePRRisk();

  const comment = formatRiskComment(result);
  const prNumber = process.env.PR_NUMBER!;

  execSync(
    `gh pr comment ${prNumber} --repo $GITHUB_REPOSITORY --body ${JSON.stringify(comment)}`,
    { encoding: "utf-8" },
  );

  if (result.overallRisk === "CRITICAL") {
    console.error("CRITICAL 위험도 감지 -- 배포 차단");
    process.exit(1);
  }
}

main();
```

```typescript
// scripts/setup-github-environments.ts
import { execSync } from "node:child_process";

interface EnvironmentConfig {
  name: string;
  protectionRules: ProtectionRule[];
  variables: Record<string, string>;
  deploymentBranchPolicy: BranchPolicy;
}

interface ProtectionRule {
  type: "required_reviewers" | "wait_timer" | "custom";
  reviewers?: string[];
  waitMinutes?: number;
  integrationId?: number;
}

interface BranchPolicy {
  protectedBranches: boolean;
  customBranches?: string[];
}

const ENVIRONMENTS: EnvironmentConfig[] = [
  {
    name: "preview",
    protectionRules: [],
    variables: {
      CDN_DOMAIN: "preview.example.com",
      CACHE_TTL: "300",
      ENV_TTL_HOURS: "72",
    },
    deploymentBranchPolicy: {
      protectedBranches: false,
      customBranches: ["feature/*", "fix/*", "onboard-*"],
    },
  },
  {
    name: "beta",
    protectionRules: [
      { type: "wait_timer", waitMinutes: 5 },
    ],
    variables: {
      CDN_DOMAIN: "beta.example.com",
      CACHE_TTL: "600",
      CANARY_INITIAL_WEIGHT: "1",
    },
    deploymentBranchPolicy: {
      protectedBranches: false,
      customBranches: ["release/*", "main"],
    },
  },
  {
    name: "staging",
    protectionRules: [
      { type: "required_reviewers", reviewers: ["tech-lead-team"] },
      { type: "wait_timer", waitMinutes: 15 },
    ],
    variables: {
      CDN_DOMAIN: "staging.example.com",
      CACHE_TTL: "1800",
      CANARY_INITIAL_WEIGHT: "5",
    },
    deploymentBranchPolicy: {
      protectedBranches: true,
    },
  },
  {
    name: "production",
    protectionRules: [
      { type: "required_reviewers", reviewers: ["sre-team", "tech-lead-team"] },
      { type: "wait_timer", waitMinutes: 30 },
    ],
    variables: {
      CDN_DOMAIN: "app.example.com",
      CACHE_TTL: "86400",
      CANARY_INITIAL_WEIGHT: "0.1",
    },
    deploymentBranchPolicy: {
      protectedBranches: true,
    },
  },
];

function setupEnvironment(env: EnvironmentConfig): void {
  const repo = process.env.GITHUB_REPOSITORY!;

  // 환경 생성/업데이트
  execSync(
    `gh api repos/${repo}/environments/${env.name} -X PUT -f wait_timer=${env.protectionRules.find((r) => r.type === "wait_timer")?.waitMinutes ?? 0}`,
    { encoding: "utf-8" },
  );

  // 변수 설정
  for (const [key, value] of Object.entries(env.variables)) {
    execSync(
      `gh variable set ${key} --env ${env.name} --body "${value}" --repo ${repo}`,
      { encoding: "utf-8" },
    );
  }

  console.log(`Environment 설정 완료: ${env.name}`);
}

function setupAllEnvironments(): void {
  for (const env of ENVIRONMENTS) {
    setupEnvironment(env);
  }
}

export { setupAllEnvironments, ENVIRONMENTS };
export type { EnvironmentConfig };
```

### 3.2 Deployment Protection Rules 커스텀 게이트

```typescript
// scripts/deployment-gate.ts
interface DeploymentGateInput {
  environment: string;
  ref: string;
  prNumber?: number;
  riskLevel?: string;
}

interface GateResult {
  approved: boolean;
  reason: string;
  conditions: GateCondition[];
}

interface GateCondition {
  name: string;
  passed: boolean;
  detail: string;
}

async function evaluateDeploymentGate(
  input: DeploymentGateInput,
): Promise<GateResult> {
  const conditions: GateCondition[] = [];

  // 1. Code Freeze 체크
  const isCodeFrozen = await checkCodeFreeze();
  conditions.push({
    name: "Code Freeze",
    passed: !isCodeFrozen,
    detail: isCodeFrozen ? "현재 Code Freeze 기간입니다" : "Code Freeze 아님",
  });

  // 2. AI 위험도 체크
  if (input.riskLevel === "CRITICAL") {
    conditions.push({
      name: "AI Risk Level",
      passed: false,
      detail: "CRITICAL 위험도 -- 배포 차단",
    });
  } else {
    conditions.push({
      name: "AI Risk Level",
      passed: true,
      detail: `위험도: ${input.riskLevel ?? "UNKNOWN"}`,
    });
  }

  // 3. 업무시간 체크 (프로덕션만)
  if (input.environment === "production") {
    const now = new Date();
    const hour = now.getUTCHours() + 9; // KST
    const isBusinessHours = hour >= 10 && hour <= 17;
    const isWeekday = now.getDay() >= 1 && now.getDay() <= 5;
    const passed = isBusinessHours && isWeekday;
    conditions.push({
      name: "Business Hours",
      passed,
      detail: passed
        ? "업무시간 내 배포"
        : "비업무시간 -- 긴급 배포는 SRE 승인 필요",
    });
  }

  // 4. 이전 환경 배포 성공 여부
  const previousEnv = getPreviousEnvironment(input.environment);
  if (previousEnv) {
    const prevSuccess = await checkPreviousDeployment(previousEnv, input.ref);
    conditions.push({
      name: `${previousEnv} 검증 완료`,
      passed: prevSuccess,
      detail: prevSuccess
        ? `${previousEnv}에서 검증 완료`
        : `${previousEnv} 배포가 먼저 필요합니다`,
    });
  }

  const allPassed = conditions.every((c) => c.passed);
  return {
    approved: allPassed,
    reason: allPassed
      ? "모든 게이트 조건 통과"
      : conditions.filter((c) => !c.passed).map((c) => c.detail).join(", "),
    conditions,
  };
}

function getPreviousEnvironment(env: string): string | null {
  const order = ["preview", "beta", "staging", "production"];
  const idx = order.indexOf(env);
  return idx > 0 ? order[idx - 1] : null;
}

async function checkCodeFreeze(): Promise<boolean> {
  // Google Calendar API 또는 내부 API에서 Code Freeze 일정 조회
  const response = await fetch(
    `${process.env.INTERNAL_API_URL}/api/code-freeze/status`,
  );
  const data = (await response.json()) as { frozen: boolean };
  return data.frozen;
}

async function checkPreviousDeployment(
  env: string,
  ref: string,
): Promise<boolean> {
  const response = await fetch(
    `${process.env.INTERNAL_API_URL}/api/deployments/${env}/${ref}/status`,
  );
  const data = (await response.json()) as { success: boolean };
  return data.success;
}

export { evaluateDeploymentGate };
export type { DeploymentGateInput, GateResult };
```

## 4. 동적 S3+CloudFront 원클릭 프로비저닝

### GitHub Actions: 전체 코드

```yaml
# .github/workflows/dynamic-environment.yml
name: Dynamic Environment Provisioning

on:
  workflow_dispatch:
    inputs:
      environment_name:
        description: "환경 이름 (영문, 하이픈만)"
        required: true
        type: string
      branch:
        description: "배포할 브랜치"
        required: true
        default: "main"
        type: string
      ttl_hours:
        description: "환경 수명 (시간)"
        required: false
        default: "72"
        type: string
  pull_request:
    types: [opened, synchronize, reopened]

permissions:
  id-token: write
  contents: read
  pull-requests: write
  deployments: write

env:
  AWS_REGION: ap-northeast-2
  PREVIEW_BUCKET: ${{ vars.PREVIEW_BUCKET }}
  CF_DISTRIBUTION_ID: ${{ vars.CF_DISTRIBUTION_ID }}

jobs:
  determine-env-name:
    runs-on: ubuntu-latest
    outputs:
      env_name: ${{ steps.name.outputs.value }}
      ttl: ${{ steps.ttl.outputs.value }}
    steps:
      - id: name
        run: |
          if [ "${{ github.event_name }}" = "pull_request" ]; then
            echo "value=pr-${{ github.event.pull_request.number }}" >> "$GITHUB_OUTPUT"
          else
            echo "value=${{ inputs.environment_name }}" >> "$GITHUB_OUTPUT"
          fi
      - id: ttl
        run: |
          if [ "${{ github.event_name }}" = "pull_request" ]; then
            echo "value=72" >> "$GITHUB_OUTPUT"
          else
            echo "value=${{ inputs.ttl_hours || '72' }}" >> "$GITHUB_OUTPUT"
          fi

  provision-and-deploy:
    needs: determine-env-name
    runs-on: ubuntu-latest
    environment:
      name: preview
      url: https://${{ vars.CDN_DOMAIN }}/${{ needs.determine-env-name.outputs.env_name }}/
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event_name == 'pull_request' && github.head_ref || inputs.branch }}

      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm

      - run: pnpm install --frozen-lockfile

      - name: Build application
        run: pnpm build
```

```typescript
// scripts/ttl-cleanup.ts
import {
  S3Client,
  ListObjectsV2Command,
  DeleteObjectsCommand,
  HeadObjectCommand,
} from "@aws-sdk/client-s3";
import {
  CloudFrontClient,
  CreateInvalidationCommand,
} from "@aws-sdk/client-cloudfront";
import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import {
  DynamoDBDocumentClient,
  ScanCommand,
  UpdateCommand,
} from "@aws-sdk/lib-dynamodb";

interface ExpiredEnvironment {
  envName: string;
  expiresAt: string;
  createdBy: string;
  objectCount: number;
}

async function findExpiredEnvironments(
  docClient: DynamoDBDocumentClient,
): Promise<ExpiredEnvironment[]> {
  const now = Math.floor(Date.now() / 1000);

  const result = await docClient.send(
    new ScanCommand({
      TableName: "preview-environments",
      FilterExpression: "#s = :active AND #ttl < :now",
      ExpressionAttributeNames: { "#s": "status", "#ttl": "ttlEpoch" },
      ExpressionAttributeValues: { ":active": "active", ":now": now },
    }),
  );

  return (result.Items ?? []).map((item) => ({
    envName: item.envName as string,
    expiresAt: item.expiresAt as string,
    createdBy: item.createdBy as string,
    objectCount: 0,
  }));
}

async function deleteS3Prefix(
  s3: S3Client,
  bucket: string,
  prefix: string,
): Promise<number> {
  let deleted = 0;
  let continuationToken: string | undefined;

  do {
    const list = await s3.send(
      new ListObjectsV2Command({
        Bucket: bucket,
        Prefix: prefix,
        ContinuationToken: continuationToken,
      }),
    );

    if (list.Contents?.length) {
      await s3.send(
        new DeleteObjectsCommand({
          Bucket: bucket,
          Delete: {
            Objects: list.Contents.map((obj) => ({ Key: obj.Key })),
          },
        }),
      );
      deleted += list.Contents.length;
    }

    continuationToken = list.NextContinuationToken;
  } while (continuationToken);

  return deleted;
}

async function notifySlack(
  webhookUrl: string,
  environments: ExpiredEnvironment[],
): Promise<void> {
  const envList = environments
    .map((e) => `- \`${e.envName}\` (만료: ${e.expiresAt}, 파일: ${e.objectCount}개)`)
    .join("\n");

  await fetch(webhookUrl, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      text: `*TTL 만료 환경 정리 완료*\n정리된 환경: ${environments.length}개\n${envList}`,
    }),
  });
}

async function runCleanup(): Promise<void> {
  const region = "ap-northeast-2";
  const bucket = process.env.PREVIEW_BUCKET!;
  const distributionId = process.env.CF_DISTRIBUTION_ID!;

  const s3 = new S3Client({ region });
  const cf = new CloudFrontClient({ region });
  const docClient = DynamoDBDocumentClient.from(
    new DynamoDBClient({ region }),
  );

  const expired = await findExpiredEnvironments(docClient);

  if (expired.length === 0) {
    console.log("만료된 환경 없음");
    return;
  }

  console.log(`만료 환경 ${expired.length}개 정리 시작`);

  for (const env of expired) {
    const prefix = `${env.envName}/`;
    env.objectCount = await deleteS3Prefix(s3, bucket, prefix);

    await cf.send(
      new CreateInvalidationCommand({
        DistributionId: distributionId,
        InvalidationBatch: {
          CallerReference: `ttl-${env.envName}-${Date.now()}`,
          Paths: { Quantity: 1, Items: [`/${env.envName}/*`] },
        },
      }),
    );

    await docClient.send(
      new UpdateCommand({
        TableName: "preview-environments",
        Key: { envName: env.envName },
        UpdateExpression: "SET #s = :expired, deletedAt = :now",
        ExpressionAttributeNames: { "#s": "status" },
        ExpressionAttributeValues: {
          ":expired": "expired",
          ":now": new Date().toISOString(),
        },
      }),
    );

    console.log(`정리 완료: ${env.envName} (${env.objectCount}개 파일)`);
  }

  if (process.env.SLACK_WEBHOOK_URL) {
    await notifySlack(process.env.SLACK_WEBHOOK_URL, expired);
  }
}

runCleanup();
```

```typescript
// scripts/environment-dashboard.ts
import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import {
  DynamoDBDocumentClient,
  ScanCommand,
} from "@aws-sdk/lib-dynamodb";

interface EnvironmentStatus {
  name: string;
  url: string;
  branch: string;
  commitSha: string;
  status: "active" | "expired" | "deploying" | "failed";
  health: "healthy" | "degraded" | "down" | "unknown";
  createdAt: string;
  expiresAt: string;
  remainingHours: number;
  metrics: EnvironmentMetrics;
}

interface EnvironmentMetrics {
  p99Latency: number;
  errorRate: number;
  requestsPerMinute: number;
  lastHealthCheck: string;
}

interface DashboardData {
  timestamp: string;
  totalEnvironments: number;
  activeEnvironments: number;
  expiringWithin24h: number;
  environments: EnvironmentStatus[];
  matrix: EnvironmentMatrix;
}

interface EnvironmentMatrix {
  headers: string[];
  rows: MatrixRow[];
}

interface MatrixRow {
  feature: string;
  cells: MatrixCell[];
}

interface MatrixCell {
  environment: string;
  deployed: boolean;
  version: string;
  flagEnabled: boolean;
}

async function buildDashboard(): Promise<DashboardData> {
  const docClient = DynamoDBDocumentClient.from(
    new DynamoDBClient({ region: "ap-northeast-2" }),
  );

  const result = await docClient.send(
    new ScanCommand({
      TableName: "preview-environments",
      FilterExpression: "#s = :active",
      ExpressionAttributeNames: { "#s": "status" },
      ExpressionAttributeValues: { ":active": "active" },
    }),
  );

  const now = Date.now();
  const environments: EnvironmentStatus[] = (result.Items ?? []).map(
    (item) => {
      const expiresAt = new Date(item.expiresAt as string).getTime();
      const remainingHours = Math.max(
        0,
        Math.round((expiresAt - now) / 3600_000),
      );

      return {
        name: item.envName as string,
        url: item.envUrl as string,
        branch: item.branch as string,
        commitSha: item.commitSha as string,
        status: "active",
        health: "unknown",
        createdAt: item.createdAt as string,
        expiresAt: item.expiresAt as string,
        remainingHours,
        metrics: {
          p99Latency: 0,
          errorRate: 0,
          requestsPerMinute: 0,
          lastHealthCheck: "",
        },
      };
    },
  );

  // 헬스체크 실행
  for (const env of environments) {
    try {
      const start = Date.now();
      const response = await fetch(`${env.url}health`);
      const latency = Date.now() - start;

      env.health = response.ok ? "healthy" : "degraded";
      env.metrics.p99Latency = latency;
      env.metrics.lastHealthCheck = new Date().toISOString();
    } catch {
      env.health = "down";
    }
  }

  const expiringWithin24h = environments.filter(
    (e) => e.remainingHours <= 24,
  ).length;

  return {
    timestamp: new Date().toISOString(),
    totalEnvironments: environments.length,
    activeEnvironments: environments.filter((e) => e.health === "healthy")
      .length,
    expiringWithin24h,
    environments,
    matrix: {
      headers: environments.map((e) => e.name),
      rows: [],
    },
  };
}

function renderDashboardMarkdown(data: DashboardData): string {
  const statusIcon = (health: string): string => {
    const icons: Record<string, string> = {
      healthy: "🟢",
      degraded: "🟡",
      down: "🔴",
      unknown: "⚪",
    };
    return icons[health] ?? "⚪";
  };

  const envRows = data.environments
    .map(
      (e) =>
        `| ${statusIcon(e.health)} ${e.name} | ${e.branch} | \`${e.commitSha.slice(0, 8)}\` | ${e.remainingHours}h | ${e.metrics.p99Latency}ms | [열기](${e.url}) |`,
    )
    .join("\n");

  return `# 배포 매트릭스 대시보드

**갱신:** ${data.timestamp}
**총 환경:** ${data.totalEnvironments} | **활성:** ${data.activeEnvironments} | **24시간 내 만료:** ${data.expiringWithin24h}

## 환경 상태

| 환경 | 브랜치 | 커밋 | 남은 시간 | P99 | 링크 |
|------|--------|------|----------|-----|------|
${envRows}
`;
}

export { buildDashboard, renderDashboardMarkdown };
export type { DashboardData, EnvironmentStatus };
```

```typescript
      errorRateBelow: 0.01,
      p99LatencyBelow: 500,
      sampleSizeMin: 5000,
    },
    autoPromote: true,
  },
  {
    percentage: 50,
    minDuration: 240,
    requiredMetrics: {
      errorRateBelow: 0.005,
      p99LatencyBelow: 500,
      sampleSizeMin: 50000,
    },
    autoPromote: false, // 50->100은 수동 승인 필요
  },
  {
    percentage: 100,
    minDuration: 0,
    requiredMetrics: {
      errorRateBelow: 0.005,
      p99LatencyBelow: 500,
      sampleSizeMin: 0,
    },
    autoPromote: false,
  },
];

interface MetricsSnapshot {
  errorRate: number;
  p99Latency: number;
  sampleSize: number;
  timestamp: string;
}

async function fetchCurrentMetrics(
  flagKey: string,
): Promise<MetricsSnapshot> {
  const response = await fetch(
    `${process.env.METRICS_API_URL}/api/flags/${flagKey}/metrics`,
  );
  return (await response.json()) as MetricsSnapshot;
}

async function updateFlagPercentage(
  flagKey: string,
  percentage: number,
): Promise<void> {
  await fetch(
    `${process.env.FEATURE_FLAG_API_URL}/api/flags/${flagKey}/rollout`,
    {
      method: "PATCH",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ percentage }),
    },
  );
}

async function evaluatePromotion(
  rollout: FeatureFlagRollout,
): Promise<"promote" | "hold" | "rollback"> {
  const currentStage = rollout.stages[rollout.currentStage];
  if (!currentStage) return "hold";

  const metrics = await fetchCurrentMetrics(rollout.flagKey);

  // 롤백 조건: 에러율이 임계값의 3배 이상
  if (metrics.errorRate > currentStage.requiredMetrics.errorRateBelow * 3) {
    return "rollback";
  }

  // 승격 조건: 모든 메트릭이 임계값 이하 + 최소 지속 시간 충족
  const lastPromoted = new Date(rollout.lastPromotedAt).getTime();
  const elapsedMinutes = (Date.now() - lastPromoted) / 60_000;

  if (elapsedMinutes < currentStage.minDuration) {
    return "hold";
  }

  if (
    metrics.errorRate <= currentStage.requiredMetrics.errorRateBelow &&
    metrics.p99Latency <= currentStage.requiredMetrics.p99LatencyBelow &&
    metrics.sampleSize >= currentStage.requiredMetrics.sampleSizeMin
  ) {
    return "promote";
  }

  return "hold";
}

async function runRolloutLoop(
  rollout: FeatureFlagRollout,
): Promise<void> {
  const decision = await evaluatePromotion(rollout);

  switch (decision) {
    case "promote": {
      const nextStageIdx = rollout.currentStage + 1;
      if (nextStageIdx >= rollout.stages.length) {
        rollout.status = "completed";
        console.log(`${rollout.flagKey}: 롤아웃 완료 (100%)`);
        return;
      }

      const nextStage = rollout.stages[nextStageIdx];

      if (!nextStage.autoPromote && nextStageIdx === rollout.stages.length - 1) {
        console.log(
          `${rollout.flagKey}: ${nextStage.percentage}% 승격 대기 (수동 승인 필요)`,
        );
        await notifySlackForApproval(rollout, nextStage.percentage);
        return;
      }

      await updateFlagPercentage(rollout.flagKey, nextStage.percentage);
      rollout.currentStage = nextStageIdx;
      rollout.lastPromotedAt = new Date().toISOString();
      console.log(
        `${rollout.flagKey}: ${nextStage.percentage}%로 승격`,
      );
      break;
    }
    case "rollback": {
      await updateFlagPercentage(rollout.flagKey, 0);
      rollout.status = "rolled-back";
      console.log(`${rollout.flagKey}: 롤백 (0%)`);
      await notifySlackRollback(rollout);
      break;
    }
    case "hold": {
      const stage = rollout.stages[rollout.currentStage];
      console.log(
        `${rollout.flagKey}: ${stage.percentage}% 유지 (조건 미충족)`,
      );
      break;
    }
  }
}

async function notifySlackForApproval(
  rollout: FeatureFlagRollout,
  nextPercentage: number,
): Promise<void> {
  await fetch(process.env.SLACK_WEBHOOK_URL!, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      text: `*Feature Flag 승격 승인 요청*\nFlag: \`${rollout.flagKey}\`\n현재: ${rollout.stages[rollout.currentStage].percentage}% → 다음: ${nextPercentage}%\n승인하려면 \`/flag-promote ${rollout.flagKey}\` 실행`,
    }),
  });
}

async function notifySlackRollback(
  rollout: FeatureFlagRollout,
): Promise<void> {
  await fetch(process.env.SLACK_WEBHOOK_URL!, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      text: `*Feature Flag 자동 롤백*\nFlag: \`${rollout.flagKey}\`\n사유: 에러율 임계값 초과\n즉시 조사가 필요합니다.`,
    }),
  });
}

export {
  runRolloutLoop,
  evaluatePromotion,
  FIVE_STAGE_ROLLOUT,
};
export type { FeatureFlagRollout, RolloutStage };
```

## 9. 배포 동결(Code Freeze) 자동화

### 캘린더 연동 + GitHub Branch Protection 자동 토글

```typescript
// scripts/code-freeze-automation.ts
import { execSync } from "node:child_process";

interface CodeFreezeSchedule {
  id: string;
  title: string;
  startTime: string;
  endTime: string;
  reason: string;
  exceptions: string[]; // 허용되는 라벨 (예: "hotfix", "security")
}

interface BranchProtectionState {
  branch: string;
  enforcedBefore: boolean;
  requiredReviewers: number;
  restrictions: string[];
}

async function fetchCodeFreezeSchedule(): Promise<CodeFreezeSchedule[]> {
  // Google Calendar API에서 "Code Freeze" 이벤트 조회
  const calendarId = process.env.GOOGLE_CALENDAR_ID!;
  const apiKey = process.env.GOOGLE_API_KEY!;

  const now = new Date().toISOString();
  const oneWeekLater = new Date(
    Date.now() + 7 * 86400_000,
  ).toISOString();

  const response = await fetch(
    `https://www.googleapis.com/calendar/v3/calendars/${calendarId}/events?` +
      `key=${apiKey}&timeMin=${now}&timeMax=${oneWeekLater}&q=Code+Freeze`,
  );

  const data = (await response.json()) as {
    items: Array<{
      id: string;
      summary: string;
      start: { dateTime: string };
      end: { dateTime: string };
      description?: string;
    }>;
  };

  return data.items.map((event) => ({
    id: event.id,
    title: event.summary,
    startTime: event.start.dateTime,
    endTime: event.end.dateTime,
    reason: event.description ?? "정기 Code Freeze",
    exceptions: ["hotfix", "security"],
  }));
}

function isCurrentlyFrozen(
  schedules: CodeFreezeSchedule[],
): CodeFreezeSchedule | null {
  const now = Date.now();
  return (
    schedules.find((s) => {
      const start = new Date(s.startTime).getTime();
      const end = new Date(s.endTime).getTime();
      return now >= start && now <= end;
    }) ?? null
  );
}

function enableCodeFreeze(repo: string, branches: string[]): void {
  for (const branch of branches) {
    // Branch Protection 강화: 머지 차단
    execSync(
      `gh api repos/${repo}/branches/${branch}/protection -X PUT \
        -f "required_status_checks[strict]=true" \
        -f "enforce_admins=true" \
        -f "required_pull_request_reviews[required_approving_review_count]=99" \
        -f "restrictions=null"`,
      { encoding: "utf-8" },
    );

    console.log(`Code Freeze 활성화: ${branch}`);
  }

  // Slack 알림
  notifyCodeFreezeStatus("activated", branches);
}

function disableCodeFreeze(repo: string, branches: string[]): void {
  for (const branch of branches) {
    // Branch Protection 원복
    execSync(
      `gh api repos/${repo}/branches/${branch}/protection -X PUT \
        -f "required_status_checks[strict]=true" \
        -f "enforce_admins=false" \
        -f "required_pull_request_reviews[required_approving_review_count]=1" \
        -f "restrictions=null"`,
      { encoding: "utf-8" },
    );

    console.log(`Code Freeze 해제: ${branch}`);
  }

  notifyCodeFreezeStatus("deactivated", branches);
}

function notifyCodeFreezeStatus(
  action: "activated" | "deactivated",
  branches: string[],
): void {
  const webhookUrl = process.env.SLACK_WEBHOOK_URL;
  if (!webhookUrl) return;

  const message =
    action === "activated"
      ? `*Code Freeze 활성화*\n대상 브랜치: ${branches.map((b) => `\`${b}\``).join(", ")}\n긴급 배포는 \`hotfix\` 또는 \`security\` 라벨 PR만 허용됩니다.`
      : `*Code Freeze 해제*\n대상 브랜치: ${branches.map((b) => `\`${b}\``).join(", ")}\n정상 배포가 가능합니다.`;

  fetch(webhookUrl, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ text: message }),
  });
}

async function runCodeFreezeCheck(): Promise<void> {
  const repo = process.env.GITHUB_REPOSITORY!;
  const targetBranches = ["main", "release/current"];

  const schedules = await fetchCodeFreezeSchedule();
  const activeFreeeze = isCurrentlyFrozen(schedules);

  if (activeFreeeze) {
    console.log(`Code Freeze 감지: ${activeFreeeze.title}`);
    console.log(`종료: ${activeFreeeze.endTime}`);
    enableCodeFreeze(repo, targetBranches);
  } else {
    console.log("Code Freeze 없음 -- 정상 상태");
    disableCodeFreeze(repo, targetBranches);
  }
}

export {
  runCodeFreezeCheck,
  fetchCodeFreezeSchedule,
  isCurrentlyFrozen,
};
export type { CodeFreezeSchedule };
```

## 10. 배포 체크리스트

### Preview / Beta 배포

- [ ] PR에 AI 사고 방지 분석 결과가 코멘트로 게시되었는가
- [ ] 위험도가 HIGH 이상일 경우 시니어 리뷰어가 배정되었는가
- [ ] Preview 환경이 자동 생성되고 TTL이 설정되었는가
- [ ] E2E 테스트가 Preview 환경에서 통과했는가
- [ ] Feature Flag가 설정된 경우 0.1% 단계에서 시작하는가

### Staging 배포

- [ ] Beta 환경에서 최소 24시간 검증을 완료했는가
- [ ] Canary 메트릭(에러율, P99 레이턴시)이 임계값 이하인가
- [ ] 롤백 안전성 분석에서 DANGEROUS가 아닌가
- [ ] 배포 순서 의존성이 있는 PR이 먼저 배포되었는가

### Production 배포

- [ ] Code Freeze 기간이 아닌가 (자동 체크)
- [ ] GitHub Environment Protection Rules 승인을 받았는가
- [ ] Canary 0.1%에서 시작하여 메트릭 기반 자동 프로모션이 설정되었는가
- [ ] 롤백 스크립트가 준비되었는가
- [ ] 배포 후 30분간 모니터링 담당자가 지정되었는가
- [ ] 배포 매트릭스 대시보드에서 모든 환경 상태가 정상인가

### 긴급 배포 (Code Freeze 기간)

- [ ] PR에 `hotfix` 또는 `security` 라벨이 붙어있는가
- [ ] SRE 팀 승인을 받았는가
- [ ] 변경 범위가 최소한인가 (핫픽스만 포함)
- [ ] 롤백 계획이 문서화되었는가
