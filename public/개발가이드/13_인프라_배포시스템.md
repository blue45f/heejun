## 1. 멀티 베타 아키텍처 개요

### 1.1 핵심 설계 원칙

| 원칙 | 설명 |
|------|------|
| **PR 단위 격리** | 모든 PR이 독립된 S3 경로 + CloudFront Functions KVS 라우팅으로 격리된다 |
| **완전 자동화** | CDK Pipeline이 PR 생성 시 스택 프로비저닝, 머지/닫힘 시 자동 삭제 |
| **Multi-CDN 내결함성** | Route53 Health Check + CloudFront + Cloudflare Failover로 다운타임 제로 |
| **AI 기반 FinOps** | Cost Anomaly Detection + AI 분석으로 비용 이상 실시간 탐지 및 자동 대응 |
| **Edge-First** | CloudFront Functions KVS, Cloudflare Workers 등 Edge Computing 활용 극대화 |
| **비용 가드레일** | AWS Budgets + SNS + Lambda 연계로 예산 초과 자동 차단 |

### 1.2 전체 아키텍처 흐름

```
PR 생성
  |
  v
GitHub Actions -> CDK Pipeline
  |
  +-- S3 버킷 경로 생성 (beta/{pr-number}/)
  +-- CloudFront Functions KVS에 라우팅 규칙 등록
  +-- Route53 가중치 레코드 등록
  +-- Cloudflare DNS Failover 설정
  |
  v
빌드 & 배포
  |
  +-- 프론트엔드 빌드 결과물을 S3 경로에 업로드
  +-- CloudFront 캐시 무효화
  +-- PR에 베타 URL 코멘트 자동 등록
  |
  v
Edge 라우팅 (Multi-CDN)
  |
  +-- CloudFront Functions -> KVS에서 PR 매핑 조회
  +-- Route53 Health Check로 CF/Cloudflare 자동 전환
  +-- Edge에서 A/B 테스트, 카나리 라우팅 처리
  |
  v
FinOps 자동화
  |
  +-- Cost Anomaly Detection 실시간 모니터링
  +-- AI 분석 -> 이상 비용 근본 원인 자동 진단
  +-- Budgets + SNS + Lambda -> 예산 초과 시 자동 차단
  |
  v
PR 머지 또는 닫힘
  |
  v
CDK Pipeline: 스택 자동 삭제
  |
  +-- S3 경로 정리
  +-- KVS 라우팅 규칙 제거
  +-- Route53/Cloudflare 레코드 제거
  +-- Cost Anomaly Monitor 정리
```

## 2. CDK v2 L3 Constructs 기반 인프라

### 2.1 L3 Construct: MultiBetaDistribution

L3 Construct는 여러 L2 리소스를 조합하여 비즈니스 로직 단위의 고수준 추상화를 제공한다. PR별 베타 환경에 필요한 S3, CloudFront, Route53, WAF, 모니터링을 하나의 Construct로 캡슐화한다.

```typescript
// lib/constructs/multi-beta-distribution.ts
import * as cdk from 'aws-cdk-lib';
import * as s3 from 'aws-cdk-lib/aws-s3';
import * as cloudfront from 'aws-cdk-lib/aws-cloudfront';
import * as origins from 'aws-cdk-lib/aws-cloudfront-origins';
import * as route53 from 'aws-cdk-lib/aws-route53';
import * as route53Targets from 'aws-cdk-lib/aws-route53-targets';
import * as acm from 'aws-cdk-lib/aws-certificatemanager';
import * as cloudwatch from 'aws-cdk-lib/aws-cloudwatch';
import * as sns from 'aws-cdk-lib/aws-sns';
import * as wafv2 from 'aws-cdk-lib/aws-wafv2';
import { Construct } from 'constructs';

export interface MultiBetaDistributionProps {
  /** PR 번호 */
  prNumber: number;
  /** 커밋 해시 */
  commitHash: string;
  /** 기본 도메인 (예: example.com) */
  domainName: string;
  /** Route53 호스팅 영역 ID */
  hostedZoneId: string;
  /** us-east-1에 발급된 와일드카드 ACM 인증서 ARN */
  certificateArn: string;
  /** 환경 TTL (일) */
  ttlDays: number;
  /** CloudFront Functions KVS Store ID */
  kvsStoreId: string;
  /** WAF ACL ARN (선택) */
  wafAclArn?: string;
  /** 알림 SNS Topic ARN (선택) */
  alertTopicArn?: string;
}

/**
 * L3 Construct: PR별 완전한 베타 환경을 프로비저닝한다.
 *
 * 포함 리소스:
 * - S3 버킷 (격리된 PR별 경로)
 * - CloudFront Distribution (OAC, KVS 라우팅, SPA Fallback)
 * - Route53 A 레코드
 * - CloudWatch 알람 (4xx/5xx 에러율, 대역폭)
 * - 비용 추적 태그
 */
export class MultiBetaDistribution extends Construct {
  public readonly distribution: cloudfront.Distribution;
  public readonly bucket: s3.Bucket;
  public readonly betaDomain: string;
  public readonly distributionUrl: string;

  constructor(scope: Construct, id: string, props: MultiBetaDistributionProps) {
    super(scope, id);

    const betaSubdomain = `pr-${props.prNumber}.beta.${props.domainName}`;
    this.betaDomain = betaSubdomain;

    // --- S3 버킷: PR별 격리, 자동 만료 ---
    this.bucket = new s3.Bucket(this, 'Bucket', {
      bucketName: `beta-${props.prNumber}-${props.commitHash.slice(0, 8)}`,
      removalPolicy: cdk.RemovalPolicy.DESTROY,
      autoDeleteObjects: true,
      blockPublicAccess: s3.BlockPublicAccess.BLOCK_ALL,
      encryption: s3.BucketEncryption.S3_MANAGED,
      enforceSSL: true,
      versioned: false,
      lifecycleRules: [
        {
          id: 'auto-expire',
          expiration: cdk.Duration.days(props.ttlDays),
        },
        {
          id: 'abort-incomplete-multipart',
          abortIncompleteMultipartUploadAfter: cdk.Duration.days(1),
        },
      ],
    });

    // --- CloudFront Functions: KVS 라우팅 + SPA Fallback ---
    const kvsRoutingFunction = new cloudfront.Function(this, 'KvsRouting', {
      code: cloudfront.FunctionCode.fromInline(`
        import cf from 'cloudfront';
        const kvsHandle = cf.kvs('${props.kvsStoreId}');

        async function handler(event) {
          const request = event.request;
          const uri = request.uri;

          // KVS에서 PR 라우팅 정보 조회
          try {
            const betaPr = request.headers['x-beta-pr']
              ? request.headers['x-beta-pr'].value
              : (request.querystring['beta'] ? request.querystring['beta'].value : null);

            if (betaPr) {
              const routeConfig = await kvsHandle.get('pr-' + betaPr);
              if (routeConfig) {
                const config = JSON.parse(routeConfig);
                request.headers['x-beta-origin'] = { value: config.bucket };
                request.headers['x-beta-routed'] = { value: 'true' };
              }
            }
          } catch (e) {
            // KVS 조회 실패 시 기본 오리진 유지
          }

          // SPA Fallback: 확장자 없는 경로는 index.html로
          if (!uri.includes('.')) {
            request.uri = '/index.html';
          }

          return request;
        }
      `),
      runtime: cloudfront.FunctionRuntime.JS_2_0,
      comment: `KVS routing + SPA fallback for PR #${props.prNumber}`,
      keyValueStore: cloudfront.KeyValueStore.fromKeyValueStoreArn(
        this,
        'KvsStore',
        `arn:aws:cloudfront::${cdk.Aws.ACCOUNT_ID}:key-value-store/${props.kvsStoreId}`,
      ),
    });

    // --- ACM 인증서 ---
    const certificate = acm.Certificate.fromCertificateArn(
      this,
      'Certificate',
      props.certificateArn,
    );

    // --- CloudFront Distribution ---
    this.distribution = new cloudfront.Distribution(this, 'Distribution', {
      defaultBehavior: {
        origin: origins.S3BucketOrigin.withOriginAccessControl(this.bucket),
        viewerProtocolPolicy: cloudfront.ViewerProtocolPolicy.REDIRECT_TO_HTTPS,
        cachePolicy: cloudfront.CachePolicy.CACHING_OPTIMIZED,
        responseHeadersPolicy:
          cloudfront.ResponseHeadersPolicy.CORS_ALLOW_ALL_ORIGINS_WITH_PREFLIGHT_AND_SECURITY_HEADERS,
        functionAssociations: [
          {
            function: kvsRoutingFunction,
            eventType: cloudfront.FunctionEventType.VIEWER_REQUEST,
          },
        ],
      },
      domainNames: [betaSubdomain],
      certificate,
      defaultRootObject: 'index.html',
      minimumProtocolVersion: cloudfront.SecurityPolicyProtocol.TLS_V1_2_2021,
      httpVersion: cloudfront.HttpVersion.HTTP2_AND_3,
      webAclId: props.wafAclArn,
      errorResponses: [
        {
          httpStatus: 403,
          responseHttpStatus: 200,
          responsePagePath: '/index.html',
          ttl: cdk.Duration.minutes(5),
        },
        {
          httpStatus: 404,
          responseHttpStatus: 200,
          responsePagePath: '/index.html',
          ttl: cdk.Duration.minutes(5),
        },
      ],
      comment: `Beta PR #${props.prNumber} | ${props.commitHash.slice(0, 8)}`,
    });

    // --- 태그: 비용 추적 + 자동 정리 ---
    const tagTargets = [this.bucket, this.distribution];
    const tags: Record<string, string> = {
      Environment: 'beta',
      PRNumber: String(props.prNumber),
      ManagedBy: 'cdk-multi-beta',
      CommitHash: props.commitHash.slice(0, 8),
      ExpiresAt: new Date(
        Date.now() + props.ttlDays * 86400000,
      ).toISOString(),
    };

    for (const target of tagTargets) {
      for (const [key, value] of Object.entries(tags)) {
        cdk.Tags.of(target).add(key, value);
      }
    }

    // --- Route53 A 레코드 ---
    const hostedZone = route53.HostedZone.fromHostedZoneAttributes(
      this,
      'HostedZone',
      {
        hostedZoneId: props.hostedZoneId,
        zoneName: props.domainName,
      },
    );

    new route53.ARecord(this, 'AliasRecord', {
      zone: hostedZone,
      recordName: betaSubdomain,
      target: route53.RecordTarget.fromAlias(
        new route53Targets.CloudFrontTarget(this.distribution),
      ),
    });

    // --- CloudWatch 알람 ---
    const alertTopic = props.alertTopicArn
      ? sns.Topic.fromTopicArn(this, 'AlertTopic', props.alertTopicArn)
      : undefined;

    const errorRateAlarm = new cloudwatch.Alarm(this, 'ErrorRateAlarm', {
      metric: this.distribution.metricTotalErrorRate({
        period: cdk.Duration.minutes(5),
        statistic: 'Average',
      }),
      threshold: 5,
      evaluationPeriods: 3,
      comparisonOperator:
        cloudwatch.ComparisonOperator.GREATER_THAN_THRESHOLD,
      alarmDescription: `Beta PR #${props.prNumber} 에러율 5% 초과`,
      treatMissingData: cloudwatch.TreatMissingData.NOT_BREACHING,
    });

    if (alertTopic) {
      errorRateAlarm.addAlarmAction(
        new cdk.aws_cloudwatch_actions.SnsAction(alertTopic),
      );
    }

    // --- 출력값 ---
    this.distributionUrl = `https://${betaSubdomain}`;

    new cdk.CfnOutput(this, 'BetaUrl', {
      value: this.distributionUrl,
      description: `Beta URL for PR #${props.prNumber}`,
    });

    new cdk.CfnOutput(this, 'BucketName', {
      value: this.bucket.bucketName,
    });

    new cdk.CfnOutput(this, 'DistributionId', {
      value: this.distribution.distributionId,
    });
  }
}
```

### 2.2 L3 Construct: FinOpsGuardrail

비용 가드레일을 하나의 Construct로 캡슐화한다.

```typescript
// lib/constructs/finops-guardrail.ts
import * as cdk from 'aws-cdk-lib';
import * as budgets from 'aws-cdk-lib/aws-budgets';
import * as sns from 'aws-cdk-lib/aws-sns';
import * as snsSubscriptions from 'aws-cdk-lib/aws-sns-subscriptions';
import * as lambda from 'aws-cdk-lib/aws-lambda';
import * as lambdaNodejs from 'aws-cdk-lib/aws-lambda-nodejs';
import * as iam from 'aws-cdk-lib/aws-iam';
import { Construct } from 'constructs';

export interface FinOpsGuardrailProps {
  /** 월간 예산 (USD) */
  monthlyBudgetUsd: number;
  /** 알림 임계값 (%) - 기본: [50, 80, 100] */
  thresholdPercentages?: number[];
  /** 알림 이메일 주소 목록 */
  alertEmails: string[];
  /** 예산 초과 시 자동 차단 Lambda 활성화 여부 */
  enableAutoBlock?: boolean;
  /** 비용 태그 필터 */
  costTagFilter?: Record<string, string>;
}

export class FinOpsGuardrail extends Construct {
  public readonly alertTopic: sns.Topic;

  constructor(scope: Construct, id: string, props: FinOpsGuardrailProps) {
    super(scope, id);

    const thresholds = props.thresholdPercentages ?? [50, 80, 100];

    // --- SNS Topic: 비용 알림 ---
    this.alertTopic = new sns.Topic(this, 'CostAlertTopic', {
      displayName: 'Beta Infrastructure Cost Alerts',
    });

    for (const email of props.alertEmails) {
      this.alertTopic.addSubscription(
        new snsSubscriptions.EmailSubscription(email),
      );
    }

    // --- AWS Budgets ---
    const notifications = thresholds.map((threshold) => ({
      notification: {
        comparisonOperator: 'GREATER_THAN' as const,
        notificationType: 'ACTUAL' as const,
        threshold,
        thresholdType: 'PERCENTAGE' as const,
      },
      subscribers: [
        {
          subscriptionType: 'SNS' as const,
          address: this.alertTopic.topicArn,
        },
      ],
    }));

    const costFilters: Record<string, string[]> = {};
    if (props.costTagFilter) {
      for (const [key, value] of Object.entries(props.costTagFilter)) {
        costFilters[`TagKeyValue`] = [
          ...(costFilters['TagKeyValue'] ?? []),
          `user:${key}$${value}`,
        ];
      }
    }

    new budgets.CfnBudget(this, 'MonthlyBudget', {
      budget: {
        budgetName: 'MultiBeta-Monthly-Budget',
        budgetType: 'COST',
        timeUnit: 'MONTHLY',
        budgetLimit: {
          amount: props.monthlyBudgetUsd,
          unit: 'USD',
        },
        costFilters: Object.keys(costFilters).length > 0
          ? costFilters
          : undefined,
      },
      notificationsWithSubscribers: notifications,
    });

    // --- 자동 차단 Lambda (100% 초과 시) ---
    if (props.enableAutoBlock) {
      const blockLambda = new lambdaNodejs.NodejsFunction(this, 'BlockFn', {
        runtime: lambda.Runtime.NODEJS_22_X,
        handler: 'handler',
        entry: require.resolve('./handlers/budget-block-handler'),
        timeout: cdk.Duration.seconds(30),
        environment: {
          COST_TAG_KEY: 'Environment',
          COST_TAG_VALUE: 'beta',
        },
      });

      blockLambda.addToRolePolicy(
        new iam.PolicyStatement({
          effect: iam.Effect.ALLOW,
          actions: [
            'cloudformation:ListStacks',
            'cloudformation:DescribeStacks',
            'cloudformation:UpdateTerminationProtection',
          ],
          resources: ['*'],
          conditions: {
            StringLike: {
              'aws:ResourceTag/ManagedBy': 'cdk-multi-beta',
            },
          },
        }),
      );

      this.alertTopic.addSubscription(
        new snsSubscriptions.LambdaSubscription(blockLambda),
      );
    }
  }
}
```

### 2.3 스택 조합: MultiBetaStack

```typescript
// lib/multi-beta-stack.ts
import * as cdk from 'aws-cdk-lib';
import { Construct } from 'constructs';
import { MultiBetaDistribution } from './constructs/multi-beta-distribution';
import { FinOpsGuardrail } from './constructs/finops-guardrail';

interface MultiBetaStackProps extends cdk.StackProps {
  prNumber: number;
  commitHash: string;
  domainName: string;
  hostedZoneId: string;
  certificateArn: string;
  ttlDays: number;
  kvsStoreId: string;
  monthlyBudgetUsd: number;
  alertEmails: string[];
  wafAclArn?: string;
}

export class MultiBetaStack extends cdk.Stack {
  public readonly distributionUrl: string;

  constructor(scope: Construct, id: string, props: MultiBetaStackProps) {
    super(scope, id, props);

    // L3 Construct: 베타 배포 환경
    const beta = new MultiBetaDistribution(this, 'Beta', {
      prNumber: props.prNumber,
      commitHash: props.commitHash,
      domainName: props.domainName,
      hostedZoneId: props.hostedZoneId,
      certificateArn: props.certificateArn,
      ttlDays: props.ttlDays,
      kvsStoreId: props.kvsStoreId,
      wafAclArn: props.wafAclArn,
      alertTopicArn: undefined, // FinOpsGuardrail에서 생성
    });

    // L3 Construct: 비용 가드레일
    new FinOpsGuardrail(this, 'FinOps', {
      monthlyBudgetUsd: props.monthlyBudgetUsd,
      alertEmails: props.alertEmails,
      enableAutoBlock: true,
      costTagFilter: {
        Environment: 'beta',
        PRNumber: String(props.prNumber),
      },
    });

    this.distributionUrl = beta.distributionUrl;
  }
}
```

```typescript
import 'source-map-support/register';
import * as cdk from 'aws-cdk-lib';

const app = new cdk.App();

    account: process.env.CDK_DEFAULT_ACCOUNT,
    region: 'us-east-1',
  },
});
```

## 3. CDK Pipeline PR별 스택 자동 생성/삭제

### 3.1 PR 생성 시 자동 프로비저닝

```yaml
# .github/workflows/beta-provision.yml
name: Beta Environment Provision

on:
  pull_request:
    types: [opened, synchronize, reopened]

permissions:
  id-token: write
  contents: read
  pull-requests: write

concurrency:
  group: beta-${{ github.event.pull_request.number }}
  cancel-in-progress: true

jobs:
  provision-and-deploy:
    runs-on: ubuntu-latest
    timeout-minutes: 20

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: 'pnpm'

      - name: Install dependencies
        run: |
          corepack enable
          pnpm install --frozen-lockfile

      - name: Configure AWS Credentials
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-arn: ${{ secrets.AWS_DEPLOY_ROLE_ARN }}
          aws-region: us-east-1

      - name: CDK Deploy - Beta Infrastructure
        working-directory: infra
        run: |
          npx cdk deploy MultiBeta-PR-${{ github.event.pull_request.number }} \
            --context prNumber=${{ github.event.pull_request.number }} \
            --context commitHash=${{ github.sha }} \
            --require-approval never \
            --outputs-file cdk-outputs.json
        env:
          DOMAIN_NAME: ${{ vars.DOMAIN_NAME }}
          HOSTED_ZONE_ID: ${{ secrets.HOSTED_ZONE_ID }}
          CERTIFICATE_ARN: ${{ secrets.CERTIFICATE_ARN }}
          KVS_STORE_ID: ${{ secrets.KVS_STORE_ID }}
          BETA_TTL_DAYS: '7'
          MONTHLY_BUDGET_USD: '100'
          ALERT_EMAILS: ${{ vars.ALERT_EMAILS }}
          WAF_ACL_ARN: ${{ secrets.WAF_ACL_ARN }}

      - name: Register KVS Routing Entry
        run: |
          PR_NUM=${{ github.event.pull_request.number }}
          STACK_NAME="MultiBeta-PR-${PR_NUM}"
          BUCKET=$(jq -r ".[\"${STACK_NAME}\"].BucketName" infra/cdk-outputs.json)

          aws cloudfront-keyvaluestore put-key \
            --kvs-arn "arn:aws:cloudfront::${{ secrets.AWS_ACCOUNT_ID }}:key-value-store/${{ secrets.KVS_STORE_ID }}" \
            --key "pr-${PR_NUM}" \
            --value "{\"bucket\":\"${BUCKET}\",\"pr\":${PR_NUM},\"createdAt\":\"$(date -u +%Y-%m-%dT%H:%M:%SZ)\"}" \
            --if-match "*"

      - name: Build Application
        run: pnpm build
        env:
          VITE_API_URL: https://api-beta.example.com
          VITE_BETA_PR: ${{ github.event.pull_request.number }}

      - name: Extract CDK Outputs
        id: cdk
```

## 4. CloudFront Functions + KVS 라우팅

### 4.1 CloudFront Functions KVS 아키텍처

CloudFront Functions는 KeyValueStore(KVS)와 연동하여 Edge에서 초저지연 라우팅을 수행한다. KVS는 CloudFront PoP에 글로벌 복제되어 읽기 지연이 1ms 미만이다.

```
사용자 요청
  |
  v
CloudFront PoP (Viewer Request)
  |
  +-- CloudFront Function 실행
  |     |
  |     +-- KVS에서 "pr-{N}" 키로 라우팅 정보 조회 (< 1ms)
  |     +-- 쿼리 파라미터 ?beta=N / 쿠키 x-beta-pr / 헤더 x-beta-pr 확인
  |     +-- 매칭 시 요청 URI/헤더 변환
  |     +-- SPA Fallback (확장자 없는 경로 -> /index.html)
  |
  v
Origin (S3 버킷)
```

### 4.2 KVS 라우팅 함수 코드

```typescript
// edge-functions/kvs-router.ts
// CloudFront Functions runtime (ES module, async handler 지원)
import cf from 'cloudfront';

const kvsHandle = cf.kvs(KVS_ID); // CDK에서 치환

interface RouteConfig {
  bucket: string;
  pr: number;
  createdAt: string;
  canary?: {
    enabled: boolean;
    percentage: number;
    targetPr: number;
  };
}

async function handler(
  event: AWSCloudFrontFunction.Event,
): Promise<AWSCloudFrontFunction.Request> {
  const request = event.request;
  const uri = request.uri;

  // 1. 베타 PR 타겟 결정 (우선순위: query > cookie > header)
  const betaPr = resolveBetaTarget(request);

  if (betaPr) {
    try {
      const raw = await kvsHandle.get(`pr-${betaPr}`);
      const config: RouteConfig = JSON.parse(raw);

      // 카나리 라우팅 처리
      if (config.canary?.enabled) {
        const hash = simpleHash(getClientId(request));
        if (hash % 100 < config.canary.percentage) {
          const canaryRaw = await kvsHandle.get(`pr-${config.canary.targetPr}`);
          const canaryConfig: RouteConfig = JSON.parse(canaryRaw);
          applyRouting(request, canaryConfig, config.canary.targetPr);
        } else {
          applyRouting(request, config, betaPr);
        }
      } else {
        applyRouting(request, config, betaPr);
      }
    } catch {
      // KVS 조회 실패 시 기본 오리진 유지
    }
  }

  // SPA Fallback
  if (!uri.includes('.')) {
    request.uri = '/index.html';
  }

  return request;
}

function resolveBetaTarget(
  request: AWSCloudFrontFunction.Request,
): string | null {
  // 쿼리 파라미터
  if (request.querystring?.beta) {
    return request.querystring.beta.value;
  }
  // 쿠키
  if (request.cookies?.['x-beta-pr']) {
    return request.cookies['x-beta-pr'].value;
  }
  // 헤더
  if (request.headers?.['x-beta-pr']) {
    return request.headers['x-beta-pr'].value;
  }
  return null;
}

function applyRouting(
  request: AWSCloudFrontFunction.Request,
  config: RouteConfig,
  prNumber: string | number,
): void {
  request.headers['x-beta-origin'] = { value: config.bucket };
  request.headers['x-beta-pr'] = { value: String(prNumber) };
  request.headers['x-beta-routed'] = { value: 'true' };
}

function getClientId(request: AWSCloudFrontFunction.Request): string {
  return (
    request.headers?.['x-forwarded-for']?.value ??
    request.cookies?.['_session_id']?.value ??
    'anonymous'
  );
}

function simpleHash(str: string): number {
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    const char = str.charCodeAt(i);
    hash = (hash << 5) - hash + char;
    hash = hash & hash; // 32bit 정수 변환
  }
  return Math.abs(hash);
}
```

### 4.3 KVS 관리 유틸리티

```typescript
// scripts/kvs-manager.ts
import {
  CloudFrontKeyValueStoreClient,
  PutKeyCommand,
  DeleteKeyCommand,
  ListKeysCommand,
  GetKeyCommand,
  DescribeKeyValueStoreCommand,
} from '@aws-sdk/client-cloudfront-keyvaluestore';

interface KvsRouteEntry {
  bucket: string;
  pr: number;
  createdAt: string;
  canary?: {
    enabled: boolean;
    percentage: number;
    targetPr: number;
  };
}

export class KvsManager {
  private readonly client: CloudFrontKeyValueStoreClient;
  private readonly kvsArn: string;

  constructor(kvsArn: string) {
    this.client = new CloudFrontKeyValueStoreClient({});
    this.kvsArn = kvsArn;
  }

  async registerRoute(prNumber: number, entry: KvsRouteEntry): Promise<void> {
    const etag = await this.getETag();
    await this.client.send(
      new PutKeyCommand({
        KvsARN: this.kvsArn,
        Key: `pr-${prNumber}`,
        Value: JSON.stringify(entry),
        IfMatch: etag,
      }),
    );
  }

  async removeRoute(prNumber: number): Promise<void> {
    try {
      const etag = await this.getETag();
      await this.client.send(
        new DeleteKeyCommand({
          KvsARN: this.kvsArn,
          Key: `pr-${prNumber}`,
          IfMatch: etag,
        }),
      );
    } catch (error: unknown) {
      if ((error as { name?: string }).name !== 'ResourceNotFoundException') {
        throw error;
      }
    }
  }

  async listRoutes(): Promise<Array<{ key: string; value: KvsRouteEntry }>> {
    const result = await this.client.send(
      new ListKeysCommand({ KvsARN: this.kvsArn }),
    );

    const routes: Array<{ key: string; value: KvsRouteEntry }> = [];
    for (const item of result.Items ?? []) {
      if (item.Key?.startsWith('pr-')) {
        const detail = await this.client.send(
          new GetKeyCommand({ KvsARN: this.kvsArn, Key: item.Key }),
        );
        routes.push({
          key: item.Key,
          value: JSON.parse(detail.Value ?? '{}'),
        });
      }
    }
    return routes;
  }

  private async getETag(): Promise<string> {
    const result = await this.client.send(
      new DescribeKeyValueStoreCommand({ KvsARN: this.kvsArn }),
    );
    return result.ETag ?? '*';
  }
}
```

## 5. Multi-CDN Failover (Route53 + CloudFront + Cloudflare)

### 5.1 아키텍처 개요

단일 CDN 장애 시에도 서비스 연속성을 보장하기 위해 Route53 DNS Failover로 CloudFront(Primary)와 Cloudflare(Secondary)를 연결한다.

```
사용자
  |
  v
Route53 (Failover Routing Policy)
  |
  +-- Primary: CloudFront Distribution
  |     |-- Health Check: HTTPS 200 확인 (10초 간격)
  |     +-- Origin: S3 (OAC)
  |
  +-- Secondary (Failover): Cloudflare CDN
        |-- Cloudflare Worker: S3 오리진 프록시
        +-- Origin: 동일 S3 버킷 (Signed URL)
```

### 5.2 Route53 Failover 설정 (CDK)

```typescript
// lib/constructs/multi-cdn-failover.ts
import * as cdk from 'aws-cdk-lib';
import * as route53 from 'aws-cdk-lib/aws-route53';
import * as route53Targets from 'aws-cdk-lib/aws-route53-targets';
import * as cloudfront from 'aws-cdk-lib/aws-cloudfront';
import { Construct } from 'constructs';

export interface MultiCdnFailoverProps {
  domainName: string;
  hostedZoneId: string;
  recordName: string;
  cfDistribution: cloudfront.Distribution;
  cloudflareCname: string; // Cloudflare에서 발급한 CNAME
  healthCheckPath: string;
}

export class MultiCdnFailover extends Construct {
  constructor(scope: Construct, id: string, props: MultiCdnFailoverProps) {
    super(scope, id);

    const hostedZone = route53.HostedZone.fromHostedZoneAttributes(
      this,
      'Zone',
      {
        hostedZoneId: props.hostedZoneId,
        zoneName: props.domainName,
      },
    );

    // --- Health Check: CloudFront Primary ---
    const healthCheck = new route53.CfnHealthCheck(this, 'CfHealthCheck', {
      healthCheckConfig: {
        type: 'HTTPS',
        fullyQualifiedDomainName: `${props.recordName}.${props.domainName}`,
        resourcePath: props.healthCheckPath,
        requestInterval: 10,
        failureThreshold: 2,
        enableSni: true,
      },
      healthCheckTags: [
        { key: 'Name', value: `${props.recordName}-cf-health` },
      ],
    });

    // --- Primary: CloudFront ---
    new route53.ARecord(this, 'PrimaryRecord', {
      zone: hostedZone,
      recordName: props.recordName,
      target: route53.RecordTarget.fromAlias(
        new route53Targets.CloudFrontTarget(props.cfDistribution),
      ),
    });

    // Failover 설정은 CfnRecordSet으로 직접 구성
    new route53.CfnRecordSet(this, 'FailoverPrimary', {
      hostedZoneId: props.hostedZoneId,
      name: `${props.recordName}.${props.domainName}`,
      type: 'A',
      setIdentifier: 'primary-cloudfront',
      failover: 'PRIMARY',
      aliasTarget: {
        hostedZoneId: 'Z2FDTNDATAQYW2', // CloudFront 고정 Hosted Zone ID
        dnsName: props.cfDistribution.distributionDomainName,
        evaluateTargetHealth: true,
      },
      healthCheckId: healthCheck.attrHealthCheckId,
    });

    new route53.CfnRecordSet(this, 'FailoverSecondary', {
      hostedZoneId: props.hostedZoneId,
      name: `${props.recordName}.${props.domainName}`,
      type: 'CNAME',
      setIdentifier: 'secondary-cloudflare',
      failover: 'SECONDARY',
      resourceRecords: [props.cloudflareCname],
      ttl: '60',
    });
  }
}
```

```typescript
// edge-functions/ab-test.ts
// CloudFront Functions: KVS 기반 A/B 테스트
import cf from 'cloudfront';

const kvsHandle = cf.kvs(KVS_ID);

interface AbTestConfig {
  experimentId: string;
  variants: Array<{
    id: string;
    weight: number; // 0-100
    origin: string;
  }>;
  sticky: boolean; // 쿠키 기반 고정 여부
}

async function handler(
  event: AWSCloudFrontFunction.Event,
): Promise<AWSCloudFrontFunction.Request | AWSCloudFrontFunction.Response> {
  const request = event.request;

  try {
    const raw = await kvsHandle.get('ab-test-active');
    const config: AbTestConfig = JSON.parse(raw);

    // 기존 할당 확인 (쿠키)
    const existingVariant =
      request.cookies?.[`ab-${config.experimentId}`]?.value;
    if (existingVariant && config.sticky) {
      request.headers['x-ab-variant'] = { value: existingVariant };
      return request;
    }

    // 가중치 기반 변형 선택
    const clientId = request.headers?.['x-forwarded-for']?.value ?? '';
    const hash = simpleHash(clientId + config.experimentId);
    const bucket = hash % 100;

    let cumulative = 0;
    for (const variant of config.variants) {
      cumulative += variant.weight;
      if (bucket < cumulative) {
        request.headers['x-ab-variant'] = { value: variant.id };
        request.headers['x-ab-origin'] = { value: variant.origin };

        // Set-Cookie로 변형 고정
        if (config.sticky) {
          request.headers['x-ab-set-cookie'] = {
            value: `ab-${config.experimentId}=${variant.id}; Path=/; Max-Age=86400; SameSite=Lax`,
          };
        }
        break;
      }
    }
  } catch {
    // A/B 테스트 설정 없으면 기본 동작
  }

  return request;
}

function simpleHash(str: string): number {
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    hash = (hash << 5) - hash + str.charCodeAt(i);
    hash = hash & hash;
  }
  return Math.abs(hash);
}
```

### 8.1 자동 차단 Lambda 핸들러

예산 100% 초과 시 신규 베타 환경 생성을 자동 차단하는 Lambda 함수이다.

```typescript
// lib/handlers/budget-block-handler.ts
import {
  CloudFormationClient,
  ListStacksCommand,
  UpdateTerminationProtectionCommand,
} from '@aws-sdk/client-cloudformation';
import {
  SSMClient,
  PutParameterCommand,
  GetParameterCommand,
} from '@aws-sdk/client-ssm';
import { SNSEvent, Context } from 'aws-lambda';

const SSM_BLOCK_FLAG_KEY = '/multi-beta/budget-block';

interface BudgetNotification {
  budgetName: string;
  notificationType: string;
  budgetType: string;
  actualSpend: { amount: string; unit: string };
  budgetedSpend: { amount: string; unit: string };
}

export async function handler(event: SNSEvent, context: Context): Promise<void> {
  const ssmClient = new SSMClient({});
  const cfnClient = new CloudFormationClient({});

  for (const record of event.Records) {
    const notification: BudgetNotification = JSON.parse(record.Sns.Message);

    const actualSpend = parseFloat(notification.actualSpend.amount);
    const budgetLimit = parseFloat(notification.budgetedSpend.amount);
    const usagePercentage = (actualSpend / budgetLimit) * 100;

    console.log(
      `Budget alert: ${usagePercentage.toFixed(1)}% used ($${actualSpend}/$${budgetLimit})`,
    );

    if (usagePercentage >= 100) {
      // 1. 신규 생성 차단 플래그 설정
      await ssmClient.send(
        new PutParameterCommand({
          Name: SSM_BLOCK_FLAG_KEY,
          Value: JSON.stringify({
            blocked: true,
            reason: `Budget exceeded: $${actualSpend} / $${budgetLimit}`,
            timestamp: new Date().toISOString(),
          }),
          Type: 'String',
          Overwrite: true,
        }),
      );

      console.log('New beta environment creation BLOCKED due to budget exceeded.');
    }

    if (usagePercentage >= 80 && usagePercentage < 100) {
      // 80% 경고: 유휴 환경 목록 조회 및 정리 권고
      const stacks = await cfnClient.send(
        new ListStacksCommand({
          StackStatusFilter: ['CREATE_COMPLETE', 'UPDATE_COMPLETE'],
        }),
      );

      const betaStacks =
        stacks.StackSummaries?.filter((s) =>
          s.StackName?.startsWith('MultiBeta-PR-'),
        ) ?? [];

      console.log(
        `Budget warning (${usagePercentage.toFixed(1)}%): ${betaStacks.length} active beta stacks.`,
      );
    }
  }
}
```

### 8.2 생성 전 차단 확인 (CI에서 호출)

```typescript
// scripts/check-budget-block.ts
import { SSMClient, GetParameterCommand } from '@aws-sdk/client-ssm';

const SSM_BLOCK_FLAG_KEY = '/multi-beta/budget-block';

interface BlockStatus {
  blocked: boolean;
  reason: string;
  timestamp: string;
}

export async function isBetaCreationBlocked(): Promise<BlockStatus> {
  const ssmClient = new SSMClient({});

  try {
    const result = await ssmClient.send(
      new GetParameterCommand({ Name: SSM_BLOCK_FLAG_KEY }),
    );

    const status: BlockStatus = JSON.parse(result.Parameter?.Value ?? '{}');
    return status;
  } catch (error: unknown) {
    if ((error as { name?: string }).name === 'ParameterNotFound') {
      return { blocked: false, reason: '', timestamp: '' };
    }
    throw error;
  }
}

// CLI 실행
async function main(): Promise<void> {
  const status = await isBetaCreationBlocked();

  if (status.blocked) {
    console.error(`Beta creation is BLOCKED: ${status.reason}`);
    console.error(`Blocked since: ${status.timestamp}`);
    process.exit(1);
  }

  console.log('Beta creation is allowed.');
  process.exit(0);
}

main();
```

- [ ] 동시 베타 환경 상한(maxConcurrentBetas)이 설정되어 있는가

### 10.2 일일 운영 확인

- [ ] 활성 베타 환경 수가 상한 이내인가
- [ ] Cost Anomaly Detection 알림이 발생하지 않았는가
- [ ] 만료된 환경이 정상적으로 정리되었는가 (KVS 엔트리 포함)
- [ ] 스케줄 스윕 워크플로우가 정상 실행되었는가
- [ ] Route53 Health Check가 모두 Healthy인가
- [ ] 비용이 예산 범위 이내인가 (Budgets 대시보드 확인)
- [ ] 고아 리소스(삭제 실패한 스택, 잔존 KVS 엔트리)가 없는가

### 10.3 장애 대응

| 상황 | 확인 사항 | 조치 |
|------|----------|------|
| CDK Deploy 실패 | CloudFormation 이벤트 로그, 예산 차단 여부 | 스택 롤백 후 재시도, 리소스 충돌/한도 확인 |
| CDK Destroy 실패 | S3 버킷 비우기 실패 여부, KVS 엔트리 잔존 | 수동 버킷 비우기 + KVS 엔트리 삭제 후 재실행 |

| Multi-CDN Failover 발동 | Route53 Health Check 상태, CF Distribution 상태 | Primary 복구 확인, Failover 원인 조사, Health Check 정상화 |
