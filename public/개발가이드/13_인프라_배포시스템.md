## 1. 멀티 베타 아키텍처 개요

### 1.1 핵심 설계 원칙

| 원칙 | 설명 |
|------|------|
| **PR 단위 격리** | 모든 PR이 독립된 S3 버킷 + CloudFront Distribution을 가진다 |
| **완전 자동화** | PR 생성 시 인프라 프로비저닝, 머지/닫힘 시 자동 정리 |
| **비용 제어** | TTL 만료, 스케줄 기반 정리, 사용량 모니터링으로 비용 폭증 방지 |
| **Feature Flag 통합** | Edge Function에서 Feature Flag를 읽어 트래픽을 동적으로 라우팅 |
| **프로덕션 동일성** | 베타 환경이 프로덕션과 동일한 인프라 구성을 사용 |

### 1.2 전체 아키텍처 흐름

```
PR 생성
  |
  v
GitHub Actions: CDK Deploy
  |
  +-- S3 버킷 생성 (beta-{pr-number}-{hash})
  +-- CloudFront Distribution 생성
  +-- OAC(Origin Access Control) 설정
  +-- Route 53 레코드 등록 (pr-{number}.beta.example.com)
  |
  v
빌드 & 배포
  |
  +-- 프론트엔드 빌드 결과물을 S3에 업로드
  +-- CloudFront 캐시 무효화
  +-- PR에 베타 URL 코멘트 자동 등록
  |
  v
Edge Function 라우팅
  |
  +-- Feature Flag 서비스에서 플래그 조회
  +-- 플래그 상태에 따라 베타/프로덕션 오리진 선택
  |
  v
PR 머지 또는 닫힘
  |
  v
GitHub Actions: CDK Destroy
  |
  +-- CloudFront Distribution 삭제
  +-- S3 버킷 비우기 + 삭제
  +-- Route 53 레코드 제거
```

## 2. 동적 S3 + CloudFront 자동 프로비저닝 (CDK)

### 2.1 CDK 스택 전체 코드

```typescript
// lib/multi-beta-stack.ts
import * as cdk from 'aws-cdk-lib';
import * as s3 from 'aws-cdk-lib/aws-s3';
import * as cloudfront from 'aws-cdk-lib/aws-cloudfront';
import * as origins from 'aws-cdk-lib/aws-cloudfront-origins';
import * as route53 from 'aws-cdk-lib/aws-route53';
import * as route53Targets from 'aws-cdk-lib/aws-route53-targets';
import * as acm from 'aws-cdk-lib/aws-certificatemanager';
import * as iam from 'aws-cdk-lib/aws-iam';
import { Construct } from 'constructs';

interface MultiBetaStackProps extends cdk.StackProps {
  prNumber: number;
  commitHash: string;
  domainName: string;
  hostedZoneId: string;
  certificateArn: string;
  ttlDays: number;
}

export class MultiBetaStack extends cdk.Stack {
  public readonly distributionUrl: string;
  public readonly betaDomain: string;

  constructor(scope: Construct, id: string, props: MultiBetaStackProps) {
    super(scope, id, props);

    const betaSubdomain = `pr-${props.prNumber}.beta.${props.domainName}`;
    this.betaDomain = betaSubdomain;

    // S3 버킷: PR별 격리
    const bucket = new s3.Bucket(this, 'BetaBucket', {
      bucketName: `beta-${props.prNumber}-${props.commitHash.slice(0, 8)}`,
      removalPolicy: cdk.RemovalPolicy.DESTROY,
      autoDeleteObjects: true,
      blockPublicAccess: s3.BlockPublicAccess.BLOCK_ALL,
      encryption: s3.BucketEncryption.S3_MANAGED,
      lifecycleRules: [
        {
          expiration: cdk.Duration.days(props.ttlDays),
          id: 'auto-expire',
        },
      ],
    });

    // 태그: 비용 추적 및 자동 정리용
    cdk.Tags.of(bucket).add('Environment', 'beta');
    cdk.Tags.of(bucket).add('PRNumber', String(props.prNumber));
    cdk.Tags.of(bucket).add('ManagedBy', 'cdk-multi-beta');
    cdk.Tags.of(bucket).add(
      'ExpiresAt',
      new Date(Date.now() + props.ttlDays * 86400000).toISOString(),
    );

    // ACM 인증서 참조 (us-east-1에 미리 생성된 와일드카드 인증서)
    const certificate = acm.Certificate.fromCertificateArn(
      this,
      'Certificate',
      props.certificateArn,
    );

    // CloudFront Function: SPA 라우팅
    const spaRoutingFunction = new cloudfront.Function(this, 'SpaRouting', {
      code: cloudfront.FunctionCode.fromInline(`
        function handler(event) {
          var request = event.request;
          var uri = request.uri;
          if (uri.includes('.')) {
            return request;
          }
          request.uri = '/index.html';
          return request;
        }
      `),
      runtime: cloudfront.FunctionRuntime.JS_2_0,
    });

    // CloudFront Distribution
    const distribution = new cloudfront.Distribution(this, 'BetaDistribution', {
      defaultBehavior: {
        origin: origins.S3BucketOrigin.withOriginAccessControl(bucket),
        viewerProtocolPolicy: cloudfront.ViewerProtocolPolicy.REDIRECT_TO_HTTPS,
        cachePolicy: cloudfront.CachePolicy.CACHING_OPTIMIZED,
        functionAssociations: [
          {
            function: spaRoutingFunction,
            eventType: cloudfront.FunctionEventType.VIEWER_REQUEST,
          },
        ],
      },
      domainNames: [betaSubdomain],
      certificate,
      defaultRootObject: 'index.html',
      errorResponses: [
        {
          httpStatus: 403,
          responseHttpStatus: 200,
          responsePagePath: '/index.html',
          ttl: cdk.Duration.minutes(5),
        },
        {
          httpStatus: 404,
          responseHttpStatus: 200,
          responsePagePath: '/index.html',
          ttl: cdk.Duration.minutes(5),
        },
      ],
      comment: `Beta environment for PR #${props.prNumber}`,
    });

    cdk.Tags.of(distribution).add('Environment', 'beta');
    cdk.Tags.of(distribution).add('PRNumber', String(props.prNumber));

    // Route 53 레코드
    const hostedZone = route53.HostedZone.fromHostedZoneAttributes(
      this,
      'HostedZone',
      {
        hostedZoneId: props.hostedZoneId,
        zoneName: props.domainName,
      },
    );

    new route53.ARecord(this, 'BetaAliasRecord', {
      zone: hostedZone,
      recordName: betaSubdomain,
      target: route53.RecordTarget.fromAlias(
        new route53Targets.CloudFrontTarget(distribution),
      ),
    });

    // 출력값
    this.distributionUrl = `https://${betaSubdomain}`;

    new cdk.CfnOutput(this, 'BetaUrl', {
      value: this.distributionUrl,
      description: `Beta URL for PR #${props.prNumber}`,
    });

    new cdk.CfnOutput(this, 'BucketName', {
      value: bucket.bucketName,
    });

    new cdk.CfnOutput(this, 'DistributionId', {
      value: distribution.distributionId,
    });
  }
}
```

## 3. PR별 인프라 자동 프로비저닝/정리 파이프라인

### 3.1 PR 생성 시 자동 프로비저닝

```yaml
# .github/workflows/beta-provision.yml
name: Beta Environment Provision

on:
  pull_request:
    types: [opened, synchronize, reopened]

permissions:
  id-token: write
  contents: read
  pull-requests: write

concurrency:
  group: beta-${{ github.event.pull_request.number }}
  cancel-in-progress: true

jobs:
  provision-and-deploy:
    runs-on: ubuntu-latest
    timeout-minutes: 20

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: 'pnpm'

      - name: Install dependencies
        run: |
          corepack enable
          pnpm install --frozen-lockfile

      - name: Configure AWS Credentials
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-arn: ${{ secrets.AWS_DEPLOY_ROLE_ARN }}
          aws-region: us-east-1

      - name: CDK Deploy - Beta Infrastructure
        working-directory: infra
        run: |
          npx cdk deploy MultiBeta-PR-${{ github.event.pull_request.number }} \
            --context prNumber=${{ github.event.pull_request.number }} \
            --context commitHash=${{ github.sha }} \
            --require-approval never \
            --outputs-file cdk-outputs.json
        env:
          DOMAIN_NAME: ${{ vars.DOMAIN_NAME }}
          HOSTED_ZONE_ID: ${{ secrets.HOSTED_ZONE_ID }}
          CERTIFICATE_ARN: ${{ secrets.CERTIFICATE_ARN }}
          BETA_TTL_DAYS: '7'

      - name: Build Application
        run: pnpm build
        env:
          VITE_API_URL: https://api-beta.example.com
          VITE_BETA_PR: ${{ github.event.pull_request.number }}

      - name: Extract CDK Outputs
        id: cdk
        run: |
          STACK_NAME="MultiBeta-PR-${{ github.event.pull_request.number }}"
          BUCKET=$(jq -r ".[\"${STACK_NAME}\"].BucketName" infra/cdk-outputs.json)
          DIST_ID=$(jq -r ".[\"${STACK_NAME}\"].DistributionId" infra/cdk-outputs.json)
          BETA_URL=$(jq -r ".[\"${STACK_NAME}\"].BetaUrl" infra/cdk-outputs.json)
          echo "bucket=${BUCKET}" >> "$GITHUB_OUTPUT"
          echo "distribution_id=${DIST_ID}" >> "$GITHUB_OUTPUT"
          echo "beta_url=${BETA_URL}" >> "$GITHUB_OUTPUT"

      - name: Deploy to S3
        run: |
          aws s3 sync dist/ s3://${{ steps.cdk.outputs.bucket }} \
            --delete \
            --cache-control "public, max-age=31536000, immutable" \
            --exclude "index.html" \
            --exclude "sw.js"
          aws s3 cp dist/index.html s3://${{ steps.cdk.outputs.bucket }}/index.html \
            --cache-control "no-cache, no-store, must-revalidate"

      - name: Invalidate CloudFront Cache
        run: |
          aws cloudfront create-invalidation \
            --distribution-id ${{ steps.cdk.outputs.distribution_id }} \
            --paths "/*"

      - name: Comment PR with Beta URL
        uses: actions/github-script@v7
        with:
          script: |
            const betaUrl = '${{ steps.cdk.outputs.beta_url }}';
            const prNumber = context.payload.pull_request.number;
            const sha = context.sha.slice(0, 7);

            const body = [
              '## Beta Environment',
              '',
              `| Item | Value |`,
              `|------|-------|`,
              `| URL | [${betaUrl}](${betaUrl}) |`,
              `| Commit | \`${sha}\` |`,
              `| Status | Deployed |`,
              `| TTL | 7 days |`,
              '',
              '> This environment will be automatically destroyed when the PR is merged or closed.',
            ].join('\n');

            // 기존 코멘트 업데이트 또는 새로 생성
            const comments = await github.rest.issues.listComments({
              owner: context.repo.owner,
              repo: context.repo.repo,
              issue_number: prNumber,
            });

            const botComment = comments.data.find(
              (c) => c.body?.includes('## Beta Environment'),
            );

            if (botComment) {
              await github.rest.issues.updateComment({
                owner: context.repo.owner,
                repo: context.repo.repo,
                comment_id: botComment.id,
                body,
              });
            } else {
              await github.rest.issues.createComment({
                owner: context.repo.owner,
                repo: context.repo.repo,
                issue_number: prNumber,
                body,
              });
            }
```

### 3.3 스케줄 기반 만료 환경 일괄 정리

```yaml
# .github/workflows/beta-sweep.yml
name: Beta Environment Sweep (Scheduled)

on:
  schedule:
    - cron: '0 3 * * *'  # 매일 새벽 3시 (UTC)
  workflow_dispatch:

permissions:
  id-token: write
  contents: read

jobs:
  sweep:
    runs-on: ubuntu-latest
    timeout-minutes: 30

    steps:
      - name: Configure AWS Credentials
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-arn: ${{ secrets.AWS_DEPLOY_ROLE_ARN }}
          aws-region: us-east-1

      - name: Find and Destroy Expired Stacks
        run: |
          NOW=$(date -u +%s)

          aws cloudformation list-stacks \
            --stack-status-filter CREATE_COMPLETE UPDATE_COMPLETE \
            --query "StackSummaries[?starts_with(StackName, 'MultiBeta-PR-')].StackName" \
            --output text | tr '\t' '\n' | while read STACK; do

            EXPIRES_AT=$(aws cloudformation describe-stacks \
              --stack-name "$STACK" \
              --query "Stacks[0].Tags[?Key=='ExpiresAt'].Value" \
              --output text 2>/dev/null || echo "")

            if [ -n "$EXPIRES_AT" ] && [ "$EXPIRES_AT" != "None" ]; then
              EXPIRES_TS=$(date -d "$EXPIRES_AT" +%s 2>/dev/null || echo "0")
              if [ "$NOW" -gt "$EXPIRES_TS" ]; then
                echo "Destroying expired stack: $STACK (expired at $EXPIRES_AT)"
                aws cloudformation delete-stack --stack-name "$STACK"
                aws cloudformation wait stack-delete-complete --stack-name "$STACK" || true
              fi
            fi
          done

      - name: Report Cleanup Results
        if: always()
        run: |
          REMAINING=$(aws cloudformation list-stacks \
            --stack-status-filter CREATE_COMPLETE UPDATE_COMPLETE \
            --query "StackSummaries[?starts_with(StackName, 'MultiBeta-PR-')] | length(@)" \
            --output text)
          echo "Remaining beta stacks: $REMAINING"
```

## 4. Feature Flag 기반 Edge Function 라우팅

### 4.1 Edge Function 라우팅 코드

```typescript
// edge-functions/feature-flag-router.ts
interface FeatureFlagConfig {
  flags: Record<string, FlagRule>;
  defaultOrigin: string;
}

interface FlagRule {
  enabled: boolean;
  betaOrigin: string;
  targeting: TargetingRule[];
}

interface TargetingRule {
  type: 'header' | 'cookie' | 'query' | 'percentage';
  key?: string;
  value?: string;
  percentage?: number;
}

// CloudFront Function (Viewer Request)
function handler(event: CloudFrontFunctionEvent): CloudFrontRequest {
  const request = event.request;
  const headers = request.headers;
  const cookies = parseCookies(request.cookies);

  // Feature Flag 평가
  const betaPr = resolveBetaTarget(headers, cookies, request.querystring);

  if (betaPr) {
    // 베타 오리진으로 라우팅
    request.headers['x-beta-pr'] = { value: String(betaPr) };
    request.headers['x-beta-routed'] = { value: 'true' };

    // Origin을 베타 S3 버킷으로 변경 (Origin Request에서 처리)
    request.origin = {
      s3: {
        domainName: `beta-${betaPr}.s3.us-east-1.amazonaws.com`,
        region: 'us-east-1',
        authMethod: 'origin-access-identity',
        path: '',
      },
    };
  }

  return request;
}

function resolveBetaTarget(
  headers: Record<string, { value: string }>,
  cookies: Record<string, string>,
  querystring: Record<string, { value: string }>,
): number | null {
  // 1. 쿼리 파라미터로 명시적 베타 지정 (?beta=123)
  if (querystring.beta) {
    return Number(querystring.beta.value);
  }

  // 2. 쿠키 기반 베타 세션 유지
  if (cookies['x-beta-pr']) {
    return Number(cookies['x-beta-pr']);
  }

  // 3. 헤더 기반 (내부 도구, QA 용도)
  if (headers['x-beta-pr']) {
    return Number(headers['x-beta-pr'].value);
  }

  return null;
}

function parseCookies(
  cookies?: Record<string, { value: string }>,
): Record<string, string> {
  const result: Record<string, string> = {};
  if (!cookies) return result;

  for (const [key, val] of Object.entries(cookies)) {
    result[key] = val.value;
  }
  return result;
}
```

### 4.2 Feature Flag 관리 서비스

```typescript
// services/beta-flag-manager.ts
interface BetaEnvironment {
  prNumber: number;
  distributionUrl: string;
  s3Bucket: string;
  distributionId: string;
  createdAt: string;
  expiresAt: string;
  status: 'provisioning' | 'active' | 'expired' | 'destroying';
  featureFlags: string[];
}

interface BetaFlagManagerConfig {
  tableName: string;
  region: string;
}

class BetaFlagManager {
  private readonly config: BetaFlagManagerConfig;

  constructor(config: BetaFlagManagerConfig) {
    this.config = config;
  }

  async registerBetaEnvironment(env: BetaEnvironment): Promise<void> {
    // DynamoDB에 베타 환경 정보 등록
    const params = {
      TableName: this.config.tableName,
      Item: {
        pk: `BETA#${env.prNumber}`,
        sk: 'METADATA',
        ...env,
        ttl: Math.floor(new Date(env.expiresAt).getTime() / 1000),
      },
    };
    // DynamoDB put 실행
    console.log('Beta environment registered:', params);
  }

  async getActiveBetas(): Promise<BetaEnvironment[]> {
    // status가 active인 베타 환경 목록 조회
    const params = {
      TableName: this.config.tableName,
      FilterExpression: '#s = :active',
      ExpressionAttributeNames: { '#s': 'status' },
      ExpressionAttributeValues: { ':active': 'active' },
    };
    console.log('Querying active betas:', params);
    return [];
  }

  async deactivateBeta(prNumber: number): Promise<void> {
    const params = {
      TableName: this.config.tableName,
      Key: { pk: `BETA#${prNumber}`, sk: 'METADATA' },
      UpdateExpression: 'SET #s = :destroying',
      ExpressionAttributeNames: { '#s': 'status' },
      ExpressionAttributeValues: { ':destroying': 'destroying' },
    };
    console.log('Deactivating beta:', params);
  }
}

export { BetaFlagManager, BetaEnvironment, BetaFlagManagerConfig };
```

## 5. N개 환경 비용 최적화

### 5.1 비용 구조 분석

| 리소스 | 베타 1개당 월 비용 (추정) | N개 환경 시 | 최적화 전략 |
|--------|--------------------------|------------|------------|
| S3 버킷 | $0.02 | $0.02 x N | TTL 기반 자동 삭제, Lifecycle Rule |
| CloudFront Distribution | $0 (요청 기반) | 최소 요청 | 미사용 환경 자동 비활성화 |
| CloudFront 요청 | $0.01/만건 | 트래픽 비례 | 테스트 트래픽만 허용 |
| Route 53 레코드 | $0.50/호스팅 영역 | $0.50 (공유) | 단일 호스팅 영역에 레코드만 추가 |
| Lambda@Edge | $0.60/백만 요청 | 최소 | 베타별 별도 함수 불필요 |

### 5.2 비용 제어 정책

```typescript
// cost-optimizer/beta-cost-policy.ts
interface CostPolicy {
  maxConcurrentBetas: number;
  defaultTtlDays: number;
  maxTtlDays: number;
  autoDisableAfterIdleDays: number;
  budgetAlertThresholdUsd: number;
}

const defaultCostPolicy: CostPolicy = {
  maxConcurrentBetas: 20,
  defaultTtlDays: 7,
  maxTtlDays: 30,
  autoDisableAfterIdleDays: 3,
  budgetAlertThresholdUsd: 50,
};

interface BetaUsageMetrics {
  prNumber: number;
  lastAccessedAt: string;
  totalRequests: number;
  storageBytes: number;
  createdAt: string;
}

function identifyIdleBetas(
  metrics: BetaUsageMetrics[],
  policy: CostPolicy,
): number[] {
  const now = Date.now();
  const idleThreshold = policy.autoDisableAfterIdleDays * 86400000;

  return metrics
    .filter((m) => {
      const lastAccessed = new Date(m.lastAccessedAt).getTime();
      return now - lastAccessed > idleThreshold;
    })
    .map((m) => m.prNumber);
}

function calculateMonthlyCost(activeBetas: number): {
  estimated: number;
  breakdown: Record<string, number>;
} {
  const s3 = activeBetas * 0.02;
  const cloudfront = activeBetas * 0.01;
  const route53 = 0.5;
  const lambda = activeBetas * 0.001;

  return {
    estimated: s3 + cloudfront + route53 + lambda,
    breakdown: { s3, cloudfront, route53, lambda },
  };
}

export { defaultCostPolicy, identifyIdleBetas, calculateMonthlyCost };
```

### 5.3 자동 정리 스케줄

| 트리거 | 조건 | 액션 |
|--------|------|------|
| PR 닫힘/머지 | 즉시 | CDK Destroy 실행 |
| TTL 만료 | 생성 후 7일 (기본값) | 스케줄 스윕에서 삭제 |
| 유휴 감지 | 3일간 요청 0건 | 알림 후 24시간 뒤 삭제 |
| 동시 개수 초과 | 20개 초과 시 | 가장 오래된 환경부터 삭제 |
| 예산 초과 | 월 $50 초과 시 | 신규 생성 차단 + 알림 |
| 매일 새벽 스윕 | 매일 03:00 UTC | 만료/유휴 환경 일괄 정리 |

- [ ] OIDC Provider와 IAM Role이 구성되어 있는가

- [ ] 동시 베타 환경 상한(maxConcurrentBetas)이 설정되어 있는가

### 7.2 일일 운영 확인

- [ ] 활성 베타 환경 수가 상한 이내인가
- [ ] 만료된 환경이 정상적으로 정리되었는가
- [ ] 스케줄 스윕 워크플로우가 정상 실행되었는가
- [ ] 비용이 예산 범위 이내인가
- [ ] 고아 리소스(삭제 실패한 스택)가 없는가
