## AI-First 개발 철학

2026년 소프트웨어 개발에서 AI는 보조 도구가 아니라 **핵심 인프라**다. 코드의 70% 이상이 AI와의 협업으로 작성되며, 개발자의 역할은 "코드 작성자"에서 "AI 오케스트레이터"로 전환되었다.

### 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **AI First** | 모든 개발 작업의 시작점은 AI 도구다. 직접 코딩 전에 AI에게 먼저 물어본다 |
| **검증 중심** | AI 생성 코드는 반드시 인간이 검증한다. 신뢰하되 확인한다 |
| **컨텍스트 최적화** | AI의 품질은 컨텍스트 품질에 비례한다. 프로젝트 메타데이터를 체계적으로 관리한다 |
| **도구 조합** | 단일 AI 도구에 의존하지 않는다. 각 도구의 강점을 조합한다 |
| **비용 인식** | AI 도구 사용량을 추적하고 ROI를 측정한다 |

### AI 도구 포지셔닝 맵

| 도구 | 주요 용도 | 강점 | 월 비용 (개인) |
|------|-----------|------|---------------|
| **Claude Code** | 복잡한 설계, 리팩토링, 디버깅 | 긴 컨텍스트, 깊은 추론 | $20~$100 |
| **GitHub Copilot** | 인라인 코드 완성, 테스트 생성 | IDE 통합, 빠른 응답 | $10~$39 |
| **Cursor** | 멀티파일 편집, 프로젝트 전체 리팩토링 | Composer, 자연어 편집 | $20~$40 |
| **CodeRabbit** | 코드 리뷰 자동화 | PR 분석, 보안 검사 | $15~$30 |

## Claude Code 완벽 활용법

### CLAUDE.md 작성법

`CLAUDE.md`는 Claude Code가 프로젝트를 이해하는 데 사용하는 핵심 컨텍스트 파일이다. 프로젝트 루트에 위치하며, Claude Code 세션 시작 시 자동으로 읽힌다.

```markdown
<!-- CLAUDE.md -->
# 프로젝트 컨텍스트

## 기술 스택
- Next.js 15 (App Router) + React 19 + TypeScript 5.8
- 상태 관리: Zustand v5 (클라이언트), TanStack Query v6 (서버)
- 스타일링: Tailwind CSS v4 + CSS Modules
- 테스트: Vitest + Testing Library + Playwright
- 패키지 매니저: pnpm 9

## 아키텍처 원칙
- Feature-Sliced Design 변형 적용
- 서버 컴포넌트 기본, 클라이언트 컴포넌트는 최소화
- API 호출은 반드시 서버 액션 또는 Route Handler를 통해
- 전역 상태는 Zustand, 서버 상태는 TanStack Query 분리

## 네이밍 컨벤션
- 컴포넌트: PascalCase (ProductCard.tsx)
- 훅: camelCase with use prefix (useProduct.ts)
- 유틸리티: camelCase (formatCurrency.ts)
- 상수: UPPER_SNAKE_CASE
- 타입/인터페이스: PascalCase with 접미사 (ProductProps, UserResponse)

## 디렉토리 구조
```
src/
├── app/          # Next.js App Router 페이지
├── features/     # 도메인별 기능 모듈
├── shared/       # 공유 컴포넌트, 훅, 유틸리티
├── entities/     # 도메인 엔티티 (타입, API)
└── widgets/      # 조합 컴포넌트
```

## 코딩 규칙
- 함수형 컴포넌트만 사용 (클래스 컴포넌트 금지)
- any 타입 금지 (unknown 사용)
- 매직 넘버 금지 (상수 추출)
- 컴포넌트당 200줄 이하
- 테스트 커버리지 80% 이상 유지

## 주의사항
- /api/internal/* 엔드포인트는 내부 전용, 외부 노출 금지
- 결제 관련 코드 수정 시 반드시 payment 팀 리뷰 필요
- 환경 변수는 .env.local에서만 관리, 커밋 금지
```

```typescript
// 의존성 기반 병렬 실행
async function executeTaskGraph(tasks: AgentTask[]): Promise<void> {
  const completed = new Set<string>();
  const running = new Map<string, Promise<void>>();

  async function tryExecute(task: AgentTask): Promise<void> {
    // 의존성 완료 대기
    const deps = task.dependencies.map(d => running.get(d)).filter(Boolean);
    await Promise.all(deps);

    // Claude Code 세션 실행
    console.log(`[${task.id}] 시작: ${task.description}`);
    await executeClaudeCodeSession(task.prompt, task.workingDir);
    completed.add(task.id);
    console.log(`[${task.id}] 완료: ${task.description}`);
  }

  // 모든 태스크를 동시에 시작 (의존성은 내부에서 대기)
  const promises = tasks.map(task => {
    const promise = tryExecute(task);
    running.set(task.id, promise);
    return promise;
  });

  await Promise.all(promises);
}

async function executeClaudeCodeSession(prompt: string, workingDir: string): Promise<void> {
  // 실제 구현에서는 claude CLI 호출
  console.log(`Executing in ${workingDir}: ${prompt.slice(0, 50)}...`);
}
```

### 인라인 / Chat / Agent 모드 활용

```typescript
// 1. 인라인 모드: 코드 완성에 최적
// 함수 시그니처를 작성하면 Copilot이 구현을 제안한다

// 복잡한 정렬 함수 - 시그니처만 작성
function sortProducts(
  products: Product[],
  sortBy: 'price' | 'rating' | 'name' | 'createdAt',
  order: 'asc' | 'desc',
): Product[] {
  // Copilot이 여기서부터 구현을 제안
  const comparator = (a: Product, b: Product): number => {
    const multiplier = order === 'asc' ? 1 : -1;

    switch (sortBy) {
      case 'price':
        return (a.price - b.price) * multiplier;
      case 'rating':
        return (a.rating - b.rating) * multiplier;
      case 'name':
        return a.name.localeCompare(b.name) * multiplier;
      case 'createdAt':
        return (new Date(a.createdAt).getTime() - new Date(b.createdAt).getTime()) * multiplier;
    }
  };

  return [...products].sort(comparator);
}
```

```typescript
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
}

// 좋은 예: 구체적 주석으로 고급 검증 유도
// RFC 5322 기반 이메일 검증
// 허용: user@domain.com, user+tag@domain.com
// 거부: user@.com, @domain.com, user@domain
// Disposable 이메일 도메인 차단 (mailinator, tempmail 등)
function validateEmailStrict(email: string): {
  isValid: boolean;
  reason?: string;
} {
  // Copilot이 더 정교한 구현을 제안
  if (!email) return { isValid: false, reason: '이메일이 비어있습니다' };

  const emailRegex = /^[a-zA-Z0-9.!#$%&'*+/=?^_`{|}~-]+@[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?(?:\.[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?)*$/;
  if (!emailRegex.test(email)) {
    return { isValid: false, reason: '이메일 형식이 올바르지 않습니다' };
  }

  const disposableDomains = ['mailinator.com', 'tempmail.com', 'throwaway.email'];
  const domain = email.split('@')[1]?.toLowerCase();
  if (domain && disposableDomains.includes(domain)) {
    return { isValid: false, reason: '일회용 이메일은 사용할 수 없습니다' };
  }

  return { isValid: true };
}

// 팁 2: 타입을 먼저 정의하면 Copilot이 구현을 더 잘 추론한다
interface PaginationOptions {
  page: number;
  limit: number;
  totalItems: number;
}

interface PaginationResult {
  currentPage: number;
  totalPages: number;
  hasNext: boolean;
  hasPrev: boolean;
  startIndex: number;
  endIndex: number;
  pageNumbers: number[];
}

// 타입이 정의된 상태에서 Copilot이 정확한 구현을 제안
function calculatePagination(options: PaginationOptions): PaginationResult {
  const { page, limit, totalItems } = options;
  const totalPages = Math.ceil(totalItems / limit);
  const currentPage = Math.min(Math.max(1, page), totalPages);

  const maxVisiblePages = 5;
  const half = Math.floor(maxVisiblePages / 2);
  let start = Math.max(1, currentPage - half);
  const end = Math.min(totalPages, start + maxVisiblePages - 1);
  start = Math.max(1, end - maxVisiblePages + 1);

  return {
    currentPage,
    totalPages,
    hasNext: currentPage < totalPages,
    hasPrev: currentPage > 1,
    startIndex: (currentPage - 1) * limit,
    endIndex: Math.min(currentPage * limit - 1, totalItems - 1),
    pageNumbers: Array.from({ length: end - start + 1 }, (_, i) => start + i),
  };
}
```

```typescript
// 1. src/features/cart/types.ts
export interface CartItem {
  productId: string;
  name: string;
  price: number;
  quantity: number;
  image: string;
  maxQuantity: number;
}

export interface CartState {
  items: CartItem[];
  isOpen: boolean;
}

export interface CartActions {
  addItem: (item: Omit<CartItem, 'quantity'>) => void;
  removeItem: (productId: string) => void;
  updateQuantity: (productId: string, quantity: number) => void;
  clearCart: () => void;
  toggleCart: () => void;
}

export type CartStore = CartState & CartActions;

// 2. src/features/cart/hooks/useCart.ts
import { create } from 'zustand';
import { persist } from 'zustand/middleware';
import type { CartStore } from '../types';

export const useCart = create<CartStore>()(
  persist(
    (set) => ({
      items: [],
      isOpen: false,

      addItem: (newItem) =>
        set((state) => {
          const existing = state.items.find(i => i.productId === newItem.productId);
          if (existing) {
            return {
              items: state.items.map(i =>
                i.productId === newItem.productId
                  ? { ...i, quantity: Math.min(i.quantity + 1, i.maxQuantity) }
                  : i,
              ),
            };
          }
          return { items: [...state.items, { ...newItem, quantity: 1 }] };
        }),

      removeItem: (productId) =>
        set((state) => ({
          items: state.items.filter(i => i.productId !== productId),
        })),

      updateQuantity: (productId, quantity) =>
        set((state) => ({
          items: quantity <= 0
            ? state.items.filter(i => i.productId !== productId)
            : state.items.map(i =>
                i.productId === productId
                  ? { ...i, quantity: Math.min(quantity, i.maxQuantity) }
                  : i,
              ),
        })),

      clearCart: () => set({ items: [] }),
      toggleCart: () => set((state) => ({ isOpen: !state.isOpen })),
    }),
    { name: 'cart-storage' },
  ),
);
```

```typescript
// scripts/ai-code-quality-check.ts
interface QualityCheckResult {
  category: string;
  check: string;
  passed: boolean;
  details?: string;
}

async function checkAiGeneratedCode(filePath: string): Promise<QualityCheckResult[]> {
  const results: QualityCheckResult[] = [];

  // 1. 타입 검사
  results.push({
    category: '타입 안전성',
    check: 'any 타입 미사용',
    passed: !(await fileContains(filePath, /:\s*any\b/)),
    details: 'any 대신 unknown 또는 구체적 타입을 사용하세요',
  });

  results.push({
    category: '타입 안전성',
    check: 'ts-ignore 미사용',
    passed: !(await fileContains(filePath, /@ts-ignore/)),
    details: 'ts-ignore 대신 ts-expect-error를 사용하고 이유를 명시하세요',
  });

  // 2. 에러 핸들링
  results.push({
    category: '에러 핸들링',
    check: '빈 catch 블록 없음',
    passed: !(await fileContains(filePath, /catch\s*\([^)]*\)\s*\{\s*\}/)),
    details: 'catch 블록에서 에러를 적절히 처리하세요',
  });

  // 3. 보안
  results.push({
    category: '보안',
    check: 'dangerouslySetInnerHTML 미사용',
    passed: !(await fileContains(filePath, /dangerouslySetInnerHTML/)),
    details: 'XSS 위험. 반드시 필요한 경우 DOMPurify로 sanitize하세요',
  });

  results.push({
    category: '보안',
    check: '하드코딩된 시크릿 없음',
    passed: !(await fileContains(filePath, /(api[_-]?key|secret|password|token)\s*[:=]\s*['"][^'"]+['"]/i)),
    details: '시크릿은 환경 변수로 관리하세요',
  });

  // 4. 성능
  results.push({
    category: '성능',
    check: '인라인 객체/배열 Props 없음',
    passed: !(await fileContains(filePath, /<\w+[^>]*(?:style|className)=\{\{/)),
    details: '인라인 객체는 매 렌더마다 새 참조를 생성합니다',
  });

  // 5. 접근성
  results.push({
    category: '접근성',
    check: 'img에 alt 속성 존재',
    passed: !(await fileContains(filePath, /<img(?![^>]*alt=)/)),
    details: '모든 img 태그에 alt 속성을 추가하세요',
  });

  // 6. 코드 품질
  results.push({
    category: '코드 품질',
    check: 'console.log 미사용',
    passed: !(await fileContains(filePath, /console\.(log|debug|info)\(/)),
    details: 'logger 유틸리티를 사용하세요',
  });

  return results;
}

async function fileContains(filePath: string, pattern: RegExp): Promise<boolean> {
  const { readFile } = await import('fs/promises');
  const content = await readFile(filePath, 'utf-8');
  return pattern.test(content);
}

// CI에서 실행
async function runQualityGate(changedFiles: string[]): Promise<boolean> {
  let allPassed = true;

  for (const file of changedFiles) {
    if (!file.endsWith('.ts') && !file.endsWith('.tsx')) continue;

    const results = await checkAiGeneratedCode(file);
    const failures = results.filter(r => !r.passed);

    if (failures.length > 0) {
      console.error(`\n${file}:`);
      failures.forEach(f => {
        console.error(`  [${f.category}] ${f.check}: ${f.details}`);
      });
      allPassed = false;
    }
  }

  return allPassed;
}

export { checkAiGeneratedCode, runQualityGate };
```

### 비용 추적 대시보드

```typescript
// lib/ai-cost-tracker.ts
interface AiUsageRecord {
  tool: 'claude-code' | 'copilot' | 'cursor' | 'coderabbit' | 'claude-api';
  timestamp: Date;
  inputTokens?: number;
  outputTokens?: number;
  model?: string;
  taskType: 'coding' | 'review' | 'testing' | 'design' | 'debugging';
  estimatedCost: number;
}

interface MonthlySummary {
  tool: string;
  totalCost: number;
  usageCount: number;
  avgCostPerUse: number;
  topTaskTypes: { type: string; count: number }[];
}

// 비용 단가 (2026년 기준 예상)
const COST_PER_TOKEN: Record<string, { input: number; output: number }> = {
  'claude-sonnet': { input: 0.003 / 1000, output: 0.015 / 1000 },
  'claude-opus': { input: 0.015 / 1000, output: 0.075 / 1000 },
  'gpt-4o': { input: 0.005 / 1000, output: 0.015 / 1000 },
};

function calculateCost(model: string, inputTokens: number, outputTokens: number): number {
  const rates = COST_PER_TOKEN[model];
  if (!rates) return 0;
  return inputTokens * rates.input + outputTokens * rates.output;
}

function generateMonthlySummary(records: AiUsageRecord[]): MonthlySummary[] {
  const byTool = new Map<string, AiUsageRecord[]>();

  for (const record of records) {
    const existing = byTool.get(record.tool) ?? [];
    existing.push(record);
    byTool.set(record.tool, existing);
  }

  return Array.from(byTool.entries()).map(([tool, toolRecords]) => {
    const totalCost = toolRecords.reduce((sum, r) => sum + r.estimatedCost, 0);
    const taskCounts = new Map<string, number>();
    for (const r of toolRecords) {
      taskCounts.set(r.taskType, (taskCounts.get(r.taskType) ?? 0) + 1);
    }

    return {
      tool,
      totalCost,
      usageCount: toolRecords.length,
      avgCostPerUse: totalCost / toolRecords.length,
      topTaskTypes: Array.from(taskCounts.entries())
        .map(([type, count]) => ({ type, count }))
        .sort((a, b) => b.count - a.count)
        .slice(0, 3),
    };
  });
}

export { calculateCost, generateMonthlySummary };
export type { AiUsageRecord, MonthlySummary };
```

### ROI 측정

```typescript
// scripts/ai-roi-calculator.ts
interface RoiMetric {
  category: string;
  withoutAi: number; // 시간 (분)
  withAi: number;    // 시간 (분)
  aiCost: number;    // USD
  developerRate: number; // USD/시간
}

function calculateRoi(metrics: RoiMetric[]): {
  totalTimeSaved: number;
  totalCostSaved: number;
  totalAiCost: number;
  roi: number;
} {
  let totalTimeSaved = 0;
  let totalCostSaved = 0;
  let totalAiCost = 0;

  for (const metric of metrics) {
    const timeSavedMinutes = metric.withoutAi - metric.withAi;
    const costSaved = (timeSavedMinutes / 60) * metric.developerRate;

    totalTimeSaved += timeSavedMinutes;
    totalCostSaved += costSaved;
    totalAiCost += metric.aiCost;
  }

  return {
    totalTimeSaved,
    totalCostSaved,
    totalAiCost,
    roi: totalAiCost > 0 ? ((totalCostSaved - totalAiCost) / totalAiCost) * 100 : 0,
  };
}

// 예시: 월간 ROI 계산
const monthlyMetrics: RoiMetric[] = [
  { category: '코드 생성', withoutAi: 2400, withAi: 600, aiCost: 100, developerRate: 80 },
  { category: '코드 리뷰', withoutAi: 800, withAi: 200, aiCost: 30, developerRate: 80 },
  { category: '테스트 작성', withoutAi: 1200, withAi: 300, aiCost: 50, developerRate: 80 },
  { category: '버그 디버깅', withoutAi: 600, withAi: 150, aiCost: 40, developerRate: 80 },
  { category: '문서 작성', withoutAi: 400, withAi: 100, aiCost: 20, developerRate: 80 },
];

const result = calculateRoi(monthlyMetrics);
// 예상 결과:
// 시간 절약: 4,250분 (약 70시간)
// 비용 절약: $5,666
// AI 비용: $240
// ROI: 2,261%

export { calculateRoi };
```
