## AI 기반 i18n 혁신

국제화의 가장 큰 병목은 **번역 키 추출, 하드코딩 문자열 탐지, 번역 품질 검증**이다. AI를 활용하면 이 세 가지를 근본적으로 자동화할 수 있다.

### Claude로 번역 키 자동 추출 프롬프트

#### 프롬프트 1: 컴포넌트에서 번역 키 일괄 추출

```bash
claude "src/features 디렉토리의 모든 React 컴포넌트를 스캔해서
       하드코딩된 한국어/영어 문자열을 찾아줘.
       1) 파일 경로와 라인 번호
       2) 원본 문자열
       3) 추천 번역 키 (dot notation, 예: payment.checkout.title)
       4) 네임스페이스 분류 (common, feature별)
       결과를 CSV 형식으로 출력해줘."
```

#### 프롬프트 2: 기존 번역 파일 기반 누락 키 탐지

```bash
claude "public/locales/ko.json과 public/locales/en.json을 비교해서
       1) ko에는 있지만 en에 없는 키 목록
       2) en에는 있지만 ko에 없는 키 목록
       3) 값이 동일한 키 (번역 누락 의심)
       4) 사용되지 않는 키 (코드에서 참조 없음)
       각 항목에 대한 수정 제안도 함께 출력해줘."
```

#### 프롬프트 3: 컨텍스트 기반 번역 키 네이밍 표준화

```bash
claude "현재 번역 파일의 키 네이밍 패턴을 분석하고
       1) 일관성 없는 키 패턴 식별 (camelCase vs snake_case 혼용 등)
       2) 네이밍 컨벤션 표준안 제안
       3) 자동 리네이밍 스크립트 생성
       4) feature 기반 네임스페이스 구조 제안
       기존 키를 새 표준에 맞게 마이그레이션하는 codemod도 만들어줘."
```

### AI 기반 번역 품질 검증 및 컨텍스트 보존

번역은 단순 텍스트 변환이 아니다. UI 컨텍스트, 문자 길이 제한, 톤앤매너를 모두 고려해야 한다.

```typescript
// ai-translation-validator.ts
interface TranslationContext {
  key: string;
  source: string;
  target: string;
  locale: string;
  maxLength?: number;
  uiContext?: 'button' | 'label' | 'title' | 'description' | 'placeholder' | 'error' | 'toast';
  screenshot?: string;
}

interface ValidationResult {
  key: string;
  status: 'pass' | 'warn' | 'fail';
  issues: ValidationIssue[];
}

interface ValidationIssue {
  type: 'length' | 'tone' | 'placeholder' | 'context' | 'grammar' | 'consistency';
  severity: 'error' | 'warning' | 'info';
  message: string;
  suggestion?: string;
}

async function validateTranslations(
  entries: TranslationContext[],
): Promise<ValidationResult[]> {
  const prompt = `
    다음 번역 항목들을 검증해줘. 각 항목에 대해:
    1) 원문의 의미가 정확히 전달되는지
    2) UI 컨텍스트에 적합한 길이인지 (maxLength 초과 여부)
    3) 플레이스홀더({name}, {count} 등)가 보존되는지
    4) 톤앤매너가 UI 요소에 적합한지 (버튼은 간결하게, 설명은 자연스럽게)
    5) 문법 오류가 없는지

    번역 항목:
    ${JSON.stringify(entries, null, 2)}
  `;

  const response = await callClaudeAPI(prompt);
  return parseValidationResponse(response);
}

// CI 파이프라인에서 번역 품질 게이트로 활용
async function translationQualityGate(): Promise<boolean> {
  const changedKeys = await getChangedTranslationKeys();
  const results = await validateTranslations(changedKeys);

  const errors = results.filter(r => r.status === 'fail');
  if (errors.length > 0) {
    console.error('번역 품질 검증 실패:', errors);
    return false;
  }

  return true;
}
```

### AI로 하드코딩된 문자열 자동 탐지 및 키 추출

```typescript
// hardcoded-string-detector.ts
import { Project, SyntaxKind } from 'ts-morph';

interface HardcodedString {
  filePath: string;
  line: number;
  text: string;
  suggestedKey: string;
  context: string;
}

function detectHardcodedStrings(projectPath: string): HardcodedString[] {
  const project = new Project({
    tsConfigFilePath: `${projectPath}/tsconfig.json`,
  });

  const results: HardcodedString[] = [];

  // JSX 텍스트와 문자열 리터럴에서 한국어/일본어/중국어 등 탐지
  const cjkPattern = /[\u3131-\uD79D\u4E00-\u9FFF\u3040-\u309F\u30A0-\u30FF]/;

  for (const sourceFile of project.getSourceFiles()) {
    // JSX 텍스트 노드
    sourceFile.getDescendantsOfKind(SyntaxKind.JsxText).forEach(node => {
      const text = node.getText().trim();
      if (text && cjkPattern.test(text)) {
        results.push({
          filePath: sourceFile.getFilePath(),
          line: node.getStartLineNumber(),
          text,
          suggestedKey: generateKeyFromPath(sourceFile.getFilePath(), text),
          context: node.getParent()?.getText().slice(0, 200) ?? '',
        });
      }
    });

    // 문자열 리터럴
    sourceFile.getDescendantsOfKind(SyntaxKind.StringLiteral).forEach(node => {
      const text = node.getLiteralText();
      if (cjkPattern.test(text)) {
        results.push({
          filePath: sourceFile.getFilePath(),
          line: node.getStartLineNumber(),
          text,
          suggestedKey: generateKeyFromPath(sourceFile.getFilePath(), text),
          context: node.getParent()?.getText().slice(0, 200) ?? '',
        });
      }
    });
  }

  return results;
}

function generateKeyFromPath(filePath: string, _text: string): string {
  // src/features/payment/CheckoutForm.tsx → payment.checkoutForm
  const parts = filePath
    .replace(/.*src\/features\//, '')
    .replace(/\.(tsx?|jsx?)$/, '')
    .split('/');

  const namespace = parts[0]?.toLowerCase() ?? 'common';
  const component = parts[parts.length - 1];
  const camelComponent = component
    ? component.charAt(0).toLowerCase() + component.slice(1)
    : 'unknown';

  return `${namespace}.${camelComponent}`;
}

// 탐지 결과를 AI에 전달하여 자동 변환
async function autoExtractToI18n(strings: HardcodedString[]): Promise<void> {
  const prompt = `
    다음 하드코딩된 문자열들을 i18n 키로 변환해줘.
    각 항목에 대해:
    1) 적절한 번역 키 (dot notation)
    2) 영어 번역
    3) 코드 수정 diff (useTranslation 훅 사용)

    ${JSON.stringify(strings, null, 2)}
  `;

  const response = await callClaudeAPI(prompt);
  await applyCodeModifications(response);
}
```

### ESLint 규칙으로 하드코딩 방지

```typescript
// eslint-plugin-i18n/no-hardcoded-strings.ts
import type { Rule } from 'eslint';

const rule: Rule.RuleModule = {
  meta: {
    type: 'suggestion',
    docs: {
      description: 'JSX 내 하드코딩된 문자열을 금지하고 i18n 키 사용을 강제한다',
    },
    fixable: 'code',
    schema: [
      {
        type: 'object',
        properties: {
          allowList: { type: 'array', items: { type: 'string' } },
        },
      },
    ],
  },
  create(context) {
    const allowList = (context.options[0] as { allowList?: string[] })?.allowList ?? [];

    return {
      JSXText(node) {
        const text = node.value.trim();
        if (!text || allowList.includes(text)) return;

        const cjkPattern = /[\u3131-\uD79D\u4E00-\u9FFF]/;
        if (cjkPattern.test(text)) {
          context.report({
            node,
            message: `하드코딩된 문자열 "${text}"을 발견했습니다. t() 함수를 사용하세요.`,
          });
        }
      },
    };
  },
};

export default rule;
```

## i18n 라이브러리 비교

### next-intl vs react-i18next vs FormatJS

| 기준 | next-intl | react-i18next | FormatJS (react-intl) |
|------|-----------|---------------|----------------------|
| **Next.js 통합** | 네이티브 (App Router 최적) | 플러그인 필요 | 플러그인 필요 |
| **번들 크기** | ~2KB | ~10KB | ~12KB |
| **서버 컴포넌트** | 완전 지원 | 부분 지원 (v15+) | 미지원 |
| **ICU 포맷** | 완전 지원 | 플러그인 필요 | 완전 지원 (표준) |
| **타입 안전성** | 내장 (자동 추론) | @types 필요 | 제한적 |
| **복수형/성별** | ICU 기반 | ICU 플러그인 | ICU 네이티브 |
| **네임스페이스** | 파일 기반 | 다중 네임스페이스 | 단일 메시지 맵 |
| **SSR 성능** | 최적 (RSC 네이티브) | 양호 | 양호 |
| **학습 곡선** | 낮음 | 중간 | 높음 |
| **생태계** | Next.js 중심 | 범용 (React, RN) | 범용 |
| **추천 시나리오** | Next.js App Router | 범용 React 프로젝트 | ICU 표준 필수 |

### next-intl 설정 (Next.js App Router)

```typescript
// i18n/request.ts
import { getRequestConfig } from 'next-intl/server';
import { routing } from './routing';

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale;

  if (!locale || !routing.locales.includes(locale as typeof routing.locales[number])) {
    locale = routing.defaultLocale;
  }

  return {
    locale,
    messages: (await import(`../../messages/${locale}.json`)).default,
  };
});
```

```typescript
// i18n/routing.ts
import { defineRouting } from 'next-intl/routing';

export const routing = defineRouting({
  locales: ['ko', 'en', 'ja', 'zh'],
```

```typescript
// app/[locale]/layout.tsx
import { NextIntlClientProvider } from 'next-intl';
import { getMessages } from 'next-intl/server';
import { notFound } from 'next/navigation';
import { routing } from '@/i18n/routing';

interface LayoutProps {
  children: React.ReactNode;
  params: Promise<{ locale: string }>;
}

export default async function LocaleLayout({ children, params }: LayoutProps) {
  const { locale } = await params;

  if (!routing.locales.includes(locale as typeof routing.locales[number])) {
    notFound();
  }

  const messages = await getMessages();

  return (
    <html lang={locale} dir={locale === 'ar' || locale === 'he' ? 'rtl' : 'ltr'}>
      <body>
        <NextIntlClientProvider messages={messages}>
          {children}
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```

## RTL 지원

### 방향 감지 및 레이아웃

```typescript
// hooks/useDirection.ts
import { useLocale } from 'next-intl';

const RTL_LOCALES = ['ar', 'he', 'fa', 'ur'] as const;

type Direction = 'ltr' | 'rtl';

export function useDirection(): Direction {
  const locale = useLocale();
  return RTL_LOCALES.includes(locale as typeof RTL_LOCALES[number]) ? 'rtl' : 'ltr';
}
```

### Tailwind CSS RTL 유틸리티

```tsx
function Sidebar({ children }: { children: React.ReactNode }) {
  return (
    // ms = margin-start (LTR: margin-left, RTL: margin-right)
    // me = margin-end (LTR: margin-right, RTL: margin-left)
    <aside className="ms-0 me-4 rtl:me-0 rtl:ms-4 border-e border-gray-200">
      {children}
    </aside>
  );
}

function NavigationItem({ icon, label }: { icon: React.ReactNode; label: string }) {
  return (
    <li className="flex items-center gap-2 ps-4 pe-2">
      <span className="shrink-0">{icon}</span>
      <span className="text-start">{label}</span>
      {/* 화살표 아이콘도 RTL에서 자동 반전 */}
      <span className="ms-auto rtl:rotate-180">→</span>
    </li>
  );
}
```

```typescript
// test-utils/rtl-render.tsx
import { render, type RenderOptions } from '@testing-library/react';
import { NextIntlClientProvider } from 'next-intl';

const RTL_WRAPPER_LOCALES = ['ar', 'he'] as const;

function createDirectionWrapper(locale: string) {
  const dir = RTL_WRAPPER_LOCALES.includes(locale as typeof RTL_WRAPPER_LOCALES[number])
    ? 'rtl'
    : 'ltr';

  return function Wrapper({ children }: { children: React.ReactNode }) {
    return (
      <div dir={dir}>
        <NextIntlClientProvider locale={locale} messages={{}}>
          {children}
        </NextIntlClientProvider>
      </div>
    );
  };
}

export function renderWithDirection(
  ui: React.ReactElement,
  locale: string,
  options?: Omit<RenderOptions, 'wrapper'>,
) {
  return render(ui, {
    wrapper: createDirectionWrapper(locale),
    ...options,
  });
}
```

### CI/CD 연동 번역 파이프라인

```yaml
# .github/workflows/i18n-sync.yml
name: i18n Sync

on:
  push:
    paths:
      - 'messages/**'
  pull_request:
    paths:
      - 'src/**/*.tsx'

jobs:
  check-translations:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: 번역 키 누락 검사
        run: |
          npx i18n-check --source messages/ko.json \
                         --targets messages/en.json,messages/ja.json \
```

### 의사 로컬라이제이션 (Pseudo-Localization)

UI가 번역 확장에 대응하는지 확인하는 기법이다. 텍스트를 인위적으로 늘려서 레이아웃 깨짐을 사전 탐지한다.

```typescript
// utils/pseudo-locale.ts
const CHAR_MAP: Record<string, string> = {
  a: 'ä', b: 'ḅ', c: 'ç', d: 'ḍ', e: 'ë', f: 'ḟ', g: 'ġ', h: 'ḥ',
  i: 'ï', j: 'ĵ', k: 'ḳ', l: 'ḷ', m: 'ṁ', n: 'ñ', o: 'ö', p: 'ṗ',
  q: 'q', r: 'ṛ', s: 'ṡ', t: 'ṭ', u: 'ü', v: 'ṿ', w: 'ẇ', x: 'ẋ',
  y: 'ÿ', z: 'ẓ',
};

export function pseudoLocalize(text: string): string {
  // 플레이스홀더 보존: {name}, {count} 등
  const placeholderPattern = /\{[^}]+\}/g;
  const placeholders: string[] = [];
  const stripped = text.replace(placeholderPattern, match => {
    placeholders.push(match);
    return `__PH${placeholders.length - 1}__`;
  });

  // 문자 변환 + 30% 길이 확장
  let result = stripped
    .split('')
    .map(char => CHAR_MAP[char.toLowerCase()] ?? char)
    .join('');

  // 길이 확장 (독일어 등 번역 확장 시뮬레이션)
  const padding = '~'.repeat(Math.ceil(result.length * 0.3));
  result = `[${result}${padding}]`;

  // 플레이스홀더 복원
  placeholders.forEach((ph, i) => {
    result = result.replace(`__PH${i}__`, ph);
  });

  return result;
}
```
