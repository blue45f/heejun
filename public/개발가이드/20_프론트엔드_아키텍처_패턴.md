## 1. AI 기반 아키텍처 설계

> 프론트엔드 아키텍처 설계에서 AI를 활용하면 **기존 코드베이스의 구조적 문제를 자동 탐지**하고, **최적의 모듈 경계를 데이터 기반으로 제안**받을 수 있다. **전체 아키텍처 설계 시간의 30% 이상을 AI 기반 분석에 투자**한다.

### 1.2 AI로 의존성 그래프 분석 및 순환 의존성 탐지

```typescript
// ai-circular-dependency-detector.ts
interface CircularDependency {
  cycle: string[];
  severity: 'critical' | 'warning';
  resolution: ResolutionStrategy;
}

interface ResolutionStrategy {
  method: 'extract-interface' | 'event-based' | 'dependency-injection' | 'merge-modules';
  description: string;
  codeExample: string;
}

async function detectCircularDependenciesWithAI(
  importGraph: Map<string, string[]>,
): Promise<CircularDependency[]> {
  // 1단계: 알고리즘으로 순환 탐지 (Tarjan's SCC)
  const cycles = findStronglyConnectedComponents(importGraph);

  if (cycles.length === 0) return [];

  // 2단계: AI로 해소 전략 제안
  const prompt = `
다음 순환 의존성을 분석하고, 각각에 대한 해소 전략을 제안하라.

## 발견된 순환 의존성
${cycles.map((cycle, i) => `${i + 1}. ${cycle.join(' → ')} → ${cycle[0]}`).join('\n')}

## 해소 전략 옵션
1. 인터페이스 추출: 공통 인터페이스를 별도 모듈로 분리
2. 이벤트 기반: 직접 import 대신 이벤트로 통신
3. DI(의존성 주입): 런타임에 의존성 주입
4. 모듈 병합: 밀접한 모듈을 하나로 합침

각 순환 의존성에 가장 적합한 전략과 코드 예시를 제시하라.`;

  const response = await callAI(prompt);
  return response as CircularDependency[];
}

function findStronglyConnectedComponents(
  graph: Map<string, string[]>,
): string[][] {
  const index = new Map<string, number>();
  const lowlink = new Map<string, number>();
  const onStack = new Set<string>();
  const stack: string[] = [];
  const sccs: string[][] = [];
  let idx = 0;

  function strongconnect(v: string) {
    index.set(v, idx);
    lowlink.set(v, idx);
    idx++;
    stack.push(v);
    onStack.add(v);

    for (const w of graph.get(v) ?? []) {
      if (!index.has(w)) {
        strongconnect(w);
        lowlink.set(v, Math.min(lowlink.get(v)!, lowlink.get(w)!));
      } else if (onStack.has(w)) {
        lowlink.set(v, Math.min(lowlink.get(v)!, index.get(w)!));
      }
    }

    if (lowlink.get(v) === index.get(v)) {
      const scc: string[] = [];
      let w: string;
      do {
        w = stack.pop()!;
        onStack.delete(w);
        scc.push(w);
      } while (w !== v);

      if (scc.length > 1) {
        sccs.push(scc);
      }
    }
  }

  for (const v of graph.keys()) {
    if (!index.has(v)) strongconnect(v);
  }

  return sccs;
}

async function callAI(prompt: string): Promise<unknown> {
  // AI API 호출 구현
  console.log('Calling AI with prompt:', prompt.substring(0, 100));

}
```

```typescript
interface ModuleBoundaryReport {

function collectExports(root: string): Record<string, string[]> {
  const result: Record<string, string[]> = {};
  const configPath = ts.findConfigFile(root, ts.sys.fileExists);
  if (!configPath) return result;

  const config = ts.readConfigFile(configPath, ts.sys.readFile);
  const parsed = ts.parseJsonConfigFileContent(config.config, ts.sys, root);
  const program = ts.createProgram(parsed.fileNames, parsed.options);
  const checker = program.getTypeChecker();

  for (const sourceFile of program.getSourceFiles()) {
    if (sourceFile.isDeclarationFile) continue;
    const symbol = checker.getSymbolAtLocation(sourceFile);
    if (symbol) {
      const exports = checker.getExportsOfModule(symbol);
      result[sourceFile.fileName] = exports.map((e) => e.getName());
    }
  }

  return result;
}
```

## 2. Feature-Sliced Design (FSD) 상세 가이드

> FSD는 **비즈니스 도메인 중심으로 코드를 조직화**하는 아키텍처 방법론이다. 계층(Layer), 슬라이스(Slice), 세그먼트(Segment)의 3단계 구조로 코드를 구성한다.

### 2.1 계층 구조

```
src/
├── app/          # Layer 1: 앱 초기화, 프로바이더, 라우팅
├── processes/    # Layer 2: 여러 페이지에 걸친 비즈니스 프로세스 (선택)
├── pages/        # Layer 3: 페이지 단위 컴포넌트
├── widgets/      # Layer 4: 독립적인 UI 블록 (페이지 섹션)
├── features/     # Layer 5: 사용자 상호작용 (비즈니스 액션)
├── entities/     # Layer 6: 비즈니스 엔티티 (데이터 모델)
└── shared/       # Layer 7: 재사용 가능한 유틸, UI 킷
```

**핵심 규칙**: 상위 계층은 하위 계층만 import할 수 있다. 같은 계층 간 import는 금지.

```
app → pages → widgets → features → entities → shared
                ↓ (허용)       ↓ (허용)        ↓ (허용)
              features      entities        shared
```

### 2.2 슬라이스와 세그먼트

```
src/features/
├── auth/
│   ├── ui/           # Segment: UI 컴포넌트
│   │   ├── LoginForm.tsx
│   │   └── index.ts
│   ├── model/        # Segment: 비즈니스 로직, 상태
│   │   ├── useAuth.ts
│   │   └── index.ts
│   ├── api/          # Segment: API 호출
│   │   ├── authApi.ts
│   │   └── index.ts
│   ├── lib/          # Segment: 유틸리티
│   │   └── tokenUtils.ts
│   └── index.ts      # Public API (barrel export)
├── checkout/
│   ├── ui/
│   ├── model/
│   ├── api/
│   └── index.ts
```

```typescript
// src/features/auth/index.ts (Public API)
export { LoginForm } from './ui/LoginForm';
export { useAuth } from './model/useAuth';
export type { AuthState, LoginCredentials } from './model/types';

// src/features/auth/model/useAuth.ts
import { create } from 'zustand';
import { authApi } from '../api';
// entities 계층 import (허용: features → entities)
import { type User } from '@/entities/user';

interface AuthState {
  user: User | null;
  isAuthenticated: boolean;
  isLoading: boolean;
  login: (credentials: LoginCredentials) => Promise<void>;
  logout: () => Promise<void>;
}

interface LoginCredentials {
  email: string;
  password: string;
}

export const useAuth = create<AuthState>((set) => ({
  user: null,
  isAuthenticated: false,
  isLoading: false,
  login: async (credentials) => {
    set({ isLoading: true });
    try {
      const user = await authApi.login(credentials);
      set({ user, isAuthenticated: true, isLoading: false });
    } catch {
      set({ isLoading: false });
      throw new Error('Login failed');
    }
  },
  logout: async () => {
    await authApi.logout();
    set({ user: null, isAuthenticated: false });
  },
}));

// src/features/auth/ui/LoginForm.tsx
```

```typescript
// eslint-plugin-fsd/rules/layer-imports.ts
const LAYER_ORDER = [
  'app',
  'processes',
  'pages',
  'widgets',
  'features',
  'entities',
  'shared',
] as const;

type Layer = (typeof LAYER_ORDER)[number];

function getLayerFromPath(filePath: string): Layer | null {
  for (const layer of LAYER_ORDER) {
    if (filePath.includes(`/src/${layer}/`) || filePath.includes(`@/${layer}/`)) {
      return layer;
    }
  }
  return null;
}

function isValidImport(fromLayer: Layer, toLayer: Layer): boolean {
  const fromIdx = LAYER_ORDER.indexOf(fromLayer);
  const toIdx = LAYER_ORDER.indexOf(toLayer);
  // 상위 계층 → 하위 계층만 허용 (인덱스가 작을수록 상위)
  return fromIdx < toIdx;
}

// ESLint rule 구현 예시
export const layerImportsRule = {
  meta: { type: 'problem' as const, messages: { invalidImport: 'Layer "{{from}}" cannot import from "{{to}}"' } },
  create(context: { getFilename: () => string; report: (opts: Record<string, unknown>) => void }) {
    return {
      ImportDeclaration(node: { source: { value: string }; loc: unknown }) {
        const filePath = context.getFilename();
        const fromLayer = getLayerFromPath(filePath);
        const toLayer = getLayerFromPath(node.source.value);

        if (fromLayer && toLayer && !isValidImport(fromLayer, toLayer)) {
          context.report({
            node,
            messageId: 'invalidImport',
            data: { from: fromLayer, to: toLayer },
          });
        }
      },
    };
  },
};
```

```typescript
// domain/entities/Order.ts — 순수 TypeScript, 프레임워크 의존성 없음
interface OrderItem {
  productId: string;
  name: string;
  price: number;
  quantity: number;
}

export class Order {
  constructor(
    public readonly id: string,
    public readonly items: OrderItem[],
    public readonly status: 'draft' | 'confirmed' | 'shipped' | 'delivered',
    public readonly createdAt: Date,
  ) {}

  get totalAmount(): number {
    return this.items.reduce((sum, item) => sum + item.price * item.quantity, 0);
  }

  get itemCount(): number {
    return this.items.reduce((sum, item) => sum + item.quantity, 0);
  }

  canBeCancelled(): boolean {
    return this.status === 'draft' || this.status === 'confirmed';
  }

  addItem(item: OrderItem): Order {
    if (this.status !== 'draft') {
      throw new Error('Cannot add items to a non-draft order');
    }
    return new Order(this.id, [...this.items, item], this.status, this.createdAt);
  }
}

// application/ports/OrderRepository.ts — 인터페이스만 정의
export interface OrderRepository {
  findById(id: string): Promise<Order | null>;
  findByUserId(userId: string): Promise<Order[]>;
  save(order: Order): Promise<void>;
}

// domain/use-cases/CancelOrder.ts — 순수 비즈니스 로직
import { Order } from '../entities/Order';

export interface CancelOrderPort {
  findById(id: string): Promise<Order | null>;
  save(order: Order): Promise<void>;
}

export class CancelOrderUseCase {
  constructor(private readonly orderPort: CancelOrderPort) {}

  async execute(orderId: string): Promise<Order> {
    const order = await this.orderPort.findById(orderId);
    if (!order) throw new Error('Order not found');
    if (!order.canBeCancelled()) throw new Error('Order cannot be cancelled');

    const cancelledOrder = new Order(
      order.id,
      order.items,
      'draft', // 취소 → draft로 되돌림
      order.createdAt,
    );

    await this.orderPort.save(cancelledOrder);
    return cancelledOrder;
  }
}

// infrastructure/adapters/ApiOrderRepository.ts — 포트 구현체
import type { OrderRepository } from '../../application/ports/OrderRepository';
import { Order } from '../../domain/entities/Order';

export class ApiOrderRepository implements OrderRepository {
  constructor(private readonly baseUrl: string) {}

  async findById(id: string): Promise<Order | null> {
    const res = await fetch(`${this.baseUrl}/orders/${id}`);
    if (!res.ok) return null;
    const data = await res.json();
    return new Order(data.id, data.items, data.status, new Date(data.createdAt));
  }

  async findByUserId(userId: string): Promise<Order[]> {
    const res = await fetch(`${this.baseUrl}/users/${userId}/orders`);
    const data = await res.json();
    return data.map(
      (d: { id: string; items: OrderItem[]; status: Order['status']; createdAt: string }) =>
        new Order(d.id, d.items, d.status, new Date(d.createdAt)),
    );
  }

  async save(order: Order): Promise<void> {
    await fetch(`${this.baseUrl}/orders/${order.id}`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(order),
    });
  }
}

// presentation/hooks/useOrders.ts — UI 계층에서 유스케이스 사용
import { useState, useEffect, useCallback } from 'react';
import { Order } from '../../domain/entities/Order';
import { CancelOrderUseCase } from '../../domain/use-cases/CancelOrder';
import { ApiOrderRepository } from '../../infrastructure/adapters/ApiOrderRepository';

const orderRepo = new ApiOrderRepository('/api');
const cancelOrderUseCase = new CancelOrderUseCase(orderRepo);

export function useOrders(userId: string) {
  const [orders, setOrders] = useState<Order[]>([]);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    orderRepo.findByUserId(userId).then((data) => {
      setOrders(data);
      setIsLoading(false);
    });
  }, [userId]);

  const cancelOrder = useCallback(async (orderId: string) => {
    const updated = await cancelOrderUseCase.execute(orderId);
    setOrders((prev) => prev.map((o) => (o.id === orderId ? updated : o)));
  }, []);

  return { orders, isLoading, cancelOrder };
}
```

```typescript
import { useState, useEffect, useCallback } from 'react';
import type { ProductService } from '../../../core/ports/inbound/ProductService';
import type { Product } from '../../../core/ports/outbound/ProductRepository';

export function createUseProducts(productService: ProductService) {
  return function useProducts() {
    const [products, setProducts] = useState<Product[]>([]);
    const [isLoading, setIsLoading] = useState(true);
    const [error, setError] = useState<Error | null>(null);

    useEffect(() => {
      productService
        .getProducts()
        .then(setProducts)
        .catch(setError)
        .finally(() => setIsLoading(false));
    }, []);

    const search = useCallback(async (query: string) => {
      setIsLoading(true);
      try {
        const results = await productService.searchProducts(query);
        setProducts(results);
      } catch (err) {
        setError(err instanceof Error ? err : new Error(String(err)));
      } finally {
        setIsLoading(false);
      }
    }, []);

    return { products, isLoading, error, search };
  };
}
```

| **FSD** | `src/{app,pages,features,...}/` | 계층 규칙 명확 | 학습 곡선 높음 | 중대규모 |
| **Clean Architecture** | `src/{domain,application,infra}/` | 비즈니스 로직 독립 | 보일러플레이트 많음 | 대규모 |
| **Hexagonal** | `src/{core,adapters,config}/` | 외부 의존성 교체 용이 | 구조 복잡 | 대규모 |
| **Atomic Design** | `src/{atoms,molecules,organisms}/` | UI 일관성 | 비즈니스 로직 위치 모호 | UI 라이브러리 |

## 8. 아키텍처 의사결정 프레임워크

### 8.1 결정 매트릭스

아키텍처 선택 시 다음 기준으로 평가한다.

| 기준 | 가중치 | 평가 질문 |
|------|--------|-----------|
| **팀 규모** | 25% | 현재 및 6개월 후 예상 팀 규모는? |
| **도메인 복잡도** | 25% | 비즈니스 로직의 복잡도와 변경 빈도는? |
| **기술 다양성** | 15% | 다른 프레임워크/라이브러리 혼용 필요성은? |
| **배포 독립성** | 15% | 팀별 독립 배포가 필요한가? |
| **학습 비용** | 10% | 팀원이 해당 패턴에 익숙한가? |
| **마이그레이션 비용** | 10% | 기존 코드에서 전환하는 비용은? |

### 8.2 의사결정 플로우

```typescript
// architecture-decision-flow.ts
interface ProjectContext {
  teamSize: number;
  domainComplexity: 'low' | 'medium' | 'high';
  deploymentIndependence: boolean;
  techDiversity: boolean;
  existingArchitecture: string | null;
}

type ArchitectureRecommendation =
  | 'feature-based'
  | 'fsd'
  | 'clean-architecture'
  | 'hexagonal'
  | 'micro-frontend';

function recommendArchitecture(
  context: ProjectContext,
): { primary: ArchitectureRecommendation; reasoning: string } {
  // 마이크로 프론트엔드: 대규모 팀 + 독립 배포 필요
  if (context.teamSize > 15 && context.deploymentIndependence) {
    return {
      primary: 'micro-frontend',
      reasoning: '팀 규모가 크고 독립 배포가 필요하여 마이크로 FE 권장',
    };
  }

  // Clean/Hexagonal: 높은 도메인 복잡도
  if (context.domainComplexity === 'high') {
    return {
      primary: context.techDiversity ? 'hexagonal' : 'clean-architecture',
      reasoning: '도메인 복잡도가 높아 비즈니스 로직 독립이 중요',
    };
  }

  // FSD: 중규모 팀 + 중간 복잡도
  if (context.teamSize > 5 && context.domainComplexity === 'medium') {
    return {
      primary: 'fsd',
      reasoning: '팀 규모와 복잡도를 고려하여 FSD의 명확한 계층 규칙이 적합',
    };
  }

  // Feature-Based: 소규모 팀 + 낮은 복잡도
  return {
    primary: 'feature-based',
    reasoning: '소규모 팀에서 빠르게 시작하기에 Feature-Based가 가장 효율적',
  };
}

export { recommendArchitecture };
```
