## 1. AI 프롬프트 -- 디자인-개발 협업 시나리오 7선

디자인-개발 사이의 **핸드오프 병목**을 AI로 해소한다. 각 프롬프트는 Figma 산출물을 입력으로 받아 실제 프로덕션 코드를 생성하는 실전 시나리오이다.

### 프롬프트 1: Figma 프레임을 React 컴포넌트로 변환

> ```
> Figma Dev Mode에서 추출한 아래 디자인 스펙을 React 컴포넌트로 변환해줘.
>
> 변환 규칙:
> - Figma Auto Layout → Flexbox/Grid (Tailwind CSS v4 @theme 토큰 활용)
> - Figma 컴포넌트 프로퍼티 → TypeScript props 인터페이스
> - Figma Variant → CVA variant 매핑
> - 색상/타이포/스페이싱은 W3C Design Token 변수로 (--dt-color-*, --dt-space-*)
> - forwardRef + displayName + ARIA 역할 설정
> - Storybook 스토리 동시 생성 (Default, Variants, Interactive)
>
> --- Figma 스펙 ---
> {Dev Mode에서 복사한 CSS/속성 붙여넣기}
>
> --- 디자인 토큰 (W3C DTCG 포맷) ---
> {tokens.json 관련 부분 붙여넣기}
> ```

### 프롬프트 2: 기존 컴포넌트를 CVA variant로 리팩토링

> ```

> - 인라인 조건부 className → CVA variants로 통합

> ```
> Figma 컴포넌트의 프로퍼티 목록을 TypeScript 인터페이스로 변환해줘.

## 2. Figma Dev Mode + Code Connect 2026

Figma Dev Mode의 2026 최신 기능을 활용하여 디자인-코드 간 **양방향 동기화**를 구현한다.

### 2.1 Code Connect 설정

```typescript
// button.figma.tsx -- Figma 컴포넌트와 React 코드 연결
import figma from '@figma/code-connect';
import { Button } from './Button';

figma.connect(Button, 'https://figma.com/design/FILE_KEY/node-id=COMPONENT_NODE_ID', {
  props: {
    // Figma Variant → React prop 매핑
    variant: figma.enum('Variant', {
      Primary: 'primary',
      Secondary: 'secondary',
      Ghost: 'ghost',
      Destructive: 'destructive',
    }),
    size: figma.enum('Size', {
      Small: 'sm',
      Medium: 'md',
      Large: 'lg',
    }),
    disabled: figma.boolean('Disabled'),
    label: figma.string('Label'),
    icon: figma.instance('Icon'),
    children: figma.children('Content'),
  },
  example: (props) => (
    <Button
      variant={props.variant}
      size={props.size}
      disabled={props.disabled}
    >
      {props.icon}
      {props.label}
    </Button>
  ),
});
```

### 2.2 Code Connect CLI 자동화

```typescript
// scripts/code-connect-sync.ts
import { execSync } from 'node:child_process';
import { globSync } from 'node:fs';

interface SyncConfig {
  figmaFileKey: string;
  componentDir: string;
  outputDir: string;
}

function syncCodeConnect(config: SyncConfig): void {
  // 1. .figma.tsx 파일 자동 탐색
  const connectFiles = globSync(`${config.componentDir}/**/*.figma.tsx`);

  console.log(`Found ${connectFiles.length} Code Connect files`);

  // 2. Figma에 코드 스니펫 게시
  execSync('npx figma connect publish', {
    stdio: 'inherit',
    env: {
      ...process.env,
      FIGMA_ACCESS_TOKEN: process.env.FIGMA_ACCESS_TOKEN,
    },
  });

  // 3. 연결 상태 검증
  execSync('npx figma connect verify', { stdio: 'inherit' });

  console.log('Code Connect sync complete');
}

// CI에서 PR 머지 시 자동 실행
syncCodeConnect({
  figmaFileKey: process.env.FIGMA_FILE_KEY!,
  componentDir: 'src/components',
  outputDir: 'dist/code-connect',
});
```

## 3. shadcn/ui v3 vs Radix Themes 4 비교

| 비교 항목 | shadcn/ui v3 | Radix Themes 4 |
|---|---|---|
| **철학** | 코드 소유권 (복사+수정) | 패키지 의존성 (설치+설정) |
| **설치 방식** | `npx shadcn@latest add button` | `npm install @radix-ui/themes` |
| **스타일링** | Tailwind CSS v4 + CVA | 자체 CSS + CSS 변수 |
| **커스터마이징** | 소스 코드 직접 수정 | Theme 컴포넌트 + 토큰 오버라이드 |
| **Figma 연동** | 커뮤니티 Figma Kit | 공식 Figma Kit 제공 |
| **다크 모드** | CSS 변수 + class 전환 | `appearance` prop 내장 |
| **컴포넌트 수** | 50+ (커뮤니티 확장) | 30+ (공식 큐레이션) |
| **접근성** | Radix Primitives 기반 | Radix Primitives 기반 (동일) |
| **번들 크기** | 사용 컴포넌트만 포함 | 전체 테마 CSS 포함 |
| **브랜드 커스텀** | 완전 자유 | 제한적 (토큰 범위 내) |
| **Server Components** | 완전 지원 | 완전 지원 |
| **적합한 케이스** | 고도 커스텀 디자인 시스템 | 빠른 프로토타이핑, 일관된 UI |

### 4.3 Style Dictionary 4.0 설정

```typescript
// style-dictionary.config.ts
import StyleDictionary from 'style-dictionary';
import type { Config } from 'style-dictionary/types';

// 커스텀 W3C DTCG 파서 등록
StyleDictionary.registerParser({
  name: 'w3c-dtcg',
  pattern: /\.tokens\.json$/,
  parser: ({ contents }) => {
    const parsed = JSON.parse(contents);
    return flattenDTCGTokens(parsed);
  },
});

// CSS 변수 커스텀 포맷
StyleDictionary.registerFormat({
  name: 'css/variables-layered',
  format: ({ dictionary, options }) => {
    const layer = options.layer ?? 'tokens';
    const tokens = dictionary.allTokens
      .map((token) => `  --dt-${token.name}: ${token.value};`)
      .join('\n');

    return `@layer ${layer} {\n  :root {\n${tokens}\n  }\n}`;
  },
});

// Tailwind CSS v4 @theme 포맷
StyleDictionary.registerFormat({
  name: 'tailwind/v4-theme',
  format: ({ dictionary }) => {
    const colors = dictionary.allTokens
      .filter((t) => t.$type === 'color')
      .map((t) => `  --color-${t.name}: ${t.value};`)
      .join('\n');

    const spacing = dictionary.allTokens
      .filter((t) => t.$type === 'dimension')
      .map((t) => `  --spacing-${t.name}: ${t.value};`)
      .join('\n');

    return `@theme {\n${colors}\n${spacing}\n}`;
  },
});

const config: Config = {
  source: ['tokens/global/**/*.tokens.json', 'tokens/semantic/**/*.tokens.json'],
  parsers: ['w3c-dtcg'],
  platforms: {
    css: {
      transformGroup: 'css',
      buildPath: 'dist/css/',
      files: [
        {
          destination: 'tokens.css',
          format: 'css/variables-layered',
          options: { layer: 'design-tokens' },
        },
      ],
    },
    tailwind: {
      transformGroup: 'css',
      buildPath: 'dist/tailwind/',
      files: [
        {
          destination: 'theme.css',
          format: 'tailwind/v4-theme',
        },
      ],
    },
    typescript: {
      transformGroup: 'js',
      buildPath: 'dist/ts/',
      files: [
        {
          destination: 'tokens.ts',
          format: 'javascript/es6',
        },
      ],
    },
  },
};

export default config;

// W3C DTCG 토큰 플래트닝 유틸
function flattenDTCGTokens(
  obj: Record<string, unknown>,
  prefix = '',
): Record<string, unknown>[] {
  const result: Record<string, unknown>[] = [];

  for (const [key, value] of Object.entries(obj)) {
    if (key.startsWith('$')) continue;
    const path = prefix ? `${prefix}-${key}` : key;

    if (typeof value === 'object' && value !== null && '$value' in value) {
      result.push({
        name: path,
        value: (value as Record<string, unknown>).$value,
        $type: (value as Record<string, unknown>).$type ?? obj.$type,
        $description: (value as Record<string, unknown>).$description,
      });
    } else if (typeof value === 'object' && value !== null) {
      const inherited = { ...value, $type: (value as Record<string, unknown>).$type ?? obj.$type };
      result.push(...flattenDTCGTokens(inherited as Record<string, unknown>, path));
    }
  }

  return result;
}
```

### 5.2 CSS Layers 우선순위 설명

```
@layer 우선순위 (낮은 → 높은):

  design-tokens   -- Style Dictionary 생성 CSS 변수 (기반)
       ↓
  theme           -- @theme 디렉티브 (Tailwind 연결)
       ↓
  base            -- HTML 요소 기본 스타일
       ↓
  components      -- 재사용 컴포넌트 스타일 (@apply)
       ↓
  utilities       -- Tailwind 유틸리티 (최고 우선순위)

→ 유틸리티 클래스가 항상 컴포넌트 기본 스타일을 오버라이드
→ 디자인 토큰 변경 시 모든 레이어에 자동 전파
```

import StyleDictionary from 'style-dictionary';

interface BrandConfig {
  name: string;
  source: string[];
  darkOverrides: string;

const brands: BrandConfig[] = [
  {
    name: 'default',

      'tokens/semantic/**/*.tokens.json',
      'tokens/brand-a/overrides.tokens.json',
    ],
    darkOverrides: 'tokens/dark/overrides.tokens.json',
  },
  {
    name: 'brand-b',
    source: [
      'tokens/global/**/*.tokens.json',
      'tokens/semantic/**/*.tokens.json',
      'tokens/brand-b/overrides.tokens.json',
    ],
    darkOverrides: 'tokens/dark/overrides.tokens.json',
  },
];

async function buildAllBrands(): Promise<void> {
  for (const brand of brands) {
    // 라이트 모드
    const sdLight = new StyleDictionary({
      source: brand.source,
      platforms: {
        css: {
          transformGroup: 'css',
          buildPath: `dist/${brand.name}/`,
          files: [
            {
              destination: 'tokens-light.css',
              format: 'css/variables-layered',
              options: { layer: 'design-tokens', selector: `[data-brand="${brand.name}"]` },
            },
          ],
        },
      },
    });

    // 다크 모드
    const sdDark = new StyleDictionary({
      source: [...brand.source, brand.darkOverrides],
      platforms: {
        css: {
          transformGroup: 'css',
          buildPath: `dist/${brand.name}/`,
          files: [
            {
              destination: 'tokens-dark.css',
              format: 'css/variables-layered',
              options: {
                layer: 'design-tokens',
                selector: `[data-brand="${brand.name}"].dark`,
              },
            },
          ],
        },
      },
    });

    await sdLight.buildAllPlatforms();
    await sdDark.buildAllPlatforms();

    console.log(`Built tokens for brand: ${brand.name}`);
  }
}

buildAllBrands();

### 6.2 런타임 브랜드/테마 전환

```typescript
// hooks/useDesignTokens.ts
import { useCallback, useEffect, useState } from 'react';

type Theme = 'light' | 'dark' | 'system';
type Brand = 'default' | 'brand-a' | 'brand-b';

interface DesignTokenState {
  theme: Theme;
  brand: Brand;
  resolvedTheme: 'light' | 'dark';
}

interface UseDesignTokensReturn extends DesignTokenState {
  setTheme: (theme: Theme) => void;
  setBrand: (brand: Brand) => void;
  toggleTheme: () => void;
}

export function useDesignTokens(): UseDesignTokensReturn {
  const [state, setState] = useState<DesignTokenState>({
    theme: 'system',
    brand: 'default',
    resolvedTheme: 'light',
  });

  const resolveTheme = useCallback((theme: Theme): 'light' | 'dark' => {
    if (theme === 'system') {
      return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
    }
    return theme;
  }, []);

  useEffect(() => {
    const resolved = resolveTheme(state.theme);
    setState((prev) => ({ ...prev, resolvedTheme: resolved }));

    // DOM 속성 업데이트
    const root = document.documentElement;
    root.setAttribute('data-brand', state.brand);
    root.classList.toggle('dark', resolved === 'dark');

    // 동적 CSS 로드
    loadBrandCSS(state.brand, resolved);

    // 시스템 테마 변경 감지
    if (state.theme === 'system') {
      const mql = window.matchMedia('(prefers-color-scheme: dark)');
      const handler = (e: MediaQueryListEvent) => {
        setState((prev) => ({ ...prev, resolvedTheme: e.matches ? 'dark' : 'light' }));
        root.classList.toggle('dark', e.matches);
      };
      mql.addEventListener('change', handler);
      return () => mql.removeEventListener('change', handler);
    }
  }, [state.theme, state.brand, resolveTheme]);

  return {
    ...state,
    setTheme: (theme) => setState((prev) => ({ ...prev, theme })),
    setBrand: (brand) => setState((prev) => ({ ...prev, brand })),
    toggleTheme: () =>
      setState((prev) => ({
        ...prev,
        theme: prev.resolvedTheme === 'light' ? 'dark' : 'light',
      })),
  };
}

async function loadBrandCSS(brand: Brand, theme: 'light' | 'dark'): Promise<void> {
  const id = 'brand-tokens';
  const existing = document.getElementById(id);
  if (existing) existing.remove();

  const link = document.createElement('link');
  link.id = id;
  link.rel = 'stylesheet';
  link.href = `/tokens/${brand}/tokens-${theme}.css`;
  document.head.appendChild(link);
}
```

  pull_request:
    paths:

          if git diff --name-only origin/main | grep -q "tokens/brand-b/"; then

    runs-on: ubuntu-latest

      matrix:
        brand: ${{ fromJson(needs.detect-changes.outputs.brands) }}

      - uses: actions/checkout@v4

          fetch-depth: 0

            });

import { createContext, forwardRef, useContext, type HTMLAttributes } from 'react';
import { cn } from '@/lib/utils';

interface CardContextValue {
  variant: 'elevated' | 'outlined' | 'filled';
}

const CardContext = createContext<CardContextValue>({ variant: 'elevated' });

const useCardContext = () => useContext(CardContext);

// Root
interface CardProps extends HTMLAttributes<HTMLDivElement> {
  variant?: CardContextValue['variant'];
}

const Card = forwardRef<HTMLDivElement, CardProps>(
  ({ className, variant = 'elevated', children, ...props }, ref) => {
    const variantStyles = {
      elevated: 'bg-card text-card-foreground shadow-md',
      outlined: 'border border-border bg-transparent',
      filled: 'bg-muted text-muted-foreground',
    };

    return (
      <CardContext.Provider value={{ variant }}>
        <div ref={ref} className={cn('rounded-xl p-6', variantStyles[variant], className)} {...props}>
          {children}
        </div>
      </CardContext.Provider>
    );
  },
);
Card.displayName = 'Card';

const CardHeader = forwardRef<HTMLDivElement, HTMLAttributes<HTMLDivElement>>(
