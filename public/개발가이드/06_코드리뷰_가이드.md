## 1. 코드리뷰 원칙

### 1.1 리뷰의 목표

1. **품질 보증**: 버그, 보안 취약점, 성능 문제 사전 탐지
2. **지식 공유**: 팀 전체의 코드 이해도 향상
3. **일관성 유지**: 코딩 표준 및 아키텍처 패턴 준수
4. **성장**: 리뷰어와 작성자 모두의 역량 향상

### 1.2 리뷰 에티켓

| 역할 | 해야 할 것 | 하지 말아야 할 것 |
|------|------------|-------------------|
| 리뷰어 | 구체적 개선안 제시, 칭찬 포함, 질문 형태 피드백 | 인신공격, 모호한 "이상함", 취향 강요 |
| 작성자 | 변경 의도 설명, 리뷰 코멘트 24시간 내 응답 | 방어적 태도, 리뷰 무시, 과도하게 큰 PR |

### 1.3 PR 크기 가이드라인

| 크기 | 변경 라인 수 | 리뷰 시간 목표 | 권장 |
|------|-------------|----------------|------|
| XS | ~50줄 | 10분 이내 | 최적 |
| S | ~200줄 | 30분 이내 | 권장 |
| M | ~400줄 | 1시간 이내 | 허용 |
| L | ~800줄 | 분할 권장 | 주의 |
| XL | 800줄+ | 반드시 분할 | 금지 |

## 2. AI 리뷰 파이프라인 2.0

### 2.1 3단계 리뷰 아키텍처

```
PR 생성 -> [1단계: 자동] -> [2단계: 심화] -> [3단계: 아키텍처] -> Merge
              CodeRabbit       Copilot          Claude
              (즉시)           (5분 이내)       (요청 시)
```

| 단계 | 도구 | 범위 | 트리거 |
|------|------|------|--------|
| 1단계 자동 | CodeRabbit | 스타일, 버그 패턴, 보안 기본, 복잡도 | PR 생성 시 자동 |
| 2단계 심화 | GitHub Copilot | 로직 검증, 테스트 커버리지 분석, 성능 | 1단계 통과 후 자동 |
| 3단계 아키텍처 | Claude | 설계 적합성, 대안 제시, RFC 준수 여부 | 라벨 `needs-arch-review` 또는 수동 |

### 2.2 AI 리뷰 파이프라인 구현

```typescript
// ai-review-pipeline.ts
interface ReviewStage {
  name: string;
  tool: 'coderabbit' | 'copilot' | 'claude';
  trigger: 'auto' | 'manual' | 'label';
  timeout: number;
  requiredForMerge: boolean;
}

interface PipelineConfig {
  stages: ReviewStage[];
  skipConditions: Array<{
    filePatterns: string[];
    reason: string;
  }>;
  escalationRules: Array<{
    condition: string;
    escalateTo: string;
  }>;
}

const REVIEW_PIPELINE: PipelineConfig = {
  stages: [
    {
      name: '자동 린트/보안 검사',
      tool: 'coderabbit',
      trigger: 'auto',
      timeout: 120_000,
      requiredForMerge: true,
    },
    {
      name: '심화 로직 분석',
      tool: 'copilot',
      trigger: 'auto',
      timeout: 300_000,
      requiredForMerge: true,
    },
    {
      name: '아키텍처 리뷰',
      tool: 'claude',
      trigger: 'label',
      timeout: 600_000,
      requiredForMerge: false,
    },
  ],
  skipConditions: [
    {
      filePatterns: ['**/*.md', '**/*.json', '**/package.json'],
      reason: '문서/설정 파일만 변경된 PR은 1단계만 실행',
    },
    {
      filePatterns: ['**/*.lock'],
      reason: '락파일 변경은 AI 리뷰 스킵',
    },
  ],
  escalationRules: [
    {
      condition: 'security 관련 파일 변경 시',
      escalateTo: 'security-team',
    },
    {
      condition: 'DB 마이그레이션 포함 시',
      escalateTo: 'dba-team',
    },
    {
      condition: '공개 API 변경 시',
      escalateTo: 'api-team',
    },
  ],
};

interface AiReviewComment {
  path: string;
  line: number;
  severity: 'critical' | 'suggestion' | 'nitpick' | 'praise';
  body: string;
  stage: string;
  tool: string;
  confidence: number;
}

async function runReviewPipeline(
  prNumber: number,
  changedFiles: string[],
  config: PipelineConfig,
): Promise<AiReviewComment[]> {
  const allComments: AiReviewComment[] = [];

  const shouldSkipStages = evaluateSkipConditions(changedFiles, config.skipConditions);

  for (const stage of config.stages) {
    if (shouldSkipStages.includes(stage.name)) {
      continue;
    }

    if (stage.trigger === 'label') {
      const hasLabel = await checkPrLabel(prNumber, 'needs-arch-review');
      if (!hasLabel) continue;
    }

    const comments = await executeStage(stage, prNumber, changedFiles);
    allComments.push(...comments);

    const hasCritical = comments.some((c) => c.severity === 'critical');
    if (hasCritical) {
      await applyEscalationRules(prNumber, comments, config.escalationRules);
    }
  }

  return allComments;
}

function evaluateSkipConditions(
  changedFiles: string[],
  conditions: PipelineConfig['skipConditions'],
): string[] {
  const skipped: string[] = [];

  for (const condition of conditions) {
    const allMatch = changedFiles.every((file) =>
      condition.filePatterns.some((pattern) => matchGlob(file, pattern)),
    );
    if (allMatch) {
      skipped.push(condition.reason);
    }
  }

  return skipped;
}
```

### 2.3 GitHub Actions: AI 리뷰 워크플로우

```yaml
# .github/workflows/ai-review.yml
name: AI Review Pipeline
on:
  pull_request:
    types: [opened, synchronize, labeled]

permissions:
  pull-requests: write
  contents: read

jobs:
  stage-1-auto:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: CodeRabbit Auto Review
        uses: coderabbitai/ai-pr-reviewer@v3
        with:
          review_level: detailed
          language: ko

  stage-2-deep:
    needs: stage-1-auto
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Copilot Deep Analysis
        uses: github/copilot-review@v2
        with:
          analysis_depth: deep
          include_test_coverage: true

  stage-3-architecture:
    if: contains(github.event.pull_request.labels.*.name, 'needs-arch-review')
    needs: stage-2-deep
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Claude Architecture Review
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          npx tsx scripts/claude-arch-review.ts \
            --pr=${{ github.event.pull_request.number }} \
            --depth=architecture
```

## 4. Stacked PRs 2.0 (Graphite CLI)

### 4.1 Stacked PRs 개요

대규모 변경을 논리적 단위로 분할하여 순차적으로 리뷰한다. 각 PR은 이전 PR에 의존하며, Graphite CLI로 스택을 관리한다.

```
main
  +-- feature/auth-types        (PR #1: 타입 정의)
       +-- feature/auth-api     (PR #2: API 레이어)
            +-- feature/auth-ui (PR #3: UI 컴포넌트)
```

### 4.2 Graphite CLI 핵심 명령어

```bash
# 스택 생성
gt branch create feature/auth-types    # 첫 번째 브랜치
# ... 작업 후 커밋
gt branch create feature/auth-api      # 두 번째 브랜치 (자동으로 위에 쌓임)
# ... 작업 후 커밋
gt branch create feature/auth-ui       # 세 번째 브랜치

# 스택 전체 확인
gt log                                 # 현재 스택의 모든 브랜치와 커밋 시각화
gt log --all                           # 모든 스택 확인

# 스택 전체 PR 제출
gt stack submit                        # 스택의 모든 브랜치를 PR로 제출
gt stack submit --draft                # 드래프트로 제출
gt stack submit --reviewers="user1"    # 리뷰어 지정

# 스택 중간 브랜치 수정 후 리베이스
gt branch checkout feature/auth-api    # 중간 브랜치로 이동
# ... 수정 후 커밋
gt stack restack                       # 이후 브랜치들 자동 리베이스

# 스택 네비게이션
gt branch up                           # 스택에서 위로 이동
gt branch down                         # 스택에서 아래로 이동
gt branch top                          # 스택 최상단으로 이동
gt branch bottom                       # 스택 최하단으로 이동

# 머지 후 정리
gt repo sync                           # main pull + 머지된 브랜치 정리
```

### 4.3 스택 리뷰 전략

```typescript
// stacked-pr-review-strategy.ts
interface StackReviewStrategy {
  stackSize: number;
  reviewOrder: 'bottom-up' | 'top-down' | 'parallel';
  perPrPolicy: {
    maxChangedLines: number;
    requiredApprovals: number;
    mergeOrder: 'sequential' | 'batch';
  };
}

const STACK_REVIEW_STRATEGIES: Record<string, StackReviewStrategy> = {
  small: {
    stackSize: 3,
    reviewOrder: 'bottom-up',
    perPrPolicy: {
      maxChangedLines: 300,
      requiredApprovals: 1,
      mergeOrder: 'sequential',
    },
  },
  large: {
    stackSize: 10,
    reviewOrder: 'bottom-up',
    perPrPolicy: {
      maxChangedLines: 200,
      requiredApprovals: 1,
      mergeOrder: 'sequential',
    },
  },
};

// 스택 리뷰 가이드라인:
// 1. 항상 bottom-up으로 리뷰 (기반 PR부터)
// 2. 각 PR은 독립적으로 이해 가능해야 함
// 3. 각 PR의 커밋 메시지가 해당 PR의 목적을 명확히 설명
// 4. 기반 PR이 승인되어야 다음 PR 리뷰 시작
// 5. 중간 PR 수정 시 gt stack restack으로 상위 브랜치 자동 업데이트

interface StackPrTemplate {
  title: string;
  body: string;
}

function generateStackPrDescription(
  stackPosition: number,
  totalInStack: number,
  branchName: string,
  dependsOn?: number,
): StackPrTemplate {
  return {
    title: `[${stackPosition}/${totalInStack}] ${branchName}`,
    body: `## Stack Info
- **Position**: ${stackPosition} of ${totalInStack}
- **Depends on**: ${dependsOn ? `#${dependsOn}` : 'main'}
- **Review order**: 이 PR은 ${dependsOn ? `#${dependsOn} 승인 후` : '바로'} 리뷰해주세요.

---

## Changes
(변경 내용 기술)

## Context
이 PR은 스택의 일부입니다. 전체 스택 구조:
\`gt log\` 명령으로 확인하세요.`,
  };
}
```

## 5. 멀티 베타 환경별 리뷰 정책

### 5.1 환경별 리뷰 정책 매트릭스

| 환경 | AI 리뷰 | 사람 리뷰 | 필수 승인 수 | 자동 머지 |
|------|---------|-----------|-------------|-----------|
| Preview | 자동 AI만 (1-2단계) | 불필요 | 0 | 가능 |
| Staging | 자동 AI + 수동 | 팀원 1명 | 1 | 조건부 |
| Production | 자동 AI 전체 | 팀원 2명 + 테크리드 | 2+ | 불가 |

### 5.2 PR별 Preview URL 자동 포함

```typescript
// preview-url-commenter.ts
interface PreviewDeployment {
  prNumber: number;
  url: string;
  environment: string;
  status: 'deploying' | 'ready' | 'failed';
  deployedAt: string;
  expiresAt: string;
  commitSha: string;
}

async function postPreviewComment(
  prNumber: number,
  deployment: PreviewDeployment,
): Promise<void> {
  const statusLabel: Record<PreviewDeployment['status'], string> = {
    deploying: '[Deploying]',
    ready: '[Ready]',
    failed: '[Failed]',
  };

  const comment = `## Preview Deployment ${statusLabel[deployment.status]}

| 항목 | 값 |
|------|-----|
| **URL** | [${deployment.url}](${deployment.url}) |
| **환경** | ${deployment.environment} |
| **커밋** | \`${deployment.commitSha.slice(0, 7)}\` |
| **배포 시간** | ${deployment.deployedAt} |
| **만료 예정** | ${deployment.expiresAt} |

### 확인 사항
- [ ] 주요 기능 동작 확인
- [ ] 반응형 레이아웃 확인
- [ ] 에러 상태 확인
- [ ] 접근성 확인 (키보드 탐색, 스크린리더)

> 이 환경은 ${deployment.expiresAt}에 자동 만료됩니다.`;

  await updateOrCreateComment(prNumber, 'preview-deployment', comment);
}

async function updateOrCreateComment(
  prNumber: number,
  identifier: string,
  body: string,
): Promise<void> {
  const existingComments = await listPrComments(prNumber);
  const existing = existingComments.find((c) =>
    c.body.includes(`<!-- ${identifier} -->`),
  );

  const taggedBody = `<!-- ${identifier} -->\n${body}`;

  if (existing) {
    await updateComment(existing.id, taggedBody);
  } else {
    await createComment(prNumber, taggedBody);
  }
}
```

### 5.3 GitHub Actions: Preview URL 자동 코멘트

```yaml
# .github/workflows/preview-comment.yml
name: Preview Deployment Comment
on:
  deployment_status:

jobs:
  comment:
    if: github.event.deployment_status.state == 'success'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Find PR number
        id: find-pr
        run: |
          PR=$(gh pr list --head "${{ github.event.deployment.ref }}" --json number -q '.[0].number')
          echo "pr_number=$PR" >> $GITHUB_OUTPUT
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Post preview URL
        if: steps.find-pr.outputs.pr_number
        uses: actions/github-script@v7
        with:
          script: |
            const prNumber = ${{ steps.find-pr.outputs.pr_number }};
            const url = '${{ github.event.deployment_status.environment_url }}';
            const sha = '${{ github.event.deployment.sha }}'.slice(0, 7);
            const identifier = '<!-- preview-deployment -->';

            const { data: comments } = await github.rest.issues.listComments({
              owner: context.repo.owner,
              repo: context.repo.repo,
              issue_number: prNumber,
            });

            const existing = comments.find(c => c.body.includes(identifier));

            const body = `${identifier}
            ## Preview Deployment [Ready]

            | 항목 | 값 |
            |------|-----|
            | **URL** | [${url}](${url}) |
            | **커밋** | \`${sha}\` |
            | **배포 시간** | ${new Date().toISOString()} |

            ### 확인 사항
            - [ ] 주요 기능 동작 확인
            - [ ] 반응형 레이아웃 확인
            - [ ] 에러 상태 확인`;

            if (existing) {
              await github.rest.issues.updateComment({
                owner: context.repo.owner,
                repo: context.repo.repo,
                comment_id: existing.id,
                body,
              });
            } else {
              await github.rest.issues.createComment({
                owner: context.repo.owner,
                repo: context.repo.repo,
                issue_number: prNumber,
                body,
              });
            }
```

```typescript
      'lighthouse',
      'bundle-size',
      'accessibility',
    ],
  },
];

function getReviewPolicy(
  targetBranch: string,
): EnvironmentReviewPolicy {
  if (targetBranch === 'main' || targetBranch === 'production') {
    return ENVIRONMENT_POLICIES.find((p) => p.environment === 'production')!;
  }
  if (targetBranch.startsWith('staging') || targetBranch === 'develop') {
    return ENVIRONMENT_POLICIES.find((p) => p.environment === 'staging')!;
  }
  return ENVIRONMENT_POLICIES.find((p) => p.environment === 'preview')!;
}

function validateMergeReadiness(
  policy: EnvironmentReviewPolicy,
  prStatus: {
    aiReviewPassed: boolean;
    ciPassed: boolean;
    approvalCount: number;
    codeOwnerApproved: boolean;
    requiredTeamApprovals: Record<string, boolean>;
  },
): { canMerge: boolean; blockers: string[] } {
  const blockers: string[] = [];

  if (policy.aiReview.blockOnFailure && !prStatus.aiReviewPassed) {
    blockers.push('AI 리뷰를 통과하지 못했습니다.');
  }

  if (!prStatus.ciPassed) {
    blockers.push('CI 검사가 실패했습니다.');
  }

  if (policy.humanReview.required && prStatus.approvalCount < policy.humanReview.minApprovals) {
    blockers.push(
      `승인 ${prStatus.approvalCount}/${policy.humanReview.minApprovals}명 (부족)`,
    );
  }

  if (policy.humanReview.requireCodeOwner && !prStatus.codeOwnerApproved) {
    blockers.push('코드 오너의 승인이 필요합니다.');
  }

  for (const team of policy.humanReview.requiredTeams) {
    if (!prStatus.requiredTeamApprovals[team]) {
      blockers.push(`${team} 팀의 승인이 필요합니다.`);
    }
  }

  return {
    canMerge: blockers.length === 0,
    blockers,
  };
}
```

```typescript
// review-metrics-collector.ts
interface ReviewMetrics {
  period: { start: string; end: string };
  pullRequests: {
    total: number;
    merged: number;
    closed: number;
    open: number;
    averageSize: number;
  };
  reviewTimes: {
    timeToFirstReview: number;       // 분
    timeToApproval: number;          // 분
    timeToMerge: number;             // 분 (DORA Lead Time 구성 요소)
    reviewCycleCount: number;        // 리뷰 라운드 수 평균
  };
  participants: {
    activeReviewers: number;
    averageReviewsPerPerson: number;
    reviewDistribution: Record<string, number>;
  };
  aiMetrics: {
    aiCommentsTotal: number;
    aiCommentsAccepted: number;
    aiCommentsDismissed: number;
    aiFalsePositiveRate: number;
    timeSavedByAiMinutes: number;
  };
  quality: {
    postMergeDefects: number;
    revertRate: number;
    hotfixCount: number;
  };
}

interface GitHubPrData {
  number: number;
  createdAt: string;
  mergedAt: string | null;
  closedAt: string | null;
  additions: number;
  deletions: number;
  reviews: Array<{
    author: string;
    submittedAt: string;
    state: 'APPROVED' | 'CHANGES_REQUESTED' | 'COMMENTED';
  }>;
  comments: Array<{
    author: string;
    createdAt: string;
    isBot: boolean;
    body: string;
  }>;
}

async function collectReviewMetrics(
  owner: string,
  repo: string,
  startDate: string,
  endDate: string,
): Promise<ReviewMetrics> {
  const prs = await fetchPullRequests(owner, repo, startDate, endDate);

  const merged = prs.filter((pr) => pr.mergedAt !== null);
  const closed = prs.filter((pr) => pr.closedAt !== null && pr.mergedAt === null);

  const reviewTimes = calculateReviewTimes(merged);
  const participants = calculateParticipantStats(prs);
  const aiMetrics = calculateAiMetrics(prs);

  return {
    period: { start: startDate, end: endDate },
    pullRequests: {
      total: prs.length,
      merged: merged.length,
      closed: closed.length,
      open: prs.length - merged.length - closed.length,
      averageSize: calculateAverageSize(prs),
    },
    reviewTimes,
    participants,
    aiMetrics,
    quality: await calculateQualityMetrics(owner, repo, startDate, endDate),
  };
}

function calculateReviewTimes(
  mergedPrs: GitHubPrData[],
): ReviewMetrics['reviewTimes'] {
  const firstReviewTimes: number[] = [];
  const approvalTimes: number[] = [];
  const mergeTimes: number[] = [];
  const cycleCounts: number[] = [];

  for (const pr of mergedPrs) {
    const created = new Date(pr.createdAt).getTime();
    const merged = new Date(pr.mergedAt!).getTime();

    // 첫 리뷰까지 시간
    const humanReviews = pr.reviews.filter(
      (r) => !pr.comments.some((c) => c.isBot && c.author === r.author),
    );
    if (humanReviews.length > 0) {
      const firstReview = new Date(humanReviews[0].submittedAt).getTime();
      firstReviewTimes.push((firstReview - created) / 60_000);
    }

    // 승인까지 시간
    const approvals = pr.reviews.filter((r) => r.state === 'APPROVED');
    if (approvals.length > 0) {
      const firstApproval = new Date(approvals[0].submittedAt).getTime();
      approvalTimes.push((firstApproval - created) / 60_000);
    }

    // 머지까지 시간 (DORA Lead Time 구성 요소)
    mergeTimes.push((merged - created) / 60_000);

    // 리뷰 라운드 수
    const changesRequested = pr.reviews.filter(
      (r) => r.state === 'CHANGES_REQUESTED',
    ).length;
    cycleCounts.push(changesRequested + 1);
  }

  return {
    timeToFirstReview: average(firstReviewTimes),
    timeToApproval: average(approvalTimes),
    timeToMerge: average(mergeTimes),
    reviewCycleCount: average(cycleCounts),
  };
}

function calculateAiMetrics(prs: GitHubPrData[]): ReviewMetrics['aiMetrics'] {
  let aiCommentsTotal = 0;
  let aiCommentsAccepted = 0;
  let aiCommentsDismissed = 0;

  for (const pr of prs) {
    const aiComments = pr.comments.filter((c) => c.isBot);
    aiCommentsTotal += aiComments.length;

    for (const comment of aiComments) {
      const wasAddressed = checkIfCommentAddressed(comment, pr);
      if (wasAddressed === 'accepted') aiCommentsAccepted++;
      if (wasAddressed === 'dismissed') aiCommentsDismissed++;
    }
  }

  const total = aiCommentsAccepted + aiCommentsDismissed;
  return {
    aiCommentsTotal,
    aiCommentsAccepted,
    aiCommentsDismissed,
    aiFalsePositiveRate: total > 0 ? aiCommentsDismissed / total : 0,
    timeSavedByAiMinutes: aiCommentsAccepted * 5,
  };
}

function average(values: number[]): number {
  if (values.length === 0) return 0;
  return Math.round(values.reduce((a, b) => a + b, 0) / values.length);
}
```

```typescript
function rateLeadTime(minutes: number): DoraMetrics['leadTimeForChanges']['rating'] {
  const hours = minutes / 60;
  if (hours < 24) return 'elite';
  if (hours < 24 * 7) return 'high';
  if (hours < 24 * 30) return 'medium';
  return 'low';
}

function rateDeploymentFrequency(
  deploymentsPerWeek: number,
): DoraMetrics['deploymentFrequency']['rating'] {
  if (deploymentsPerWeek >= 7) return 'elite';
  if (deploymentsPerWeek >= 1) return 'high';
  if (deploymentsPerWeek >= 0.25) return 'medium';
  return 'low';
}

function rateChangeFailureRate(rate: number): DoraMetrics['changeFailureRate']['rating'] {
  if (rate <= 0.05) return 'elite';
  if (rate <= 0.10) return 'high';
  if (rate <= 0.15) return 'medium';
  return 'low';
}
```
