## 1. 프로젝트 초기 설정 -- i18n 부트스트랩

국제화를 프로젝트에 처음 도입할 때 필요한 디렉토리 구조, 설정 파일, 초기 번역 파일 구성을 다룬다. **처음부터 올바른 구조를 잡아야** 나중에 언어 추가 시 리팩토링 비용이 없다.

### 권장 디렉토리 구조

```
프로젝트 루트/
├── messages/                    # 번역 파일 디렉토리
│   ├── ko.json                  # 소스 언어 (한국어)
│   ├── en.json                  # 영어
│   ├── ja.json                  # 일본어
│   ├── zh.json                  # 중국어 간체
│   ├── ar.json                  # 아랍어
│   └── glossary.json            # 용어집 (번역 일관성 유지)
├── i18n/
│   ├── request.ts               # next-intl 서버 설정
│   ├── routing.ts               # 로케일 라우팅 정의
│   └── navigation.ts            # 로케일 인식 네비게이션 헬퍼
├── app/
│   └── [locale]/                # 로케일별 동적 세그먼트
│       ├── layout.tsx
│       └── page.tsx
├── scripts/
│   ├── ai-translate.ts          # Claude API 자동 번역
│   ├── validate-translations.ts # 번역 누락/불일치 검증
│   └── pseudo-locale.ts         # Pseudo-locale 생성
└── middleware.ts                 # 로케일 감지 및 리다이렉트
```

## 2. AI 번역 QA 시나리오 프롬프트

번역 품질은 텍스트 정확성만이 아니다. **UI에 실제로 렌더링했을 때** 글자 잘림, 레이아웃 깨짐, 컨텍스트 부적합이 없어야 한다. 아래 프롬프트들은 번역 QA의 실전 시나리오를 다룬다.

### 프롬프트 1: 번역이 UI에 맞는지 시각적 검증

```
검증 항목:
1) 버튼 텍스트가 컨테이너 너비를 초과하는지 (max-width 기준)
```

## 3. next-intl 4.0 vs Paraglide.js 비교

2026년 기준 i18n 라이브러리 선택의 핵심 축은 **런타임 vs 컴파일 타임** 접근이다.

### 비교 매트릭스

| 기준 | next-intl 4.0 | Paraglide.js |
|---|---|---|
| **접근 방식** | 런타임 (JSON 로딩) | 컴파일 타임 (함수 생성) |
| **번들 사이즈** | 전체 locale JSON 포함 | 사용된 키만 tree-shake |
| **타입 안전성** | 플러그인 기반 | 네이티브 (함수 시그니처) |
| **Next.js App Router** | 네이티브 지원 | 어댑터 필요 |
| **ICU 메시지 포맷** | 완전 지원 | 부분 지원 |
| **서버 컴포넌트** | 네이티브 | 어댑터 필요 |
| **동적 로케일 전환** | `useLocale` 훅 | 라우팅 기반 |
| **번역 키 자동완성** | VS Code 플러그인 | 네이티브 (import) |
| **러닝 커브** | 낮음 (JSON 기반 직관적) | 중간 (빌드 파이프라인 이해 필요) |
| **커뮤니티/생태계** | 대규모, Next.js 공식 추천 | 성장 중, inlang 생태계 |

### next-intl 4.0 설정

```typescript
// i18n/request.ts -- next-intl 4.0 서버 설정
import { getRequestConfig } from 'next-intl/server';
import { routing } from './routing';

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale;

  // 지원하지 않는 로케일이면 기본값으로 폴백
  if (!locale || !routing.locales.includes(locale as any)) {
    locale = routing.defaultLocale;
  }

  // 동적 import로 번들 분할 -- 요청한 언어만 로딩
  const messages = (await import(`../../messages/${locale}.json`)).default;

  return {
    locale,
    messages,
    timeZone: 'Asia/Seoul',
    now: new Date(),
    formats: {
      dateTime: {
        short: { day: 'numeric', month: 'short', year: 'numeric' },
        long: { day: 'numeric', month: 'long', year: 'numeric', weekday: 'long' },
      },
      number: {
        currency: { style: 'currency', currency: 'KRW' },
        percent: { style: 'percent', minimumFractionDigits: 1 },
      },
    },
  };
});
```

```typescript
// i18n/routing.ts -- 로케일 라우팅 정의
import { defineRouting } from 'next-intl/routing';

export const routing = defineRouting({
  locales: ['ko', 'en', 'ja', 'zh', 'ar'] as const,
  defaultLocale: 'ko',
  localePrefix: 'as-needed', // 기본 로케일(ko)은 URL prefix 없음
  pathnames: {
    '/about': {
      ko: '/소개',
      en: '/about',
      ja: '/紹介',
      zh: '/关于',
      ar: '/حول',
    },
    '/products/[slug]': {
      ko: '/제품/[slug]',
      en: '/products/[slug]',
      ja: '/製品/[slug]',
      zh: '/产品/[slug]',
      ar: '/منتجات/[slug]',
    },
  },
});

export type Locale = (typeof routing.locales)[number];
export type Pathnames = keyof typeof routing.pathnames;
```

### next-intl 클라이언트/서버 컴포넌트 사용

```typescript
// app/[locale]/layout.tsx -- 로케일별 레이아웃
import { NextIntlClientProvider } from 'next-intl';
import { getMessages, getLocale } from 'next-intl/server';
import { notFound } from 'next/navigation';
import { routing } from '@/i18n/routing';

export default async function LocaleLayout({
  children,
  params,
}: {
  children: React.ReactNode;
  params: Promise<{ locale: string }>;
}) {
  const { locale } = await params;

  // 지원하지 않는 로케일이면 404
  if (!routing.locales.includes(locale as any)) {
    notFound();
  }

  // 서버에서 메시지 로딩 -- 클라이언트 컴포넌트에 전달
  const messages = await getMessages();

  return (
    <html lang={locale} dir={locale === 'ar' ? 'rtl' : 'ltr'}>
      <body>
        <NextIntlClientProvider messages={messages}>
          {children}
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```

```typescript
// scripts/ai-translate.ts
import Anthropic from '@anthropic-ai/sdk';
import { readFileSync, writeFileSync } from 'fs';
import { diff } from 'deep-object-diff';

interface TranslationConfig {
  sourceLocale: string;
  targetLocales: string[];
  glossaryPath: string;       // 용어집 경로 -- 브랜드명, 고유명사 보호
  contextPath: string;        // 프로젝트 컨텍스트 파일 경로
  maxBatchSize: number;       // API 호출당 최대 키 수
}

interface TranslationEntry {
  key: string;
  source: string;
  context?: string;           // UI 상의 맥락 설명
  maxLength?: number;         // 글자 수 제한 (버튼 등)
  uiElement?: 'button' | 'label' | 'title' | 'description' | 'placeholder' | 'error' | 'toast';
}

interface TranslationResult {
  key: string;
  locale: string;
  translation: string;
  confidence: number;         // 0~1 범위 -- 0.8 미만이면 수동 리뷰 플래그
  alternatives: string[];     // 대안 번역 목록
  notes: string;              // 번역 시 고려사항
}

const client = new Anthropic();

async function translateBatch(
  entries: TranslationEntry[],
  targetLocale: string,
  glossary: Record<string, Record<string, string>>,
): Promise<TranslationResult[]> {
  const localeNames: Record<string, string> = {
    en: 'English',
    ja: 'Japanese',
    zh: 'Simplified Chinese',
    ar: 'Arabic',
    de: 'German',
    fr: 'French',
    es: 'Spanish',
  };

  // 시스템 프롬프트에 번역 규칙과 용어집을 포함
  const systemPrompt = `You are a professional UI translator for a web application.
Target language: ${localeNames[targetLocale] ?? targetLocale}

Rules:
1. Preserve all ICU message format syntax ({name}, {count, plural, ...}, {gender, select, ...})
2. Never translate brand names, technical terms in the glossary
3. Match the tone: buttons should be concise, descriptions natural
4. Consider maxLength constraints -- abbreviate naturally if needed
5. For Arabic: ensure proper RTL markers for mixed content
6. Return valid JSON array

Glossary: ${JSON.stringify(glossary[targetLocale] ?? {})}`;

  const message = await client.messages.create({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 4096,
    system: systemPrompt,
    messages: [
      {
        role: 'user',
        content: `Translate these UI strings. Return JSON array with keys: key, translation, confidence (0-1), alternatives (array), notes.

${JSON.stringify(entries, null, 2)}`,
      },
    ],
  });

  const content = message.content[0];
  if (content.type !== 'text') throw new Error('Unexpected response type');

  // 응답에서 JSON 배열 추출
  const jsonMatch = content.text.match(/\[[\s\S]*\]/);
  if (!jsonMatch) throw new Error('No JSON array in response');

  return JSON.parse(jsonMatch[0]).map((r: TranslationResult) => ({
    ...r,
    locale: targetLocale,
  }));
}

// 이전 소스와 현재 소스를 비교하여 변경된 키만 추출
function extractChangedKeys(
  prevSource: Record<string, string>,
  currentSource: Record<string, string>,
): string[] {
  const changes = diff(prevSource, currentSource) as Record<string, unknown>;
  return Object.keys(flattenObject(changes));
}

function flattenObject(obj: Record<string, unknown>, prefix = ''): Record<string, string> {
  const result: Record<string, string> = {};
  for (const [key, value] of Object.entries(obj)) {
    const fullKey = prefix ? `${prefix}.${key}` : key;
    if (typeof value === 'object' && value !== null) {
      Object.assign(result, flattenObject(value as Record<string, unknown>, fullKey));
    } else {
      result[fullKey] = String(value);
    }
  }
  return result;
}

// 메인 파이프라인 -- 변경 감지 → 번역 → 파일 업데이트
async function runTranslationPipeline(config: TranslationConfig): Promise<void> {
  const prevSource = JSON.parse(
    readFileSync(`messages/${config.sourceLocale}.prev.json`, 'utf-8'),
  );
  const currentSource = JSON.parse(
    readFileSync(`messages/${config.sourceLocale}.json`, 'utf-8'),
  );
  const glossary = JSON.parse(readFileSync(config.glossaryPath, 'utf-8'));

  const changedKeys = extractChangedKeys(prevSource, currentSource);
  if (changedKeys.length === 0) {
    console.log('No translation changes detected');
    return;
  }

  console.log(`Found ${changedKeys.length} changed keys`);
  const flat = flattenObject(currentSource);
  const entries: TranslationEntry[] = changedKeys.map((key) => ({
    key,
    source: flat[key] ?? '',
  }));

  // 각 대상 언어별로 배치 단위 번역 실행
  for (const locale of config.targetLocales) {
    const results: TranslationResult[] = [];
    for (let i = 0; i < entries.length; i += config.maxBatchSize) {
      const batch = entries.slice(i, i + config.maxBatchSize);
      const batchResults = await translateBatch(batch, locale, glossary);
      results.push(...batchResults);
    }

    // confidence가 0.8 미만인 항목은 수동 리뷰 플래그
    const lowConfidence = results.filter((r) => r.confidence < 0.8);
    if (lowConfidence.length > 0) {
      console.warn(`[${locale}] ${lowConfidence.length} low-confidence translations:`);
      lowConfidence.forEach((r) => {
        console.warn(`  - ${r.key}: "${r.translation}" (${r.confidence}) -- ${r.notes}`);
      });
    }

    // 기존 번역 파일에 새 번역 병합
    const targetPath = `messages/${locale}.json`;
    const existing = JSON.parse(readFileSync(targetPath, 'utf-8'));
    for (const result of results) {
      setNestedValue(existing, result.key, result.translation);
    }
    writeFileSync(targetPath, JSON.stringify(existing, null, 2) + '\n');
    console.log(`Updated ${targetPath} with ${results.length} translations`);
  }

  // 다음 비교를 위해 현재 소스를 prev로 저장
  writeFileSync(
    `messages/${config.sourceLocale}.prev.json`,
    JSON.stringify(currentSource, null, 2) + '\n',
  );
}

function setNestedValue(obj: Record<string, unknown>, path: string, value: string): void {
  const keys = path.split('.');
  let current = obj;
  for (let i = 0; i < keys.length - 1; i++) {
    if (!(keys[i] in current)) current[keys[i]] = {};
    current = current[keys[i]] as Record<string, unknown>;
  }
  current[keys[keys.length - 1]] = value;
}
```

```typescript
// scripts/validate-translations.ts -- 번역 파일 무결성 검증
import { readFileSync, readdirSync } from 'fs';

interface ValidationError {
  locale: string;
  key: string;
  type: 'missing' | 'extra' | 'placeholder_mismatch' | 'icu_syntax_error' | 'empty';
  message: string;
}

function validateTranslations(sourceLocale: string, messagesDir: string): ValidationError[] {
  const errors: ValidationError[] = [];

  // 소스 언어 파일 로딩
  const source = JSON.parse(readFileSync(`${messagesDir}/${sourceLocale}.json`, 'utf-8'));
  const sourceKeys = new Set(Object.keys(flattenObject(source)));

  // 소스 언어의 플레이스홀더 추출
  const sourceFlat = flattenObject(source);
  const placeholderRegex = /\{[^}]+\}/g;

  // 각 대상 언어 파일 검증
  const localeFiles = readdirSync(messagesDir).filter(
    (f) => f.endsWith('.json') && !f.includes('prev') && !f.includes('glossary'),
  );

  for (const file of localeFiles) {
    const locale = file.replace('.json', '');
    if (locale === sourceLocale) continue;

    const target = JSON.parse(readFileSync(`${messagesDir}/${file}`, 'utf-8'));
    const targetFlat = flattenObject(target);
    const targetKeys = new Set(Object.keys(targetFlat));

    // 1) 누락된 키 검출
    for (const key of sourceKeys) {
      if (!targetKeys.has(key)) {
        errors.push({ locale, key, type: 'missing', message: `키가 ${locale}에 없음` });
      }
    }

    // 2) 소스에 없는 잉여 키 검출
    for (const key of targetKeys) {
      if (!sourceKeys.has(key)) {
        errors.push({ locale, key, type: 'extra', message: `소스에 없는 잉여 키` });
      }
    }

    // 3) 플레이스홀더 불일치 검출
    for (const key of sourceKeys) {
      if (!targetKeys.has(key)) continue;
      const sourcePlaceholders = (sourceFlat[key]?.match(placeholderRegex) ?? []).sort();
      const targetPlaceholders = (targetFlat[key]?.match(placeholderRegex) ?? []).sort();
      if (JSON.stringify(sourcePlaceholders) !== JSON.stringify(targetPlaceholders)) {
        errors.push({
          locale,
          key,
          type: 'placeholder_mismatch',
          message: `플레이스홀더 불일치: 소스 ${sourcePlaceholders.join(',')} vs 번역 ${targetPlaceholders.join(',')}`,
        });
      }
    }

    // 4) 빈 값 검출
    for (const [key, value] of Object.entries(targetFlat)) {
      if (value === '' || value === undefined) {
        errors.push({ locale, key, type: 'empty', message: '빈 번역 값' });
      }
    }
  }

  return errors;
}

function flattenObject(obj: Record<string, unknown>, prefix = ''): Record<string, string> {
  const result: Record<string, string> = {};
  for (const [key, value] of Object.entries(obj)) {
    const fullKey = prefix ? `${prefix}.${key}` : key;
    if (typeof value === 'object' && value !== null) {
      Object.assign(result, flattenObject(value as Record<string, unknown>, fullKey));
    } else {
      result[fullKey] = String(value ?? '');
    }
  }
  return result;
}

// 실행
const errors = validateTranslations('ko', './messages');
if (errors.length > 0) {
  console.error(`번역 검증 실패: ${errors.length}개 오류 발견`);
  errors.forEach((e) => console.error(`  [${e.locale}] ${e.type}: ${e.key} -- ${e.message}`));
  process.exit(1);
} else {
  console.log('번역 검증 통과');
}
```

## 5. Pseudo-Localization으로 UI 깨짐 자동 탐지

Pseudo-localization은 번역 없이도 UI 국제화 문제를 조기에 발견하는 기법이다. 문자열을 의도적으로 늘이거나 특수 문자로 치환하여 하드코딩, 글자 잘림, 레이아웃 깨짐을 시각적으로 드러낸다.

> **왜 Pseudo-Localization인가?** 독일어는 영어 대비 평균 30% 길고, 아랍어는 RTL 레이아웃이 필요하다. 모든 언어를 번역하기 전에 pseudo-locale로 시뮬레이션하면 UI 깨짐을 빌드 타임에 잡을 수 있다.

### Pseudo-Locale 생성기

```typescript
// lib/pseudo-locale.ts
type PseudoStrategy = 'accented' | 'elongated' | 'mirrored' | 'enclosed';

interface PseudoConfig {
  strategy: PseudoStrategy;
  elongationFactor: number; // 1.0 = 원본, 1.5 = 50% 길어짐
  prefix: string;           // 문자열 시작 마커
  suffix: string;           // 문자열 종료 마커
  preservePlaceholders: boolean; // ICU 플레이스홀더 보존 여부
}

// 악센트 맵 -- 라틴 문자를 악센트가 있는 유사 문자로 치환
const ACCENTED_MAP: Record<string, string> = {
  a: 'ààà', b: 'ƀ', c: 'ç', d: 'ð', e: 'ééé', f: 'ƒ', g: 'ĝ', h: 'ĥ',
  i: 'ííí', j: 'ĵ', k: 'ķ', l: 'ĺ', m: 'ḿ', n: 'ñ', o: 'óóó', p: 'þ',
  q: 'q', r: 'ŕ', s: 'š', t: 'ţ', u: 'ùùù', v: 'ṽ', w: 'ŵ', x: 'x',
  y: 'ý', z: 'ž',
};

// 미러 맵 -- RTL 시뮬레이션을 위해 문자를 뒤집힌 형태로 치환
const MIRROR_MAP: Record<string, string> = {
  a: '\u0252', b: 'd', c: '\u0254', d: 'b', e: '\u01DD', f: '\u025F',
  g: '\u0183', h: '\u0265', i: '\u0131', j: '\u027E', k: '\u029E', l: 'l',
  m: '\u026F', n: 'u', o: 'o', p: 'q', q: 'p', r: '\u0279', s: 's',
  t: '\u0287', u: 'n', v: '\u028C', w: '\u028D', x: 'x', y: '\u028E', z: 'z',
};

function pseudoLocalize(text: string, config: PseudoConfig): string {
  const placeholderRegex = /\{[^}]+\}/g;
  const placeholders: { index: number; match: string }[] = [];

  // ICU 플레이스홀더 위치 기록 -- 변환 대상에서 제외
  if (config.preservePlaceholders) {
    let match: RegExpExecArray | null;
    while ((match = placeholderRegex.exec(text)) !== null) {
      placeholders.push({ index: match.index, match: match[0] });
    }
  }

  let result = '';
  let skipUntil = -1;

  for (let i = 0; i < text.length; i++) {
    if (i < skipUntil) continue;

    // 플레이스홀더 구간은 원본 그대로 유지
    const placeholder = placeholders.find((p) => p.index === i);
    if (placeholder) {
      result += placeholder.match;
      skipUntil = i + placeholder.match.length;
      continue;
    }

    const char = text[i].toLowerCase();
    const map = config.strategy === 'accented' ? ACCENTED_MAP
      : config.strategy === 'mirrored' ? MIRROR_MAP
      : undefined;

    if (map && map[char]) {
      result += text[i] === text[i].toUpperCase() ? map[char].toUpperCase() : map[char];
    } else {
      result += text[i];
    }
  }

  // 문자열 늘이기 (elongation) -- 긴 언어(독일어, 핀란드어) 시뮬레이션
  if (config.elongationFactor > 1.0) {
    const padding = '~'.repeat(Math.floor(result.length * (config.elongationFactor - 1)));
    result = result + padding;
  }

  return `${config.prefix}${result}${config.suffix}`;
}

// 전체 번역 파일을 pseudo-locale로 변환
function generatePseudoLocale(
  messages: Record<string, unknown>,
  config: PseudoConfig,
): Record<string, unknown> {
  const result: Record<string, unknown> = {};

  for (const [key, value] of Object.entries(messages)) {
    if (typeof value === 'string') {
      result[key] = pseudoLocalize(value, config);
    } else if (typeof value === 'object' && value !== null) {
      result[key] = generatePseudoLocale(value as Record<string, unknown>, config);
    } else {
      result[key] = value;
    }
  }

  return result;
}

// 프리셋 -- 일반적인 테스트 시나리오별 설정
const PSEUDO_PRESETS: Record<string, PseudoConfig> = {
  // 문자열 길이 테스트 (독일어/핀란드어 시뮬레이션)
  longText: {
    strategy: 'accented',
    elongationFactor: 1.5,
    prefix: '[!!',
    suffix: '!!]',
    preservePlaceholders: true,
  },
  // RTL 테스트 (아랍어 시뮬레이션)
  rtl: {
    strategy: 'mirrored',
    elongationFactor: 1.0,
    prefix: '\u202E', // RTL override
    suffix: '\u202C', // Pop directional
    preservePlaceholders: true,
  },
  // 하드코딩 문자열 탐지 (pseudo 처리 안 된 텍스트 = 하드코딩)
  detection: {
    strategy: 'enclosed',
    elongationFactor: 1.0,
    prefix: '[[',
    suffix: ']]',
    preservePlaceholders: true,
  },
};

export { pseudoLocalize, generatePseudoLocale, PSEUDO_PRESETS };
export type { PseudoConfig, PseudoStrategy };
```

```typescript
    variants: [
      { id: 'control', locale: 'ko', key: 'checkout.cta', value: '결제하기', description: '기존 문구' },
      { id: 'variant-a', locale: 'ko', key: 'checkout.cta', value: '지금 구매하기', description: '긴급성 강조' },
      { id: 'variant-b', locale: 'ko', key: 'checkout.cta', value: '주문 완료', description: '완료 지향' },
    ],
    targetEnvironments: ['preview-beta-1', 'preview-beta-2', 'preview-beta-3'],
    metrics: ['cta_click_rate', 'checkout_completion_rate', 'time_to_click'],
    startDate: '2026-03-15',
    endDate: '2026-04-15',
  },
];

function getTranslationOverride(
  key: string,
  locale: string,
  environment: string,
): string | null {
  for (const experiment of experiments) {
    if (experiment.status !== 'active') continue;

    const envIndex = experiment.targetEnvironments.indexOf(environment);
    if (envIndex === -1) continue;

    const matchingVariants = experiment.variants.filter(
      (v) => v.key === key && v.locale === locale,
    );

    if (matchingVariants.length > 0) {
      // 환경 인덱스에 따라 다른 변형 배정
      const variant = matchingVariants[envIndex % matchingVariants.length];
      return variant?.value ?? null;
    }
  }

  return null;
}

export { getTranslationOverride, experiments };
export type { I18nExperiment, TranslationVariant };
```

```typescript
// 단, 시계/재생 등 보편적 아이콘은 미러링하면 안 됨

  const isRTL = locale === 'ar' || locale === 'he';

      <Icon name={name} />
    </span>

}
```

### 로케일별 숫자/날짜 포맷

```typescript
// lib/locale-formatters.ts
type SupportedLocale = 'ko' | 'en' | 'ja' | 'zh' | 'ar' | 'de' | 'fr';

interface FormatterConfig {
  locale: SupportedLocale;
  currency: string;
  timezone: string;
  numberingSystem?: string;  // 아랍어는 아라비아-인도 숫자 사용
  calendar?: string;         // 이슬람력, 일본 연호 등
}

const LOCALE_FORMATTER_CONFIG: Record<SupportedLocale, FormatterConfig> = {
  ko: { locale: 'ko', currency: 'KRW', timezone: 'Asia/Seoul' },
  en: { locale: 'en', currency: 'USD', timezone: 'America/New_York' },
  ja: { locale: 'ja', currency: 'JPY', timezone: 'Asia/Tokyo' },
  zh: { locale: 'zh', currency: 'CNY', timezone: 'Asia/Shanghai' },
  ar: { locale: 'ar', currency: 'SAR', timezone: 'Asia/Riyadh', numberingSystem: 'arab' },
  de: { locale: 'de', currency: 'EUR', timezone: 'Europe/Berlin' },
  fr: { locale: 'fr', currency: 'EUR', timezone: 'Europe/Paris' },
};

function createLocalizedFormatter(locale: SupportedLocale) {
  const config = LOCALE_FORMATTER_CONFIG[locale];
  // numberingSystem이 있으면 Unicode 확장 태그로 로케일에 추가
  const localeTag = config.numberingSystem
    ? `${config.locale}-u-nu-${config.numberingSystem}`
    : config.locale;

  return {
    // 통화 포맷 -- KRW/JPY는 소수점 없이 표시
    currency(amount: number): string {
      return new Intl.NumberFormat(localeTag, {
        style: 'currency',
        currency: config.currency,
        maximumFractionDigits: config.currency === 'KRW' || config.currency === 'JPY' ? 0 : 2,
      }).format(amount);
    },

    // 숫자 포맷 -- 로케일별 천단위 구분자 자동 적용
    number(value: number): string {
      return new Intl.NumberFormat(localeTag).format(value);
    },

    // 날짜 포맷 -- 로케일별 타임존 반영
    date(date: Date, style: 'short' | 'medium' | 'long' = 'medium'): string {
      const options: Intl.DateTimeFormatOptions = {
        timeZone: config.timezone,
        ...(style === 'short' && { day: 'numeric', month: 'numeric', year: '2-digit' }),
        ...(style === 'medium' && { day: 'numeric', month: 'short', year: 'numeric' }),
        ...(style === 'long' && { day: 'numeric', month: 'long', year: 'numeric', weekday: 'long' }),
      };
      return new Intl.DateTimeFormat(localeTag, options).format(date);
    },

    // 상대 시간 포맷 -- "3분 전", "2시간 후" 등
    relativeTime(date: Date): string {
      const rtf = new Intl.RelativeTimeFormat(localeTag, { numeric: 'auto' });
      const diffMs = date.getTime() - Date.now();
      const diffSec = Math.round(diffMs / 1000);
      const diffMin = Math.round(diffSec / 60);
      const diffHour = Math.round(diffMin / 60);
      const diffDay = Math.round(diffHour / 24);

      if (Math.abs(diffSec) < 60) return rtf.format(diffSec, 'second');
      if (Math.abs(diffMin) < 60) return rtf.format(diffMin, 'minute');
      if (Math.abs(diffHour) < 24) return rtf.format(diffHour, 'hour');
      return rtf.format(diffDay, 'day');
    },

    // 목록 포맷 -- "A, B, 그리고 C" 형식
    list(items: string[], type: 'conjunction' | 'disjunction' = 'conjunction'): string {
      return new Intl.ListFormat(localeTag, { type }).format(items);
    },
  };
}

export { createLocalizedFormatter, LOCALE_FORMATTER_CONFIG };
export type { SupportedLocale, FormatterConfig };
```

### 번역 파일 분할 전략

```typescript
// 프로젝트 규모에 따른 파일 분할 전략

// 소규모 (키 500개 미만): 단일 파일
// messages/ko.json

// 중규모 (키 500~2000개): 네임스페이스별 분할
// messages/ko/common.json
// messages/ko/auth.json
// messages/ko/checkout.json

// 대규모 (키 2000개 이상): 네임스페이스 + 기능별 분할
// messages/ko/common/index.json
// messages/ko/auth/login.json
// messages/ko/auth/signup.json
// messages/ko/checkout/cart.json
// messages/ko/checkout/payment.json

// next-intl에서 분할된 파일 로딩
// i18n/request.ts
import { getRequestConfig } from 'next-intl/server';

export default getRequestConfig(async ({ requestLocale }) => {
  const locale = await requestLocale;

  // 여러 파일을 병합하여 하나의 messages 객체로 전달
  const [common, auth, checkout] = await Promise.all([
    import(`../../messages/${locale}/common.json`),
    import(`../../messages/${locale}/auth.json`),
    import(`../../messages/${locale}/checkout.json`),
  ]);

  return {
    locale,
    messages: {
      common: common.default,
      auth: auth.default,
      checkout: checkout.default,
    },
  };
});
```
