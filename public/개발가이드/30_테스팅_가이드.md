## 1. 유닛 & 통합 테스트: Vitest & MSW 2.x

Vite 생태계의 표준인 **Vitest**와 네트워크 수준 모킹인 **MSW 2.x**를 사용하여 빠르고 정확한 테스트 환경을 구축합니다.

### 1.1 MSW 2.x 기반 모킹 전략
실제 네트워크 요청을 가로채어 API 가이드에서 정의한 `Result` 패턴에 맞는 응답을 반환합니다.

```typescript
// mocks/handlers.ts
import { http, HttpResponse } from 'msw';

export const handlers = [
  http.get('/api/user/:id', ({ params }) => {
    return HttpResponse.json({
      id: params.id,
      name: 'AI-Tester',
      role: 'Engineer'
    });
  }),
];
```

### 1.2 Testing Library: 사용자 관점의 테스트
구현 세부 사항(함수 호출 여부 등)이 아닌, 사용자가 화면에서 보는 텍스트와 상호작용을 기반으로 테스트합니다.

## 2. E2E 테스트: Playwright

[40. 인프라 가이드](./40_인프라_및_AWS_CDK_가이드.md)에서 생성된 PR별 독립 Preview URL을 대상으로 실제 브라우저 환경에서 시나리오 테스트를 수행합니다.

*   **자동화**: PR이 생성되면 GitHub Actions가 Preview URL을 생성하고, Playwright가 해당 URL로 접속하여 주요 비즈니스 흐름을 검증합니다.
*   **Visual Regression**: UI의 미세한 픽셀 변화를 감지하여 의도치 않은 레이아웃 깨짐을 방지합니다.

---

## 3. AI 기반 테스팅 완전 자동화

AI(Claude Code)를 활용하여 테스트 코드 작성 시간을 70% 이상 단축합니다.

### 3.1 AI 테스트 생성 프롬프트
> **Prompt**: "아래 `AddToCart` 컴포넌트의 유닛 테스트를 Vitest와 Testing Library로 작성해줘. 특히 재고가 0일 때 버튼이 비활성화되는 케이스와, 네트워크 오류 시 에러 메시지가 표시되는 엣지 케이스를 포함해줘. API 모킹은 MSW를 사용해."

### 3.2 AI 테스트 코드 리뷰
AI는 테스트가 빠진 시나리오를 찾아내거나, 테스트 코드 자체의 가독성을 높이는 조언을 제공합니다.

---

## 4. 고도화된 품질 관리: 뮤테이션 테스팅

단순히 테스트가 실행되는 것을 넘어, 테스트 코드가 실제 버그를 잡아낼 수 있는지 검증합니다.

*   **Stryker Mutator**: 소스 코드를 미세하게 수정(예: `>`를 `<`로 변경)한 후 테스트가 실패하는지 확인합니다. 테스트가 성공한다면, 해당 지점의 테스트가 부족하다는 증거입니다.
